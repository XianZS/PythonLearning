## 模块1：OOP的核心思想与基本术语

在进入实操之前，我们先建立OOP的基本认知，理解其核心思想和关键术语，这是后续学习的基础。

### 1.1 OOP的核心思想

OOP的核心是「**模拟现实世界，抽象事物本质**」。现实世界中的每个事物都有「属性」（比如人的姓名、年龄）和「行为」（比如人的吃饭、跑步），OOP将这种事物抽象为「类」，将具体的某个事物实例化为「对象」，通过类和对象的交互实现程序功能。

对比我们之前接触的「面向过程编程（POP）」：

- 面向过程：以「步骤」为核心，关注「怎么做」，按步骤编写函数实现功能（适合简单小型任务）。

- 面向对象：以「事物」为核心，关注「谁来做」，将事物的属性和行为封装为类，通过对象调用实现功能（适合复杂大型项目）。

举个简单例子：实现「小狗叫」的功能

- 面向过程：定义一个 `dog_bark()` 函数，直接实现叫的逻辑。

- 面向对象：先抽象「狗」类（包含属性：名字、品种；包含行为：叫），再实例化具体的小狗对象，调用「叫」的行为。

### 1.2 OOP的核心基本术语

在Python中，OOP有几个不可替代的核心术语，必须准确理解：

1. **类（Class）**

    - 定义：对一类事物的「抽象描述」，是创建对象的「模板」或「蓝图」。

    - 包含内容：类中定义了该类事物的共同「属性」（数据）和「方法」（行为/功能）。

    - 通俗理解：类就像「汽车设计图纸」，描述了汽车的通用属性（颜色、排量）和通用方法（行驶、刹车），但图纸本身不是可驾驶的汽车。

2. **对象（Object/Instance）**

    - 定义：类的「具体实例」，是具备类中描述的属性和方法的「具体存在」。

    - 通俗理解：对象就像「根据图纸生产的具体某一辆汽车」，有具体的颜色（红色）、排量（2.0T），可以执行行驶、刹车的行为。

3. **属性（Attribute）**

    - 定义：描述事物的「静态特征」，对应程序中的「数据/变量」。

    - 分类：后续会详细区分「类属性」和「实例属性」，前者是类的所有对象共享的属性，后者是单个对象独有的属性。

    - 示例：人的姓名、年龄，汽车的颜色、价格。

4. **方法（Method）**

    - 定义：描述事物的「动态行为」，对应程序中的「函数」（与普通函数的区别是：方法依赖于类或对象存在）。

    - 分类：后续会详细区分「实例方法」、「类方法」和「静态方法」。

    - 示例：人的吃饭、跑步，汽车的行驶、停车。

5. **`OOP`三大核心特性**
- 封装（Encapsulation）：将事物的属性和方法封装在类内部，隐藏实现细节，仅对外提供统一的访问接口。
  
- 继承（Inheritance）：让一个类（子类）可以继承另一个类（父类）的属性和方法，实现代码复用，构建类的层级关系。
  
- 多态（Polymorphism）：同一行为在不同对象上有不同的实现方式，提高代码的灵活性和可扩展性。

## 模块2：`Python`中类与对象的创建和基础使用

这是`OOP`的入门实操，我们将学习如何定义类、实例化对象，以及如何访问对象的属性和方法。

### 2.1 类的定义

在Python中，使用 `class` 关键字定义类，语法格式如下：

```Python

# 语法：class 类名(父类列表): （父类列表可省略，默认继承object类）
class 类名:
    """类的文档字符串（描述类的功能）"""
    # 定义类属性（可选）
    类属性名 = 类属性值
    
    # 定义实例方法（必选，至少包含一个self参数）
    def 实例方法名(self, 参数列表):
        """方法的文档字符串"""
        # 方法体逻辑
        pass
```

**注意事项**：

1. 类名遵循「大驼峰命名法」（每个单词首字母大写，无下划线），如 `Person`、`Dog`、`Car`。

2. `object` 是Python中所有类的「根类」（基类），若类没有显式指定父类，默认继承 `object`。

3. 实例方法的第一个参数必须是 `self`（名称可自定义，但约定俗成使用 `self`），用于指代当前实例对象本身。

### 2.2 对象的实例化

定义类后，通过「类名()」的方式可以实例化对象，语法格式如下：

```Python

# 语法：对象名 = 类名(参数列表)（参数列表对应__init__方法的参数，后续讲解）
对象名 = 类名()
```

### 2.3 实例属性与实例方法的使用

实例属性是单个对象独有的属性，通常在「构造方法 `__init__`」中定义（`__init__` 是类的魔法方法，后续详细讲解），也可以通过「对象.属性名」的方式动态添加。

实例方法通过「对象.方法名()」的方式调用，调用时无需手动传递 `self` 参数，Python会自动将当前对象传入 `self`。

#### 完整代码示例

```Python

# 步骤1：定义一个「Person」类（抽象描述“人”这类事物）
class Person:
    """这是一个描述“人”的类，包含姓名、年龄属性，以及吃饭、跑步方法"""
    
    # 构造方法：初始化对象的实例属性（后续详细讲解，暂时理解为“给对象赋值初始属性”）
    def __init__(self, name, age):
        # 定义实例属性：name（姓名）、age（年龄）（self.属性名 = 赋值）
        self.name = name
        self.age = age
    
    # 定义实例方法：eat（吃饭）
    def eat(self, food):
        print(f"{self.name}今年{self.age}岁，正在吃{food}。")
    
    # 定义实例方法：run（跑步）
    def run(self):
        print(f"{self.name}今年{self.age}岁，正在跑步锻炼身体。")

# 步骤2：实例化具体的对象（创建两个具体的“人”）
person1 = Person("张三", 20)  # 实例化第一个对象：张三
person2 = Person("李四", 25)  # 实例化第二个对象：李四

# 步骤3：访问对象的实例属性（对象.属性名）
print(f"person1的姓名：{person1.name}，年龄：{person1.age}")
print(f"person2的姓名：{person2.name}，年龄：{person2.age}")

# 步骤4：调用对象的实例方法（对象.方法名(参数)）
person1.eat("米饭")
person2.run()

# 步骤5：动态给对象添加实例属性（仅当前对象有效，其他对象无此属性）
person1.gender = "男"
print(f"person1的性别：{person1.gender}")
# print(f"person2的性别：{person2.gender}")  # 报错：person2没有gender属性
```

#### 运行结果

```Plain Text
person1的姓名：张三，年龄：20
person2的姓名：李四，年龄：25
张三今年20岁，正在吃米饭。
李四今年25岁，正在跑步锻炼身体。
person1的性别：男
```

### 2.4 核心关键点：`self` 参数的作用

`self` 是实例方法的第一个默认参数，核心作用有两个：

1. **绑定实例属性**：在类内部，通过 `self.属性名` 定义的属性，是当前实例对象的独有属性，不同对象的属性相互独立。

2. **调用实例方法/属性**：在类内部的其他实例方法中，通过 `self.方法名()` 可以调用当前实例的其他方法，通过 `self.属性名` 可以访问当前实例的属性。

简单理解：`self` 就是「当前对象本身」，在实例化对象后，调用方法时Python会自动将对象传入 `self`，无需手动传递。

## 模块3：OOP三大特性之一——封装（Encapsulation）

### 3.1 封装的核心定义与目的

#### 定义

封装是指将类的「属性」和「方法」隐藏在类内部，不允许外部直接访问或修改，仅通过类提供的「公共接口」（公开方法）来访问和操作内部数据。

#### 核心目的

1. **数据保护**：防止外部随意修改类的内部属性，避免数据被非法篡改，保证数据的安全性和一致性。

2. **隐藏实现细节**：外部只需关注类的公共接口，无需了解内部的实现逻辑，简化外部调用，降低使用成本。

3. **提高可维护性**：后续修改类的内部实现逻辑时，只要保持公共接口不变，就不会影响外部代码的使用。

#### 注意

Python中**没有真正的“私有”机制**，它通过「命名约定」来实现封装效果，而非强制限制访问。

### 3.2 Python中的封装实现方式

#### 方式1：单下划线 `_` （约定俗成的私有，浅度封装）

- 定义：在属性或方法名前加一个下划线 `_`，如 `_name`、`_eat()`。

- 含义：这是一种「编程约定」，告诉其他开发者“该属性/方法是私有或保护的，外部尽量不要直接访问”。

- 实际效果：外部依然可以直接访问和修改，Python不会做任何强制限制，仅起到提示作用。

#### 方式2：双下划线 `__` （名字改写机制，深度封装）

- 定义：在属性或方法名前加两个下划线 `__`，如 `__name`、`__eat()`。

- 含义：这是Python的「名字改写（Name Mangling）」机制，Python会自动将该属性/方法名改写为 `_类名__属性名`（如 `_Person__name`），从而避免外部直接访问。

- 实际效果：外部无法直接通过 `对象.__属性名` 访问，只能通过改写后的名字 `对象._类名__属性名` 访问（不推荐），实现了近似“私有”的效果。

#### 代码示例：封装的实现

```Python

class Person:
    def __init__(self, name, age):
        # 公共属性（外部可直接访问）
        self.id = 1001
        # 浅度封装（单下划线，约定私有）
        self._name = name
        # 深度封装（双下划线，名字改写）
        self.__age = age
    
    # 公共方法（外部可调用，作为访问私有属性的接口）
    def get_info(self):
        return f"姓名：{self._name}，年龄：{self.__age}，ID：{self.id}"
    
    # 浅度封装方法（单下划线）
    def _say_hello(self):
        print(f"你好，我是{self._name}。")
    
    # 深度封装方法（双下划线）
    def __say_age(self):
        print(f"我今年{self.__age}岁了。")

# 实例化对象
p = Person("张三", 20)

# 1. 访问公共属性和方法
print("公共属性id：", p.id)
print("公共方法返回结果：", p.get_info())

# 2. 访问浅度封装属性和方法（可直接访问，不推荐）
print("浅度封装属性_name：", p._name)
p._say_hello()

# 3. 访问深度封装属性和方法（直接访问报错）
# print("深度封装属性__age：", p.__age)  # 报错：AttributeError
# p.__say_age()  # 报错：AttributeError

# 4. 访问改写后的深度封装属性和方法（不推荐）
print("改写后的深度封装属性：", p._Person__age)
p._Person__say_age()
```

#### 运行结果

```Plain Text

公共属性id： 1001
公共方法返回结果： 姓名：张三，年龄：20，ID：1001
浅度封装属性_name： 张三
你好，我是张三。
改写后的深度封装属性： 20
我今年20岁了。
```

### 3.3 优雅的封装：属性访问器与修改器（`@property`）

直接暴露改写后的私有属性不够优雅，Python提供了 `@property` 装饰器，用于将类的方法“伪装”成属性，实现对私有属性的优雅访问和修改，分为「访问器（getter）」和「修改器（setter）」。

#### 核心用法

1. `@property`：定义访问器，用于获取私有属性的值，调用时无需加括号（像访问普通属性一样）。

2. `@属性名.setter`：定义修改器，用于修改私有属性的值，赋值时直接使用「对象.属性名 = 值」。

#### 代码示例：`@property` 实现优雅封装

```Python

class Person:
    def __init__(self, name, age):
        self._name = name  # 私有属性
        self.__age = age   # 深度私有属性
    
    # 1. 定义name的访问器（getter）
    @property
    def name(self):
        return self._name
    
    # 2. 定义name的修改器（setter）（必须先定义访问器，才能定义修改器）
    @name.setter
    def name(self, new_name):
        if isinstance(new_name, str) and len(new_name) > 0:
            self._name = new_name
        else:
            raise ValueError("姓名必须是非空字符串！")
    
    # 3. 定义age的访问器（仅允许获取，不允许修改，无修改器）
    @property
    def age(self):
        return self.__age

# 实例化对象
p = Person("张三", 20)

# 访问属性（调用访问器，无需加括号）
print("姓名：", p.name)
print("年龄：", p.age)

# 修改属性（调用修改器，直接赋值）
p.name = "李四"
print("修改后的姓名：", p.name)

# 尝试修改age（无修改器，报错）
# p.age = 25  # 报错：AttributeError: can't set attribute

# 尝试传入非法姓名（触发修改器的异常）
# p.name = ""  # 报错：ValueError: 姓名必须是非空字符串！
```

#### 运行结果

```Plain Text

姓名： 张三
年龄： 20
修改后的姓名： 李四
```

### 3.4 封装的核心总结

1. 封装的核心是「隐藏细节，暴露接口」，而非完全禁止访问。

2. Python通过「单下划线」和「双下划线」实现封装，其中双下划线的名字改写机制是近似私有方案。

3. `@property` 是优雅的封装方式，实现了私有属性的安全访问和修改，推荐在实际开发中使用。

## 模块4：`OOP`三大特性之二——继承（Inheritance）

### 4.1 继承的核心定义与目的

#### 定义

​	继承是指让一个「子类（派生类）」可以继承另一个「父类（基类/超类）」的所有公共属性和公共方法，子类可以在父类的基础上扩展新的属性和方法，也可以重写父类的方法。

> 角度1：如何实现
>
> 角度2：单继承（继承实现，父类复写）
>
> 角度3：多继承（菱形继承，`mro`机制，`super()`调用）

#### 核心目的

1. **代码复用**：避免重复编写父类已有的属性和方法，提高代码复用率，减少冗余。

2. **构建类的层级关系**：通过继承构建类与类之间的父子关系、层级关系，更符合现实世界的逻辑（如「动物」→「哺乳动物」→「人类」）。

3. **实现扩展**：子类可以在父类的基础上快速扩展新功能，无需修改父类代码（符合开闭原则）。

### 4.2 Python中的继承语法

#### 1. 单继承（一个子类仅继承一个父类）

```Python

# 语法：class 子类名(父类名):
class 父类名:
    # 父类的属性和方法
    pass

class 子类名(父类名):
    # 子类的扩展属性和方法
    pass
```

#### 2. 多继承（一个子类继承多个父类，Python支持，其他语言如Java不支持）

```Python

# 语法：class 子类名(父类1, 父类2, 父类3, ...):
class 子类名(父类1, 父类2):
    # 子类的属性和方法
    pass
```

### 4.3 单继承的实现与扩展

子类继承父类后，会自动拥有父类的所有公共属性和公共方法，同时子类可以：

1. 扩展新的属性和方法。

2. 重写父类的方法（覆盖父类的实现逻辑，满足子类的特有需求）。

3. 通过 `super()` 函数调用父类的方法（保留父类逻辑，同时添加子类逻辑）。

#### 代码示例：单继承的实现

```Python

# 步骤1：定义父类（基类）：Animal（动物）
class Animal:
    def __init__(self, name, color):
        self.name = name
        self.color = color
    
    # 父类的公共方法
    def eat(self):
        print(f"{self.name}（{self.color}）正在吃东西。")
    
    def sleep(self):
        print(f"{self.name}（{self.color}）正在睡觉。")

# 步骤2：定义子类（派生类）：Dog（狗），继承自Animal
class Dog(Animal):
    # 子类的构造方法：扩展新属性（品种）
    def __init__(self, name, color, breed):
        # 调用父类的构造方法，初始化父类的属性（两种方式）
        # 方式1：父类名.__init__(self, 参数)（推荐单继承使用）
        Animal.__init__(self, name, color)
        # 方式2：super().__init__(参数)（推荐多继承使用，后续讲解）
        # super().__init__(name, color)
        
        # 子类扩展的新属性
        self.breed = breed
    
    # 子类扩展的新方法
    def bark(self):
        print(f"{self.name}（{self.breed}，{self.color}）正在汪汪叫。")
    
    # 子类重写父类的eat方法（覆盖父类逻辑）
    def eat(self):
        print(f"{self.name}（{self.breed}）正在啃骨头，吃得很香。")

# 步骤3：实例化子类对象
dog = Dog("旺财", "黄色", "中华田园犬")

# 调用子类扩展的方法
dog.bark()

# 调用重写后的方法（执行子类的逻辑）
dog.eat()

# 调用继承自父类的方法（执行父类的逻辑）
dog.sleep()

# 访问继承自父类的属性和子类扩展的属性
print(f"狗的名字：{dog.name}，颜色：{dog.color}，品种：{dog.breed}")
```

#### 运行结果

```Plain Text

旺财（中华田园犬，黄色）正在汪汪叫。
旺财（中华田园犬）正在啃骨头，吃得很香。
旺财（黄色）正在睡觉。
狗的名字：旺财，颜色：黄色，品种：中华田园犬
```

### 4.4 多继承的实现与方法解析顺序（MRO）

#### 1. 多继承的问题

多继承虽然可以让子类获得多个父类的功能，但也会带来「菱形继承问题」（又称「钻石继承问题」）：当子类的多个父类最终继承自同一个根类时，可能会导致根类的方法被多次调用，出现逻辑混乱。

为了解决这个问题，Python采用了「**方法解析顺序（Method Resolution Order，简称MRO）**」机制，它定义了子类调用方法时的查找顺序，确保每个方法只被调用一次。

#### 2. MRO的核心规则

1. 「子类优先于父类」：子类的方法优先于父类的方法被查找。

2. 「左父类优先于右父类」：多继承中，左边的父类优先于右边的父类被查找。

3. 「深度优先→广度优先」：Python3中采用「C3算法」，本质是「广度优先」，避免菱形继承中的重复调用问题。

4. 可以通过「`类名.__mro__`」或「`类名.mro()`」查看类的MRO顺序。

#### 代码示例：多继承与MRO

```Python

# 定义根类：A
class A:
    def show(self):
        print("我是类A的show方法。")

# 定义类B，继承自A
class B(A):
    def show(self):
        print("我是类B的show方法。")

# 定义类C，继承自A
class C(A):
    def show(self):
        print("我是类C的show方法。")

# 定义类D，多继承自B和C（左B右C）
class D(B, C):
    pass

# 查看类D的MRO顺序
print("类D的MRO顺序：", D.__mro__)

# 实例化类D的对象
d = D()

# 调用show方法（按照MRO顺序查找：D → B → C → A → object）
d.show()
```

#### 运行结果

```Plain Text

类D的MRO顺序： (<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>)
我是类B的show方法。
```

### 4.5 `super()` 函数的核心作用

`super()` 函数的核心作用是「**按照MRO顺序调用父类的方法**」，它不仅可以在单继承中调用父类方法，还可以在多继承中避免重复调用根类方法，解决菱形继承问题。

#### 代码示例：`super()` 函数的使用

```Python

class A:
    def __init__(self):
        print("初始化类A。")

class B(A):
    def __init__(self):
        super().__init__()  # 按照MRO顺序调用父类的__init__方法
        print("初始化类B。")

class C(A):
    def __init__(self):
        super().__init__()  # 按照MRO顺序调用父类的__init__方法
        print("初始化类C。")

class D(B, C):
    def __init__(self):
        super().__init__()  # 按照MRO顺序调用父类的__init__方法
        print("初始化类D。")

# 实例化类D的对象（按照MRO顺序：D → B → C → A）
d = D()
```

#### 运行结果

```Plain Text

初始化类A。
初始化类C。
初始化类B。
初始化类D。
```

### 4.6 继承的核心总结

1. 继承的核心是「代码复用和扩展」，单继承简洁安全，多继承功能强大但需注意MRO顺序。

2. 子类可以重写父类方法，`super()` 函数用于按照MRO顺序调用父类方法。

3. MRO是多继承的核心，通过 `__mro__` 可以查看方法查找顺序，避免逻辑混乱。

## 模块5：`OOP`三大特性之三——多态（`Polymorphism`）

### 5.1 多态的核心定义

​	多态是指「**同一行为（方法），在不同对象上有不同的实现方式**」，即“一个接口，多种实现”。

​	通俗理解：同样的一个「调用动作」，作用在不同的对象上，会产生不同的「执行结果」。比如“叫”这个行为，狗的叫是“汪汪汪”，猫的叫是“喵喵喵”，这就是多态。

### 5.2 多态的实现前提

​	在Python中，实现多态无需像Java那样强制实现接口或继承抽象类，它是一种「动态类型语言」，支持「鸭子类型」（Duck Typing），但多态的实现通常满足两个前提：

1. **继承**：子类继承自父类（非强制，但通常如此，便于构建统一接口）。

2. **方法重写**：子类重写父类的同一方法，实现不同的逻辑。

### 5.3 多态的核心优势

1. **提高代码灵活性**：无需关注对象的具体类型，只需调用统一的方法，即可实现不同的功能。

2. **提高代码可扩展性**：新增子类时，无需修改原有调用代码，只需重写父类方法即可（符合开闭原则）。

3. **简化代码逻辑**：外部调用者只需关注统一接口，无需关注不同对象的具体实现细节。

#### 代码示例：多态的实现

```Python

# 步骤1：定义父类：Animal（动物），定义统一的接口（方法）
class Animal:
    def __init__(self, name):
        self.name = name
    
    # 统一的接口：call（叫）
    def call(self):
        """动物的叫声（父类定义统一接口，具体实现由子类完成）"""
        pass

# 步骤2：定义子类，重写父类的call方法（不同实现）
class Dog(Animal):
    def call(self):
        print(f"{self.name}：汪汪汪！")

class Cat(Animal):
    def call(self):
        print(f"{self.name}：喵喵喵！")

class Duck(Animal):
    def call(self):
        print(f"{self.name}：嘎嘎嘎！")

# 步骤3：定义统一的调用函数（无需关注对象的具体类型）
def animal_call(animal):
    # 调用统一接口，实现多态
    animal.call()

# 步骤4：创建不同的对象，调用统一函数
dog = Dog("旺财")
cat = Cat("咪咪")
duck = Duck("可达鸭")

# 同一调用动作，不同执行结果（多态的体现）
animal_call(dog)
animal_call(cat)
animal_call(duck)
```

#### 运行结果

```Plain Text

旺财：汪汪汪！
咪咪：喵喵喵！
可达鸭：嘎嘎嘎！
```

### 5.4 鸭子类型（Duck Typing）

Python是动态类型语言，支持鸭子类型，其核心思想是：「**一个对象的特性不是由它的类型决定的，而是由它的行为（方法）决定的**」。

通俗理解：“如果一只动物走起来像鸭子、叫起来像鸭子，那么它就是鸭子”。也就是说，只要一个对象拥有某个方法，就可以调用该方法，无需关注它是否继承自某个类。

#### 代码示例：鸭子类型的体现

```Python

# 定义一个“飞机”类，没有继承自Animal，但拥有call方法
class Plane:
    def __init__(self, name):
        self.name = name
    
    def call(self):
        print(f"{self.name}：轰隆隆！")

# 调用统一的animal_call函数（Plane对象没有继承Animal，但拥有call方法，可正常调用）
plane = Plane("波音747")
animal_call(plane)
```

#### 运行结果

```Plain Text
波音747：轰隆隆！
```

### 5.5 多态的核心总结

1. <font color="red">多态的核心是「同一接口，多种实现」，体现了代码的灵活性和可扩展性。</font>

2. Python通过鸭子类型实现多态，无需强制继承，只需对象拥有对应的方法即可。

3. 多态的关键是「统一接口」，外部调用者只需关注接口，无需关注具体实现。

## 模块6：类的特殊成员（魔法方法）

在Python中，以「双下划线开头+双下划线结尾」的方法称为「魔法方法（Magic Method）」，也叫「特殊成员方法」。魔法方法无需手动调用，会在特定场景下自动触发执行，是实现类的特殊功能的核心。

下面讲解常用的核心魔法方法：

### 6.1 构造方法：`__init__(self, ...)`

- 触发时机：实例化对象时自动触发（`类名()` 时）。

- 核心作用：初始化对象的实例属性，为对象赋值初始值。

- 注意事项：无返回值（不能返回非None的值），子类重写时可通过 `super()` 调用父类的 `__init__`。

### 6.2 析构方法：`__del__(self)`

- 触发时机：对象被销毁时自动触发（如程序结束、手动删除对象、对象无引用时）。

- 核心作用：释放对象占用的资源（如文件句柄、数据库连接等）。

- 注意事项：Python的垃圾回收机制会自动回收对象，析构方法的执行时机不确定，不依赖它实现核心业务逻辑。

### 6.3 字符串表示方法：`__str__(self)` 和 `__repr__(self)`

- 触发时机：

    - `__str__`：调用 `print(对象)`、`str(对象)` 时自动触发。

    - `__repr__`：调用 `repr(对象)`、在交互式环境中直接输入对象时自动触发。

- 核心作用：返回对象的友好字符串描述，方便查看对象信息。

- 注意事项：`__str__` 优先于 `__repr__`，若只定义 `__repr__`，`__str__` 会默认调用 `__repr__`。

### 6.4 可调用方法：`__call__(self, ...)`

- 触发时机：将对象当作函数一样调用时自动触发（`对象()` 时）。

- 核心作用：让对象具备函数的行为，可接收参数，返回结果。

- 应用场景：实现可调用对象，简化函数调用逻辑。

### 6.5 相等判断方法：`__eq__(self, other)`

- 触发时机：使用 `==` 比较两个对象时自动触发。

- 核心作用：重写对象的相等判断逻辑，默认比较对象的内存地址，可自定义比较规则。

### 代码示例：常用魔法方法

```Python
class Person:
    # 构造方法：初始化对象
    def __init__(self, name, age):
        self.name = name
        self.age = age
        print(f"构造方法触发：{self.name}对象已创建。")
    
    # 字符串表示方法：__str__（友好输出）
    def __str__(self):
        return f"Person(name='{self.name}', age={self.age})"
    
    # 字符串表示方法：__repr__（开发者模式输出）
    def __repr__(self):
        return f"Person('{self.name}', {self.age})"
    
    # 可调用方法：让对象可以像函数一样被调用
    def __call__(self, message):
        print(f"{self.name}说：{message}")
    
    # 相等判断方法：自定义相等规则（比较姓名和年龄）
    def __eq__(self, other):
        if isinstance(other, Person):
            return self.name == other.name and self.age == other.age
        return False
    
    # 析构方法：销毁对象
    def __del__(self):
        print(f"析构方法触发：{self.name}对象已销毁。")

# 1. 实例化对象（触发__init__）
p1 = Person("张三", 20)
p2 = Person("张三", 20)
p3 = Person("李四", 25)

# 2. 打印对象（触发__str__）
print("打印p1：", p1)

# 3. 调用repr（触发__repr__）
print("repr(p1)：", repr(p1))

# 4. 将对象当作函数调用（触发__call__）
p1("大家好！")

# 5. 比较对象（触发__eq__）
print("p1 == p2：", p1 == p2)
print("p1 == p3：", p1 == p3)

# 6. 手动删除对象（触发__del__）
del p1
```

#### 运行结果

```Plain Text

构造方法触发：张三对象已创建。
构造方法触发：张三对象已创建。
构造方法触发：李四对象已创建。
打印p1： Person(name='张三', age=20)
repr(p1)： Person('张三', 20)
张三说：大家好！
p1 == p2： True
p1 == p3： False
析构方法触发：张三对象已销毁。
析构方法触发：张三对象已销毁。
析构方法触发：李四对象已销毁。
```

## 模块7：类的其他核心知识点

### 7.1 类属性 vs 实例属性

|对比维度|类属性|实例属性|
|---|---|---|
|定义位置|类内部，方法外部|类内部的 `__init__` 方法中（或对象动态添加）|
|访问方式|类.类属性、对象.类属性|对象.实例属性（类无法访问实例属性）|
|共享性|所有对象共享，一个对象修改类属性，其他对象可见|每个对象独有，对象之间的实例属性相互独立|
|内存占用|仅占用一份内存，节省空间|每个对象占用一份内存，对象多时占用空间大|
### 7.2 实例方法 vs 类方法 vs 静态方法

|对比维度|实例方法|类方法|静态方法|
|---|---|---|---|
|装饰器|无（默认）|`@classmethod`|`@staticmethod`|
|默认参数|`self`（指代当前实例对象）|`cls`（指代当前类）|无默认参数|
|访问属性|可访问实例属性和类属性|仅可访问类属性（不可访问实例属性）|不可访问实例属性和类属性（独立于类和实例）|
|调用方式|对象.方法名()、类.方法名(对象)|类.方法名()、对象.方法名()|类.方法名()、对象.方法名()|
|核心作用|操作实例属性，实现对象的特有行为|操作类属性，实现与类相关的功能|实现与类和对象无关的通用功能，提高代码复用|
#### 代码示例：三种方法的区别

```Python

class Person:
    # 类属性
    species = "人类"
    
    # 实例方法
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    # 实例方法
    def show_info(self):
        print(f"实例方法：姓名={self.name}，年龄={self.age}，物种={Person.species}")
    
    # 类方法
    @classmethod
    def change_species(cls, new_species):
        cls.species = new_species
        print(f"类方法：修改物种为{cls.species}")
    
    # 静态方法
    @staticmethod
    def calculate_add(a, b):
        return a + b

# 1. 调用类方法
Person.change_species("智人")

# 2. 实例化对象，调用实例方法
p = Person("张三", 20)
p.show_info()

# 3. 调用静态方法
print("静态方法计算结果：", Person.calculate_add(10, 20))
```

#### 运行结果

```Plain Text

类方法：修改物种为智人
实例方法：姓名=张三，年龄=20，物种=智人
静态方法计算结果： 30
```

### 7.3 抽象类与接口

抽象类是一种「不能被实例化，仅用于被子类继承」的类，它定义了子类必须实现的抽象方法，强制子类遵循统一的接口规范，避免不规范的实现。

Python中通过 `abc` 模块实现抽象类：

1. 导入 `ABC`（抽象基类）和 `abstractmethod`（抽象方法装饰器）。

2. 定义抽象类，继承自 `ABC`。

3. 用 `@abstractmethod` 装饰抽象方法，抽象方法无具体实现（方法体为 `pass` 或 `...`）。

4. 子类必须实现所有抽象方法，否则无法实例化。

#### 代码示例：抽象类的实现

```Python

from abc import ABC, abstractmethod

# 定义抽象类：Shape（形状）
class Shape(ABC):
    # 抽象方法：计算面积
    @abstractmethod
    def calculate_area(self):
        pass
    
    # 抽象方法：计算周长
    @abstractmethod
    def calculate_perimeter(self):
        pass

# 定义子类：Circle（圆形），实现抽象方法
class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def calculate_area(self):
        return 3.14 * self.radius ** 2
    
    def calculate_perimeter(self):
        return 2 * 3.14 * self.radius

# 定义子类：Rectangle（矩形），实现抽象方法
class Rectangle(Shape):
    def __init__(self, length, width):
        self.length = length
        self.width = width
    
    def calculate_area(self):
        return self.length * self.width
    
    def calculate_perimeter(self):
        return 2 * (self.length + self.width)

# 实例化子类（正常实例化）
circle = Circle(5)
rectangle = Rectangle(4, 5)

# 调用实现的方法
print("圆形面积：", circle.calculate_area())
print("矩形周长：", rectangle.calculate_perimeter())

# 尝试实例化抽象类（报错）
# shape = Shape()  # 报错：TypeError: Can't instantiate abstract class Shape with abstract methods calculate_area, calculate_perimeter
```

#### 运行结果

```Plain Text

圆形面积： 78.5
矩形周长： 18
```

## 模块8：OOP的实际应用场景与核心优势总结

### 8.1 OOP的核心优势

1. **高复用性**：通过继承实现代码复用，避免重复编写冗余代码。

2. **高可读性**：类和对象模拟现实世界，代码结构清晰，易于理解和维护。

3. **高可维护性**：封装隐藏了实现细节，修改内部逻辑不影响外部代码，降低维护成本。

4. **高可扩展性**：通过多态和子类扩展，新增功能无需修改原有代码，符合开闭原则。

5. **支持模块化开发**：将复杂系统拆分为多个类和对象，实现模块化开发，便于团队协作。

### 8.2 实际应用场景

1. **大型项目开发**：如电商系统、管理系统，通过类和对象拆分功能模块（用户模块、订单模块、商品模块）。

2. **Python框架开发**：如Django、Flask、TensorFlow，核心都是基于面向对象思想构建的。

3. **数据封装与处理**：如定义数据模型类（用户模型、商品模型），封装数据和数据处理方法。

4. **设计模式实现**：如单例模式、工厂模式、观察者模式，都是基于OOP思想实现的。
