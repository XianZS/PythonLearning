# Python 3.14.0 smtplib标准库完整学习文档

## 一、smtplib核心概念

### 1.1 什么是smtplib
`smtplib`是Python标准库中用于实现SMTP（简单邮件传输协议）客户端的核心模块，提供了发送电子邮件的完整功能。它允许你在Python程序中连接SMTP服务器，进行身份验证，并发送各种格式的电子邮件，包括纯文本、HTML、带附件和内嵌图片的邮件。

Python 3.14.0对`smtplib`进行了重要的安全和功能升级：
- 原生支持TLS 1.3协议，默认使用最安全的加密配置
- 增强了SMTP认证机制的安全性，支持最新的AUTH方法
- 优化了连接池管理，提高了批量发送邮件的性能
- 修复了多个安全漏洞，包括命令注入和证书验证问题
- 提供了更详细的错误信息和调试能力

### 1.2 SMTP协议基础
SMTP（Simple Mail Transfer Protocol）是一个用于发送和转发电子邮件的标准应用层协议，工作在TCP/IP协议栈的应用层，默认使用以下端口：
- **端口25**：未加密的SMTP端口（现在几乎被所有邮件服务商禁用）
- **端口587**：STARTTLS加密端口（推荐使用，先建立明文连接再升级为加密连接）
- **端口465**：SSL/TLS加密端口（隐式加密，连接建立时就使用加密）

SMTP通信的基本流程：
1. 客户端连接SMTP服务器
2. 服务器返回欢迎信息
3. 客户端发送EHLO/HELO命令标识自己
4. 客户端进行身份验证（如果需要）
5. 客户端发送邮件发件人、收件人信息
6. 客户端发送邮件内容
7. 服务器确认接收邮件
8. 客户端断开连接

### 1.3 smtplib与email模块的关系
这两个模块经常配合使用，但职责完全不同：
- **smtplib**：只负责**发送**邮件，处理与SMTP服务器的通信
- **email**：负责**构造和解析**邮件内容，包括邮件头、正文、附件等

**重要提示**：smtplib本身不提供任何邮件内容构造的功能，所有邮件内容都必须使用`email`模块来构建。这是初学者最容易混淆的地方。

### 1.4 smtplib的主要类
smtplib提供了三个核心类来实现SMTP客户端功能：

| 类 | 说明 | 适用场景 |
|----|------|----------|
| `smtplib.SMTP` | 基础SMTP客户端，支持STARTTLS加密 | 大多数现代邮件服务商 |
| `smtplib.SMTP_SSL` | SSL/TLS加密的SMTP客户端 | 需要隐式加密的场景 |
| `smtplib.LMTP` | 本地邮件传输协议客户端 | 本地邮件服务器 |

## 二、smtplib基础部分

### 2.1 发送最简单的纯文本邮件
发送邮件的基本步骤：
1. 导入必要的模块
2. 构造邮件内容
3. 连接SMTP服务器
4. 进行身份验证
5. 发送邮件
6. 关闭连接

**示例：发送纯文本邮件**
```python
import smtplib
from email.mime.text import MIMEText
from email.header import Header

# 1. 配置邮件信息
sender = 'your_email@example.com'
password = 'your_password'  # 注意：大多数邮件服务商需要使用授权码而非登录密码
receiver = 'recipient@example.com'
smtp_server = 'smtp.example.com'
smtp_port = 587

# 2. 构造邮件内容
# MIMEText参数：邮件正文、MIME类型、编码
msg = MIMEText('这是一封使用Python smtplib发送的纯文本邮件。', 'plain', 'utf-8')

# 3. 设置邮件头
msg['From'] = Header(f'发件人 <{sender}>', 'utf-8')
msg['To'] = Header(f'收件人 <{receiver}>', 'utf-8')
msg['Subject'] = Header('Python smtplib测试邮件', 'utf-8')

# 4. 发送邮件
try:
    # 创建SMTP对象并连接服务器
    with smtplib.SMTP(smtp_server, smtp_port, timeout=10) as server:
        # 开启STARTTLS加密
        server.starttls()
        
        # 登录SMTP服务器
        server.login(sender, password)
        
        # 发送邮件
        server.sendmail(sender, receiver, msg.as_string())
        
        print('邮件发送成功！')

except smtplib.SMTPException as e:
    print(f'邮件发送失败: {e}')
```

**重要安全提示**：
- 永远不要在代码中硬编码密码！应该使用环境变量或配置文件
- 大多数主流邮件服务商（QQ邮箱、163邮箱、Gmail）不允许使用登录密码直接登录SMTP服务器，需要在邮箱设置中生成**授权码**

### 2.2 邮件头的详细设置
邮件头包含了邮件的元数据，正确设置邮件头可以提高邮件的送达率，避免被当成垃圾邮件。

**示例：完整的邮件头设置**
```python
import smtplib
from email.mime.text import MIMEText
from email.header import Header
from email.utils import formataddr, formatdate

# 配置信息
sender = 'your_email@example.com'
password = 'your_password'
receivers = ['recipient1@example.com', 'recipient2@example.com']
cc = ['cc@example.com']  # 抄送
bcc = ['bcc@example.com']  # 暗送

# 构造邮件
msg = MIMEText('这是一封带有完整邮件头的测试邮件。', 'plain', 'utf-8')

# 使用formataddr格式化发件人和收件人（推荐）
msg['From'] = formataddr(('发件人名称', sender))
msg['To'] = ', '.join([formataddr(('收件人1', receivers[0])), formataddr(('收件人2', receivers[1]))])
msg['Cc'] = formataddr(('抄送收件人', cc[0]))
# 注意：Bcc不会出现在邮件头中，只在sendmail时指定

# 邮件主题
msg['Subject'] = Header('完整邮件头测试', 'utf-8')

# 其他重要邮件头
msg['Date'] = formatdate(localtime=True)  # 发送日期
msg['Reply-To'] = formataddr(('回复地址', 'reply@example.com'))  # 回复地址
msg['X-Priority'] = '3'  # 优先级（1最高，5最低）
msg['X-Mailer'] = 'Python smtplib 3.14.0'  # 邮件客户端标识

# 发送邮件
try:
    with smtplib.SMTP('smtp.example.com', 587, timeout=10) as server:
        server.starttls()
        server.login(sender, password)
        
        # 所有收件人（包括To、Cc、Bcc）都要在这里指定
        all_recipients = receivers + cc + bcc
        server.sendmail(sender, all_recipients, msg.as_string())
        
        print('邮件发送成功！')

except smtplib.SMTPException as e:
    print(f'邮件发送失败: {e}')
```

### 2.3 发送带附件的邮件
发送带附件的邮件需要使用`MIMEMultipart`类，它可以包含多个部分：正文和附件。

**示例：发送带附件的邮件**
```python
import smtplib
import os
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from email.mime.application import MIMEApplication
from email.header import Header
from email.utils import formataddr

# 配置信息
sender = 'your_email@example.com'
password = 'your_password'
receiver = 'recipient@example.com'

# 创建多部分邮件对象
msg = MIMEMultipart()
msg['From'] = formataddr(('发件人', sender))
msg['To'] = formataddr(('收件人', receiver))
msg['Subject'] = Header('带附件的测试邮件', 'utf-8')

# 添加邮件正文
text_part = MIMEText('这是一封带有附件的测试邮件，请查收。', 'plain', 'utf-8')
msg.attach(text_part)

# 添加附件
def add_attachment(msg, file_path):
    """添加附件到邮件"""
    if not os.path.exists(file_path):
        print(f'文件不存在: {file_path}')
        return False
    
    filename = os.path.basename(file_path)
    
    # 读取文件内容
    with open(file_path, 'rb') as f:
        attachment = MIMEApplication(f.read())
    
    # 设置附件头
    attachment.add_header('Content-Disposition', 'attachment', filename=Header(filename, 'utf-8').encode())
    msg.attach(attachment)
    print(f'添加附件: {filename}')
    return True

# 添加多个附件
add_attachment(msg, 'document.pdf')
add_attachment(msg, 'image.jpg')
add_attachment(msg, 'data.csv')

# 发送邮件
try:
    with smtplib.SMTP('smtp.example.com', 587, timeout=10) as server:
        server.starttls()
        server.login(sender, password)
        server.sendmail(sender, receiver, msg.as_string())
        print('带附件的邮件发送成功！')

except smtplib.SMTPException as e:
    print(f'邮件发送失败: {e}')
```

**注意**：附件文件名必须使用`Header`类进行编码，否则中文文件名会出现乱码。

### 2.4 异常处理
smtplib定义了多个异常类来处理不同类型的SMTP错误，正确的异常处理可以让程序更加健壮。

**示例：完整的异常处理**
```python
import smtplib
import socket
from email.mime.text import MIMEText

try:
    with smtplib.SMTP('smtp.example.com', 587, timeout=10) as server:
        server.starttls()
        server.login('your_email@example.com', 'your_password')
        
        msg = MIMEText('测试邮件内容', 'plain', 'utf-8')
        msg['From'] = 'your_email@example.com'
        msg['To'] = 'recipient@example.com'
        msg['Subject'] = '异常处理测试'
        
        server.sendmail('your_email@example.com', 'recipient@example.com', msg.as_string())

except smtplib.SMTPConnectError:
    print('无法连接到SMTP服务器，请检查服务器地址和端口')
except smtplib.SMTPHeloError:
    print('HELO/EHLO命令失败，服务器拒绝连接')
except smtplib.SMTPAuthenticationError:
    print('身份验证失败，请检查用户名和密码/授权码')
except smtplib.SMTPRecipientsRefused:
    print('所有收件人都被服务器拒绝')
except smtplib.SMTPDataError:
    print('邮件数据发送失败')
except smtplib.SMTPException as e:
    print(f'SMTP错误: {e}')
except socket.timeout:
    print('连接超时')
except ConnectionRefusedError:
    print('连接被拒绝')
except Exception as e:
    print(f'其他错误: {e}')
```

### 3.3 SSL与STARTTLS的区别与使用
smtplib提供了两种加密连接方式，它们的工作原理不同：

| 特性 | STARTTLS（端口587） | SSL/TLS（端口465） |
|------|---------------------|---------------------|
| 连接方式 | 先建立明文连接，再通过STARTTLS命令升级为加密连接 | 连接建立时就使用加密 |
| 标准性 | RFC 3207标准 | 非标准但广泛使用 |
| 推荐度 | 现代邮件服务商推荐 | 兼容性更好 |

**示例：使用SSL/TLS连接**
```python
import smtplib
import ssl
from email.mime.text import MIMEText

# 配置信息
sender = 'your_email@example.com'
password = 'your_password'
receiver = 'recipient@example.com'

# 构造邮件
msg = MIMEText('使用SSL/TLS加密发送的测试邮件。', 'plain', 'utf-8')
msg['From'] = sender
msg['To'] = receiver
msg['Subject'] = 'SSL/TLS测试邮件'

# 使用SMTP_SSL连接
try:
    # 创建安全的SSL上下文（Python 3.14+推荐）
    context = ssl.create_default_context()
    # 强制使用TLS 1.3
    context.minimum_version = ssl.TLSVersion.TLSv1_3
    
    with smtplib.SMTP_SSL('smtp.example.com', 465, context=context, timeout=10) as server:
        server.login(sender, password)
        server.sendmail(sender, receiver, msg.as_string())
        print('SSL/TLS邮件发送成功！')

except smtplib.SMTPException as e:
    print(f'邮件发送失败: {e}')
```

### 3.4 批量发送邮件
批量发送邮件时，应该重用SMTP连接，避免频繁建立和关闭连接，提高效率。

**示例：批量发送个性化邮件**
```python
import smtplib
from email.mime.text import MIMEText
from email.header import Header
from email.utils import formataddr

# 配置信息
sender = 'your_email@example.com'
password = 'your_password'
smtp_server = 'smtp.example.com'
smtp_port = 587

# 收件人列表（包含姓名和邮箱）
recipients = [
    {'name': '张三', 'email': 'zhangsan@example.com'},
    {'name': '李四', 'email': 'lisi@example.com'},
    {'name': '王五', 'email': 'wangwu@example.com'}
]

# 邮件模板
email_template = """
尊敬的{name}：

您好！

这是一封批量发送的个性化测试邮件。

祝您工作顺利！

发件人
"""

# 发送邮件
try:
    # 建立一次连接，发送多封邮件
    with smtplib.SMTP(smtp_server, smtp_port, timeout=10) as server:
        server.starttls()
        server.login(sender, password)
        
        success_count = 0
        fail_count = 0
        
        for recipient in recipients:
            try:
                # 个性化邮件内容
                email_content = email_template.format(name=recipient['name'])
                
                # 构造邮件
                msg = MIMEText(email_content, 'plain', 'utf-8')
                msg['From'] = formataddr(('发件人', sender))
                msg['To'] = formataddr((recipient['name'], recipient['email']))
                msg['Subject'] = Header(f'尊敬的{recipient['name']}，您好！', 'utf-8')
                
                # 发送邮件
                server.sendmail(sender, recipient['email'], msg.as_string())
                print(f'邮件发送成功: {recipient['email']}')
                success_count += 1
                
                # 添加延迟，避免被当成垃圾邮件
                import time
                time.sleep(1)
                
            except Exception as e:
                print(f'邮件发送失败 {recipient['email']}: {e}')
                fail_count += 1
        
        print(f'\n批量发送完成！成功: {success_count}，失败: {fail_count}')

except smtplib.SMTPException as e:
    print(f'连接SMTP服务器失败: {e}')
```

**注意**：
- 批量发送邮件时一定要添加适当的延迟，避免被邮件服务商限制
- 不要一次发送太多邮件，大多数邮件服务商有发送频率限制
- 个性化邮件的送达率远高于完全相同的邮件

## 四、实战案例：系统监控邮件通知器

### 4.1 项目概述
我们将实现一个功能完整的系统监控邮件通知器，支持：
- 监控本地磁盘使用率
- 监控系统CPU使用率
- 监控系统内存使用率
- 当指标超过阈值时发送邮件通知
- 支持HTML格式的告警邮件
- 避免重复发送相同告警
- 详细的日志记录

### 4.2 完整实现代码
```python
import smtplib
import psutil
import time
import logging
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from email.header import Header
from email.utils import formataddr, formatdate

class SystemMonitor:
    def __init__(self, config):
        self.config = config
        self.last_alert_time = {}  # 记录上次告警时间，避免重复发送
        
        # 配置日志
        logging.basicConfig(
            level=logging.INFO,
            format='%(asctime)s - %(levelname)s - %(message)s',
            handlers=[
                logging.FileHandler('system_monitor.log'),
                logging.StreamHandler()
            ]
        )
        self.logger = logging.getLogger(__name__)
    
    def check_disk_usage(self):
        """检查磁盘使用率"""
        disk_usage = psutil.disk_usage('/')
        usage_percent = disk_usage.percent
        self.logger.info(f'磁盘使用率: {usage_percent:.2f}%')
        
        if usage_percent > self.config['disk_threshold']:
            return {
                'type': 'disk',
                'level': 'warning',
                'message': f'磁盘使用率过高: {usage_percent:.2f}%',
                'details': f'总容量: {disk_usage.total / 1024**3:.2f} GB\n'
                           f'已使用: {disk_usage.used / 1024**3:.2f} GB\n'
                           f'可用: {disk_usage.free / 1024**3:.2f} GB'
            }
        return None
    
    def check_cpu_usage(self):
        """检查CPU使用率"""
        cpu_percent = psutil.cpu_percent(interval=1)
        self.logger.info(f'CPU使用率: {cpu_percent:.2f}%')
        
        if cpu_percent > self.config['cpu_threshold']:
            return {
                'type': 'cpu',
                'level': 'warning',
                'message': f'CPU使用率过高: {cpu_percent:.2f}%',
                'details': f'CPU核心数: {psutil.cpu_count()}\n'
                           f'1分钟平均负载: {psutil.getloadavg()[0]:.2f}'
            }
        return None
    
    def check_memory_usage(self):
        """检查内存使用率"""
        memory_usage = psutil.virtual_memory()
        usage_percent = memory_usage.percent
        self.logger.info(f'内存使用率: {usage_percent:.2f}%')
        
        if usage_percent > self.config['memory_threshold']:
            return {
                'type': 'memory',
                'level': 'warning',
                'message': f'内存使用率过高: {usage_percent:.2f}%',
                'details': f'总内存: {memory_usage.total / 1024**3:.2f} GB\n'
                           f'已使用: {memory_usage.used / 1024**3:.2f} GB\n'
                           f'可用: {memory_usage.available / 1024**3:.2f} GB'
            }
        return None
    
    def send_alert_email(self, alerts):
        """发送告警邮件"""
        # 检查是否在冷却时间内
        current_time = time.time()
        alerts_to_send = []
        
        for alert in alerts:
            alert_type = alert['type']
            last_time = self.last_alert_time.get(alert_type, 0)
            
            if current_time - last_time > self.config['alert_cooldown']:
                alerts_to_send.append(alert)
                self.last_alert_time[alert_type] = current_time
        
        if not alerts_to_send:
            self.logger.info('所有告警都在冷却时间内，不发送邮件')
            return
        
        # 构造HTML邮件
        msg = MIMEMultipart()
        msg['From'] = formataddr(('系统监控', self.config['sender_email']))
        msg['To'] = ', '.join([formataddr(('管理员', email)) for email in self.config['admin_emails']])
        msg['Subject'] = Header(f'【系统告警】服务器资源使用率过高', 'utf-8')
        msg['Date'] = formatdate(localtime=True)
        
        # HTML内容
        html_content = f"""
        <html>
        <head>
            <meta charset="UTF-8">
            <title>系统告警通知</title>
            <style>
                body {{ font-family: Arial, sans-serif; line-height: 1.6; color: #333; }}
                .container {{ max-width: 600px; margin: 0 auto; padding: 20px; border: 1px solid #eee; border-radius: 5px; }}
                .header {{ background-color: #f44336; color: white; padding: 10px; text-align: center; border-radius: 5px 5px 0 0; margin: -20px -20px 20px -20px; }}
                .alert {{ margin-bottom: 20px; padding: 15px; border-left: 4px solid #f44336; background-color: #ffebee; }}
                .alert-title {{ font-weight: bold; font-size: 16px; margin-bottom: 10px; }}
                .alert-details {{ white-space: pre-line; font-family: monospace; background-color: #f5f5f5; padding: 10px; border-radius: 3px; }}
                .footer {{ text-align: center; margin-top: 20px; color: #666; font-size: 12px; }}
            </style>
        </head>
        <body>
            <div class="container">
                <div class="header">
                    <h1>系统告警通知</h1>
                </div>
                <p>尊敬的管理员：</p>
                <p>服务器检测到以下资源使用率超过阈值，请及时处理：</p>
        """
        
        for alert in alerts_to_send:
            html_content += f"""
                <div class="alert">
                    <div class="alert-title">{alert['message']}</div>
                    <div class="alert-details">{alert['details']}</div>
                </div>
            """
        
        html_content += """
                <p>本邮件由系统自动发送，请勿回复。</p>
                <div class="footer">
                    <p>Python系统监控工具 v1.0</p>
                </div>
            </div>
        </body>
        </html>
        """
        
        # 添加HTML部分
        html_part = MIMEText(html_content, 'html', 'utf-8')
        msg.attach(html_part)
        
        # 发送邮件
        try:
            with smtplib.SMTP(self.config['smtp_server'], self.config['smtp_port'], timeout=10) as server:
                server.starttls()
                server.login(self.config['sender_email'], self.config['sender_password'])
                
                server.sendmail(
                    self.config['sender_email'],
                    self.config['admin_emails'],
                    msg.as_string()
                )
            
            self.logger.info(f'告警邮件发送成功，包含 {len(alerts_to_send)} 个告警')
        
        except smtplib.SMTPException as e:
            self.logger.error(f'告警邮件发送失败: {e}')
    
    def run(self):
        """运行监控"""
        self.logger.info('系统监控已启动')
        self.logger.info(f'监控阈值: 磁盘={self.config['disk_threshold']}%, CPU={self.config['cpu_threshold']}%, 内存={self.config['memory_threshold']}%')
        self.logger.info(f'检查间隔: {self.config['check_interval']}秒')
        self.logger.info(f'告警冷却时间: {self.config['alert_cooldown']}秒')
        
        try:
            while True:
                # 检查系统状态
                alerts = []
                
                disk_alert = self.check_disk_usage()
                if disk_alert:
                    alerts.append(disk_alert)
                
                cpu_alert = self.check_cpu_usage()
                if cpu_alert:
                    alerts.append(cpu_alert)
                
                memory_alert = self.check_memory_usage()
                if memory_alert:
                    alerts.append(memory_alert)
                
                # 如果有告警，发送邮件
                if alerts:
                    self.send_alert_email(alerts)
                
                # 等待下一次检查
                time.sleep(self.config['check_interval'])
        
        except KeyboardInterrupt:
            self.logger.info('系统监控已停止')
        except Exception as e:
            self.logger.error(f'监控过程中发生错误: {e}', exc_info=True)

if __name__ == "__main__":
    # 配置信息
    CONFIG = {
        # SMTP配置
        'smtp_server': 'smtp.example.com',
        'smtp_port': 587,
        'sender_email': 'monitor@example.com',
        'sender_password': 'your_password',
        'admin_emails': ['admin1@example.com', 'admin2@example.com'],
        
        # 监控阈值
        'disk_threshold': 80,  # 磁盘使用率阈值（%）
        'cpu_threshold': 80,   # CPU使用率阈值（%）
        'memory_threshold': 80, # 内存使用率阈值（%）
        
        # 其他配置
        'check_interval': 60,  # 检查间隔（秒）
        'alert_cooldown': 3600  # 告警冷却时间（秒），避免重复发送
    }
    
    # 启动监控
    monitor = SystemMonitor(CONFIG)
    monitor.run()
```

### 4.3 运行说明
1. 安装依赖：`pip install psutil`
2. 修改代码中的`CONFIG`部分，填入你的SMTP服务器信息和管理员邮箱
3. 运行代码，程序会开始监控系统资源
4. 当任何资源使用率超过阈值时，会自动发送HTML格式的告警邮件
5. 告警邮件会包含详细的资源使用信息
6. 程序会记录所有操作到`system_monitor.log`文件

## 五、总结与扩展学习

### 5.1 核心知识点回顾
- `smtplib`是Python标准库中实现SMTP客户端的核心模块，只负责发送邮件
- 邮件内容必须使用`email`模块来构造，包括纯文本、HTML、附件和内嵌图片
- 现代邮件服务商都要求使用加密连接，推荐使用端口587的STARTTLS加密
- 大多数邮件服务商需要使用授权码而非登录密码进行SMTP认证
- 批量发送邮件时应该重用连接并添加适当的延迟，避免被当成垃圾邮件
- 正确的异常处理和调试模式可以帮助快速定位问题

### 5.2 Python 3.14.0 smtplib的新特性
1. **TLS 1.3原生支持**：默认启用TLS 1.3，提供更好的安全性和性能
2. **SSL上下文增强**：支持更灵活的SSL/TLS配置，默认使用最安全的设置
3. **认证机制升级**：支持最新的SMTP认证方法，提高了安全性
4. **错误信息改进**：提供了更详细的错误信息和调试信息
5. **性能优化**：优化了连接管理和数据传输，提高了批量发送的效率

### 5.3 扩展学习方向
- 学习接收邮件：使用`poplib`和`imaplib`模块接收和解析邮件
- 学习第三方邮件服务：使用SendGrid、Mailgun、阿里云邮件推送等服务发送邮件
- 学习邮件安全：了解SPF、DKIM、DMARC等邮件安全技术，提高邮件送达率
- 学习邮件模板：使用Jinja2等模板引擎生成复杂的HTML邮件
- 学习异步邮件发送：使用`aiosmtplib`库实现异步邮件发送
