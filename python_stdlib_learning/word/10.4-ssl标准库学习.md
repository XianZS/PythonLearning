# Python 3.14.0 ssl标准库完整学习文档

## 一、ssl核心概念

### 1.1 什么是ssl标准库
`ssl`是Python标准库中实现**TLS/SSL协议**的核心模块，为网络通信提供加密、身份验证和数据完整性保护。它基于行业标准的OpenSSL库构建，提供了对TLS 1.0到TLS 1.3所有版本的支持，是Python中所有安全网络通信的基础。

Python 3.14.0对`ssl`库进行了重大升级，是迄今为止最安全、性能最好的版本：
- **默认启用TLS 1.3**，并将其作为首选协议
- 优化了TLS 1.3握手过程，连接建立速度提升40%以上
- 增强了证书验证的严格性，默认禁用所有不安全的密码套件
- 修复了多个高危安全漏洞，包括心脏出血漏洞的后续变种
- 提供了更完善的TLS 1.3特性支持，包括0-RTT早期数据
- 改进了错误信息的可读性和调试能力

### 1.2 TLS/SSL协议基础
TLS（传输层安全）是SSL（安全套接层）的继任者，目前SSL 3.0及更早版本已被完全废弃。TLS协议提供三个核心安全服务：

| 服务 | 说明 |
|------|------|
| **加密** | 使用对称加密算法（如AES）加密传输的数据，防止窃听 |
| **身份验证** | 使用非对称加密算法（如RSA、ECDSA）验证通信双方的身份，防止中间人攻击 |
| **数据完整性** | 使用消息认证码（如HMAC-SHA256）验证数据在传输过程中未被篡改 |

TLS通信的基本流程（握手过程）：
1. 客户端发送ClientHello消息，支持的协议版本和密码套件
2. 服务器回复ServerHello消息，选择协议版本和密码套件
3. 服务器发送证书，证明自己的身份
4. 客户端验证服务器证书
5. 双方协商生成会话密钥
6. 使用会话密钥加密后续所有通信

### 1.3 Python ssl库的核心架构
ssl库的核心是`SSLContext`类，它封装了所有TLS/SSL配置选项，包括：
- 支持的协议版本
- 允许的密码套件
- 证书和私钥
- 证书验证策略
- 会话参数

**重要原则**：永远使用`SSLContext`来配置TLS连接，而不是直接使用低级的`wrap_socket()`函数。`SSLContext`提供了安全的默认配置，并能正确处理各种边缘情况。

### 1.4 常见术语解释
- **证书**：由可信第三方（CA）颁发的电子文档，证明某个实体的身份
- **私钥**：与证书配对的秘密密钥，用于解密和签名
- **CA证书**：证书颁发机构的根证书，用于验证其他证书的真实性
- **密码套件**：一组加密算法的组合，包括密钥交换、加密和消息认证算法
- **握手**：TLS连接建立前的协商过程
- **会话**：一次完整的TLS连接，可以复用多个连接

## 二、ssl基础部分

### 2.1 创建安全的默认上下文
`ssl.create_default_context()`是Python推荐的创建SSL上下文的方式，它会自动应用最安全的默认配置：
- 禁用SSLv3、TLS 1.0和TLS 1.1
- 只启用安全的密码套件
- 开启证书验证和主机名验证
- 使用系统默认的CA证书

**示例：创建默认SSL上下文**
```python
import ssl
import socket

# 创建用于客户端的默认上下文（验证服务器证书）
client_context = ssl.create_default_context(ssl.Purpose.SERVER_AUTH)
print("客户端默认上下文配置:")
print(f"支持的最高协议版本: {client_context.maximum_version.name}")
print(f"支持的最低协议版本: {client_context.minimum_version.name}")
print(f"证书验证模式: {client_context.verify_mode.name}")
print(f"是否检查主机名: {client_context.check_hostname}")

# 创建用于服务器的默认上下文（验证客户端证书）
server_context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
print("\n服务器默认上下文配置:")
print(f"支持的最高协议版本: {server_context.maximum_version.name}")
print(f"支持的最低协议版本: {server_context.minimum_version.name}")
```

### 2.2 安全的HTTPS客户端
使用默认上下文创建安全的HTTPS客户端，这是最常用的场景。

**示例：安全的HTTPS客户端**
```python
import ssl
import socket

def https_get(host, path="/"):
    """安全的HTTPS GET请求"""
    # 创建默认SSL上下文
    context = ssl.create_default_context()
    
    # 创建普通socket
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        # 连接服务器
        sock.connect((host, 443))
        
        # 包装成SSL socket
        with context.wrap_socket(sock, server_hostname=host) as ssl_sock:
            print(f"已建立安全连接到 {host}")
            print(f"使用的协议版本: {ssl_sock.version()}")
            print(f"使用的密码套件: {ssl_sock.cipher()[0]}")
            print(f"服务器证书主题: {ssl_sock.getpeercert()['subject']}")
            
            # 发送HTTP请求
            request = f"GET {path} HTTP/1.1\r\nHost: {host}\r\nConnection: close\r\n\r\n"
            ssl_sock.sendall(request.encode('utf-8'))
            
            # 接收响应
            response = b""
            while True:
                data = ssl_sock.recv(4096)
                if not data:
                    break
                response += data
            
            return response.decode('utf-8', errors='replace')

# 使用示例
if __name__ == "__main__":
    response = https_get("www.example.com")
    print("\n响应前500字符:")
    print(response[:500])
```

**重要安全提示**：
- 必须指定`server_hostname`参数，否则主机名验证会失败
- 永远不要禁用证书验证（`verify_mode=CERT_NONE`），除非你完全知道自己在做什么
- 永远不要禁用主机名验证（`check_hostname=False`）

### 2.3 基础SSL服务器
创建一个简单的SSL服务器，需要服务器证书和私钥。

**示例：基础SSL服务器**
```python
import ssl
import socket
import threading

def handle_client(ssl_sock):
    """处理客户端连接"""
    try:
        print(f"客户端已连接: {ssl_sock.getpeername()}")
        print(f"使用的协议版本: {ssl_sock.version()}")
        print(f"使用的密码套件: {ssl_sock.cipher()[0]}")
        
        # 接收数据
        data = ssl_sock.recv(1024)
        print(f"收到数据: {data.decode('utf-8')}")
        
        # 发送响应
        response = "你好，客户端！这是来自SSL服务器的响应。"
        ssl_sock.sendall(response.encode('utf-8'))
    
    except Exception as e:
        print(f"处理客户端时发生错误: {e}")
    finally:
        ssl_sock.close()

def start_ssl_server(host, port, certfile, keyfile):
    """启动SSL服务器"""
    # 创建服务器SSL上下文
    context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
    
    # 加载服务器证书和私钥
    context.load_cert_chain(certfile=certfile, keyfile=keyfile)
    
    # 创建普通socket
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        sock.bind((host, port))
        sock.listen(5)
        
        print(f"SSL服务器已启动，监听 {host}:{port}")
        print("按 Ctrl+C 停止服务器")
        
        try:
            while True:
                client_sock, addr = sock.accept()
                # 包装成SSL socket
                ssl_sock = context.wrap_socket(client_sock, server_side=True)
                # 启动新线程处理客户端
                client_thread = threading.Thread(
                    target=handle_client,
                    args=(ssl_sock,),
                    daemon=True
                )
                client_thread.start()
        
        except KeyboardInterrupt:
            print("\n服务器正在关闭...")

# 使用示例
if __name__ == "__main__":
    # 注意：需要先生成自签名证书用于测试
    # openssl req -x509 -newkey rsa:4096 -keyout server.key -out server.crt -days 365 -nodes
    start_ssl_server(
        host='127.0.0.1',
        port=8443,
        certfile='server.crt',
        keyfile='server.key'
    )
```

### 2.4 证书验证基础
证书验证是TLS安全的核心，它确保你正在与正确的服务器通信，而不是中间人。

**示例：验证服务器证书**
```python
import ssl
import socket

def verify_server_cert(host, port):
    """验证服务器证书"""
    context = ssl.create_default_context()
    
    # 强制开启证书验证和主机名验证
    context.verify_mode = ssl.CERT_REQUIRED
    context.check_hostname = True
    
    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
            with context.wrap_socket(sock, server_hostname=host) as ssl_sock:
                print(f"证书验证成功")
                print(f"证书主题: {ssl_sock.getpeercert()['subject']}")
                print(f"证书颁发者: {ssl_sock.getpeercert()['issuer']}")
                print(f"证书有效期: {ssl_sock.getpeercert()['notBefore']} 到 {ssl_sock.getpeercert()['notAfter']}")
                return True
    
    except ssl.SSLCertVerificationError as e:
        print(f"证书验证失败: {e}")
        return False
    except Exception as e:
        print(f"连接失败: {e}")
        return False

# 测试
if __name__ == "__main__":
    print("验证www.example.com证书:")
    verify_server_cert("www.example.com", 443)
    
    print("\n验证自签名证书（应该失败）:")
    verify_server_cert("127.0.0.1", 8443)
```

### 3.3 客户端身份验证
除了服务器向客户端证明身份外，客户端也可以向服务器证明身份，这称为双向认证。

**示例：带客户端验证的SSL服务器**
```python
import ssl
import socket
import threading

def handle_client_with_auth(ssl_sock):
    """处理带客户端验证的连接"""
    try:
        print(f"客户端已连接: {ssl_sock.getpeername()}")
        
        # 获取客户端证书
        client_cert = ssl_sock.getpeercert()
        if client_cert:
            print(f"客户端证书主题: {client_cert['subject']}")
        else:
            print("客户端未提供证书")
            ssl_sock.close()
            return
        
        # 处理通信
        data = ssl_sock.recv(1024)
        print(f"收到数据: {data.decode('utf-8')}")
        ssl_sock.sendall("认证成功，欢迎访问！".encode('utf-8'))
    
    except Exception as e:
        print(f"处理客户端时发生错误: {e}")
    finally:
        ssl_sock.close()

def start_ssl_server_with_client_auth(host, port, server_cert, server_key, ca_cert):
    """启动带客户端验证的SSL服务器"""
    context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
    context.load_cert_chain(certfile=server_cert, keyfile=server_key)
    
    # 要求客户端提供证书并验证
    context.verify_mode = ssl.CERT_REQUIRED
    # 加载用于验证客户端证书的CA证书
    context.load_verify_locations(cafile=ca_cert)
    
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        sock.bind((host, port))
        sock.listen(5)
        
        print(f"带客户端验证的SSL服务器已启动，监听 {host}:{port}")
        
        try:
            while True:
                client_sock, addr = sock.accept()
                try:
                    ssl_sock = context.wrap_socket(client_sock, server_side=True)
                    client_thread = threading.Thread(
                        target=handle_client_with_auth,
                        args=(ssl_sock,),
                        daemon=True
                    )
                    client_thread.start()
                except ssl.SSLError as e:
                    print(f"SSL握手失败: {e}")
                    client_sock.close()
        
        except KeyboardInterrupt:
            print("\n服务器正在关闭...")

# 使用示例
# start_ssl_server_with_client_auth(
#     host='127.0.0.1',
#     port=8443,
#     server_cert='server.crt',
#     server_key='server.key',
#     ca_cert='ca.crt'
# )
```

### 3.4 TLS 1.3高级特性
Python 3.14.0对TLS 1.3提供了完整支持，包括0-RTT早期数据，这可以显著减少连接建立时间。

**示例：TLS 1.3 0-RTT早期数据**
```python
import ssl
import socket

# 服务器端支持0-RTT
def start_tls13_server(host, port, certfile, keyfile):
    context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
    context.load_cert_chain(certfile=certfile, keyfile=keyfile)
    
    # 启用0-RTT
    context.max_early_data = 1024  # 允许的最大早期数据大小
    
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        sock.bind((host, port))
        sock.listen(1)
        
        print(f"TLS 1.3服务器已启动，支持0-RTT")
        
        client_sock, addr = sock.accept()
        with context.wrap_socket(client_sock, server_side=True) as ssl_sock:
            print(f"使用的协议版本: {ssl_sock.version()}")
            
            # 读取早期数据
            early_data = ssl_sock.read_early_data()
            if early_data:
                print(f"收到0-RTT早期数据: {early_data.decode('utf-8')}")
            
            # 读取普通数据
            data = ssl_sock.recv(1024)
            print(f"收到普通数据: {data.decode('utf-8')}")
            
            ssl_sock.sendall("服务器响应".encode('utf-8'))

# 客户端发送0-RTT数据
def tls13_client_with_0rtt(host, port):
    context = ssl.create_default_context()
    context.check_hostname = False
    context.verify_mode = ssl.CERT_NONE
    
    # 第一次连接，获取会话
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        with context.wrap_socket(sock, server_hostname=host) as ssl_sock:
            ssl_sock.connect((host, port))
            session = ssl_sock.session
            print("第一次连接完成，已获取会话")
    
    # 第二次连接，使用会话发送0-RTT数据
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        with context.wrap_socket(
            sock,
            server_hostname=host,
            session=session,
            early_data=b"这是0-RTT早期数据"
        ) as ssl_sock:
            ssl_sock.connect((host, port))
            print("第二次连接，已发送0-RTT数据")
            
            ssl_sock.sendall("这是普通数据".encode('utf-8'))
            response = ssl_sock.recv(1024)
            print(f"收到服务器响应: {response.decode('utf-8')}")
```

### 3.5 SSL会话复用
会话复用可以避免重复进行完整的TLS握手，显著提高连接建立速度。

**示例：SSL会话复用**
```python
import ssl
import socket

def test_session_reuse(host, port):
    """测试SSL会话复用"""
    context = ssl.create_default_context()
    
    # 第一次连接
    print("第一次连接（完整握手）:")
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        with context.wrap_socket(sock, server_hostname=host) as ssl_sock:
            ssl_sock.connect((host, port))
            print(f"握手完成，会话ID: {ssl_sock.session.id.hex()}")
            session = ssl_sock.session
    
    # 第二次连接，复用会话
    print("\n第二次连接（会话复用）:")
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        with context.wrap_socket(sock, server_hostname=host, session=session) as ssl_sock:
            ssl_sock.connect((host, port))
            print(f"握手完成，是否复用会话: {ssl_sock.session_reused}")
            print(f"会话ID: {ssl_sock.session.id.hex()}")

# 测试
if __name__ == "__main__":
    test_session_reuse("www.example.com", 443)
```

### 3.6 错误处理与调试
ssl库定义了多个异常类来处理不同类型的SSL错误。

**示例：完整的SSL错误处理**

import ssl
import socket

def ssl_error_handling_example(host, port):
    """SSL错误处理示例"""
    context = ssl.create_default_context()
    
    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
            sock.settimeout(10)
            with context.wrap_socket(sock, server_hostname=host) as ssl_sock:
                ssl_sock.connect((host, port))
                print("连接成功")
    
    except ssl.SSLCertVerificationError as e:
        print(f"证书验证错误: {e}")
    except ssl.SSLZeroReturnError:
        print("连接被对方正常关闭")
    except ssl.SSLWantReadError:
        print("需要更多数据才能完成操作")
    except ssl.SSLWantWriteError:
        print("需要写入更多数据才能完成操作")
    except ssl.SSLEOFError:
        print("连接被异常关闭")
    except ssl.SSLError as e:
        print(f"通用SSL错误: {e}")
    except socket.timeout:
        print("连接超时")
    except ConnectionRefusedError:
        print("连接被拒绝")
    except Exception as e:
        print(f"其他错误: {e}")

### 3.7 常见安全陷阱
1. **禁用证书验证**：这是最常见的安全错误，会完全暴露在中间人攻击之下
2. **使用过时的协议**：永远不要使用SSLv3、TLS 1.0或TLS 1.1
3. **使用弱密码套件**：避免使用任何包含MD5、SHA1、RC4、3DES的密码套件
4. **硬编码证书和私钥**：永远不要在代码中硬编码私钥
5. **不验证主机名**：即使证书有效，也可能是中间人伪造的
6. **使用自签名证书**：自签名证书无法提供身份验证，仅用于测试

### 4.3 服务器端实现
```python
import ssl
import socket
import os
import json
import threading

class SecureFileServer:
    def __init__(self, host, port, server_cert, server_key, ca_cert):
        self.host = host
        self.port = port
        self.server_cert = server_cert
        self.server_key = server_key
        self.ca_cert = ca_cert
        self.upload_dir = "server_uploads"
        os.makedirs(self.upload_dir, exist_ok=True)
        
        # 创建SSL上下文
        self.context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
        self.context.load_cert_chain(certfile=server_cert, keyfile=server_key)
        self.context.verify_mode = ssl.CERT_REQUIRED
        self.context.load_verify_locations(cafile=ca_cert)
        # 只允许TLS 1.3
        self.context.minimum_version = ssl.TLSVersion.TLSv1_3
    
    def handle_client(self, ssl_sock):
        """处理客户端连接"""
        try:
            client_addr = ssl_sock.getpeername()
            client_cert = ssl_sock.getpeercert()
            print(f"\n客户端已连接: {client_addr}")
            print(f"客户端证书主题: {client_cert['subject']}")
            
            # 接收命令
            data = ssl_sock.recv(1024).decode('utf-8')
            command = json.loads(data)
            
            if command['type'] == 'upload':
                self._handle_upload(ssl_sock, command)
            elif command['type'] == 'download':
                self._handle_download(ssl_sock, command)
            else:
                ssl_sock.sendall(json.dumps({'status': 'error', 'message': '未知命令'}).encode('utf-8'))
        
        except Exception as e:
            print(f"处理客户端时发生错误: {e}")
            try:
                ssl_sock.sendall(json.dumps({'status': 'error', 'message': str(e)}).encode('utf-8'))
            except:
                pass
        finally:
            ssl_sock.close()
            print(f"客户端 {client_addr} 已断开连接")
    
    def _handle_upload(self, ssl_sock, command):
        """处理文件上传"""
        filename = command['filename']
        file_size = command['size']
        save_path = os.path.join(self.upload_dir, filename)
        
        print(f"接收文件: {filename} ({file_size} 字节)")
        
        # 发送确认
        ssl_sock.sendall(json.dumps({'status': 'ready'}).encode('utf-8'))
        
        # 接收文件
        received_size = 0
        with open(save_path, 'wb') as f:
            while received_size < file_size:
                chunk = ssl_sock.recv(8192)
                if not chunk:
                    break
                f.write(chunk)
                received_size += len(chunk)
                progress = (received_size / file_size) * 100
                print(f"\r上传进度: {received_size}/{file_size} 字节 ({progress:.2f}%)", end='')
        
        print("\n文件上传完成")
        ssl_sock.sendall(json.dumps({'status': 'success', 'message': '文件上传成功'}).encode('utf-8'))
    
    def _handle_download(self, ssl_sock, command):
        """处理文件下载"""
        filename = command['filename']
        file_path = os.path.join(self.upload_dir, filename)
        
        if not os.path.exists(file_path):
            ssl_sock.sendall(json.dumps({'status': 'error', 'message': '文件不存在'}).encode('utf-8'))
            return
        
        file_size = os.path.getsize(file_path)
        print(f"发送文件: {filename} ({file_size} 字节)")
        
        # 发送文件信息
        ssl_sock.sendall(json.dumps({
            'status': 'ready',
            'filename': filename,
            'size': file_size
        }).encode('utf-8'))
        
        # 等待客户端确认
        response = ssl_sock.recv(1024).decode('utf-8')
        if json.loads(response)['status'] != 'ready':
            return
        
        # 发送文件
        sent_size = 0
        with open(file_path, 'rb') as f:
            while chunk := f.read(8192):
                ssl_sock.sendall(chunk)
                sent_size += len(chunk)
                progress = (sent_size / file_size) * 100
                print(f"\r下载进度: {sent_size}/{file_size} 字节 ({progress:.2f}%)", end='')
        
        print("\n文件发送完成")
    
    def start(self):
        """启动服务器"""
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
            sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
            sock.bind((self.host, self.port))
            sock.listen(5)
            
            print(f"安全文件服务器已启动，监听 {self.host}:{self.port}")
            print(f"使用TLS 1.3加密和双向身份验证")
            print("按 Ctrl+C 停止服务器")
            
            try:
                while True:
                    client_sock, addr = sock.accept()
                    try:
                        ssl_sock = self.context.wrap_socket(client_sock, server_side=True)
                        client_thread = threading.Thread(
                            target=self.handle_client,
                            args=(ssl_sock,),
                            daemon=True
                        )
                        client_thread.start()
                    except ssl.SSLError as e:
                        print(f"SSL握手失败: {e}")
                        client_sock.close()
            
            except KeyboardInterrupt:
                print("\n服务器正在关闭...")

if __name__ == "__main__":
    server = SecureFileServer(
        host='127.0.0.1',
        port=8443,
        server_cert='server.crt',
        server_key='server.key',
        ca_cert='ca.crt'
    )
    server.start()
```

### 4.4 客户端实现
```python
import ssl
import socket
import os
import json

class SecureFileClient:
    def __init__(self, host, port, client_cert, client_key, ca_cert):
        self.host = host
        self.port = port
        self.client_cert = client_cert
        self.client_key = client_key
        self.ca_cert = ca_cert
        
        # 创建SSL上下文
        self.context = ssl.create_default_context()
        self.context.load_verify_locations(cafile=ca_cert)
        self.context.load_cert_chain(certfile=client_cert, keyfile=client_key)
        self.context.minimum_version = ssl.TLSVersion.TLSv1_3
    
    def upload_file(self, file_path):
        """上传文件到服务器"""
        if not os.path.exists(file_path):
            print(f"文件不存在: {file_path}")
            return False
        
        filename = os.path.basename(file_path)
        file_size = os.path.getsize(file_path)
        
        try:
            with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
                with self.context.wrap_socket(sock, server_hostname=self.host) as ssl_sock:
                    ssl_sock.connect((self.host, self.port))
                    
                    # 发送上传命令
                    command = {
                        'type': 'upload',
                        'filename': filename,
                        'size': file_size
                    }
                    ssl_sock.sendall(json.dumps(command).encode('utf-8'))
                    
                    # 等待服务器确认
                    response = ssl_sock.recv(1024).decode('utf-8')
                    if json.loads(response)['status'] != 'ready':
                        print("服务器拒绝上传")
                        return False
                    
                    # 发送文件
                    print(f"上传文件: {filename} ({file_size} 字节)")
                    sent_size = 0
                    with open(file_path, 'rb') as f:
                        while chunk := f.read(8192):
                            ssl_sock.sendall(chunk)
                            sent_size += len(chunk)
                            progress = (sent_size / file_size) * 100
                            print(f"\r上传进度: {sent_size}/{file_size} 字节 ({progress:.2f}%)", end='')
                    
                    print("\n文件上传完成")
                    
                    # 等待服务器响应
                    response = ssl_sock.recv(1024).decode('utf-8')
                    result = json.loads(response)
                    print(f"服务器响应: {result['message']}")
                    return result['status'] == 'success'
        
        except Exception as e:
            print(f"\n上传失败: {e}")
            return False
    
    def download_file(self, filename, save_path=None):
        """从服务器下载文件"""
        if save_path is None:
            save_path = filename
        
        try:
            with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
                with self.context.wrap_socket(sock, server_hostname=self.host) as ssl_sock:
                    ssl_sock.connect((self.host, self.port))
                    
                    # 发送下载命令
                    command = {
                        'type': 'download',
                        'filename': filename
                    }
                    ssl_sock.sendall(json.dumps(command).encode('utf-8'))
                    
                    # 接收服务器响应
                    response = ssl_sock.recv(1024).decode('utf-8')
                    result = json.loads(response)
                    
                    if result['status'] != 'ready':
                        print(f"下载失败: {result['message']}")
                        return False
                    
                    file_size = result['size']
                    print(f"下载文件: {filename} ({file_size} 字节)")
                    
                    # 发送确认
                    ssl_sock.sendall(json.dumps({'status': 'ready'}).encode('utf-8'))
                    
                    # 接收文件
                    received_size = 0
                    with open(save_path, 'wb') as f:
                        while received_size < file_size:
                            chunk = ssl_sock.recv(8192)
                            if not chunk:
                                break
                            f.write(chunk)
                            received_size += len(chunk)
                            progress = (received_size / file_size) * 100
                            print(f"\r下载进度: {received_size}/{file_size} 字节 ({progress:.2f}%)", end='')
                    
                    print("\n文件下载完成")
                    return True
        
        except Exception as e:
            print(f"\n下载失败: {e}")
            return False

if __name__ == "__main__":
    client = SecureFileClient(
        host='127.0.0.1',
        port=8443,
        client_cert='client.crt',
        client_key='client.key',
        ca_cert='ca.crt'
    )
    
    # 测试上传
    client.upload_file("test_file.txt")
    
    # 测试下载
    client.download_file("test_file.txt", "downloaded_test_file.txt")
```

## 五、总结与扩展学习

### 5.1 核心知识点回顾
- `ssl`库是Python中实现TLS/SSL协议的标准库，基于OpenSSL构建
- `SSLContext`是核心对象，应该使用`create_default_context()`创建安全的默认配置
- 证书验证是TLS安全的核心，永远不要禁用证书验证和主机名验证
- Python 3.14.0默认使用TLS 1.3，提供了最好的安全性和性能
- 双向认证可以同时验证服务器和客户端的身份
- 会话复用和0-RTT可以显著提高连接建立速度
- 必须避免常见的安全陷阱，如使用过时的协议和弱密码套件

### 5.2 Python 3.14.0 ssl库的新特性
1. **默认启用TLS 1.3**，并将其作为首选协议
2. **TLS 1.3握手优化**，连接建立速度提升40%以上
3. **增强的证书验证**，默认禁用所有不安全的密码套件
4. **完善的0-RTT支持**，可以在握手完成前发送数据
5. **安全修复**，修复了多个高危安全漏洞
6. **改进的错误信息**，提供了更详细的调试信息
