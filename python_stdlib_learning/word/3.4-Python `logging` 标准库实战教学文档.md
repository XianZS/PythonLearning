# Python `logging` 标准库实战教学文档

## 一、快速入门：5 分钟上手 `logging`

### 核心内容讲解

`logging` 是 Python 内置的标准库，用于灵活记录程序运行日志。相比 `print`，它支持**日志分级**、**多输出渠道**（控制台 / 文件）、**自定义格式**等功能，是生产环境的必备工具。

### 示例代码

```python
import logging

# 1. 基础配置（仅需执行一次）
logging.basicConfig(
    level=logging.DEBUG,  # 设置最低日志级别
    format='%(asctime)s - %(levelname)s - %(message)s',  # 日志格式
    filename='app.log',  # 日志输出文件
    filemode='w'  # 写入模式：'w'覆盖，'a'追加
)

# 2. 输出不同级别的日志
logging.debug('调试信息：变量x的值是10')
logging.info('普通信息：程序启动成功')
logging.warning('警告信息：内存使用率超过80%')
logging.error('错误信息：数据库连接失败')
logging.critical('严重错误：程序崩溃')
```

### 应用场景

- **小型脚本**：快速记录运行状态，替代杂乱的 `print`

- **临时调试**：通过 `level=logging.DEBUG` 查看详细变量信息

## 二、日志级别：精准控制日志输出

### 核心内容讲解

`logging` 定义了 5 个标准日志级别（从低到高），只有**大于等于**设置级别的日志才会被输出：

|级别|数值|用途说明|
|---|---|---|
|`DEBUG`|10|详细调试信息（开发阶段用）|
|`INFO`|20|普通运行信息（关键流程记录）|
|`WARNING`|30|警告信息（潜在问题）|
|`ERROR`|40|错误信息（功能异常）|
|`CRITICAL`|50|严重错误（程序终止）|

### 示例代码

```python
import logging

# 只输出 WARNING 及以上级别的日志
logging.basicConfig(level=logging.WARNING)

logging.debug('这条不会显示')  # 级别太低
logging.info('这条也不会显示')  # 级别太低
logging.warning('这条会显示')   # ✅
logging.error('这条也会显示')   # ✅
```

### 应用场景

- **开发环境**：设置 `DEBUG` 查看所有细节

- **生产环境**：设置 `WARNING` 或 `ERROR`，减少日志噪音

## 三、Handler：将日志发送到不同位置

### 核心内容讲解

`Handler` 负责决定日志的输出目的地（控制台、文件、网络等）。常用 Handler 包括：

- `StreamHandler`：输出到控制台

- `FileHandler`：输出到文件

- `RotatingFileHandler`：按文件大小分割日志（防止单个文件过大）

- `TimedRotatingFileHandler`：按时间分割日志（每天 / 每小时一个文件）

### 示例代码：同时输出到控制台和文件

```python
import logging
from logging.handlers import RotatingFileHandler

# 1. 创建 Logger 对象（命名建议用 __name__）
logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)  # Logger 级别设为最低
logger.propagate = False  # 禁止向上传递到父 Logger

# 2. 创建 Handler1：输出到控制台（仅显示 INFO+）
console_handler = logging.StreamHandler()
console_handler.setLevel(logging.INFO)
console_formatter = logging.Formatter('%(levelname)s: %(message)s')
console_handler.setFormatter(console_formatter)
logger.addHandler(console_handler)

# 3. 创建 Handler2：输出到文件（按大小分割，保留3个备份）
file_handler = RotatingFileHandler(
    'app.log',
    maxBytes=1*1024*1024,  # 每个文件最大 1MB
    backupCount=3,          # 保留最近 3 个备份文件
    encoding='utf-8'
)
file_handler.setLevel(logging.DEBUG)
file_formatter = logging.Formatter(
    '%(asctime)s - %(module)s:%(lineno)d - %(levelname)s - %(message)s'
)
file_handler.setFormatter(file_formatter)
logger.addHandler(file_handler)

# 4. 测试日志
logger.debug('调试信息（仅文件可见）')
logger.info('普通信息（控制台+文件可见）')
logger.error('错误信息（控制台+文件可见）')
```

### 应用场景

- **生产环境**：用 `RotatingFileHandler` 避免日志文件无限增长

- **实时监控**：用 `StreamHandler` 在控制台实时查看关键日志

- **长期归档**：用 `TimedRotatingFileHandler` 按天分割日志

## 四、Formatter：自定义日志格式

### 核心内容讲解

`Formatter` 用于定义日志的显示格式，常用占位符包括：

|占位符|说明|
|---|---|
|`%(asctime)s`|日志时间（如 2023-10-01 12:00:00）|
|`%(levelname)s`|日志级别（DEBUG/INFO 等）|
|`%(message)s`|日志内容|
|`%(module)s`|模块名|
|`%(lineno)d`|行号|
|`%(funcName)s`|函数名|

### 示例代码

```python
import logging

# 自定义格式：包含时间、模块、行号、级别、内容
formatter = logging.Formatter(
    '[%(asctime)s] [%(module)s:%(lineno)d] %(levelname)s - %(message)s',
    datefmt='%Y-%m-%d %H:%M:%S'  # 自定义时间格式
)

# 应用到 Handler
handler = logging.StreamHandler()
handler.setFormatter(formatter)

logger = logging.getLogger(__name__)
logger.addHandler(handler)
logger.setLevel(logging.INFO)

logger.info('这是一条带格式的日志')
# 输出示例：[2023-10-01 12:00:00] [test:18] INFO - 这是一条带格式的日志
```

### 应用场景

- **问题定位**：包含 `module`、`lineno` 快速找到报错位置

- **日志分析**：统一格式方便后续用 ELK 等工具分析

## 五、实战案例：简易任务处理系统日志

### 需求描述

开发一个任务处理系统，要求：

1. 记录任务开始、完成、失败的详细信息

2. 控制台实时显示 `INFO+` 日志

3. 文件记录 `DEBUG+` 日志（按大小分割，保留 5 个备份）

4. 错误日志包含堆栈信息

### 完整代码

```python
import logging
from logging.handlers import RotatingFileHandler
import time
import random

def setup_task_logger():
    """配置任务专用 Logger"""
    logger = logging.getLogger('task_processor')
    logger.setLevel(logging.DEBUG)
    logger.propagate = False

    # 1. 控制台 Handler（INFO+）
    console_handler = logging.StreamHandler()
    console_handler.setLevel(logging.INFO)
    console_formatter = logging.Formatter('%(levelname)s: %(message)s')
    console_handler.setFormatter(console_formatter)
    logger.addHandler(console_handler)

    # 2. 文件 Handler（DEBUG+，按大小分割）
    file_handler = RotatingFileHandler(
        'task_system.log',
        maxBytes=2*1024*1024,  # 2MB
        backupCount=5,
        encoding='utf-8'
    )
    file_handler.setLevel(logging.DEBUG)
    file_formatter = logging.Formatter(
        '%(asctime)s - %(funcName)s:%(lineno)d - %(levelname)s - %(message)s'
    )
    file_handler.setFormatter(file_formatter)
    logger.addHandler(file_handler)

    return logger

def process_single_task(task_id, logger):
    """处理单个任务"""
    logger.debug(f'开始处理任务 {task_id}')
    start_time = time.time()

    try:
        # 模拟任务处理（随机失败）
        if random.random() < 0.2:
            raise ValueError(f'任务 {task_id} 参数校验失败')
        time.sleep(random.uniform(0.1, 0.3))  # 模拟耗时

        # 任务成功
        duration = time.time() - start_time
        logger.info(f'任务 {task_id} 完成，耗时 {duration:.2f}s')

    except Exception as e:
        # 任务失败：exc_info=True 记录堆栈
        logger.error(f'任务 {task_id} 处理失败', exc_info=True)

if __name__ == '__main__':
    task_logger = setup_task_logger()
    task_logger.info('=== 任务系统启动 ===')
    
    # 模拟处理10个任务
    for task_id in range(1, 11):
        process_single_task(task_id, task_logger)
    
    task_logger.info('=== 所有任务处理完毕 ===')
```

### 运行效果

1. **控制台**：实时显示任务完成 / 失败的简洁信息

2. **文件 ****`task_system.log`**：
- 包含所有调试细节
    
- 错误日志有完整堆栈（方便排查）
    
- 超过 2MB 自动分割为 `task_system.log.1`、`task_system.log.2` 等

## 六、进阶扩展：日志配置的三种方式

除了代码直接配置，`logging` 还支持更灵活的配置方式：

### 1. 字典配置（推荐用于复杂项目）

```python
import logging.config

log_config = {
    'version': 1,
    'disable_existing_loggers': False,
    'formatters': {
        'standard': {
            'format': '%(asctime)s - %(levelname)s - %(message)s'
        }
    },
    'handlers': {
        'file': {
            'class': 'logging.FileHandler',
            'filename': 'app.log',
            'formatter': 'standard',
            'encoding': 'utf-8'
        }
    },
    'root': {
        'level': 'INFO',
        'handlers': ['file']
    }
}

logging.config.dictConfig(log_config)
logging.info('通过字典配置记录的日志')
```

### 2. 文件配置（`.conf` 格式）

创建 `logging.conf`：

```ini
[loggers]
keys=root

[handlers]
keys=fileHandler

[formatters]
keys=standardFormatter

[logger_root]
level=INFO
handlers=fileHandler

[handler_fileHandler]
class=FileHandler
args=('app.log', 'a', 'utf-8')
formatter=standardFormatter

[formatter_standardFormatter]
format=%(asctime)s - %(levelname)s - %(message)s
```

加载配置：

```python
import logging.config
logging.config.fileConfig('logging.conf')
logging.info('通过文件配置记录的日志')
```

## 总结

`logging` 核心四要素：

1. **Logger**：日志入口，负责产生日志

2. **Handler**：日志出口，决定日志发往何处

3. **Formatter**：定义日志的显示格式

4. **Filter**：（可选）精细控制日志过滤
