# B站Python授课：`pathlib` 标准库——面向对象的路径操作革命

## 课程导入

之前我们学了 `os.path` 和 `shutil` 处理文件路径，但 `os.path` 是**面向过程**的，路径拼接用 `join()`、拆分用 `dirname()`，代码冗长且容易出错。

`pathlib` 是 Python 3.4+ 引入的**面向对象路径库**，用“路径对象”替代字符串操作，代码更优雅、跨平台兼容性更好，现已成为 Python 官方推荐的路径处理方式（可完全替代 `os.path`）。

---

## 第一部分：核心类与基础对象

### 核心知识点

`pathlib` 有两类核心类，区别在于是否直接操作文件系统：

- **纯路径类**：仅处理路径字符串（如拼接、拆分），不访问实际文件系统，适合跨平台逻辑判断。

    - `PurePosixPath`：Unix/macOS 风格路径

    - `PureWindowsPath`：Windows 风格路径

    - `PurePath`：自动根据系统适配的纯路径（推荐用这个）

- **具体路径类**：继承纯路径类，增加文件系统操作（如创建、删除、判断存在），**最常用**。

    - `Path`：自动根据系统适配的具体路径（99% 的场景用它即可）

### 示例代码

```Python

from pathlib import Path, PurePath

# 1. 创建 Path 对象（最常用）
# 方式1：用字符串初始化
p1 = Path("test.txt")
p2 = Path("/home/user/documents")  # 绝对路径

# 方式2：用 / 拼接（后续重点讲）
p3 = Path.home() / "projects" / "python"  # Path.home() 获取用户主目录

# 2. 纯路径 vs 具体路径
pure_p = PurePath("test.txt")
print(f"纯路径拼接：{pure_p / 'subdir'}")  # 仅字符串操作，不检查文件是否存在
print(f"具体路径判断存在：{p1.exists()}")  # 实际访问文件系统

# 3. 常用快捷路径
print(f"当前工作目录：{Path.cwd()}")  # 类似 os.getcwd()
print(f"用户主目录：{Path.home()}")  # 类似 os.path.expanduser("~")
```

### 内容讲解

- `Path` 对象是**不可变**的（类似字符串），所有拼接/修改操作都会返回新的 `Path` 对象。

- 纯路径类适合“只处理路径格式、不碰文件”的场景（如生成配置文件路径模板）；实际操作文件一律用 `Path`。

### 应用场景

1. 跨平台路径生成：用 `Path` 自动适配 Windows/macOS 路径分隔符，无需手动判断 `os.name`。

2. 快捷定位用户目录：用 `Path.home()` 快速找到桌面、文档等系统目录。

## 第二部分：路径拼接与属性获取（核心亮点）

### 核心知识点  

`pathlib` 最惊艳的设计是用 **`/`** ** 操作符**替代 `os.path.join()`，同时提供直观的属性获取路径各部分（文件名、后缀、父目录等）。

### 常用函数与示例代码

```Python

from pathlib import Path

# 1. 路径拼接：用 / 操作符（比 os.path.join 直观10倍！）
base_dir = Path.home() / "projects"
project_dir = base_dir / "my_python_app"
log_file = project_dir / "logs" / "app.log"
print(f"拼接后的路径：{log_file}")

# 2. 获取路径各部分属性
p = Path("/home/user/projects/my_python_app/main.py")
print(f"完整文件名（含后缀）：{p.name}")       # 输出：main.py
print(f"文件名（不含后缀）：{p.stem}")         # 输出：main
print(f"文件后缀：{p.suffix}")                 # 输出：.py
print(f"多个后缀（如 .tar.gz）：{p.with_suffix('.tar.gz').suffixes}")  # 输出：['.tar', '.gz']
print(f"父目录（上一级）：{p.parent}")         # 输出：/home/user/projects/my_python_app
print(f"上级目录链（可迭代）：{list(p.parents)}")  # 输出：[my_python_app, projects, user, home, /]
print(f"路径是否为绝对路径：{p.is_absolute()}")  # 输出：True
```

### 内容讲解

- `/` 操作符支持链式调用，且自动处理多余的分隔符（如 `Path("a") / "/b"` 会自动合并为 `Path("/b")`）。

- 属性获取无需像 `os.path` 那样调用多个函数（如 `os.path.basename()`、`os.path.splitext()`），直接通过对象属性访问，代码更简洁。

### 应用场景

1. **批量修改文件后缀**：用 `with_suffix()` 快速替换后缀（如把 `.txt` 改为 `.md`）。

2. **生成备份文件路径**：用 `stem + "_backup" + suffix` 生成 `main_backup.py` 这样的备份文件名。

## 第三部分：路径判断与文件系统操作

### 核心知识点

`Path` 对象封装了常用的文件系统操作（创建、删除、重命名等），替代 `os` 和 `os.path` 中的对应函数。

### 常用函数与示例代码

```Python

from pathlib import Path

# 1. 路径判断
p = Path("test.txt")
print(f"路径是否存在：{p.exists()}")       # 类似 os.path.exists()
print(f"是否为文件：{p.is_file()}")         # 类似 os.path.isfile()
print(f"是否为目录：{p.is_dir()}")         # 类似 os.path.isdir()
print(f"文件大小（字节）：{p.stat().st_size}")  # 类似 os.path.getsize()，stat() 返回更多元数据

# 2. 创建目录
dir_path = Path("data") / "input"
dir_path.mkdir(parents=True, exist_ok=True)  # 关键参数：
# - parents=True：递归创建父目录（类似 os.makedirs()）
# - exist_ok=True：目录已存在时不报错（避坑必备！）

# 3. 创建空文件（类似 touch 命令）
file_path = dir_path / "data.txt"
file_path.touch(exist_ok=True)  # exist_ok=True：文件已存在时不报错

# 4. 重命名/移动文件
new_file = file_path.with_name("data_processed.txt")
file_path.rename(new_file)  # 重命名（同一目录下）
# 移动到其他目录：new_file.rename(Path("data/output") / "data_processed.txt")

# 5. 删除文件/目录
new_file.unlink()  # 删除文件（类似 os.remove()）
dir_path.rmdir()   # 删除空目录（类似 os.rmdir()）
# 注意：删除非空目录仍需用 shutil.rmtree()
```

### 内容讲解

- `mkdir(parents=True, exist_ok=True)` 是**最常用的目录创建方式**，避免手动判断父目录是否存在、避免重复创建报错。

- `touch(exist_ok=True)` 快速创建空文件，适合生成占位文件。

- `rename()` 既可以重命名也可以移动文件，跨分区移动时自动处理复制+删除逻辑。

### 应用场景

1. **自动创建项目目录结构**：一键生成 `data/input`、`data/output`、`logs` 等项目必备目录。

2. **安全重命名配置文件**：用 `with_name()` 生成新文件名，避免手动拼接字符串出错。

## 第四部分：目录遍历与文件查找（替代 `os.walk`）

### 核心知识点

`pathlib` 提供了三种遍历方式，替代繁琐的 `os.walk`，代码更简洁：

- `iterdir()`：遍历当前目录（非递归）

- `glob(pattern)`：匹配当前目录下的文件（支持通配符）

- `rglob(pattern)`：**递归匹配所有子目录**（r = recursive，神器级功能）

### 常用函数与示例代码

```Python

from pathlib import Path

# 准备测试环境
base_dir = Path("test_project")
(base_dir / "src").mkdir(parents=True, exist_ok=True)
(base_dir / "docs").mkdir(exist_ok=True)
(base_dir / "src" / "main.py").touch()
(base_dir / "src" / "utils.py").touch()
(base_dir / "docs" / "readme.md").touch()
(base_dir / "notes.txt").touch()

# 1. iterdir()：遍历当前目录（非递归）
print("=== 当前目录内容 ===")
for item in base_dir.iterdir():
    print(item)  # 输出 test_project/src, test_project/docs, test_project/notes.txt

# 2. glob()：匹配当前目录文件（非递归）
print("\n=== 当前目录的 .txt 文件 ===")
for txt_file in base_dir.glob("*.txt"):
    print(txt_file)  # 输出 test_project/notes.txt

# 3. rglob()：递归匹配所有子目录（替代 os.walk！）
print("\n=== 所有子目录的 .py 文件 ===")
for py_file in base_dir.rglob("*.py"):
    print(py_file)  # 输出 test_project/src/main.py, test_project/src/utils.py

# 进阶：结合 is_file() 过滤
print("\n=== 所有文件（不含目录） ===")
for file in base_dir.rglob("*"):
    if file.is_file():
        print(file)
```

### 内容讲解

- `rglob("*.py")` 等价于 `glob("**/*.py", recursive=True)`，但写法更简洁。

- 通配符规则：`*` 匹配任意字符（不含目录分隔符），`**` 匹配任意目录（含子目录），`?` 匹配单个字符。

### 应用场景

1. **批量查找项目日志文件**：用 `rglob("*.log")` 快速找到所有子目录下的日志。

2. **统计代码行数**：用 `rglob("*.py")` 遍历所有 Python 文件，逐行读取统计。

## 第五部分：简化文件读写（一行代码搞定）

### 核心知识点

`Path` 对象封装了文件读写方法，无需手动调用 `open()`，代码更简洁：

- `read_text()` / `write_text()`：读写文本文件

- `read_bytes()` / `write_bytes()`：读写二进制文件

- `open()`：替代内置 `open()`，支持上下文管理器（`with` 语句）

### 常用函数与示例代码

```Python

from pathlib import Path

# 1. 快速读写文本文件（一行代码！）
file_path = Path("test.txt")

# 写入文本（自动创建文件，覆盖已存在内容）
file_path.write_text("Hello pathlib!\n这是第二行")

# 读取文本（自动处理编码，默认 utf-8）
content = file_path.read_text(encoding="utf-8")
print("文件内容：")
print(content)

# 2. 用 open() 方法（替代内置 open，支持 with）
with file_path.open("a", encoding="utf-8") as f:
    f.write("\n这是追加的第三行")

# 3. 读写二进制文件（如图片、PDF）
# img_path = Path("test.jpg")
# img_data = img_path.read_bytes()
# new_img = Path("test_copy.jpg")
# new_img.write_bytes(img_data)
```

### 内容讲解

- `read_text()` / `write_text()` 适合小文件读写，大文件仍建议用 `open()` 逐行处理。

- 默认编码为 `utf-8`，避免了 Windows 下 `open()` 默认 `gbk` 编码的坑。

### 应用场景

1. **快速读取配置文件**：用 `read_text()` 读取 JSON/YAML 配置（结合 `json`/`yaml` 库解析）。

2. **生成简单报告**：用 `write_text()` 直接写入统计结果到 `.txt` 或 `.md` 文件。

## 课程总结与实战练习

### 核心回顾

1. **核心对象**：用 `Path` 处理 99% 的场景，`/` 操作符拼接路径是灵魂。

2. **路径属性**：`name`/`stem`/`suffix`/`parent` 快速获取路径各部分。

3. **文件操作**：`mkdir(parents=True, exist_ok=True)` 安全创建目录，`rglob()` 递归遍历神器。

4. **文件读写**：`read_text()`/`write_text()` 简化小文件操作。

### 实战练习

用 `pathlib` 写一个“图片整理脚本”，实现以下功能：

1. 在当前目录创建 `photos` 文件夹，并在其下创建 `jpg`、`png`、`others` 三个子文件夹。

2. 递归遍历当前目录（不含 `photos` 文件夹），找到所有图片文件：

    - `.jpg`/`.jpeg` 移动到 `photos/jpg`

    - `.png` 移动到 `photos/png`

    - 其他图片格式（`.gif`/`.bmp`）移动到 `photos/others`

3. 最后在 `photos` 目录下生成 `photo_report.txt`，统计各类图片的数量。
