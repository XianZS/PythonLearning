# Python `datetime` 标准库教学文档

## 一、基础概念与使用场景

### 1. 基础概念

`datetime` 是 Python 标准库中专门用于**处理日期和时间**的核心模块，提供了一系列类来表示日期、时间、时间间隔以及时区信息，能实现日期时间的创建、计算、格式化、转换等操作，是时间相关开发的 “基础工具箱”。

其核心类包括：

- `date`：表示日期（年、月、日）；

- `time`：表示时间（时、分、秒、微秒）；

- `datetime`：表示日期 + 时间（结合了 `date` 和 `time`）；

- `timedelta`：表示时间间隔（用于日期时间的加减计算）；

- `tzinfo`：时区信息的抽象基类（用于处理时区）。

### 2. 使用场景

- **日志与数据记录**：为日志添加时间戳，记录数据的创建 / 修改时间；

- **任务调度**：计算定时任务的执行时间，判断任务是否过期；

- **用户界面**：在应用中展示友好的日期时间格式（如 “3 分钟前”）；

- **数据处理**：转换不同格式的时间字符串，计算两个日期的间隔；

- **倒计时与提醒**：计算活动剩余时间，设置日程提醒。

## 二、基础用法

### 2.1 获取当前日期和时间

快速获取本地当前的日期或日期时间。

#### 语法规范

- `datetime.date.today()`：返回当前本地日期（`date` 对象）；

- `datetime.datetime.now()`：返回当前本地日期时间（`datetime` 对象，可选时区参数）。

#### 示例代码

```python
import datetime

# 1. 获取当前日期
today = datetime.date.today()
print("当前日期:", today)  # 输出: 当前日期: 2024-05-20

# 2. 获取当前日期时间
now = datetime.datetime.now()
print("当前日期时间:", now)  # 输出: 当前日期时间: 2024-05-20 14:30:45.123456
```

### 2.2 创建指定的日期和时间

通过指定年、月、日、时、分、秒等参数，创建自定义的 `date` 或 `datetime` 对象。

#### 语法规范

- `datetime.date(year, month, day)`：创建日期对象；

- `datetime.datetime(year, month, day, hour=0, minute=0, second=0, microsecond=0)`：创建日期时间对象。

#### 示例代码

```python
import datetime

# 1. 创建指定日期
d = datetime.date(2024, 10, 1)
print("指定日期:", d)  # 输出: 指定日期: 2024-10-01

# 2. 创建指定日期时间
dt = datetime.datetime(2024, 10, 1, 9, 30, 0)
print("指定日期时间:", dt)  # 输出: 指定日期时间: 2024-10-01 09:30:00
```

### 2.3 访问日期时间的属性

从 `date` 或 `datetime` 对象中提取年、月、日、时、分、秒等具体属性。

#### 语法规范

- `date` 对象属性：`year`、`month`、`day`；

- `datetime` 对象属性：`year`、`month`、`day`、`hour`、`minute`、`second`、`microsecond`。

#### 示例代码

```python
import datetime

dt = datetime.datetime(2024, 5, 20, 14, 30, 45, 123456)

print("年:", dt.year)    # 输出: 年: 2024
print("月:", dt.month)   # 输出: 月: 5
print("日:", dt.day)     # 输出: 日: 20
print("时:", dt.hour)    # 输出: 时: 14
print("分:", dt.minute)  # 输出: 分: 30
print("秒:", dt.second)  # 输出: 秒: 45
```

### 2.4 日期时间与字符串的转换

实现 `datetime` 对象与字符串之间的双向转换：

- `strftime()`：将 `datetime` 格式化为字符串；

- `strptime()`：将字符串解析为 `datetime`。

#### 语法规范

- `datetime_obj.strftime(format)`：返回格式化后的字符串；

- `datetime.datetime.strptime(date_str, format)`：返回 `datetime` 对象。

常用格式码：

|格式码|含义|示例|
|---|---|---|
|`%Y`|四位数年份|2024|
|`%m`|两位数月份（01-12）|05|
|`%d`|两位数日期（01-31）|20|
|`%H`|24 小时制小时（00-23）|14|
|`%M`|两位数分钟（00-59）|30|
|`%S`|两位数秒（00-59）|45|
|`%A`|完整星期名|Monday|

#### 示例代码

```python
import datetime

# 1. datetime -> 字符串（strftime）
now = datetime.datetime.now()
formatted1 = now.strftime("%Y-%m-%d %H:%M:%S")
formatted2 = now.strftime("%Y年%m月%d日 %A")
print("格式化1:", formatted1)  # 输出: 格式化1: 2024-05-20 14:30:45
print("格式化2:", formatted2)  # 输出: 格式化2: 2024年05月20日 Monday

# 2. 字符串 -> datetime（strptime）
date_str = "2024-10-01 09:30:00"
dt = datetime.datetime.strptime(date_str, "%Y-%m-%d %H:%M:%S")
print("解析后的datetime:", dt)  # 输出: 解析后的datetime: 2024-10-01 09:30:00
```

### 2.5 时间间隔（`timedelta`）的基础使用

`timedelta` 表示两个日期或时间之间的间隔，用于日期时间的加减计算。

#### 语法规范

```python
datetime.timedelta(days=0, seconds=0, microseconds=0, milliseconds=0, minutes=0, hours=0, weeks=0)
```

常用参数：`days`（天）、`hours`（小时）、`minutes`（分钟）、`seconds`（秒）。

#### 示例代码

```python
import datetime

now = datetime.datetime.now()

# 1. 计算3天后的时间
delta_3d = datetime.timedelta(days=3)
after_3d = now + delta_3d
print("3天后:", after_3d.strftime("%Y-%m-%d"))

# 2. 计算2小时前的时间
delta_2h = datetime.timedelta(hours=2)
before_2h = now - delta_2h
print("2小时前:", before_2h.strftime("%H:%M:%S"))

# 3. 计算两个日期的间隔
d1 = datetime.date(2024, 5, 1)
d2 = datetime.date(2024, 5, 20)
delta = d2 - d1
print("间隔天数:", delta.days)  # 输出: 间隔天数: 19
```

## 三、进阶用法

### 3.1 时区处理

通过自定义 `tzinfo` 子类或使用 Python 3.9+ 的 `zoneinfo` 模块处理时区。

#### 语法规范（自定义 `tzinfo` 子类）

继承 `datetime.tzinfo`，实现 `utcoffset()`、`tzname()`、`dst()` 三个方法。

#### 示例代码

```python
import datetime

# 自定义 UTC+8 时区（北京时间）
class UTC8(datetime.tzinfo):
    def utcoffset(self, dt):
        return datetime.timedelta(hours=8)  # 偏移量+8小时
    
    def tzname(self, dt):
        return "UTC+8"  # 时区名称
    
    def dst(self, dt):
        return datetime.timedelta(0)  # 无夏令时

# 创建带时区的datetime
dt_utc8 = datetime.datetime(2024, 5, 20, 14, 30, tzinfo=UTC8())
print("带时区的时间:", dt_utc8)  # 输出: 带时区的时间: 2024-05-20 14:30:00+08:00

# Python 3.9+ 也可使用 zoneinfo（需确保系统有时区数据库）
# from zoneinfo import ZoneInfo
# dt = datetime.datetime(2024, 5, 20, tzinfo=ZoneInfo("Asia/Shanghai"))
```

### 3.2 时间戳与 `datetime` 的转换

时间戳是指从 1970 年 1 月 1 日 00:00:00 UTC 到现在的秒数（或微秒数）。

#### 语法规范

- `datetime_obj.timestamp()`：返回时间戳（浮点数，单位秒）；

- `datetime.datetime.fromtimestamp(timestamp)`：将时间戳转为本地 `datetime`；

- `datetime.datetime.utcfromtimestamp(timestamp)`：将时间戳转为 UTC `datetime`。

#### 示例代码

```python
import datetime

# 1. datetime -> 时间戳
now = datetime.datetime.now()
timestamp = now.timestamp()
print("时间戳:", timestamp)  # 输出: 时间戳: 1716186645.123456

# 2. 时间戳 -> datetime
dt = datetime.datetime.fromtimestamp(timestamp)
print("从时间戳转回:", dt)  # 输出: 从时间戳转回: 2024-05-20 14:30:45.123456
```

### 3.3 日期时间的比较

直接使用比较运算符（`&lt;`、`&gt;`、`==`、`&lt;=`、`&gt;=`）比较两个日期或时间的先后。

#### 示例代码

```python
import datetime

dt1 = datetime.datetime(2024, 5, 1)
dt2 = datetime.datetime(2024, 5, 20)

print("dt1 < dt2?", dt1 < dt2)  # 输出: dt1 < dt2? True
print("dt1 > dt2?", dt1 > dt2)  # 输出: dt1 > dt2? False
print("dt1 == dt2?", dt1 == dt2)  # 输出: dt1 == dt2? False
```

### 3.4 替换日期时间的属性

通过 `replace()` 方法创建一个新的 `date` 或 `datetime` 对象，替换部分属性（原对象不变）。

#### 语法规范

- `date_obj.replace(year=None, month=None, day=None)`：返回新的 `date`；

- `datetime_obj.replace(year=None, month=None, day=None, hour=None, minute=None, second=None, microsecond=None, tzinfo=None)`：返回新的 `datetime`。

#### 示例代码

```python
import datetime

dt = datetime.datetime(2024, 5, 20, 14, 30)

# 替换年份为2025，小时为10
new_dt = dt.replace(year=2025, hour=10)
print("原时间:", dt)       # 输出: 原时间: 2024-05-20 14:30:00
print("替换后:", new_dt)    # 输出: 替换后: 2025-05-20 10:30:00
```

### 3.5 星期几的判断

通过 `weekday()` 或 `isoweekday()` 方法判断日期是星期几。

#### 语法规范

- `date_obj.weekday()`：返回 0（周一）~ 6（周日）；

- `date_obj.isoweekday()`：返回 1（周一）~ 7（周日）。

#### 示例代码

```python
import datetime

d = datetime.date(2024, 5, 20)  # 2024年5月20日是周一

print("weekday():", d.weekday())      # 输出: weekday(): 0
print("isoweekday():", d.isoweekday())# 输出: isoweekday(): 1
```

## 四、实战案例：任务调度与时间追踪工具

### 1. 需求描述

开发一个**任务调度与时间追踪工具**，实现以下功能：

- 添加任务（包含任务名称、截止时间）；

- 计算任务的剩余时间（或已过期时间）；

- 判断任务是否已过期；

- 按截止时间对任务进行排序；

- 统计本周内需要完成的任务。

### 2. 完整代码实现

```python
import datetime

class Task:
    def __init__(self, name, deadline):
        self.name = name
        self.deadline = deadline  # deadline 是 datetime 对象

    def is_overdue(self):
        """判断任务是否已过期"""
        return datetime.datetime.now() > self.deadline

    def get_remaining_time(self):
        """获取剩余时间（返回 timedelta 对象）"""
        now = datetime.datetime.now()
        if self.is_overdue():
            return now - self.deadline  # 已过期，返回已过期的时间
        else:
            return self.deadline - now  # 未过期，返回剩余时间

    def __str__(self):
        status = "已过期" if self.is_overdue() else "进行中"
        remaining = self.get_remaining_time()
        if self.is_overdue():
            time_str = f"已过期 {remaining.days} 天 {remaining.seconds//3600} 小时"
        else:
            time_str = f"剩余 {remaining.days} 天 {remaining.seconds//3600} 小时"
        return f"【{status}】{self.name} | 截止时间: {self.deadline.strftime('%Y-%m-%d %H:%M')} | {time_str}"

class TaskManager:
    def __init__(self):
        self.tasks = []

    def add_task(self, name, deadline_str, deadline_format="%Y-%m-%d %H:%M"):
        """添加任务（deadline_str 是时间字符串，deadline_format 是对应的格式）"""
        try:
            deadline = datetime.datetime.strptime(deadline_str, deadline_format)
            self.tasks.append(Task(name, deadline))
            print(f"任务添加成功: {name}")
        except ValueError:
            print(f"时间格式错误，请使用格式: {deadline_format}")

    def sort_tasks_by_deadline(self):
        """按截止时间排序任务（最早的在前）"""
        self.tasks.sort(key=lambda task: task.deadline)

    def get_this_week_tasks(self):
        """获取本周内的任务（周一到周日）"""
        today = datetime.date.today()
        # 计算本周一的日期
        monday = today - datetime.timedelta(days=today.weekday())
        # 计算本周日的日期
        sunday = monday + datetime.timedelta(days=6)
        # 筛选截止时间在本周一到周日之间的任务
        this_week_tasks = []
        for task in self.tasks:
            task_date = task.deadline.date()
            if monday <= task_date <= sunday:
                this_week_tasks.append(task)
        return this_week_tasks

    def show_all_tasks(self):
        """展示所有任务"""
        if not self.tasks:
            print("暂无任务")
            return
        print("="*70)
        print("所有任务列表")
        print("="*70)
        for i, task in enumerate(self.tasks, 1):
            print(f"{i}. {task}")
        print("="*70)

# 实战案例使用
if __name__ == "__main__":
    manager = TaskManager()

    # 1. 添加任务
    manager.add_task("完成Python作业", "2024-05-21 18:00")
    manager.add_task("提交项目报告", "2024-05-25 10:00")
    manager.add_task("购买生日礼物", "2024-05-18 00:00")  # 已过期
    manager.add_task("参加技术会议", "2024-05-22 14:00")

    # 2. 按截止时间排序
    manager.sort_tasks_by_deadline()

    # 3. 展示所有任务
    manager.show_all_tasks()

    # 4. 展示本周任务
    print("n本周任务：")
    this_week = manager.get_this_week_tasks()
    for task in this_week:
        print(f"- {task.name} (截止: {task.deadline.strftime('%Y-%m-%d')})")
```

## 五、总结

- `datetime` 模块的核心是 `date`、`time`、`datetime`、`timedelta` 四个类，覆盖了日期时间的表示、计算、转换等需求；

- 基础用法需掌握当前时间获取、自定义日期创建、字符串转换、`timedelta` 计算；

- 进阶用法需关注时区处理、时间戳转换、日期比较、属性替换、星期判断；

- 实战中，`datetime` 常与任务调度、日志记录、数据处理结合，能显著提升时间相关功能的开发效率。
