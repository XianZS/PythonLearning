# Python 3.14.0 ftplib标准库完整学习文档

## 一、ftplib核心概念

### 1.1 什么是ftplib
`ftplib`是Python标准库中用于实现FTP（文件传输协议）客户端的核心模块，提供了对FTP协议的完整实现，允许你在Python程序中轻松连接FTP服务器，执行文件上传、下载、目录管理等操作。

Python 3.14.0对`ftplib`进行了重要的安全和性能升级：
- 原生支持TLS 1.3协议，大幅提升了FTPS连接的安全性
- 优化了大文件传输的性能，减少了内存占用
- 修复了多个安全漏洞，包括命令注入和证书验证问题
- 增强了错误信息的可读性，提供了更详细的调试信息
- 保持了完全的向后兼容性

### 1.2 FTP协议基础
FTP（File Transfer Protocol）是一个用于在计算机网络上进行文件传输的标准应用层协议，工作在TCP/IP协议栈的应用层，使用两个独立的连接：
- **控制连接**（默认端口21）：用于发送命令和接收响应
- **数据连接**（默认端口20）：用于实际的文件数据传输

FTP有两种工作模式：
- **主动模式（PORT）**：服务器主动连接客户端的数据端口
- **被动模式（PASV）**：客户端主动连接服务器的数据端口（现代网络环境下更常用）

### 1.3 ftplib的主要类
ftplib提供了两个核心类来实现FTP客户端功能：

| 类 | 说明 | 适用场景 |
|----|------|----------|
| `ftplib.FTP` | 基础FTP客户端，使用明文传输 | 内部网络、测试环境 |
| `ftplib.FTP_TLS` | 安全FTP客户端，支持TLS/SSL加密 | 生产环境、互联网传输 |

**重要安全提示**：明文FTP传输的所有数据（包括用户名、密码和文件内容）都可以被网络嗅探器截获。在互联网上传输敏感数据时，**必须使用FTPS（FTP over TLS/SSL）或SFTP**。

### 1.4 ftplib与其他文件传输库的关系
- **ftplib**：Python标准库，无需安装，支持FTP和FTPS
- **paramiko**：第三方库，支持SSH和SFTP（SSH文件传输协议）
- **requests**：不直接支持FTP，但可以通过`requests-ftp`扩展实现

## 二、ftplib基础部分

### 2.1 连接FTP服务器
使用`FTP`类可以连接到标准的FTP服务器，支持匿名登录和用户名密码登录。

**示例：连接并登录FTP服务器**
```python
import ftplib

# 1. 匿名登录（最常用）
try:
    # 创建FTP对象并连接服务器
    ftp = ftplib.FTP("ftp.gnu.org")
    # 匿名登录（用户名anonymous，密码通常是邮箱地址）
    ftp.login()
    print("匿名登录成功")
    print(f"服务器欢迎信息: {ftp.getwelcome()}")
    print(f"当前工作目录: {ftp.pwd()}")
    
    # 关闭连接
    ftp.quit()
    print("已断开连接")

except ftplib.all_errors as e:
    print(f"FTP错误: {e}")

# 2. 用户名密码登录
try:
    ftp = ftplib.FTP("ftp.example.com")
    ftp.login("username", "password")
    print("用户名密码登录成功")
    ftp.quit()

except ftplib.error_perm as e:
    print(f"权限错误: {e}")
except ftplib.all_errors as e:
    print(f"其他错误: {e}")
```

**常用连接方法**：
- `FTP(host='', user='', passwd='', acct='', timeout=None)`：创建FTP对象并连接
- `login(user='anonymous', passwd='', acct='')`：登录服务器
- `quit()`：发送QUIT命令并关闭连接（优雅关闭）
- `close()`：强制关闭连接（不发送QUIT命令）

### 2.2 目录操作
FTP服务器的目录操作与本地文件系统类似，包括列出目录、切换目录、创建和删除目录。

**示例：FTP目录操作**
```python
import ftplib

ftp = ftplib.FTP("ftp.gnu.org")
ftp.login()
print("登录成功")

# 1. 列出当前目录内容
print("\n当前目录内容:")
ftp.dir()  # 直接打印目录列表

# 2. 获取目录列表（返回列表）
file_list = ftp.nlst()
print(f"\n文件列表: {file_list}")

# 3. 切换目录
ftp.cwd("gnu")
print(f"\n切换到目录: {ftp.pwd()}")

# 4. 创建目录

    ftp.mkd("test_dir")
    print("\n创建目录成功")
except ftplib.error_perm as e:
    print(f"\n创建目录失败: {e}")  # 通常因为权限不足

# 5. 删除目录

    ftp.rmd("test_dir")
    print("删除目录成功")
except ftplib.error_perm as e:
    print(f"删除目录失败: {e}")

# 6. 返回上级目录
ftp.cwd("..")
print(f"\n返回上级目录: {ftp.pwd()}")

ftp.quit()
```

### 2.3 文件下载
ftplib提供了两种文件下载方法：
- `retrbinary()`：下载二进制文件（图片、视频、压缩包等）
- `retrlines()`：下载文本文件（逐行读取）

**示例：下载文件**
```python
import ftplib
import os

ftp = ftplib.FTP("ftp.gnu.org")
ftp.login()
ftp.cwd("gnu/emacs")

# 1. 下载二进制文件（推荐用于所有文件类型）
def download_binary(ftp, remote_filename, local_filename=None):
    if local_filename is None:
        local_filename = remote_filename
    
    # 以二进制写模式打开本地文件
    with open(local_filename, "wb") as f:
        # 下载文件，每次写入8192字节
        ftp.retrbinary(f"RETR {remote_filename}", f.write, 8192)
    
    print(f"下载完成: {remote_filename} -> {local_filename}")
    print(f"文件大小: {os.path.getsize(local_filename)} 字节")

# 下载README文件
download_binary(ftp, "README")

# 2. 下载文本文件
def download_text(ftp, remote_filename, local_filename=None):
    if local_filename is None:
        local_filename = remote_filename
    
    with open(local_filename, "w", encoding="utf-8") as f:
        # 逐行下载并写入
        def write_line(line):
            f.write(line + "\n")
        
        ftp.retrlines(f"RETR {remote_filename}", write_line)
    
    print(f"文本文件下载完成: {remote_filename}")

# 下载ANNOUNCE文件
download_text(ftp, "ANNOUNCE")

ftp.quit()
```

### 2.4 文件上传
与下载类似，文件上传也有两种方法：
- `storbinary()`：上传二进制文件
- `storlines()`：上传文本文件

**示例：上传文件**
```python
import ftplib
import os

# 注意：需要一个允许上传的FTP服务器才能测试此代码
try:
    ftp = ftplib.FTP("ftp.example.com")
    ftp.login("username", "password")
    print("登录成功")

    # 1. 上传二进制文件
    def upload_binary(ftp, local_filename, remote_filename=None):
        if remote_filename is None:
            remote_filename = os.path.basename(local_filename)
        
        # 以二进制读模式打开本地文件
        with open(local_filename, "rb") as f:
            # 上传文件
            ftp.storbinary(f"STOR {remote_filename}", f, 8192)
        
        print(f"上传完成: {local_filename} -> {remote_filename}")

    # 上传本地文件
    upload_binary(ftp, "local_file.txt")

    # 2. 上传文本文件
    def upload_text(ftp, local_filename, remote_filename=None):
        if remote_filename is None:
            remote_filename = os.path.basename(local_filename)
        
        with open(local_filename, "r", encoding="utf-8") as f:
            ftp.storlines(f"STOR {remote_filename}", f)
        
        print(f"文本文件上传完成: {local_filename}")

    upload_text(ftp, "local_text.txt")

    ftp.quit()

except ftplib.all_errors as e:
    print(f"上传失败: {e}")
```

### 2.6 异常处理
ftplib定义了多个异常类来处理不同类型的FTP错误，正确的异常处理可以让程序更加健壮。

**示例：完整的异常处理**
```python
import ftplib
import socket

try:
    ftp = ftplib.FTP("ftp.example.com", timeout=10)
    ftp.login("username", "password")
    
    # 执行FTP操作
    ftp.cwd("some_dir")
    ftp.retrbinary("RETR file.txt", open("file.txt", "wb").write)

except ftplib.error_reply as e:
    # 收到意外的服务器回复
    print(f"服务器回复错误: {e}")
except ftplib.error_temp as e:
    # 临时错误（4xx状态码）
    print(f"临时错误: {e}")
except ftplib.error_perm as e:
    # 永久错误（5xx状态码）
    print(f"永久错误: {e}")
except ftplib.error_proto as e:
    # 协议错误
    print(f"协议错误: {e}")
except socket.timeout:
    print("连接超时")
except ConnectionRefusedError:
    print("连接被拒绝")
except Exception as e:
    print(f"其他错误: {e}")
finally:
    try:
        ftp.quit()
    except:
        pass
```

## 三、ftplib进阶部分

### 3.1 FTPS安全连接（FTP over TLS/SSL）
`FTP_TLS`类继承自`FTP`，提供了对TLS/SSL加密的支持，是生产环境中推荐使用的FTP客户端。

**示例：使用FTPS连接服务器**
```python
import ftplib
import ssl

# 1. 基本FTPS连接
try:
    # 创建FTP_TLS对象
    ftps = ftplib.FTP_TLS("ftps.example.com")
    # 登录（控制连接会自动加密）
    ftps.login("username", "password")
    # 切换到保护模式（数据连接也会加密）
    ftps.prot_p()
    
    print("FTPS连接成功")
    print(f"使用的加密套件: {ftps.sock.cipher()}")
    
    # 执行安全的文件传输
    ftps.retrbinary("RETR secure_file.txt", open("secure_file.txt", "wb").write)
    print("安全文件下载完成")
    
    ftps.quit()

except ftplib.all_errors as e:
    print(f"FTPS错误: {e}")

# 2. 自定义SSL上下文（Python 3.14+推荐）
try:
    # 创建安全的SSL上下文
    context = ssl.create_default_context()
    # 强制使用TLS 1.3
    context.minimum_version = ssl.TLSVersion.TLSv1_3
    
    ftps = ftplib.FTP_TLS("ftps.example.com", context=context)
    ftps.login("username", "password")
    ftps.prot_p()
    
    print("TLS 1.3连接成功")
    ftps.quit()

except ftplib.all_errors as e:
    print(f"TLS 1.3连接失败: {e}")

# 3. 禁用证书验证（仅用于测试，生产环境禁止！）
insecure_context = ssl._create_unverified_context()
ftps = ftplib.FTP_TLS("self-signed.example.com", context=insecure_context)
```

### 3.3 断点续传
断点续传是大文件传输中非常重要的功能，可以在传输中断后从断点处继续传输，而不需要重新开始。

**示例：断点续传下载**
```python
import ftplib
import os

def resume_download(ftp, remote_filename, local_filename):
    """支持断点续传的文件下载"""
    # 获取本地文件大小
    local_size = os.path.getsize(local_filename) if os.path.exists(local_filename) else 0
    
    # 获取远程文件大小
    remote_size = ftp.size(remote_filename)
    
    if local_size == remote_size:
        print(f"文件 {local_filename} 已存在且完整，无需下载")
        return
    
    if local_size > remote_size:
        print(f"本地文件大于远程文件，删除本地文件重新下载")
        os.remove(local_filename)
        local_size = 0
    
    # 以追加模式打开本地文件
    with open(local_filename, "ab") as f:
        # 设置文件指针位置
        ftp.sendcmd(f"REST {local_size}")
        # 从断点处开始下载
        ftp.retrbinary(f"RETR {remote_filename}", f.write)
    
    print(f"断点续传完成: {local_filename}")
    print(f"下载了 {remote_size - local_size} 字节")

# 使用示例
try:
    ftp = ftplib.FTP("ftp.example.com")
    ftp.login("username", "password")
    
    resume_download(ftp, "large_file.zip", "large_file.zip")
    
    ftp.quit()

except ftplib.all_errors as e:
    print(f"下载失败: {e}")
```

**示例：断点续传上传**
```python
import ftplib
import os

def resume_upload(ftp, local_filename, remote_filename):
    """支持断点续传的文件上传"""
    # 获取本地文件大小
    local_size = os.path.getsize(local_filename)
    
    # 获取远程文件大小
    try:
        remote_size = ftp.size(remote_filename)
    except ftplib.error_perm:
        remote_size = 0
    
    if local_size == remote_size:
        print(f"文件 {remote_filename} 已存在且完整，无需上传")
        return
    
    if remote_size > local_size:
        print(f"远程文件大于本地文件，删除远程文件重新上传")
        ftp.delete(remote_filename)
        remote_size = 0
    
    # 以读模式打开本地文件
    with open(local_filename, "rb") as f:
        # 移动文件指针到断点处
        f.seek(remote_size)
        # 从断点处开始上传
        ftp.storbinary(f"APPE {remote_filename}", f)
    
    print(f"断点续传上传完成: {local_filename}")
    print(f"上传了 {local_size - remote_size} 字节")
```

### 3.4 递归目录操作
ftplib没有提供内置的递归上传和下载功能，但我们可以自己实现。

**示例：递归下载整个目录**
```python
import ftplib
import os

def download_dir(ftp, remote_dir, local_dir):
    """递归下载整个目录"""
    # 创建本地目录
    os.makedirs(local_dir, exist_ok=True)
    
    # 切换到远程目录
    ftp.cwd(remote_dir)
    
    # 列出远程目录内容
    for item in ftp.nlst():
        # 跳过当前目录和上级目录
        if item in ('.', '..'):
            continue
        
        # 检查是文件还是目录
        try:
            # 尝试切换到该项目，如果成功则是目录
            ftp.cwd(item)
            ftp.cwd('..')
            
            # 递归下载子目录
            download_dir(ftp, item, os.path.join(local_dir, item))
        
        except ftplib.error_perm:
            # 切换失败，说明是文件
            local_file = os.path.join(local_dir, item)
            print(f"下载文件: {item} -> {local_file}")
            
            with open(local_file, "wb") as f:
                ftp.retrbinary(f"RETR {item}", f.write)
    
    # 返回上级目录
    ftp.cwd('..')

# 使用示例
try:
    ftp = ftplib.FTP("ftp.example.com")
    ftp.login("username", "password")
    
    download_dir(ftp, "remote_dir", "local_dir")
    
    ftp.quit()
    print("递归下载完成")

except ftplib.all_errors as e:
    print(f"递归下载失败: {e}")
```

**示例：递归上传整个目录**
```python
import ftplib
import os

def upload_dir(ftp, local_dir, remote_dir):
    """递归上传整个目录"""
    # 创建远程目录
    try:
        ftp.mkd(remote_dir)
    except ftplib.error_perm:
        # 目录已存在
        pass
    
    # 切换到远程目录
    ftp.cwd(remote_dir)
    
    # 遍历本地目录
    for item in os.listdir(local_dir):
        local_path = os.path.join(local_dir, item)
        
        if os.path.isdir(local_path):
            # 递归上传子目录
            upload_dir(ftp, local_path, item)
        
        else:
            # 上传文件
            print(f"上传文件: {local_path} -> {item}")
            with open(local_path, "rb") as f:
                ftp.storbinary(f"STOR {item}", f)
    
    # 返回上级目录
    ftp.cwd('..')
```

import ftplib
import os

def download_with_progress(ftp, remote_filename, local_filename):
    """带进度显示的文件下载"""
    # 获取远程文件大小
    remote_size = ftp.size(remote_filename)
    downloaded_size = 0

        nonlocal downloaded_size
        downloaded_size += len(data)
        f.write(data)

### 3.6 超时与连接池
设置合理的超时时间可以避免程序无限期等待，连接池可以提高频繁连接FTP服务器的性能。

**示例：超时设置与连接池**
```python
import ftplib
import time
from queue import Queue

class FTPPool:
    """简单的FTP连接池"""
    def __init__(self, host, user, passwd, max_connections=5, timeout=10):
        self.host = host
        self.user = user
        self.passwd = passwd
        self.max_connections = max_connections
        self.timeout = timeout
        self.pool = Queue(max_connections)
        
        # 初始化连接池
        for _ in range(max_connections):
            self.pool.put(self._create_connection())
    
    def _create_connection(self):
        """创建新的FTP连接"""
        ftp = ftplib.FTP(self.host, timeout=self.timeout)
        ftp.login(self.user, self.passwd)
        return ftp
    
    def get_connection(self):
        """从连接池获取连接"""
        return self.pool.get()
    
    def return_connection(self, ftp):
        """将连接返回连接池"""
        try:
            # 测试连接是否仍然有效
            ftp.pwd()
            self.pool.put(ftp)
        except:
            # 连接无效，创建新连接
            self.pool.put(self._create_connection())
    
    def close_all(self):
        """关闭所有连接"""
        while not self.pool.empty():
            ftp = self.pool.get()
            try:
                ftp.quit()
            except:
                pass

# 使用示例
pool = FTPPool("ftp.example.com", "username", "password", max_connections=3)

# 从连接池获取连接
ftp = pool.get_connection()
print("获取连接成功")
ftp.retrbinary("RETR file.txt", open("file.txt", "wb").write)

# 将连接返回连接池
pool.return_connection(ftp)

# 关闭所有连接
pool.close_all()
```

## 四、实战案例：FTP文件自动同步工具

### 4.1 项目概述
我们将实现一个功能完整的FTP文件自动同步工具，支持：
- 本地目录与远程FTP服务器的单向同步
- 增量同步（只同步新增和修改的文件）
- 断点续传支持
- 目录递归同步
- 文件删除同步
- 详细的日志记录
- 安全的FTPS连接

### 4.2 完整实现代码
```python
import ftplib
import os
import time
import logging
from datetime import datetime

class FTPFileSynchronizer:
    def __init__(self, host, user, passwd, remote_root, local_root, use_tls=True, timeout=30):
        self.host = host
        self.user = user
        self.passwd = passwd
        self.remote_root = remote_root
        self.local_root = os.path.abspath(local_root)
        self.use_tls = use_tls
        self.timeout = timeout
        self.ftp = None
        
        # 配置日志
        logging.basicConfig(
            level=logging.INFO,
            format='%(asctime)s - %(levelname)s - %(message)s',
            handlers=[
                logging.FileHandler('ftp_sync.log'),
                logging.StreamHandler()
            ]
        )
        self.logger = logging.getLogger(__name__)
    
    def connect(self):
        """连接到FTP服务器"""
        try:
            if self.use_tls:
                import ssl
                context = ssl.create_default_context()
                self.ftp = ftplib.FTP_TLS(self.host, context=context, timeout=self.timeout)
                self.ftp.login(self.user, self.passwd)
                self.ftp.prot_p()
                self.logger.info("FTPS连接成功")
            else:
                self.ftp = ftplib.FTP(self.host, timeout=self.timeout)
                self.ftp.login(self.user, self.passwd)
                self.logger.info("FTP连接成功")
            
            # 切换到远程根目录
            self.ftp.cwd(self.remote_root)
            self.logger.info(f"切换到远程根目录: {self.remote_root}")
            
            return True
        
        except ftplib.all_errors as e:
            self.logger.error(f"连接失败: {e}")
            return False
    
    def disconnect(self):
        """断开FTP连接"""
        if self.ftp:
            try:
                self.ftp.quit()
                self.logger.info("已断开FTP连接")
            except:
                pass
            self.ftp = None
    
    def get_remote_file_list(self, remote_dir=""):
        """获取远程目录的文件列表（包含修改时间和大小）"""
        file_list = {}
        
        try:
            # 保存当前目录
            current_dir = self.ftp.pwd()
            
            # 切换到目标目录
            if remote_dir:
                self.ftp.cwd(remote_dir)
            
            # 使用MLSD命令获取详细文件信息（现代FTP服务器支持）
            try:
                for name, facts in self.ftp.mlsd():
                    if name in ('.', '..'):
                        continue
                    
                    full_path = os.path.join(remote_dir, name) if remote_dir else name
                    
                    if facts['type'] == 'file':
                        # 获取修改时间（转换为时间戳）
                        mtime = datetime.strptime(facts['modify'], "%Y%m%d%H%M%S").timestamp()
                        size = int(facts['size'])
                        file_list[full_path] = {
                            'type': 'file',
                            'mtime': mtime,
                            'size': size
                        }
                    elif facts['type'] == 'dir':
                        file_list[full_path] = {
                            'type': 'dir'
                        }
                        # 递归获取子目录
                        sub_files = self.get_remote_file_list(full_path)
                        file_list.update(sub_files)
            
            except ftplib.error_perm:
                # MLSD命令不支持，使用LIST命令
                self.logger.warning("MLSD命令不支持，使用LIST命令")
                # 这里可以实现基于LIST命令的解析，略复杂，此处省略
            
            # 恢复当前目录
            self.ftp.cwd(current_dir)
        
        except ftplib.all_errors as e:
            self.logger.error(f"获取远程文件列表失败: {e}")
        
        return file_list
    
    def get_local_file_list(self, local_dir=""):
        """获取本地目录的文件列表（包含修改时间和大小）"""
        file_list = {}
        
        full_local_dir = os.path.join(self.local_root, local_dir)
        
        for item in os.listdir(full_local_dir):
            full_local_path = os.path.join(full_local_dir, item)
            relative_path = os.path.join(local_dir, item) if local_dir else item
            
            if os.path.isfile(full_local_path):
                mtime = os.path.getmtime(full_local_path)
                size = os.path.getsize(full_local_path)
                file_list[relative_path] = {
                    'type': 'file',
                    'mtime': mtime,
                    'size': size
                }
            elif os.path.isdir(full_local_path):
                file_list[relative_path] = {
                    'type': 'dir'
                }
                # 递归获取子目录
                sub_files = self.get_local_file_list(relative_path)
                file_list.update(sub_files)
        
        return file_list
    
    def sync_file(self, relative_path):
        """同步单个文件（本地到远程）"""
        local_path = os.path.join(self.local_root, relative_path)
        remote_path = relative_path.replace(os.path.sep, '/')
        
        try:
            # 确保远程目录存在
            remote_dir = os.path.dirname(remote_path)
            if remote_dir:
                # 递归创建远程目录
                dirs = remote_dir.split('/')
                current_dir = ''
                for d in dirs:
                    current_dir = f"{current_dir}/{d}" if current_dir else d
                    try:
                        self.ftp.mkd(current_dir)
                    except ftplib.error_perm:
                        pass
            
            # 上传文件
            self.logger.info(f"同步文件: {local_path} -> {remote_path}")
            
            with open(local_path, "rb") as f:
                self.ftp.storbinary(f"STOR {remote_path}", f)
            
            return True
        
        except ftplib.all_errors as e:
            self.logger.error(f"同步文件失败 {relative_path}: {e}")
            return False
    
    def delete_remote_file(self, relative_path):
        """删除远程文件"""
        remote_path = relative_path.replace(os.path.sep, '/')
        
        try:
            self.ftp.delete(remote_path)
            self.logger.info(f"删除远程文件: {remote_path}")
            return True
        except ftplib.all_errors as e:
            self.logger.error(f"删除远程文件失败 {remote_path}: {e}")
            return False
    
    def sync(self):
        """执行完整的同步操作"""
        self.logger.info("开始同步...")
        
        if not self.connect():
            return False
        
        try:
            # 获取本地和远程文件列表
            local_files = self.get_local_file_list()
            remote_files = self.get_remote_file_list()
            
            # 统计信息
            added = 0
            updated = 0
            deleted = 0
            errors = 0
            
            # 同步新增和修改的文件
            for path, info in local_files.items():
                if info['type'] == 'file':
                    if path not in remote_files:
                        # 新增文件
                        if self.sync_file(path):
                            added += 1
                        else:
                            errors += 1
                    else:
                        # 检查是否需要更新
                        local_mtime = info['mtime']
                        local_size = info['size']
                        remote_mtime = remote_files[path]['mtime']
                        remote_size = remote_files[path]['size']
                        
                        # 如果本地文件更新或大小不同，则同步
                        if local_mtime > remote_mtime or local_size != remote_size:
                            if self.sync_file(path):
                                updated += 1
                            else:
                                errors += 1
            
            # 删除远程存在但本地不存在的文件
            for path, info in remote_files.items():
                if info['type'] == 'file' and path not in local_files:
                    if self.delete_remote_file(path):
                        deleted += 1
                    else:
                        errors += 1
            
            # 输出统计信息
            self.logger.info("同步完成！")
            self.logger.info(f"新增文件: {added}")
            self.logger.info(f"更新文件: {updated}")
            self.logger.info(f"删除文件: {deleted}")
            self.logger.info(f"错误: {errors}")
            
            return True
        
        except Exception as e:
            self.logger.error(f"同步过程中发生错误: {e}")
            return False
        finally:
            self.disconnect()

if __name__ == "__main__":
    # 配置信息
    CONFIG = {
        'host': 'ftps.example.com',
        'user': 'your_username',
        'passwd': 'your_password',
        'remote_root': '/remote/sync/dir',
        'local_root': './local_sync_dir',
        'use_tls': True,
        'timeout': 30
    }
    
    # 创建同步器并执行同步
    synchronizer = FTPFileSynchronizer(**CONFIG)
    synchronizer.sync()
    
    # 可以添加定时任务，例如每小时同步一次
    # while True:
    #     synchronizer.sync()
    #     time.sleep(3600)
```
