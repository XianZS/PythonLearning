# B站Python授课：`tempfile` 标准库——安全高效的临时文件/目录管理

## 课程导入

在编写自动化脚本、数据处理程序或测试代码时，我们经常需要**临时存储数据**（如下载的中间文件、解压的临时素材、计算过程的缓存）。如果手动创建临时文件/目录，容易出现两个问题：

1. **忘记删除**：导致磁盘空间被垃圾文件占用。

2. **安全/冲突问题**：多进程同时运行时，临时文件名重复导致冲突，或敏感数据残留。

`tempfile` 是 Python 专门解决临时文件/目录管理的标准库，能**自动创建、自动清理**临时资源，跨平台且安全，是处理临时数据的首选工具。

---

## 第一部分：临时文件创建（核心功能）

### 核心知识点

`tempfile` 提供两类临时文件创建函数，区别在于文件是否“可见”（有文件名）、是否需要手动管理：

- **`TemporaryFile`**：最“安全”的临时文件，无文件名、关闭后立即删除，适合存储敏感数据。

- **`NamedTemporaryFile`**：有文件名的临时文件，其他进程可通过文件名访问（需配合参数控制删除时机）。

两者均推荐用 **`with`** ** 语句**，自动处理文件关闭和删除，避免资源泄漏。

### 常用函数与示例代码

```Python

import tempfile
import os

# 1. TemporaryFile：无文件名、自动删除（最安全）
print("=== TemporaryFile 示例 ===")
with tempfile.TemporaryFile(mode='w+', encoding='utf-8') as f:
    # 写入数据
    f.write("这是临时文件的内容\n")
    f.write("第二行数据")
    
    # 移动文件指针到开头，读取数据
    f.seek(0)
    content = f.read()
    print("临时文件内容：")
    print(content)

# with 语句结束后，文件已自动关闭并删除，无法再访问
print(f"文件是否还存在？（TemporaryFile无文件名，无法直接验证）\n")

# 2. NamedTemporaryFile：有文件名、可配置删除时机
print("=== NamedTemporaryFile 示例 ===")
# 参数说明：
# - delete=True（默认）：文件关闭后立即删除
# - delete=False：文件关闭后不删除，需手动删除
with tempfile.NamedTemporaryFile(mode='w+', encoding='utf-8', delete=False) as f:
    temp_file_path = f.name  # 获取临时文件路径
    print(f"临时文件路径：{temp_file_path}")
    f.write("这是有名字的临时文件内容")

# 验证文件存在（因为 delete=False）
print(f"with 结束后文件是否存在？{os.path.exists(temp_file_path)}")

# 手动删除文件（delete=False 时必须手动清理！）
os.unlink(temp_file_path)
print(f"手动删除后文件是否存在？{os.path.exists(temp_file_path)}")
```

### 内容讲解

- **`TemporaryFile`**：

    - 无文件名，仅能通过文件对象 `f` 访问，安全性最高（避免其他进程误读）。

    - 模式默认是 `w+b`（二进制读写），处理文本需指定 `w+t` 或 `w+` + `encoding`。

    - `with` 语句结束后**立即自动删除**，无需手动操作。

- **`NamedTemporaryFile`**：

    - 有真实文件名（`f.name` 获取），适合需要和其他程序/进程共享临时文件的场景。

    - `delete=True`（默认）：关闭即删；`delete=False`：需手动用 `os.unlink()` 或 `os.remove()` 删除。

    - ⚠️ Windows 平台注意：`delete=True` 时，其他进程可能无法打开该文件（系统锁定），需设 `delete=False` 并手动处理。

### 应用场景

1. **敏感数据处理**：用 `TemporaryFile` 存储密码、密钥等临时数据，确保关闭后立即删除，无残留。

2. **大文件转换**：处理 CSV/Excel 大文件时，用 `NamedTemporaryFile` 存储中间转换结果，避免占用过多内存。

## 第二部分：临时目录创建（批量临时文件管理）

### 核心知识点

当需要**多个临时文件**（如解压压缩包、生成临时测试数据）时，创建临时目录更方便。`tempfile.TemporaryDirectory` 用于创建临时目录，配合 `with` 语句自动递归删除目录及所有内容。

### 常用函数与示例代码

```Python

import tempfile
import os
from pathlib import Path

print("=== TemporaryDirectory 示例 ===")
# 用 with 语句自动管理临时目录
with tempfile.TemporaryDirectory(prefix='my_temp_', suffix='_data') as temp_dir:
    print(f"临时目录路径：{temp_dir}")
    print(f"目录是否存在？{os.path.exists(temp_dir)}")
    
    # 在临时目录下创建文件/子目录（结合 pathlib 更方便）
    temp_path = Path(temp_dir)
    (temp_path / "input.txt").write_text("临时目录下的文件内容")
    (temp_path / "sub_dir").mkdir()
    (temp_path / "sub_dir" / "output.txt").write_text("子目录下的文件")
    
    # 验证文件创建成功
    print("临时目录内容：", list(temp_path.iterdir()))

# with 语句结束后，临时目录及所有内容自动递归删除
print(f"with 结束后目录是否存在？{os.path.exists(temp_dir)}")
```

### 内容讲解

- **`TemporaryDirectory`** ** 参数**：

    - `prefix`/`suffix`：自定义临时目录名的前缀/后缀（方便识别）。

    - `dir`：指定临时目录的父目录（默认使用系统临时目录，如 Windows 的 `%TEMP%`、macOS/Linux 的 `/tmp`）。

- **自动清理机制**：`with` 语句结束后，即使目录内有文件/子目录，也会**递归强制删除**（无需手动调用 `shutil.rmtree`）。

### 应用场景

1. **压缩包处理**：下载 ZIP/TAR 包后，解压到临时目录处理文件，处理完自动删除，避免残留。

2. **单元测试**：测试文件读写功能时，用临时目录作为测试工作区，测试结束自动清理，不影响真实文件。

## 第三部分：低级临时文件/目录函数（细粒度控制）

### 核心知识点

如果需要**完全手动控制**临时资源的生命周期（不使用 `with` 语句），`tempfile` 提供了低级函数：

- `mkstemp()`：创建临时文件，返回文件描述符和路径（需手动关闭、删除）。

- `mkdtemp()`：创建临时目录，返回目录路径（需手动删除）。

这些函数适合需要长期保留临时资源、或无法使用 `with` 语句的场景，但**务必记得手动清理**。

### 常用函数与示例代码

```Python

import tempfile
import os

print("=== 低级函数 mkstemp 示例 ===")
# mkstemp() 返回 (文件描述符, 文件路径)
fd, temp_file_path = tempfile.mkstemp(suffix='.txt', prefix='manual_')
print(f"临时文件路径：{temp_file_path}")

# 步骤1：通过文件描述符打开文件（或直接用路径 open）
with os.fdopen(fd, 'w+', encoding='utf-8') as f:
    f.write("手动管理的临时文件内容")

# 步骤2：手动删除文件
os.unlink(temp_file_path)
print(f"手动删除后文件是否存在？{os.path.exists(temp_file_path)}\n")

print("=== 低级函数 mkdtemp 示例 ===")
# mkdtemp() 返回临时目录路径
temp_dir_path = tempfile.mkdtemp(prefix='manual_dir_')
print(f"临时目录路径：{temp_dir_path}")

# 在目录下创建文件
with open(os.path.join(temp_dir_path, 'test.txt'), 'w') as f:
    f.write("手动目录下的文件")

# 手动删除目录（需用 shutil.rmtree 递归删除非空目录）
import shutil
shutil.rmtree(temp_dir_path)
print(f"手动删除后目录是否存在？{os.path.exists(temp_dir_path)}")
```

### 内容讲解

- **`mkstemp()`**：

    - 返回的 `fd` 是文件描述符（整数），需用 `os.fdopen(fd, mode)` 转为文件对象，或直接忽略 `fd` 用 `open(temp_file_path)` 打开。

    - 必须手动关闭文件、手动删除文件，否则会残留。

- **`mkdtemp()`**：

    - 仅返回目录路径，需手动用 `shutil.rmtree()` 递归删除（非空目录不能用 `os.rmdir()`）。

- **何时用低级函数**：

    - 临时资源需要跨多个函数/模块使用（无法用 `with` 包裹）。

    - 需要自定义文件打开/关闭逻辑（如特殊的文件锁）。

### 应用场景

1. **后台服务临时缓存**：服务运行期间长期保留临时缓存目录，服务退出时手动清理。

2. **多进程共享临时文件**：用 `mkstemp()` 创建带唯一文件名的临时文件，多个进程通过文件名读写数据。

## 课程总结与实战练习

### 核心回顾

1. **临时文件**：

    - `TemporaryFile`：无文件名、自动删除，适合敏感数据。

    - `NamedTemporaryFile`：有文件名、可配置删除时机，适合跨进程共享。

2. **临时目录**：

    - `TemporaryDirectory`：配合 `with` 自动递归删除，适合批量临时文件管理。

3. **低级函数**：

    - `mkstemp()`/`mkdtemp()`：手动管理生命周期，务必记得清理。

4. **通用原则**：优先用 `with` 语句，自动处理资源关闭和删除，避免泄漏。

### 实战练习

结合 `tempfile`、`shutil` 和 `pathlib`，写一个“压缩包处理脚本”，实现以下功能：

1. 创建一个临时目录。

2. 在临时目录下生成 3 个测试文件（`test1.txt`、`test2.csv`、`test3.json`），写入简单内容。

3. 用 `shutil.make_archive()` 将临时目录压缩为 `test_archive.zip`。

4. 再创建一个新的临时目录，将 `test_archive.zip` 解压到其中。

5. 遍历解压后的临时目录，打印所有文件的名称和内容。

6. 验证所有临时资源是否自动清理（或手动清理）。
