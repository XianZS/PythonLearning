# B站Python授课：`csv` 标准库——表格数据处理的轻量级利器

## 课程导入

**CSV（Comma-Separated Values，逗号分隔值）** 是最通用的表格数据交换格式：它用纯文本存储表格（行和列），Excel、WPS 等工具能直接打开，几乎所有编程语言都支持处理，广泛应用于数据导出、报表生成、简单数据存储等场景。

Python 内置的 `csv` 库专门用于读写 CSV 文件，无需安装第三方库，能处理大多数 CSV 相关需求。本节课我们将重点学习它的核心功能。

---

## 第一部分：核心概念与基础读取

### 核心知识点

1. **CSV 基本结构**：

    - 每一行代表一条数据（记录），行内的列用**分隔符**（默认逗号 `,`）分隔。

    - 第一行通常是**表头**（列名），例如：

        ```Plain Text
        
        name,age,city
        张三,25,西安
        李四,30,北京
        ```

2. **`csv.reader`**：基础读取类，将 CSV 每一行解析为**列表**，通过索引访问列数据。

3. **避坑要点**：

    - 文件打开需用 `with` 语句，自动关闭文件。

    - Windows 下读取需注意编码（推荐 `utf-8-sig`，处理 BOM 头）。

### 示例代码

```Python

import csv

# 准备测试 CSV 文件（先手动创建一个 students.csv，内容如上）
# 1. 基础读取：csv.reader
print("=== 基础读取 ===")
with open("students.csv", "r", encoding="utf-8-sig", newline="") as f:
    # 创建 reader 对象
    reader = csv.reader(f)
    # 读取表头（第一行）
    headers = next(reader)
    print(f"表头：{headers}")
    # 遍历剩余行
    for row in reader:
        print(f"行数据：{row}")
        print(f"姓名：{row[0]}，年龄：{row[1]}，城市：{row[2]}")
```

### 内容讲解

- `csv.reader(f)`：返回一个**迭代器**，每次迭代返回一行数据（列表）。

- `next(reader)`：读取迭代器的第一行（表头），避免将表头当作数据处理。

- `encoding="utf-8-sig"`：`utf-8-sig` 能自动去除 Windows 记事本添加的 BOM（字节顺序标记），避免表头出现乱码（如 `\ufeffname`）。

- `newline=""`：CSV 文件读取时推荐加，避免处理换行符时出现问题。

### 应用场景

1. **简单数据导入**：读取小体积 CSV 文件，将数据转为列表处理。

2. **快速查看 CSV 内容**：遍历打印 CSV 行，检查数据格式。

## 第二部分：按列名读取（`DictReader`）

### 核心知识点

`csv.reader` 用索引访问列（如 `row[0]`）不够直观，`csv.DictReader` 会将每一行解析为**字典**，用**表头作为键**，直接通过列名访问数据，代码更易读。

### 示例代码

```Python

import csv

print("=== DictReader 按列名读取 ===")
with open("students.csv", "r", encoding="utf-8-sig", newline="") as f:
    # 创建 DictReader 对象
    reader = csv.DictReader(f)
    # 获取表头（通过 fieldnames 属性）
    print(f"表头：{reader.fieldnames}")
    # 遍历行（每行是一个字典）
    for row in reader:
        print(f"行数据（字典）：{row}")
        print(f"姓名：{row['name']}，年龄：{row['age']}，城市：{row['city']}")
```

### 内容讲解

- `csv.DictReader(f)`：默认将第一行作为字典的键（表头），后续行作为值。

- `reader.fieldnames`：获取表头列表，可手动修改（如 CSV 无表头时，需通过 `fieldnames` 参数指定）。

- 优势：通过列名访问数据，即使列顺序调整，代码也无需修改，可读性和可维护性更好。

### 应用场景

1. **业务数据处理**：处理带表头的 CSV（如用户信息表、订单表），通过列名提取特定字段。

2. **数据过滤**：根据列名条件筛选数据（如筛选 `city` 为“西安”的行）。

## 第三部分：基础写入（`csv.writer`）

### 核心知识点

`csv.writer` 用于将数据写入 CSV 文件，核心方法：

- `writerow(row)`：写入**一行**数据（row 是列表或元组）。

- `writerows(rows)`：写入**多行**数据（rows 是列表的列表/元组的列表）。

- 避坑要点：文件打开模式用 `w`，需加 `newline=""`（避免 Windows 下出现空行）。

### 示例代码

```Python

import csv

# 1. 基础写入：csv.writer
print("=== 基础写入 ===")
# 准备数据：表头 + 多行数据
headers = ["product", "price", "stock"]
data = [
    ["Python入门", 99, 100],
    ["CSV教程", 0, 500],
    ["Java进阶", 199, 50]
]

with open("products.csv", "w", encoding="utf-8-sig", newline="") as f:
    # 创建 writer 对象
    writer = csv.writer(f)
    # 写入表头
    writer.writerow(headers)
    # 写入多行数据
    writer.writerows(data)

print("已写入 products.csv")
```

### 内容讲解

- `newline=""`：**关键参数**！Windows 下如果不加，CSV 每行之间会多一个空行（因为 Python 会自动添加 `\r\n`，而 CSV 本身也有换行符）。

- `writerows(data)`：比循环调用 `writerow()` 更高效，适合批量写入数据。

- `encoding="utf-8-sig"`：写入时用 `utf-8-sig`，Excel 打开时中文不会乱码（纯 `utf-8` 可能导致 Excel 中文乱码）。

### 应用场景

1. **生成简单报表**：将程序中的列表数据导出为 CSV 报表。

2. **数据转换**：将其他格式（如 JSON）的数据转为 CSV 存储。

## 第四部分：按字典写入（`DictWriter`）

### 核心知识点

如果数据是**字典列表**（如 `[{"name": "张三", "age": 25}, ...]`），用 `csv.DictWriter` 更方便，它能直接将字典写入 CSV，需指定 `fieldnames` 参数（表头）。

### 示例代码

```Python

import csv

print("=== DictWriter 按字典写入 ===")
# 准备数据：字典列表
data = [
    {"name": "王五", "age": 28, "city": "上海"},
    {"name": "赵六", "age": 22, "city": "广州"},
    {"name": "孙七", "age": 35, "city": "深圳"}
]
# 指定表头（必须与字典的键一致）
headers = ["name", "age", "city"]

with open("new_students.csv", "w", encoding="utf-8-sig", newline="") as f:
    # 创建 DictWriter 对象，指定 fieldnames
    writer = csv.DictWriter(f, fieldnames=headers)
    # 写入表头（必须调用！）
    writer.writeheader()
    # 写入多行字典数据
    writer.writerows(data)

print("已写入 new_students.csv")
```

### 内容讲解

- `fieldnames`：**必填参数**，指定 CSV 的表头，顺序决定列的顺序，字典的键必须包含在 `fieldnames` 中。

- `writer.writeheader()`：必须显式调用，否则 CSV 没有表头。

- 优势：处理结构化字典数据时，无需手动将字典转为列表，代码更简洁。

### 应用场景

1. **API 数据导出**：将 API 返回的 JSON 字典列表直接写入 CSV。

2. **数据库查询结果导出**：将数据库查询的字典格式结果转为 CSV。

## 第五部分：常见应用场景实战

### 场景1：数据清洗（过滤与修改）

```Python

import csv

# 需求：读取 products.csv，过滤库存 > 50 的商品，修改价格为原价的 9 折，写入新 CSV
print("=== 数据清洗 ===")
with open("products.csv", "r", encoding="utf-8-sig", newline="") as f_in, \
     open("filtered_products.csv", "w", encoding="utf-8-sig", newline="") as f_out:
    
    reader = csv.DictReader(f_in)
    writer = csv.DictWriter(f_out, fieldnames=reader.fieldnames)
    writer.writeheader()
    
    for row in reader:
        # 类型转换（CSV 读取的都是字符串）
        price = float(row["price"])
        stock = int(row["stock"])
        
        # 过滤库存 > 50
        if stock > 50:
            # 修改价格为 9 折
            row["price"] = round(price * 0.9, 2)
            writer.writerow(row)

print("已生成 filtered_products.csv")
```

### 场景2：自定义分隔符（如 TSV，制表符分隔）

```Python

import csv

# 需求：读取/写入 TSV 文件（制表符 \t 分隔）
print("=== TSV 处理 ===")
# 写入 TSV
data = [["a", "b", "c"], ["1", "2", "3"]]
with open("data.tsv", "w", encoding="utf-8", newline="") as f:
    # 指定 delimiter="\t"
    writer = csv.writer(f, delimiter="\t")
    writer.writerows(data)

# 读取 TSV
with open("data.tsv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f, delimiter="\t")
    for row in reader:
        print(row)
```

## 实战案例：简单的学生成绩管理系统

### 功能需求

1. 用 CSV 文件 `scores.csv` 存储学生成绩（包含 `id`、`name`、`subject`、`score`）。

2. 支持**添加成绩**（自动生成唯一 `id`）。

3. 支持**查看所有成绩**。

4. 支持**计算某科目的平均分**。

5. 所有操作后自动保存 CSV 文件。

### 完整代码

```Python

import csv
from pathlib import Path

class ScoreManager:
    def __init__(self, csv_path="scores.csv"):
        self.csv_path = Path(csv_path)
        self.fieldnames = ["id", "name", "subject", "score"]
        self.scores = []
        self.load_or_init()

    def load_or_init(self):
        """加载 CSV 或初始化空数据"""
        if self.csv_path.exists():
            with open(self.csv_path, "r", encoding="utf-8-sig", newline="") as f:
                reader = csv.DictReader(f)
                self.scores = list(reader)
                # 将 id 和 score 转为整数/浮点数
                for s in self.scores:
                    s["id"] = int(s["id"])
                    s["score"] = float(s["score"])
        else:
            self.scores = []
            self.save_csv()

    def save_csv(self):
        """保存数据到 CSV"""
        with open(self.csv_path, "w", encoding="utf-8-sig", newline="") as f:
            writer = csv.DictWriter(f, fieldnames=self.fieldnames)
            writer.writeheader()
            # 写入时将 id 和 score 转回字符串（DictWriter 会自动处理，但显式转更安全）
            for s in self.scores:
                row = s.copy()
                row["id"] = str(row["id"])
                row["score"] = str(row["score"])
                writer.writerow(row)

    def get_next_id(self):
        """获取下一个可用 ID"""
        if not self.scores:
            return 1
        return max(s["id"] for s in self.scores) + 1

    def add_score(self, name, subject, score):
        """添加成绩"""
        new_score = {
            "id": self.get_next_id(),
            "name": name,
            "subject": subject,
            "score": float(score)
        }
        self.scores.append(new_score)
        self.save_csv()
        print(f"已添加：{name} - {subject} - {score}")

    def list_scores(self):
        """查看所有成绩"""
        if not self.scores:
            print("暂无成绩")
            return
        print("=== 成绩列表 ===")
        for s in self.scores:
            print(f"ID：{s['id']} | 姓名：{s['name']} | 科目：{s['subject']} | 分数：{s['score']}")

    def calc_average(self, subject):
        """计算某科目的平均分"""
        subject_scores = [s["score"] for s in self.scores if s["subject"] == subject]
        if not subject_scores:
            print(f"暂无 {subject} 的成绩")
            return
        avg = sum(subject_scores) / len(subject_scores)
        print(f"{subject} 的平均分：{round(avg, 2)}")

# 测试使用
if __name__ == "__main__":
    manager = ScoreManager()
    # 添加成绩
    manager.add_score("张三", "数学", 85)
    manager.add_score("李四", "数学", 92)
    manager.add_score("张三", "语文", 78)
    # 查看所有成绩
    manager.list_scores()
    # 计算数学平均分
    manager.calc_average("数学")
```

### 代码讲解

1. **`ScoreManager`** ** 类**：封装所有成绩管理功能，结构清晰。

2. **`load_or_init()`**：加载 CSV 时将 `id` 和 `score` 转为数值类型（CSV 读取的都是字符串），方便后续计算。

3. **`save_csv()`**：保存时将数值转回字符串，确保 CSV 格式正确。

4. **`get_next_id()`**：通过最大 ID + 1 生成唯一 ID，避免重复。

5. **测试部分**：演示添加、查看、计算平均分功能，运行后生成 `scores.csv`。
