# Python `statistics` 标准库详细教学文档（适配 Python 3.14）

## 一、基础概念

`statistics` 是 Python 3.4 版本首次引入、**Python 3.14 最新稳定版持续优化**的内置数理统计标准库，提供了符合业界统计规范的描述性统计、双变量分析、概率分布拟合等核心功能，是 Python 生态中零依赖、轻量级、易上手的统计分析工具。

### 核心说明

1. **核心定位**：原生内置无需安装第三方库，API 设计贴合统计教学逻辑，完美适配小到中等规模数据集的统计需求，是 Python 入门、教学演示、脚本化快速统计、轻量数据分析的首选工具；大规模高性能矩阵统计推荐使用`numpy`/`scipy`。

2. **数据要求**：绝大多数函数接收**数值型可迭代对象**（列表、元组、生成器、数组等），非数值输入、空数据集会抛出`statistics.StatisticsError`异常。

3. **版本兼容**：文档所有函数均标注最低 Python 版本要求，重点覆盖 Python 3.10+ 核心新增功能，同步适配 Python 3.14 的性能优化与边界修复。

4. **精度保障**：针对浮点数运算做了专项优化，相比手动实现的统计公式，大幅降低累计精度误差，符合统计学计算规范。

### 导入方式

```python
import statistics  # 推荐：全局导入，避免命名冲突
# 或
from statistics import mean, median, stdev, NormalDist  # 按需导入高频函数
```

## 二、常见基础用法

### 1. 集中趋势度量（核心入门功能）

集中趋势是统计学最基础的概念，用于描述数据的中心位置，是 B 站教学入门必讲的核心内容，覆盖所有主流均值、中位数、众数相关函数。

|函数|核心说明|适用场景|版本要求|
|---|---|---|---|
|`statistics.mean(data)`|算术平均数，所有数据之和除以数据个数|普通对称分布、无极端值的数值数据|Python 3.4+|
|`statistics.fmean(data, weights=None)`|快速浮点数算术平均数，支持加权计算，返回固定 float 类型，计算速度远快于`mean`|大数据量、浮点型数据、加权平均场景|Python 3.8+，weights 参数 3.11 + 新增|
|`statistics.geometric_mean(data)`|几何平均数，n 个数据乘积的 n 次方根|增长率、收益率、比率类数据（如年化收益、环比增速）|Python 3.8+|
|`statistics.harmonic_mean(data, weights=None)`|调和平均数，数据个数除以倒数之和|速率、平均速度、性价比类数据（如平均时速、单位成本）|Python 3.6+，weights 参数 3.10 + 新增|
|`statistics.median(data)`|中位数，数据排序后中间位置的数值，偶数个数据取中间两个数的平均值|存在极端值、偏态分布的数据，抗异常值能力强|Python 3.4+|
|`statistics.median_low(data)`|低中位数，偶数个数据时取中间两个数中较小的那个|离散数据、需要取数据集中已存在的值的场景|Python 3.4+|
|`statistics.median_high(data)`|高中位数，偶数个数据时取中间两个数中较大的那个|离散数据、需要取数据集中已存在的值的场景|Python 3.4+|
|`statistics.median_grouped(data, interval=1)`|分组中位数，基于连续数据的分组插值计算|连续型数据、分组统计场景|Python 3.4+|
|`statistics.mode(data)`|众数，数据集中出现次数最多的数值，多个众数时返回第一个出现的|分类数据、离散数据的高频值统计|Python 3.4+，3.8 + 优化多众数处理逻辑|
|`statistics.multimode(data)`|多众数，返回数据集中所有出现次数最多的数值列表|存在多个并列高频值的场景|Python 3.8+|

**示例代码**：

```python
from statistics import *

# 测试数据集：班级学生数学成绩
scores = [85, 92, 78, 92, 88, 76, 92, 85, 90, 85]
# 增长率数据：某产品5个月的月度环比增速
growth_rates = [1.05, 1.08, 1.12, 1.07, 1.09]
# 速度数据：同一段路程，3次行驶的时速
speeds = [60, 80, 120]

# 1. 算术平均数
print(f"算术平均分: {mean(scores):.1f}")
# 输出: 算术平均分: 86.3
# 2. 快速加权平均分（权重：平时成绩30%，期末70%）
print(f"加权平均分: {fmean([80, 90], weights=[0.3, 0.7]):.1f}")
# 输出: 加权平均分: 87.0

# 3. 几何平均数（计算平均月度增速）
print(f"平均月度增速: {geometric_mean(growth_rates):.2%}")
# 输出: 平均月度增速: 108.19%

# 4. 调和平均数（计算平均时速）
print(f"平均行驶时速: {harmonic_mean(speeds):.1f} km/h")
# 输出: 平均行驶时速: 80.0 km/h

# 5. 中位数
print(f"成绩中位数: {median(scores)}")
# 输出: 成绩中位数: 86.5
print(f"成绩低中位数: {median_low(scores)}")
# 输出: 成绩低中位数: 85
print(f"成绩高中位数: {median_high(scores)}")
# 输出: 成绩高中位数: 88

# 6. 众数
print(f"成绩众数: {mode(scores)}")
# 输出: 成绩众数: 92
print(f"成绩所有众数: {multimode(scores)}")
# 输出: 成绩所有众数: [92, 85]
```

> 新手避坑：
> 
> 1. 几何平均数**禁止输入负数和 0**，否则会抛出异常；
> 
> 2. 调和平均数**禁止输入 0**，且仅适用于正数值；
> 
> 3. 存在极端异常值时，优先使用中位数而非算术平均数，避免结果被极端值带偏。
>

### 2. 离散程度度量

离散程度用于描述数据的波动、分散情况，是统计分析的核心基础，覆盖方差、标准差、分位数等高频函数。

|函数|核心说明|版本要求|
|---|---|---|
|`statistics.pvariance(data, mu=None)`|总体方差，衡量总体数据的离散程度，除以数据个数 n|Python 3.4+|
|`statistics.pstdev(data, mu=None)`|总体标准差，总体方差的平方根，与原数据单位一致|Python 3.4+|
|`statistics.variance(data, xbar=None)`|样本方差，用于通过样本推断总体，除以 n-1（无偏估计）|Python 3.4+|
|`statistics.stdev(data, xbar=None)`|样本标准差，样本方差的平方根，最常用的离散程度指标|Python 3.4+|
|`statistics.quantiles(data, *, n=4, method=&#39;exclusive&#39;)`|分位数计算，默认计算四分位数，n 为分位数个数，支持多种计算方法|Python 3.10+，method 参数 3.11 + 新增，3.14 优化边界处理|

**示例代码**：

```python
from statistics import *

# 测试数据集：两个班级的成绩，对比波动情况
class_a = [82, 85, 88, 90, 86, 84, 89, 87, 83, 86]
class_b = [60, 72, 85, 92, 98, 78, 88, 95, 65, 97]

# 1. 总体标准差（已知数据为全年级所有学生，即总体）
print(f"A班成绩总体标准差: {pstdev(class_a):.1f}")
# 输出: A班成绩总体标准差: 2.4
print(f"B班成绩总体标准差: {pstdev(class_b):.1f}")
# 输出: B班成绩总体标准差: 13.0

# 2. 样本标准差（数据为抽样的10个学生，用于推断全年级）
print(f"A班成绩样本标准差: {stdev(class_a):.1f}")
# 输出: A班成绩样本标准差: 2.5

# 3. 四分位数计算（Python 3.10+）
# 计算class_b的四分位数，method='inclusive'适合包含边界的整数数据
quartiles = quantiles(class_b, n=4, method='inclusive')
print(f"B班成绩四分位数: Q1={quartiles[0]}, Q2(中位数)={quartiles[1]}, Q3={quartiles[2]}")
# 输出: B班成绩四分位数: Q1=73.5, Q2(中位数)=86.5, Q3=95.75

# 4. 十分位数计算
deciles = quantiles(class_b, n=10, method='inclusive')
print(f"B班成绩十分位数: {deciles}")
```

> 新手避坑：
> 
> 1. **核心区分**：数据是**全部总体**用`pstdev/pvariance`；数据是**抽样样本**（用于推断总体）用`stdev/variance`，90% 的新手会混淆这两个函数；
> 
> 2. 数据量小于 2 时，样本方差 / 标准差会抛出异常；数据量小于 1 时，总体方差 / 标准差会抛出异常；
> 
> 3. `quantiles`函数的`method`参数需根据数据类型选择：连续型数据用默认`exclusive`，离散整数型数据用`inclusive`。
> 
>

### 3. 基础异常处理

`statistics`库的所有统计函数，在输入不合法时会抛出统一的`StatisticsError`异常，教学中必须讲解基础异常处理，避免程序崩溃。

**示例代码**：

```python
from statistics import mean, StatisticsError

# 空数据集异常处理
empty_data = []
try:
    avg = mean(empty_data)
    print(f"平均值: {avg}")
except StatisticsError as e:
    print(f"计算失败: {e}")
# 输出: 计算失败: mean requires at least one data point

# 非数值数据异常处理
invalid_data = [85, "90", 78, None]
try:
    avg = mean(invalid_data)
    print(f"平均值: {avg}")
except TypeError as e:
    print(f"数据类型错误: {e}")
```

## 三、常见进阶用法

### 1. 双变量统计分析（Python 3.10+ 核心新增）

这是 Python 3.10 版本后`statistics`库的重磅功能，无需第三方库即可实现双变量的相关性、协方差、线性回归分析，是 B 站进阶教学的核心亮点，完美适配数据分析、科研入门场景。

|函数|核心说明|版本要求|
|---|---|---|
|`statistics.covariance(x, y)`|协方差，衡量两个变量的线性协同变化趋势，正值为正相关，负值为负相关|Python 3.10+|
|`statistics.correlation(x, y, *, method=&#39;pearson&#39;)`|相关系数，默认皮尔逊相关系数，取值范围 [-1,1]，绝对值越大线性相关性越强|Python 3.10+，method 参数 3.12 + 新增|
|`statistics.linear_regression(x, y, *, proportional=False)`|最小二乘法线性回归，拟合`y = slope * x + intercept`，返回斜率 slope 和截距 intercept|Python 3.10+，proportional 参数 3.12 + 新增|

**示例代码**：

```python
from statistics import *

# 测试数据集：10个学生的每周学习时长（x）和期末成绩（y）
study_hours = [5, 8, 10, 12, 6, 15, 7, 9, 11, 13]
exam_scores = [72, 78, 85, 90, 75, 96, 76, 82, 88, 92]

# 1. 协方差计算
cov = covariance(study_hours, exam_scores)
print(f"学习时长与成绩的协方差: {cov:.2f}")
# 输出: 学习时长与成绩的协方差: 21.18（正值，正相关）

# 2. 皮尔逊相关系数
corr = correlation(study_hours, exam_scores)
print(f"学习时长与成绩的相关系数: {corr:.3f}")
# 输出: 学习时长与成绩的相关系数: 0.991（极强线性正相关）

# 3. 线性回归拟合
slope, intercept = linear_regression(study_hours, exam_scores)
print(f"回归方程: 成绩 = {slope:.2f} * 学习时长 + {intercept:.2f}")
# 输出: 回归方程: 成绩 = 2.11 * 学习时长 + 61.49

# 用回归方程做预测
predict_hour = 14
predict_score = slope * predict_hour + intercept
print(f"每周学习{predict_hour}小时，预测成绩: {predict_score:.1f}")
# 输出: 每周学习14小时，预测成绩: 91.0
```

> 进阶避坑：
> 
> 1. 协方差和相关系数计算，要求两个变量的**数据长度必须完全一致**，否则抛出异常；
> 
> 2. 相关系数接近 0，仅代表无线性相关，不代表无其他非线性相关；
> 
> 3. 相关不等于因果，切勿仅凭相关系数得出因果结论。
> 
>

### 2. 正态分布高级操作（Python 3.8+）

`statistics.NormalDist`是 Python 内置的正态分布类，3.14 版本做了性能优化，无需`scipy`即可实现正态分布的 PDF、CDF、分位数、抽样、拟合等全功能操作，是概率统计、模拟实验的核心工具。

|方法 / 属性|核心说明|
|---|---|
|`NormalDist(mu=0.0, sigma=1.0)`|构造函数，创建均值为 mu、标准差为 sigma 的正态分布对象|
|`NormalDist.from_data(data)`|类方法，从数据集拟合正态分布，自动计算均值和标准差|
|`.mu`|分布的均值|
|`.sigma`|分布的标准差|
|`.pdf(x)`|概率密度函数，计算 x 处的概率密度|
|`.cdf(x)`|累积分布函数，计算随机变量≤x 的概率|
|`.inv_cdf(p)`|逆累积分布函数（分位数函数），计算累积概率 p 对应的 x 值|
|`.quantiles(n=4)`|计算分布的 n 分位数|
|`.samples(n, seed=None)`|生成 n 个符合该分布的随机样本|
|`+、-、*、/`|支持正态分布的算术运算，符合正态分布的运算规则|

**示例代码**：

```python
from statistics import NormalDist

# 1. 创建正态分布：某年级数学成绩，均值80，标准差10
score_dist = NormalDist(mu=80, sigma=10)

# 2. 基础属性
print(f"分布均值: {score_dist.mu}, 标准差: {score_dist.sigma}")
# 输出: 分布均值: 80.0, 标准差: 10.0

# 3. 概率计算：成绩低于60分的概率（不及格率）
fail_prob = score_dist.cdf(60)
print(f"不及格率: {fail_prob:.2%}")
# 输出: 不及格率: 2.28%

# 4. 概率计算：成绩高于90分的概率（优秀率）
excellent_prob = 1 - score_dist.cdf(90)
print(f"优秀率: {excellent_prob:.2%}")
# 输出: 优秀率: 15.87%

# 5. 分位数计算：80%的学生成绩不超过多少分？
score_80 = score_dist.inv_cdf(0.8)
print(f"80%分位数: {score_80:.1f}")
# 输出: 80%分位数: 88.4

# 6. 从数据拟合正态分布
data = [82, 78, 85, 90, 76, 88, 81, 79, 84, 86]
fit_dist = NormalDist.from_data(data)
print(f"拟合分布：均值={fit_dist.mu:.1f}, 标准差={fit_dist.sigma:.1f}")
# 输出: 拟合分布：均值=82.9, 标准差=4.3

# 7. 生成随机样本
samples = fit_dist.samples(5, seed=123)
print(f"生成的5个样本: {[round(s,1) for s in samples]}")

# 8. 正态分布运算：两个班级成绩相加，均值相加，方差相加
class1 = NormalDist(78, 8)
class2 = NormalDist(82, 7)
total_dist = class1 + class2
print(f"总成绩分布：均值={total_dist.mu}, 标准差={total_dist.sigma:.2f}")
# 输出: 总成绩分布：均值=160.0, 标准差=10.63
```

### 3. 进阶异常值识别与稳健统计

实战中数据往往存在异常值，结合`statistics`库的函数可实现工业界常用的 IQR 异常值识别，以及稳健统计量的应用，是进阶教学的必备内容。

**示例代码**：

```python
from statistics import median, quantiles

# 带异常值的成绩数据（存在2个极端低分）
scores = [85, 92, 78, 88, 90, 22, 86, 91, 18, 84]

# 1. IQR法识别异常值
quartiles = quantiles(scores, method='inclusive')
q1, q3 = quartiles[0], quartiles[2]
iqr = q3 - q1
# 异常值边界
lower_bound = q1 - 1.5 * iqr
upper_bound = q3 + 1.5 * iqr

print(f"异常值下界: {lower_bound:.1f}, 上界: {upper_bound:.1f}")
outliers = [s for s in scores if s < lower_bound or s > upper_bound]
print(f"识别到的异常值: {outliers}")
# 输出: 识别到的异常值: [22, 18]

# 2. 稳健统计对比：算术平均数 vs 中位数
from statistics import mean
print(f"含异常值的算术平均数: {mean(scores):.1f}")
# 输出: 含异常值的算术平均数: 73.4（被异常值严重拉低）
print(f"含异常值的中位数: {median(scores):.1f}")
# 输出: 含异常值的中位数: 85.0（抗异常值，符合数据真实中心）
```

## 四、实战案例：学生成绩综合统计分析系统

本案例综合运用`statistics`库的全量核心功能，实现一个贴近教学、可直接复用的成绩分析系统，完美适配 B 站课程的实战演示环节，所有代码可在 Python 3.14 中直接运行。

### 功能需求

1. 基础统计：计算班级成绩的集中趋势、离散程度核心指标；

2. 相关性分析：分析学习时长与成绩的相关性，构建线性回归预测模型；

3. 分布拟合：用正态分布拟合成绩数据，计算不及格率、优秀率的理论值；

4. 异常值识别：自动识别成绩中的极端异常值；

5. 输出完整的统计分析报告。

### 完整代码

```python
from statistics import *

class ScoreAnalysisSystem:
    def __init__(self, student_data):
        """
        初始化分析系统
        :param student_data: 学生数据，格式为 [(学习时长, 成绩), ...]
        """
        self.student_data = student_data
        # 拆分学习时长和成绩两个序列
        self.study_hours = [item[0] for item in student_data]
        self.scores = [item[1] for item in student_data]

    def base_statistics(self):
        """计算基础描述性统计指标"""
        print("="*60)
        print("【一、基础描述性统计报告】")
        print(f"有效样本数: {len(self.scores)}")
        print(f"算术平均分: {mean(self.scores):.1f}")
        print(f"成绩中位数: {median(self.scores):.1f}")
        print(f"成绩众数: {mode(self.scores)}")
        print(f"最高分: {max(self.scores)}, 最低分: {min(self.scores)}")
        print(f"极差: {max(self.scores) - min(self.scores)}")
        print(f"总体标准差: {pstdev(self.scores):.1f}")
        print(f"样本标准差: {stdev(self.scores):.1f}")
        
        # 四分位数
        quartiles = quantiles(self.scores, method='inclusive')
        print(f"四分位数: Q1={quartiles[0]:.1f}, Q2={quartiles[1]:.1f}, Q3={quartiles[2]:.1f}")
        print("="*60)

    def correlation_regression(self):
        """相关性分析与线性回归"""
        print("n【二、相关性与回归分析报告】")
        # 计算相关系数
        corr = correlation(self.study_hours, self.scores)
        print(f"学习时长与成绩的皮尔逊相关系数: {corr:.3f}")
        
        # 相关性解读
        if abs(corr) >= 0.8:
            corr_level = "极强线性相关"
        elif abs(corr) >= 0.5:
            corr_level = "中等线性相关"
        elif abs(corr) >= 0.3:
            corr_level = "弱线性相关"
        else:
            corr_level = "无线性相关"
        print(f"相关性水平: {corr_level}")

        # 线性回归
        slope, intercept = linear_regression(self.study_hours, self.scores)
        print(f"线性回归方程: 成绩 = {slope:.2f} * 学习时长 + {intercept:.2f}")
        
        # 预测示例
        predict_hours = 16
        predict_score = slope * predict_hours + intercept
        print(f"预测：每周学习{predict_hours}小时，期末成绩约为 {predict_score:.1f}")
        print("="*60)

    def distribution_analysis(self):
        """正态分布拟合与概率分析"""
        print("n【三、成绩分布分析报告】")
        # 拟合正态分布
        score_dist = NormalDist.from_data(self.scores)
        print(f"拟合正态分布：均值={score_dist.mu:.1f}, 标准差={score_dist.sigma:.1f}")
        
        # 概率计算
        fail_prob = score_dist.cdf(60)  # 不及格率
        pass_prob = 1 - score_dist.cdf(60)  # 及格率
        excellent_prob = 1 - score_dist.cdf(90)  # 90分以上优秀率
        print(f"理论不及格率: {fail_prob:.2%}")
        print(f"理论及格率: {pass_prob:.2%}")
        print(f"理论优秀率(90分以上): {excellent_prob:.2%}")
        
        # 分位数
        score_90 = score_dist.inv_cdf(0.9)
        print(f"90%的学生成绩不超过: {score_90:.1f}")
        print("="*60)

    def outlier_detection(self):
        """异常值识别"""
        print("n【四、异常值识别报告】")
        quartiles = quantiles(self.scores, method='inclusive')
        q1, q3 = quartiles[0], quartiles[2]
        iqr = q3 - q1
        lower_bound = q1 - 1.5 * iqr
        upper_bound = q3 + 1.5 * iqr
        
        outliers = [score for score in self.scores if score < lower_bound or score > upper_bound]
        print(f"异常值判定边界: [{lower_bound:.1f}, {upper_bound:.1f}]")
        if outliers:
            print(f"识别到的异常值: {outliers}")
        else:
            print("未识别到异常值")
        print("="*60)
```

## 五、总结与避坑指南

### 核心总结

- `statistics` 是 Python 内置的零依赖统计库，完美适配 Python 3.14 最新版本，覆盖从入门级描述性统计到进阶的回归分析、分布拟合全场景需求；

- 核心优势：原生内置无需安装、API 贴合统计教学逻辑、计算符合业界规范、上手门槛极低，是 Python 统计入门、B 站教学、轻量数据分析的首选工具；

- 适用边界：适合小到中等规模数据集，大规模高性能矩阵运算推荐使用`numpy`/`scipy`，复杂机器学习建模推荐使用`sklearn`。

### 新手高频避坑指南

1. **样本与总体统计量混淆**：数据为全量总体用`pstdev/pvariance`，数据为抽样样本用`stdev/variance`，这是统计入门最高频的错误；

2. **均值类型误用**：增长率数据用几何平均数、速率数据用调和平均数，切勿所有场景都用算术平均数；

3. **空数据 / 不合法数据未处理**：所有统计函数前需校验数据非空、数值类型合法，捕获`StatisticsError`异常避免程序崩溃；

4. **相关系数过度解读**：相关不等于因果，高相关仅代表变量存在线性关联，不代表存在因果关系；

5. **正态分布滥用**：仅当数据符合正态分布特征时，才可使用`NormalDist`拟合，切勿对偏态严重的数据强行使用正态分布分析；

6. **版本兼容问题**：`covariance`、`correlation`、`linear_regression`等函数仅支持 Python 3.10+，低版本 Python 无法使用，需提前确认运行环境。
