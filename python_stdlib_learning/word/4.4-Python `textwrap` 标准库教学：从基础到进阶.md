# Python `textwrap` 标准库教学文档

## 一、基础概念与使用场景

### 1. 基础概念

`textwrap` 是 Python 标准库中专注于**文本格式化与排版**的模块，提供了一套简洁高效的工具，用于处理文本的换行、缩进、填充、截断、空白清理等操作，能让原始文本在终端、文档、日志等场景中呈现更规范、美观的布局。

它的核心能力是“自动化文本排版”：无需手动计算每行长度、调整缩进，通过预设规则即可批量处理文本，是命令行工具开发、文档生成、UI文本展示的得力助手。

### 2. 使用场景

- **命令行工具输出**：格式化帮助信息、错误提示，让长文本自动适应终端宽度；

- **文档与报告生成**：统一段落缩进、换行规则，处理代码示例的空白；

- **日志格式化**：截断过长的日志消息，统一日志条目缩进；

- **UI文本展示**：在GUI/网页文本框中自动换行，避免文本溢出；

- **代码文档优化**：清理三引号字符串的公共缩进，让docstring更整洁。

## 二、基础用法

### 2.1 `textwrap.fill()`：文本自动填充换行

将长文本按指定宽度自动拆分为多行，并通过换行符`n`连接成一个字符串，是最常用的文本换行工具。

#### 语法规范

```Python
textwrap.fill(
    text, width=70,
    initial_indent='', subsequent_indent='',
    expand_tabs=True, replace_whitespace=True,
    drop_whitespace=True, break_long_words=True,
    break_on_hyphens=True, tabsize=8,
    max_lines=None, placeholder=' [...]'
)
```

- `text`：待处理的原始文本；

- `width`：每行的最大宽度（默认70字符）；

- `initial_indent`：首行的缩进字符串（默认空）；

- `subsequent_indent`：后续行的缩进字符串（默认空）。

#### 示例代码

```Python
import textwrap

# 长文本示例
long_text = "Python的textwrap模块提供了丰富的文本格式化功能，包括自动换行、缩进调整、空白清理等，能让文本在各种场景下呈现更美观的布局。"

# 基础填充：宽度50
filled_text = textwrap.fill(long_text, width=50)
print("基础填充（宽度50）：")
print(filled_text)
print("n" + "-"*50 + "n")

# 带缩进的填充：首行缩进2空格，后续行缩进4空格
indented_filled = textwrap.fill(
    long_text, width=50,
    initial_indent="  ",
    subsequent_indent="    "
)
print("带缩进的填充：")
print(indented_filled)
```

**输出结果**：

```Plaintext
基础填充（宽度50）：
Python的textwrap模块提供了丰富的文本格式化功能，包括自动换行、缩进调整、空白清理等，能让文本在各种场景下呈现更美观的布局。

--------------------------------------------------

带缩进的填充：
  Python的textwrap模块提供了丰富的文本格式化功能，
    包括自动换行、缩进调整、空白清理等，能让文本在
    各种场景下呈现更美观的布局。
```

### 2.2 `textwrap.wrap()`：文本拆分为行列表

与`fill()`类似，但返回的是**拆分后的行列表**（不包含换行符），适合需要单独处理每一行的场景。

#### 语法规范

参数与`fill()`完全一致，仅返回值不同：返回`list[str]`，每个元素是一行文本。

#### 示例代码

```Python
import textwrap

long_text = "Python的textwrap模块提供了丰富的文本格式化功能，包括自动换行、缩进调整、空白清理等。"

# 拆分为行列表
wrapped_lines = textwrap.wrap(long_text, width=40)
print("拆分后的行列表：")
for i, line in enumerate(wrapped_lines, 1):
    print(f"行{i}: {line}")
```

**输出结果**：

```Plaintext
拆分后的行列表：
行1: Python的textwrap模块提供了丰富的文本格式化功能，
行2: 包括自动换行、缩进调整、空白清理等。
```

### 2.3 `textwrap.shorten()`：文本截断与占位

将长文本截断到指定宽度，并在末尾添加占位符（默认`[...]`），适合展示摘要、限制日志长度等场景。

#### 语法规范

```Python
textwrap.shorten(
    text, width,
    placeholder=' [...]',
    expand_tabs=True,
    replace_whitespace=True,
    drop_whitespace=True
)
```

- `width`：截断后的最大总宽度（包含占位符长度）；

- `placeholder`：截断后的占位符（默认`[...]`）。

#### 示例代码

```Python
import textwrap

long_text = "这是一段非常长的文本，包含了很多内容，我们需要将它截断到指定长度，同时保持可读性。"

# 基础截断：宽度30
shortened1 = textwrap.shorten(long_text, width=30)
print("基础截断（宽度30）：")
print(shortened1)
print("n" + "-"*30 + "n")

# 自定义占位符：宽度25，占位符为"..."
shortened2 = textwrap.shorten(long_text, width=25, placeholder="...")
print("自定义占位符截断：")
print(shortened2)
```

**输出结果**：

```Plaintext
基础截断（宽度30）：
这是一段非常长的文本，包含了很多内容 [...]

------------------------------

自定义占位符截断：
这是一段非常长的文本，包含了...
```

### 2.4 `textwrap.dedent()`：清理公共前导空白

去除文本中**每一行的公共前导空白**（即所有行共有的缩进），特别适合处理三引号字符串（如函数docstring、多行代码示例），让文本保持原始逻辑的同时去除多余缩进。

#### 语法规范

```Python
textwrap.dedent(text)
```

- `text`：待处理的文本（通常是三引号字符串）。

#### 示例代码

```Python
import textwrap

# 三引号字符串，带有公共缩进
def demo_function():
    """
    这是一个演示函数的文档字符串
        - 第一点说明
        - 第二点说明
    """
    pass

# 未处理的docstring
print("未处理的docstring：")
print(repr(demo_function.__doc__))
print("n" + "-"*50 + "n")

# 用dedent处理后的docstring
dedented_doc = textwrap.dedent(demo_function.__doc__)
print("dedent处理后的docstring：")
print(repr(dedented_doc))
print("n实际输出：")
print(dedented_doc)
```

**输出结果**：

```Plaintext
未处理的docstring：
'n    这是一个演示函数的文档字符串n        - 第一点说明n        - 第二点说明n    '

--------------------------------------------------

dedent处理后的docstring：
'n这是一个演示函数的文档字符串n    - 第一点说明n    - 第二点说明n'

实际输出：

这是一个演示函数的文档字符串
    - 第一点说明
    - 第二点说明
```

## 三、进阶用法

### 3.1 `textwrap.indent()`：给文本添加行前缀

给文本的**每一行**添加指定的前缀（如缩进、引用标记`&gt;`等），支持通过`predicate`函数控制哪些行需要添加前缀。

#### 语法规范

```Python
textwrap.indent(text, prefix, predicate=None)
```

- `text`：待处理的文本；

- `prefix`：要添加的前缀字符串（如`&#34; &#34;`、`&#34;&gt; &#34;`）；

- `predicate`：可选函数，接收一行文本（不含末尾换行符），返回`True`表示该行需要添加前缀（默认所有非空行都添加）。

#### 示例代码

```Python
import textwrap

# 原始文本
original_text = """这是第一段文本。
这是第二段文本。

这是第四段文本（第三段是空行）。"""

# 基础缩进：给所有非空行添加"  "前缀
indented1 = textwrap.indent(original_text, "  ")
print("基础缩进（非空行加2空格）：")
print(indented1)
print("n" + "-"*50 + "n")

# 自定义predicate：给所有行（包括空行）添加"> "前缀
def indent_all_lines(line):
    return True  # 所有行都添加前缀

indented2 = textwrap.indent(original_text, "> ", predicate=indent_all_lines)
print("引用格式（所有行加> ）：")
print(indented2)
```

**输出结果**：

```Plaintext
基础缩进（非空行加2空格）：
  这是第一段文本。
  这是第二段文本。

  这是第四段文本（第三段是空行）。

--------------------------------------------------

引用格式（所有行加> ）：
> 这是第一段文本。
> 这是第二段文本。
> 
> 这是第四段文本（第三段是空行）。
```

### 3.2 `TextWrapper` 类：自定义复杂排版规则

当需要**复用排版规则**或调整更细粒度的参数时，`TextWrapper` 类是更好的选择——它允许你创建一个“排版器对象”，预设所有参数后批量处理文本。

#### 语法规范

1. 初始化排版器：

```Python
wrapper = textwrap.TextWrapper(
    width=70,
    initial_indent='',
    subsequent_indent='',
    expand_tabs=True,
    replace_whitespace=True,
    drop_whitespace=True,
    break_long_words=True,
    break_on_hyphens=True,
    tabsize=8,
    max_lines=None,
    placeholder=' [...]'
)
```

2. 核心方法：

    - `wrapper.fill(text)`：返回填充后的字符串（等价于`textwrap.fill()`）；

    - `wrapper.wrap(text)`：返回行列表（等价于`textwrap.wrap()`）。

#### 常用细粒度参数说明

|参数|作用|
|---|---|
|`expand_tabs`|是否将制表符`t`替换为空格（默认`True`，替换数量由`tabsize`决定）|
|`replace_whitespace`|是否将其他空白字符（如`r`、`f`）替换为空格（默认`True`）|
|`drop_whitespace`|是否删除行首行尾的空白（默认`True`）|
|`break_long_words`|是否打断超过`width`的长单词（默认`True`，设为`False`则长单词不换行）|
|`break_on_hyphens`|是否在连字符`-`处优先换行（默认`True`，适合英文单词）|

#### 示例代码：自定义排版器

```Python
import textwrap

# 创建自定义排版器
custom_wrapper = textwrap.TextWrapper(
    width=45,
    initial_indent="📌 ",  # 首行带emoji前缀
    subsequent_indent="   ",  # 后续行缩进3空格
    break_long_words=False,  # 不打断长单词
    expand_tabs=True,
    tabsize=4
)

# 待处理文本（包含制表符和长单词）
text_with_tabs = "Python的textwrap模块t提供了TextWrapper类，支持自定义复杂的排版规则，比如处理supercalifragilisticexpialidocious这样的长单词。"

# 批量处理文本
filled1 = custom_wrapper.fill(text_with_tabs)
print("自定义排版器输出1：")
print(filled1)
print("n" + "-"*45 + "n")

# 复用排版器处理另一段文本
another_text = "你可以创建多个TextWrapper实例，分别用于不同的排版场景，比如帮助信息、日志消息、代码注释等。"
filled2 = custom_wrapper.fill(another_text)
print("自定义排版器输出2：")
print(filled2)
```

**输出结果**：

```Plaintext
自定义排版器输出1：
📌 Python的textwrap模块    提供了TextWrapper类，支持自定义复杂的排版规则，比如处理supercalifragilisticexpialidocious这样的长单词。

---------------------------------------------

自定义排版器输出2：
📌 你可以创建多个TextWrapper实例，分别用于不同的排版场景，比如帮助信息、日志消息、代码注释等。
```

### 3.3 控制换行策略：长单词与连字符

通过`break_long_words`和`break_on_hyphens`参数，可以灵活控制文本的换行规则，尤其适合处理英文文本或包含长标识符的代码文本。

#### 示例代码

```Python
import textwrap

# 包含长单词和连字符的英文文本
english_text = "This is a text with a supercalifragilisticexpialidocious word and a high-performance component."

# 场景1：默认规则（打断长单词，在连字符处换行）
wrapper1 = textwrap.TextWrapper(width=30)
print("默认换行规则：")
print(wrapper1.fill(english_text))
print("n" + "-"*30 + "n")

# 场景2：不打断长单词，但在连字符处换行
wrapper2 = textwrap.TextWrapper(width=30, break_long_words=False)
print("不打断长单词：")
print(wrapper2.fill(english_text))
print("n" + "-"*30 + "n")

# 场景3：不打断长单词，也不在连字符处换行
wrapper3 = textwrap.TextWrapper(width=30, break_long_words=False, break_on_hyphens=False)
print("不打断长单词+不在连字符处换行：")
print(wrapper3.fill(english_text))
```

**输出结果**：

```Plaintext

performance component.

不打断长单词：
This is a text with a
supercalifragilisticexpialidocious
word and a high-
performance component.

------------------------------

不打断长单词+不在连字符处换行：
This is a text with a
supercalifragilisticexpialidocious
word and a high-performance
component.
```

### 3.4 `max_lines` 与 `placeholder`：限制最大行数

在`fill()`、`wrap()`或`TextWrapper`中使用`max_lines`参数，可以限制文本的最大行数，超出部分会被截断并添加占位符。

#### 示例代码

```Python
import textwrap

long_text = "这是第一行内容。这是第二行内容。这是第三行内容。这是第四行内容。这是第五行内容。"

# 限制最大3行，超出部分用"（更多内容省略）"占位
wrapper = textwrap.TextWrapper(
    width=20,
    max_lines=3,
    placeholder="（更多内容省略）"
)
filled = wrapper.fill(long_text)
print("限制最大行数：")
print(filled)
```

**输出结果**：

```Plaintext
限制最大行数：
这是第一行内容。这是
第二行内容。这是第三
行内容。（更多内容省略）
```

## 四、实战案例：命令行工具帮助信息格式化器

### 1. 需求描述

开发一个**命令行工具帮助信息格式化器**，用于生成美观、规范的CLI帮助文档，包含以下功能：

- 格式化工具名称与版本（居中展示）；

- 格式化工具描述（自动填充换行，首行带emoji）；

- 格式化参数列表（参数名与说明对齐，说明自动换行）；

- 格式化代码示例（清理公共缩进，添加`$`前缀）；

- 截断过长的参数说明（可选）。

### 2. 完整代码实现

```Python
import textwrap

class CLIHelpFormatter:
    def __init__(self, tool_name, version, width=60):
        self.tool_name = tool_name
        self.version = version
        self.width = width
        # 预定义不同场景的TextWrapper
        self.desc_wrapper = textwrap.TextWrapper(
            width=width,
            initial_indent="📝 ",
            subsequent_indent="   "
        )
        self.param_wrapper = textwrap.TextWrapper(
            width=width - 15,  # 预留参数名的宽度
            initial_indent=" " * 15,
            subsequent_indent=" " * 15
        )

    def format_header(self):
        """格式化工具名称与版本（居中）"""
        header = f"{self.tool_name} v{self.version}"
        return header.center(self.width) + "n" + "="*self.width + "n"

    def format_description(self, description):
        """格式化工具描述"""
        return self.desc_wrapper.fill(description) + "n"

    def format_parameters(self, params):
        """
        格式化参数列表
        params: 列表，每个元素是 (参数名, 参数说明) 的元组
        """
        result = "参数列表：n"
        for param_name, param_desc in params:
            # 先添加参数名（左对齐，占14字符）
            result += f"  {param_name:<12}"
            # 格式化参数说明
            wrapped_desc = self.param_wrapper.fill(param_desc)
            # 如果说明只有一行，直接跟在参数名后面；否则换行
            if "n" in wrapped_desc:
                result += "n" + wrapped_desc + "n"
            else:
                result += wrapped_desc.lstrip() + "n"
        return result

    def format_example(self, example_code):
        """格式化代码示例"""
        # 先清理公共缩进
        dedented_code = textwrap.dedent(example_code).strip()
        # 给每一行添加"$ "前缀（命令行提示符）
        indented_code = textwrap.indent(dedented_code, "$ ", predicate=lambda line: True)
        return "使用示例：n" + indented_code + "n"

    def generate_full_help(self, description, params, example):
        """生成完整的帮助信息"""
        help_text = self.format_header()
        help_text += "n" + self.format_description(description)
        help_text += "n" + self.format_parameters(params)
        help_text += "n" + self.format_example(example)
        return help_text

# 实战案例使用
if __name__ == "__main__":
    # 1. 初始化格式化器
    formatter = CLIHelpFormatter(tool_name="FileSync", version="1.0.0", width=60)

    # 2. 准备帮助信息内容
    tool_description = "一个轻量级的文件同步工具，支持本地目录与远程服务器之间的文件上传、下载与增量同步，操作简单且性能高效。"

    tool_params = [
        ("-s, --source", "源目录路径，指定要同步的本地或远程目录。"),
        ("-d, --dest", "目标目录路径，指定同步的目的地。"),
        ("-i, --interval", "增量同步的时间间隔（秒），默认300秒。如果设置为0，则只执行一次同步。"),
        ("-v, --verbose", "启用详细日志输出，展示同步过程中的所有操作细节。")
    ]

    tool_example = """
    # 本地目录同步到远程服务器
    filesync -s /local/path -d user@server:/remote/path

    # 启用增量同步（每5分钟同步一次）
    filesync -s /local/path -d /backup/path -i 300 -v
    """

    # 3. 生成并打印完整帮助信息
    full_help = formatter.generate_full_help(tool_description, tool_params, tool_example)
    print(full_help)
```

                 增量同步的时间间隔（秒），默认300秒。如果设

## 五、总结

- `textwrap` 的核心价值在于**自动化文本排版**，通过`fill()`、`wrap()`、`dedent()`、`indent()`等函数快速解决文本换行、缩进、空白清理等问题；

- 对于复杂排版需求，`TextWrapper` 类支持复用规则、细粒度控制换行策略、制表符处理等，是批量处理文本的首选；

- 实战中，`textwrap` 常与命令行工具、文档生成、日志系统结合，能显著提升文本的可读性与专业性。
