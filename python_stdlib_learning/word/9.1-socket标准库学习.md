# Python 3.14.0 socket标准库完整学习文档

## 一、Socket核心概念
### 1.1 什么是Socket
Socket（套接字）是**操作系统提供的网络通信抽象层**，它是应用层与传输层（TCP/UDP）之间的接口。Socket将复杂的网络通信过程封装成简单的API，使开发者无需关注底层网络协议的实现细节。

在Python 3.14.0中，`socket`标准库是网络编程的基石，它直接映射了BSD Socket API，同时提供了面向对象的封装和Pythonic的接口。

### 1.2 Socket通信的本质
Socket通信本质上是**进程间通信（IPC）的一种特殊形式**，区别在于：
- 普通IPC只能在同一台机器的进程间通信
- Socket可以在**不同机器**的进程间通信（通过网络）

每个Socket由**IP地址+端口号**唯一标识，称为"端点"。两个端点之间建立连接后，就可以进行双向数据传输。

### 1.3 主要Socket类型
Python 3.14.0支持的核心Socket类型：

| 类型 | 协议 | 特点 | 适用场景 |
|------|------|------|----------|
| `SOCK_STREAM` | TCP | 面向连接、可靠、字节流、有序、无重复 | 文件传输、网页浏览、邮件 |
| `SOCK_DGRAM` | UDP | 无连接、不可靠、数据报、无序、可能重复 | 视频直播、游戏、DNS查询 |
| `SOCK_RAW` | IP | 直接访问IP层，可自定义协议头 | 网络嗅探、ping实现、协议开发 |

### 1.4 地址族
- `AF_INET`：IPv4协议（最常用）
- `AF_INET6`：IPv6协议
- `AF_UNIX`：UNIX域套接字，用于同一机器上的高性能进程间通信

### 2.2 TCP基础通信
TCP是**面向连接**的协议，通信前必须先建立连接，通信后必须释放连接。

#### 2.2.1 TCP服务器端
```python
import socket

# 1. 创建TCP套接字
server_sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. 设置端口复用（重要！避免服务器重启时端口被占用）
server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

# 3. 绑定地址和端口
# 绑定到所有可用接口：'' 或 '0.0.0.0'
# 仅本地访问：'127.0.0.1'
server_sock.bind(('0.0.0.0', 8888))

# 4. 开始监听
# backlog参数：操作系统挂起的最大连接数
server_sock.listen(5)
print(f"TCP服务器已启动，监听端口8888")

# 5. 接受客户端连接（阻塞等待）
# 返回新的套接字（用于与该客户端通信）和客户端地址
client_sock, client_addr = server_sock.accept()
print(f"客户端 {client_addr} 已连接")

# 6. 数据收发
try:
    # 接收数据：参数是缓冲区大小（字节）
    data = client_sock.recv(1024)
    if data:
        print(f"收到数据：{data.decode('utf-8')}")
        # 发送响应
        client_sock.send(f"服务器已收到：{data.decode('utf-8')}".encode('utf-8'))
finally:
    # 7. 关闭连接
    client_sock.close()
    server_sock.close()
```

#### 2.2.2 TCP客户端
```python
import socket

# 1. 创建TCP套接字
client_sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

try:
    # 2. 连接服务器
    client_sock.connect(('127.0.0.1', 8888))
    
    # 3. 发送数据
    client_sock.send("你好，服务器！".encode('utf-8'))
    
    # 4. 接收响应
    response = client_sock.recv(1024)
    print(f"服务器响应：{response.decode('utf-8')}")
finally:
    # 5. 关闭连接
    client_sock.close()
```

### 2.3 UDP基础通信
UDP是**无连接**的协议，通信前不需要建立连接，每个数据报都是独立的。

#### 2.3.1 UDP服务器端
```python
import socket

# 1. 创建UDP套接字
server_sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

# 2. 绑定地址和端口
server_sock.bind(('0.0.0.0', 8888))
print(f"UDP服务器已启动，监听端口8888")

# 3. 接收数据（阻塞等待）
# 返回数据和发送方地址
data, client_addr = server_sock.recvfrom(1024)
print(f"收到来自 {client_addr} 的数据：{data.decode('utf-8')}")

# 4. 发送响应
server_sock.sendto("你好，UDP客户端！".encode('utf-8'), client_addr)

# 5. 关闭套接字
server_sock.close()
```

#### 2.3.2 UDP客户端
```python
import socket

# 1. 创建UDP套接字
client_sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

# 2. 发送数据（不需要连接）
client_sock.sendto("你好，UDP服务器！".encode('utf-8'), ('127.0.0.1', 8888))

# 3. 接收响应
data, server_addr = client_sock.recvfrom(1024)
print(f"服务器响应：{data.decode('utf-8')}")

# 4. 关闭套接字
client_sock.close()
```

### 2.4 基础API速查表
| API | 说明 |
|-----|------|
| `socket(family, type, proto=0)` | 创建套接字 |
| `bind((host, port))` | 绑定地址和端口 |
| `listen(backlog)` | 开始监听TCP连接 |
| `accept()` | 接受TCP连接，返回(client_sock, addr) |
| `connect((host, port))` | 连接到TCP服务器 |
| `recv(bufsize)` | 接收TCP数据，返回bytes |
| `send(bytes)` | 发送TCP数据，返回发送的字节数 |
| `recvfrom(bufsize)` | 接收UDP数据，返回(data, addr) |
| `sendto(bytes, addr)` | 发送UDP数据到指定地址 |
| `close()` | 关闭套接字，释放资源 |
| `getpeername()` | 获取连接的远程地址 |
| `getsockname()` | 获取本地套接字地址 |

## 三、进阶部分：高级特性与高性能编程
### 3.1 多客户端TCP服务器
基础TCP服务器一次只能处理一个客户端，实际应用中需要支持多客户端并发。最直接的方式是使用**多线程**：

```python
import socket
import threading

def handle_client(client_sock, client_addr):
    """处理单个客户端的通信"""
    print(f"新客户端连接：{client_addr}")
    try:
        while True:
            data = client_sock.recv(1024)
            if not data:  # 客户端关闭连接
                break
            print(f"收到 {client_addr}：{data.decode('utf-8')}")
            client_sock.send(f"回显：{data.decode('utf-8')}".encode('utf-8'))
    except Exception as e:
        print(f"客户端 {client_addr} 异常：{e}")
    finally:
        print(f"客户端 {client_addr} 断开连接")
        client_sock.close()

def main():
    server_sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind(('0.0.0.0', 8888))
    server_sock.listen(10)
    print("多线程TCP服务器已启动")
    
    try:
        while True:
            client_sock, client_addr = server_sock.accept()
            # 创建新线程处理客户端
            thread = threading.Thread(target=handle_client, args=(client_sock, client_addr))
            thread.daemon = True  # 守护线程，主线程退出时自动退出
            thread.start()
    except KeyboardInterrupt:
        print("\n服务器正在关闭...")
    finally:
        server_sock.close()

if __name__ == "__main__":
    main()
```

### 3.2 Socket选项与超时设置
通过`setsockopt()`可以精细控制Socket的行为：

```python
import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 1. 端口复用（最常用）
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

# 2. 端口快速重用（Linux 3.9+支持，Python 3.14+）
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEPORT, 1)

# 3. 设置接收缓冲区大小（默认通常是8192或65536）
s.setsockopt(socket.SOL_SOCKET, socket.SO_RCVBUF, 131072)  # 128KB

# 4. 设置发送缓冲区大小
s.setsockopt(socket.SOL_SOCKET, socket.SO_SNDBUF, 131072)

# 5. 设置TCP_NODELAY（禁用Nagle算法，降低延迟）
s.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)

# 6. 设置超时时间（秒）
s.settimeout(5.0)  # 所有阻塞操作最多等待5秒

# 7. 获取Socket选项
reuse_addr = s.getsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR)
print(f"端口复用状态：{reuse_addr}")

s.close()
```

### 3.3 非阻塞Socket与IO多路复用
多线程在高并发场景下会有线程创建和切换的开销，**IO多路复用**是更高效的解决方案。Python 3.14.0推荐使用`selectors`模块（对底层`select`/`poll`/`epoll`的高级封装）：

```python
import socket
import selectors

# 创建默认的selector（自动选择系统最优的IO多路复用机制）
sel = selectors.DefaultSelector()

def accept(sock, mask):
    """处理新连接"""
    conn, addr = sock.accept()
    print(f"新客户端连接：{addr}")
    conn.setblocking(False)  # 设置为非阻塞
    # 注册读事件，当有数据可读时调用read函数
    sel.register(conn, selectors.EVENT_READ, read)

def read(conn, mask):
    """处理客户端数据"""
    try:
        data = conn.recv(1024)
        if data:
            print(f"收到数据：{data.decode('utf-8')}")
            conn.send(f"服务器已收到：{data.decode('utf-8')}".encode('utf-8'))
        else:
            # 客户端关闭连接
            print(f"客户端断开连接")
            sel.unregister(conn)
            conn.close()
    except ConnectionResetError:
        print(f"客户端强制断开连接")
        sel.unregister(conn)
        conn.close()

def main():
    server_sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind(('0.0.0.0', 8888))
    server_sock.listen(100)
    server_sock.setblocking(False)
    
    # 注册服务器套接字的读事件（新连接到来）
    sel.register(server_sock, selectors.EVENT_READ, accept)
    
    print("IO多路复用TCP服务器已启动")
    
    try:
        while True:
            # 等待事件发生（阻塞）
            events = sel.select(timeout=None)
            for key, mask in events:
                callback = key.data
                callback(key.fileobj, mask)
    except KeyboardInterrupt:
        print("\n服务器正在关闭...")
    finally:
        sel.close()
        server_sock.close()

if __name__ == "__main__":
    main()
```

**性能优势**：IO多路复用可以在**单个线程**中处理数千个并发连接，资源消耗远低于多线程。

### 3.4 异常处理与资源管理
网络编程中异常非常常见，必须妥善处理：

```python
import socket

def safe_tcp_client(host, port, message):
    sock = None
    try:
        sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        sock.settimeout(3.0)
        sock.connect((host, port))
        sock.sendall(message.encode('utf-8'))  # sendall确保所有数据都被发送
        response = sock.recv(1024)
        return response.decode('utf-8')
    except socket.timeout:
        print("连接超时")
    except ConnectionRefusedError:
        print("连接被拒绝，服务器可能未启动")
    except ConnectionResetError:
        print("连接被重置")
    except OSError as e:
        print(f"操作系统错误：{e}")
    finally:
        if sock is not None:
            sock.close()  # 确保套接字被关闭
    return None

# 使用示例
result = safe_tcp_client('127.0.0.1', 8888, "测试消息")
if result:
    print(f"响应：{result}")
```

**Python 3.14.0最佳实践**：使用上下文管理器（with语句）自动管理Socket资源：
```python
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
    sock.connect(('127.0.0.1', 8888))
    sock.sendall("你好".encode('utf-8'))
    response = sock.recv(1024)
    print(response.decode('utf-8'))
# 离开with块时，sock会自动关闭
```

## 四、实战案例：多人在线聊天室
我们将实现一个功能完整的多人在线聊天室，支持：
- 多个客户端同时连接
- 用户名注册
- 广播消息
- 系统通知（用户加入/离开）
- 优雅退出

### 4.1 聊天室服务器
```python
import socket
import selectors
from typing import Dict

class ChatServer:
    def __init__(self, host: str = '0.0.0.0', port: int = 8888):
        self.host = host
        self.port = port
        self.server_sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        self.server_sock.bind((host, port))
        self.server_sock.listen(100)
        self.server_sock.setblocking(False)
        
        self.sel = selectors.DefaultSelector()
        self.sel.register(self.server_sock, selectors.EVENT_READ, self.accept)
        
        # 存储客户端信息：{套接字: 用户名}
        self.clients: Dict[socket.socket, str] = {}
        
        print(f"聊天室服务器已启动在 {host}:{port}")
    
    def accept(self, sock: socket.socket, mask: int):
        """处理新客户端连接"""
        conn, addr = sock.accept()
        conn.setblocking(False)
        self.sel.register(conn, selectors.EVENT_READ, self.handle_client)
        self.clients[conn] = None  # 初始用户名为None
        print(f"新连接来自 {addr}，等待用户名...")
    
    def broadcast(self, message: str, exclude: socket.socket = None):
        """广播消息给所有客户端"""
        encoded_msg = message.encode('utf-8')
        for client in list(self.clients.keys()):
            if client != exclude:
                try:
                    client.sendall(encoded_msg)
                except Exception as e:
                    print(f"发送消息给 {self.clients[client]} 失败：{e}")
                    self.remove_client(client)
    
    def remove_client(self, client: socket.socket):
        """移除客户端并清理资源"""
        username = self.clients.get(client, "未知用户")
        print(f"客户端 {username} 断开连接")
        
        if client in self.clients:
            del self.clients[client]
        
        try:
            self.sel.unregister(client)
        except KeyError:
            pass
        
        try:
            client.close()
        except Exception:
            pass
        
        # 广播用户离开消息
        if username:
            self.broadcast(f"【系统】{username} 离开了聊天室")
    
    def handle_client(self, conn: socket.socket, mask: int):
        """处理客户端消息"""
        try:
            data = conn.recv(1024)
            if not data:
                self.remove_client(conn)
                return
            
            message = data.decode('utf-8').strip()
            username = self.clients[conn]
            
            if username is None:
                # 第一条消息是用户名
                if not message:
                    self.remove_client(conn)
                    return
                
                # 检查用户名是否已存在
                if message in self.clients.values():
                    conn.sendall("【系统】用户名已被使用，请换一个".encode('utf-8'))
                    return
                
                self.clients[conn] = message
                print(f"客户端 {conn.getpeername()} 注册为：{message}")
                conn.sendall(f"【系统】欢迎 {message} 加入聊天室！".encode('utf-8'))
                self.broadcast(f"【系统】{message} 加入了聊天室", exclude=conn)
            else:
                # 普通聊天消息
                if message.lower() == 'exit':
                    self.remove_client(conn)
                    return
                
                full_message = f"{username}: {message}"
                print(full_message)
                self.broadcast(full_message, exclude=conn)
        
        except ConnectionResetError:
            self.remove_client(conn)
        except Exception as e:
            print(f"处理客户端消息时出错：{e}")
            self.remove_client(conn)
    
    def run(self):
        """运行服务器主循环"""
        try:
            while True:
                events = self.sel.select()
                for key, mask in events:
                    callback = key.data
                    callback(key.fileobj, mask)
        except KeyboardInterrupt:
            print("\n服务器正在关闭...")
        finally:
            # 关闭所有客户端连接
            for client in list(self.clients.keys()):
                try:
                    client.sendall("【系统】服务器即将关闭".encode('utf-8'))
                    client.close()
                except Exception:
                    pass
            
            self.sel.close()
            self.server_sock.close()
            print("服务器已关闭")

if __name__ == "__main__":
    server = ChatServer()
    server.run()
```

### 4.2 聊天室客户端
```python
import socket
import threading
import sys

class ChatClient:
    def __init__(self, host: str = '127.0.0.1', port: int = 8888):
        self.host = host
        self.port = port
        self.sock = None
        self.running = False
    
    def receive_messages(self):
        """接收服务器消息的线程函数"""
        while self.running:
            try:
                data = self.sock.recv(1024)
                if not data:
                    print("\n与服务器断开连接")
                    self.running = False
                    break
                print(data.decode('utf-8'))
            except Exception as e:
                if self.running:
                    print(f"\n接收消息失败：{e}")
                    self.running = False
                    break
    
    def send_messages(self):
        """发送消息的主线程函数"""
        while self.running:
            try:
                message = input()
                if not self.running:
                    break
                
                if message.lower() == 'exit':
                    self.sock.sendall(message.encode('utf-8'))
                    self.running = False
                    break
                
                if message:
                    self.sock.sendall(message.encode('utf-8'))
            except KeyboardInterrupt:
                self.running = False
                break
            except Exception as e:
                print(f"发送消息失败：{e}")
                self.running = False
                break
    
    def run(self):
        """运行客户端"""
        try:
            self.sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            self.sock.settimeout(5.0)
            self.sock.connect((self.host, self.port))
            self.running = True
            
            # 输入用户名
            username = input("请输入你的用户名：").strip()
            while not username:
                username = input("用户名不能为空，请重新输入：").strip()
            
            self.sock.sendall(username.encode('utf-8'))
            
            # 启动接收消息线程
            receive_thread = threading.Thread(target=self.receive_messages)
            receive_thread.daemon = True
            receive_thread.start()
            
            print("已连接到聊天室，输入 'exit' 退出")
            self.send_messages()
            
        except socket.timeout:
            print("连接服务器超时")
        except ConnectionRefusedError:
            print("无法连接到服务器，请检查服务器是否已启动")
        except Exception as e:
            print(f"发生错误：{e}")
        finally:
            self.running = False
            if self.sock:
                try:
                    self.sock.close()
                except Exception:
                    pass
            print("客户端已退出")

if __name__ == "__main__":
    client = ChatClient()
    client.run()
```

## 五、学习总结与进阶方向
### 5.1 核心知识点回顾
- Socket是网络通信的抽象接口，由IP地址+端口号唯一标识
- TCP是面向连接的可靠协议，UDP是无连接的不可靠协议
- 多线程适合简单并发场景，IO多路复用适合高并发场景
- 必须妥善处理网络异常和资源释放

### 5.2 Python 3.14.0 Socket库新增特性
- 支持在`socket()`创建时直接设置`SOCK_NONBLOCK`和`SOCK_CLOEXEC`标志
- 增强了IPv6支持
- 优化了`selectors`模块的性能
