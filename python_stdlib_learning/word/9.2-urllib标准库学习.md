# Python 3.14.0 urllib标准库完整学习文档

## 一、urllib核心概念

### 1.1 什么是urllib
urllib是Python标准库中用于处理URL（统一资源定位符）的核心模块集合，提供了一整套从网络请求、数据解析、错误处理到协议遵守的完整工具链。它允许你无需安装任何第三方库，就能编写各种网络爬虫、API客户端和数据下载程序。

Python 3对urllib进行了重大重构，将Python 2中分离的`urllib`和`urllib2`合并为一个统一的`urllib`包，并拆分为多个功能明确的子模块。Python 3.14.0进一步优化了urllib的性能，增强了HTTPS安全性，修复了多个长期存在的bug，并保持了完全的向后兼容性。

### 1.2 urllib的子模块结构
urllib包由5个核心子模块组成，各司其职：

| 子模块 | 主要功能 |
|--------|----------|
| `urllib.request` | 核心模块，用于发送HTTP/HTTPS请求和接收响应 |
| `urllib.parse` | 用于URL解析、构造和编码解码 |
| `urllib.error` | 定义了urllib可能抛出的异常类 |
| `urllib.response` | 定义了响应对象的接口，通常不直接使用 |
| `urllib.robotparser` | 用于解析robots.txt文件，判断网站爬取权限 |

### 1.3 urllib与第三方HTTP库的关系
- **urllib**：Python标准库，无需安装，功能基础但全面，适合简单场景和对依赖有严格限制的环境
- **requests**：基于urllib3开发的第三方库，API更加简洁友好，是大多数开发者的首选
- **aiohttp**：异步HTTP客户端/服务器库，适合高并发场景

虽然第三方库使用更方便，但掌握urllib是理解HTTP协议和网络编程基础的关键，也是在无法安装第三方库时的唯一选择。

## 二、urllib基础部分

### 2.1 发送最简单的GET请求
`urllib.request.urlopen()`是urllib最基础也是最常用的函数，用于打开一个URL并返回响应对象。

**示例：获取百度首页内容**
```python
import urllib.request

# 发送GET请求
response = urllib.request.urlopen('https://www.baidu.com')

# 读取响应内容（bytes类型）
html_bytes = response.read()

# 解码为字符串（需要知道正确的编码）
html_str = html_bytes.decode('utf-8')

print(f"响应状态码: {response.getcode()}")
print(f"实际访问的URL: {response.geturl()}")
print(f"响应头信息:\n{response.info()}")
print(f"网页前500个字符:\n{html_str[:500]}")
```

**响应对象的常用方法**：
- `read()`：读取响应内容，返回bytes类型
- `getcode()`：返回HTTP状态码（如200表示成功，404表示未找到）
- `geturl()`：返回实际访问的URL（可能与请求URL不同，如发生重定向）
- `info()`：返回响应头信息，是一个HTTPMessage对象

### 2.2 处理URL编码与解码
URL只能包含ASCII字符，非ASCII字符和特殊字符需要进行编码。`urllib.parse`模块提供了完整的URL处理功能。

**示例：URL编码与解析**
```python
import urllib.parse

# 1. 字典转查询字符串（自动编码）
params = {
    'wd': 'Python 3.14 教程',
    'ie': 'utf-8',
    'tn': 'baidu'
}
query_string = urllib.parse.urlencode(params)
print(f"编码后的查询字符串: {query_string}")
# 输出: wd=Python+3.14+%E6%95%99%E7%A8%8B&ie=utf-8&tn=baidu

# 2. 构造完整URL
base_url = 'https://www.baidu.com/s'
full_url = f"{base_url}?{query_string}"
print(f"完整URL: {full_url}")

# 3. 解析URL
url = 'https://www.example.com:8080/path/to/page.html?a=1&b=2#fragment'
parsed = urllib.parse.urlparse(url)
print(f"\nURL解析结果:")
print(f"协议: {parsed.scheme}")
print(f"域名: {parsed.netloc}")
print(f"路径: {parsed.path}")
print(f"查询参数: {parsed.query}")
print(f"片段: {parsed.fragment}")

# 4. 解析查询参数为字典
query_dict = urllib.parse.parse_qs(parsed.query)
print(f"\n查询参数字典: {query_dict}")

# 5. 手动编码/解码字符串
encoded = urllib.parse.quote('你好，世界！')
print(f"编码后的字符串: {encoded}")
decoded = urllib.parse.unquote(encoded)
print(f"解码后的字符串: {decoded}")
```

### 2.3 发送POST请求
当需要向服务器提交数据（如表单）时，使用POST请求。POST请求的数据需要放在请求体中，并进行适当的编码。

**示例：发送POST请求**
```python
import urllib.request
import urllib.parse

# 构造POST数据
data = {
    'username': 'testuser',
    'password': 'testpass123',
    'remember': 'on'
}

# 编码POST数据（application/x-www-form-urlencoded格式）
encoded_data = urllib.parse.urlencode(data).encode('utf-8')

# 发送POST请求
url = 'https://httpbin.org/post'
response = urllib.request.urlopen(url, data=encoded_data)

# 读取响应
result = response.read().decode('utf-8')
print(f"POST请求响应:\n{result}")
```

### 2.4 添加请求头
很多网站会检查请求头中的User-Agent字段，识别爬虫程序。我们可以通过构造`Request`对象来自定义请求头。

**示例：自定义请求头**
```python
import urllib.request

url = 'https://httpbin.org/headers'

# 构造请求头
headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
    'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8',
    'Accept-Language': 'zh-CN,zh;q=0.9,en;q=0.8',
    'Referer': 'https://www.google.com/'
}

# 创建Request对象
req = urllib.request.Request(url, headers=headers)

# 发送请求
response = urllib.request.urlopen(req)
result = response.read().decode('utf-8')
print(f"自定义请求头响应:\n{result}")
```

### 2.5 异常处理
网络请求可能会遇到各种错误，urllib定义了专门的异常类来处理这些情况。

**示例：完整的异常处理**
```python
import urllib.request
import urllib.error

url = 'https://www.nonexistent-website-example.com'

try:
    response = urllib.request.urlopen(url, timeout=5)
    print(f"响应状态码: {response.getcode()}")
except urllib.error.HTTPError as e:
    # HTTP错误（状态码4xx、5xx）
    print(f"HTTP错误: {e.code} - {e.reason}")
    print(f"错误响应头:\n{e.headers}")
except urllib.error.URLError as e:
    # URL错误（网络不通、域名不存在等）
    print(f"URL错误: {e.reason}")
except TimeoutError:
    print("请求超时")
except Exception as e:
    print(f"其他错误: {e}")
```

### 2.6 解析robots.txt
`urllib.robotparser`模块可以解析网站的robots.txt文件，帮助我们遵守网站的爬取规则。

**示例：检查爬取权限**
```python
import urllib.robotparser

# 创建RobotFileParser对象
rp = urllib.robotparser.RobotFileParser()

# 设置robots.txt的URL
rp.set_url('https://www.baidu.com/robots.txt')

# 读取并解析robots.txt
rp.read()

# 检查某个URL是否允许被爬取
user_agent = '*'
urls = [
    '/',
    '/s?wd=python',
    '/baidu.html',
    '/search/'
]

for url in urls:
    allowed = rp.can_fetch(user_agent, url)
    print(f"爬取 {url}: {'允许' if allowed else '禁止'}")

# 获取爬取延迟（如果有设置）
crawl_delay = rp.crawl_delay(user_agent)
print(f"\n爬取延迟: {crawl_delay}秒")
```

## 三、urllib进阶部分

### 3.1 自定义Opener与Handler
`urlopen()`函数使用的是默认的Opener，它由一系列默认的Handler组成。当我们需要实现更复杂的功能（如Cookie处理、代理、认证等）时，需要创建自定义的Opener。

**基本原理**：
- `Handler`：处理特定类型请求的处理器（如HTTPHandler、HTTPSHandler、HTTPCookieProcessor等）
- `OpenerDirector`：管理多个Handler，按照顺序处理请求
- `build_opener()`：根据传入的Handler创建Opener对象
- `install_opener()`：将自定义Opener设置为全局默认Opener

**示例：创建并使用自定义Opener**
```python
import urllib.request

# 创建HTTP和HTTPS处理器
http_handler = urllib.request.HTTPHandler(debuglevel=1)  # debuglevel=1开启调试模式
https_handler = urllib.request.HTTPSHandler(debuglevel=1)

# 创建自定义Opener
opener = urllib.request.build_opener(http_handler, https_handler)

# 使用自定义Opener发送请求
response = opener.open('https://www.baidu.com')
print(f"响应状态码: {response.getcode()}")

# 将自定义Opener设置为全局默认
# urllib.request.install_opener(opener)
# 之后使用urlopen()会使用这个自定义Opener
# response = urllib.request.urlopen('https://www.baidu.com')
```

### 3.2 Cookie处理
很多网站需要登录才能访问，而登录状态通常通过Cookie来维护。urllib通过`HTTPCookieProcessor`和`http.cookiejar`模块来处理Cookie。

**示例：保存和加载Cookie**
```python
import urllib.request
import http.cookiejar

# 1. 创建Cookie管理器
cookie_jar = http.cookiejar.CookieJar()
cookie_handler = urllib.request.HTTPCookieProcessor(cookie_jar)
opener = urllib.request.build_opener(cookie_handler)
urllib.request.install_opener(opener)

# 2. 第一次请求：设置Cookie
response = urllib.request.urlopen('https://httpbin.org/cookies/set?name=test&value=123')
print("第一次请求后的Cookie:")
for cookie in cookie_jar:
    print(f"{cookie.name} = {cookie.value}")

# 3. 第二次请求：验证自动带Cookie
response = urllib.request.urlopen('https://httpbin.org/cookies')
print(f"\n第二次请求响应:\n{response.read().decode('utf-8')}")

# ===================== 修复部分：正确保存 Cookie =====================
# 创建文件型 Cookie 管理器
cookie_jar_file = http.cookiejar.MozillaCookieJar('cookies.txt')
# 把内存里的 Cookie 复制过去（关键！）
for c in cookie_jar:
    cookie_jar_file.set_cookie(c)
# 保存到文件
cookie_jar_file.save(ignore_discard=True, ignore_expires=True)
# ====================================================================

# 4. 从文件加载Cookie
loaded_cookie_jar = http.cookiejar.MozillaCookieJar()
loaded_cookie_jar.load('cookies.txt', ignore_discard=True, ignore_expires=True)
print("\n从文件加载的Cookie:")
for cookie in loaded_cookie_jar:
    print(f"{cookie.name} = {cookie.value}")
```

### 3.4 HTTP认证
当访问需要HTTP基本认证或摘要认证的网站时，可以使用对应的认证处理器。

**示例：HTTP基本认证**
```python
import urllib.request
import urllib.error

# 认证信息
username = 'admin'
password = 'secret'
url = 'https://httpbin.org/basic-auth/admin/secret'

# 创建密码管理器
password_mgr = urllib.request.HTTPPasswordMgrWithDefaultRealm()

# 添加认证信息
password_mgr.add_password(None, url, username, password)

# 创建基本认证处理器
auth_handler = urllib.request.HTTPBasicAuthHandler(password_mgr)

# 创建Opener
opener = urllib.request.build_opener(auth_handler)

try:
    response = opener.open(url)
    print(f"认证成功，响应内容:\n{response.read().decode('utf-8')}")
except urllib.error.HTTPError as e:
    if e.code == 401:
        print("认证失败：用户名或密码错误")
    else:
        print(f"HTTP错误: {e.code}")
```

### 3.6 下载文件与进度显示
urllib可以用来下载各种类型的文件，对于大文件，建议使用分块下载并显示进度条。

**示例：分块下载文件并显示进度**
```python
import urllib.request
import os

def download_file(url, save_path):
    """下载文件并显示进度条"""
    # 发送请求
    response = urllib.request.urlopen(url)
    
    # 获取文件大小
    file_size = int(response.headers.get('Content-Length', 0))
    print(f"文件大小: {file_size / 1024 / 1024:.2f} MB")
    
    # 分块下载
    downloaded_size = 0
    block_size = 1024 * 1024  # 1MB
    
    with open(save_path, 'wb') as f:
        while True:
            buffer = response.read(block_size)
            if not buffer:
                break
            
            downloaded_size += len(buffer)
            f.write(buffer)
            
            # 计算并显示进度
            progress = (downloaded_size / file_size) * 100 if file_size > 0 else 0
            print(f"\r下载进度: {downloaded_size / 1024 / 1024:.2f} MB / {file_size / 1024 / 1024:.2f} MB ({progress:.2f}%)", end='')
    
    print("\n下载完成！")

# 下载Python官方文档
url = 'https://docs.python.org/3/archives/python-3.14.0-docs-pdf-a4.zip'
save_path = 'python-3.14.0-docs.zip'
download_file(url, save_path)
```

### 3.7 重定向处理
urllib默认会自动处理最多10次重定向。我们可以自定义重定向处理器来控制重定向行为。

**示例：自定义重定向处理**
```python
import urllib.request
import urllib.error

class NoRedirectHandler(urllib.request.HTTPRedirectHandler):
    """禁止重定向的处理器"""
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        raise urllib.error.HTTPError(req.full_url, code, msg, headers, fp)

# 创建禁止重定向的Opener
opener = urllib.request.build_opener(NoRedirectHandler())

try:
    response = opener.open('https://httpbin.org/redirect/3')
    print(f"状态码: {response.getcode()}")
except urllib.error.HTTPError as e:
    if 300 <= e.code < 400:
        print(f"检测到重定向，状态码: {e.code}")
        print(f"重定向地址: {e.headers.get('Location')}")
```

## 四、实战案例：豆瓣读书Top250爬虫

### 4.1 项目概述
我们将使用urllib标准库编写一个完整的豆瓣读书Top250爬虫，实现以下功能：
- 爬取豆瓣读书Top250的所有书籍信息
- 提取书籍标题、作者、评分、评价人数和简介
- 下载书籍封面图片
- 将数据保存为CSV文件
- 遵守robots.txt协议和爬取延迟
- 完善的异常处理和重试机制

### 4.2 完整实现代码
```python
import urllib.request
import urllib.parse
import urllib.error
import urllib.robotparser
import csv
import time
import os
from html.parser import HTMLParser

class DoubanBookParser(HTMLParser):
    """自定义HTML解析器，提取书籍信息"""
    def __init__(self):
        super().__init__()
        self.books = []
        self.current_book = {}
        self.in_title = False
        self.in_author = False
        self.in_rating = False
        self.in_rating_num = False
        self.in_cover = False
        self.in_info = False
        self.info_buffer = []

    def handle_starttag(self, tag, attrs):
        attrs_dict = dict(attrs)
        
        if tag == 'div' and attrs_dict.get('class') == 'item':
            self.current_book = {}
        
        elif tag == 'a' and attrs_dict.get('class') == 'nbg':
            self.in_cover = True
            self.current_book['cover_url'] = attrs_dict.get('href', '')
        
        elif tag == 'img' and self.in_cover:
            self.current_book['cover_src'] = attrs_dict.get('src', '')
        
        elif tag == 'div' and attrs_dict.get('class') == 'pl2':
            self.in_title = True
        
        elif tag == 'p' and attrs_dict.get('class') == 'pl':
            self.in_author = True
        
        elif tag == 'span' and attrs_dict.get('class') == 'rating_nums':
            self.in_rating = True
        
        elif tag == 'span' and attrs_dict.get('class') == 'pl':
            self.in_rating_num = True
        
        elif tag == 'span' and attrs_dict.get('class') == 'inq':
            self.in_info = True

    def handle_endtag(self, tag):
        if tag == 'a' and self.in_cover:
            self.in_cover = False
        
        elif tag == 'div' and self.in_title:
            self.in_title = False
        
        elif tag == 'p' and self.in_author:
            self.in_author = False
            # 处理作者信息
            if self.info_buffer:
                author_info = ''.join(self.info_buffer).strip()
                self.current_book['author'] = author_info
                self.info_buffer = []
        
        elif tag == 'span' and self.in_rating:
            self.in_rating = False
        
        elif tag == 'span' and self.in_rating_num:
            self.in_rating_num = False
            # 处理评价人数
            if self.info_buffer:
                rating_num = ''.join(self.info_buffer).strip()
                # 提取数字部分
                import re
                match = re.search(r'(\d+)', rating_num)
                if match:
                    self.current_book['rating_num'] = match.group(1)
                self.info_buffer = []
        
        elif tag == 'span' and self.in_info:
            self.in_info = False
            # 处理简介
            if self.info_buffer:
                self.current_book['info'] = ''.join(self.info_buffer).strip()
                self.info_buffer = []
        
        elif tag == 'div' and 'item' in self.current_book.get('cover_url', ''):
            # 一本书解析完成
            if self.current_book:
                self.books.append(self.current_book)
                self.current_book = {}

    def handle_data(self, data):
        if self.in_title and data.strip():
            self.current_book['title'] = data.strip()
        
        elif self.in_author:
            self.info_buffer.append(data)
        
        elif self.in_rating and data.strip():
            self.current_book['rating'] = data.strip()
        
        elif self.in_rating_num:
            self.info_buffer.append(data)
        
        elif self.in_info:
            self.info_buffer.append(data)

class DoubanBookSpider:
    """豆瓣读书Top250爬虫"""
    def __init__(self):
        self.base_url = 'https://book.douban.com/top250'
        self.headers = {
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
            'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8',
            'Accept-Language': 'zh-CN,zh;q=0.9,en;q=0.8'
        }
        self.books = []
        self.save_dir = 'douban_books'
        self.cover_dir = os.path.join(self.save_dir, 'covers')
        
        # 检查robots.txt

        self.rp.read()
        
        # 创建保存目录
        os.makedirs(self.cover_dir, exist_ok=True)

    def get_page(self, url, retries=3):
        """获取页面内容，带重试机制"""
        if not self.rp.can_fetch('*', url):
            print(f"robots.txt禁止爬取: {url}")
            return None
        
        for i in range(retries):
            try:
                req = urllib.request.Request(url, headers=self.headers)
                response = urllib.request.urlopen(req, timeout=10)
                return response.read().decode('utf-8')
            except urllib.error.HTTPError as e:
                if e.code == 404:
                    print(f"页面不存在: {url}")
                    return None
                print(f"HTTP错误 {e.code}: {e.reason}，重试 {i+1}/{retries}")
            except Exception as e:
                print(f"请求错误: {e}，重试 {i+1}/{retries}")
            time.sleep(2 ** i)  # 指数退避
        
        print(f"多次重试失败: {url}")
        return None

    def download_cover(self, cover_url, book_title):
        """下载书籍封面"""
        if not cover_url:
            return None
        
        # 生成文件名
        filename = f"{book_title.replace('/', '_')}.jpg"
        save_path = os.path.join(self.cover_dir, filename)
        
        # 如果文件已存在，跳过下载
        if os.path.exists(save_path):
            return save_path
        
        try:
            req = urllib.request.Request(cover_url, headers=self.headers)
            response = urllib.request.urlopen(req, timeout=10)
            
            with open(save_path, 'wb') as f:
                f.write(response.read())
            
            return save_path
        except Exception as e:
            print(f"下载封面失败 {book_title}: {e}")
            return None

    def crawl(self):
        """开始爬取"""
        print("开始爬取豆瓣读书Top250...")
        
        # 豆瓣读书Top250每页25本，共10页
        for page in range(10):
            start = page * 25
            url = f"{self.base_url}?start={start}"
            
            print(f"\n正在爬取第 {page+1} 页: {url}")
            
            # 获取页面内容
            html = self.get_page(url)
            if not html:
                continue
            
            # 解析页面
            parser = DoubanBookParser()
            parser.feed(html)
            
            # 下载封面并添加到结果
            for book in parser.books:
                cover_path = self.download_cover(book.get('cover_src', ''), book.get('title', ''))
                book['cover_path'] = cover_path
                self.books.append(book)
            
            print(f"第 {page+1} 页爬取完成，已获取 {len(parser.books)} 本书")
            
            # 遵守爬取延迟
            time.sleep(2)
        
        print(f"\n爬取完成，共获取 {len(self.books)} 本书")

    def save_to_csv(self):
        """将数据保存为CSV文件"""
        csv_path = os.path.join(self.save_dir, 'douban_book_top250.csv')
        
        # 定义CSV字段
        fieldnames = ['title', 'author', 'rating', 'rating_num', 'info', 'cover_url', 'cover_src', 'cover_path']
        
        with open(csv_path, 'w', newline='', encoding='utf-8-sig') as f:
            writer = csv.DictWriter(f, fieldnames=fieldnames)
            writer.writeheader()
            writer.writerows(self.books)
        
        print(f"数据已保存到: {csv_path}")

if __name__ == "__main__":
    spider = DoubanBookSpider()
    spider.crawl()
    spider.save_to_csv()
    print("\n所有任务完成！")
```
