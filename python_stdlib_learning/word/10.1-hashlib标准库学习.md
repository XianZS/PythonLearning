# Python 3.14.0 hashlib标准库完整学习文档

## 一、hashlib核心概念

### 1.1 什么是hashlib
`hashlib`是Python标准库中用于实现**加密哈希算法**的核心模块，提供了一系列安全的哈希函数实现，包括MD5、SHA-1、SHA-2系列和SHA-3系列等。它允许你对任意长度的数据生成固定长度的哈希值（也称为摘要），广泛应用于数据完整性校验、密码存储、数字签名等安全领域。

Python 3.14.0对`hashlib`进行了重要的性能和安全升级：
- 优化了SHA-2和SHA-3系列算法的实现，速度提升了15-30%
- 新增了对SHAKE256可变长度输出的完整支持
- 增强了算法可用性检测，提供了更清晰的错误信息
- 修复了多个潜在的安全漏洞
- 保持了完全的向后兼容性

### 1.2 哈希函数的核心特性
加密哈希函数具有以下四个不可缺少的特性：

| 特性 | 说明 |
|------|------|
| **确定性** | 相同的输入永远产生相同的输出 |
| **不可逆性** | 无法从哈希值反推出原始数据（单向性） |
| **雪崩效应** | 输入的微小变化会导致输出发生巨大变化 |
| **抗碰撞性** | 很难找到两个不同的输入产生相同的哈希值 |

**重要安全提示**：哈希函数不是加密函数。加密是可逆的（有密钥可以解密），而哈希是不可逆的。

### 1.3 hashlib支持的算法
Python 3.14.0的hashlib支持以下算法：

| 算法类别 | 算法名称 | 输出长度 | 安全性 | 推荐使用场景 |
|----------|----------|----------|--------|--------------|
| 过时算法 | MD5 | 128位 | 极低 | 仅用于非安全场景的兼容性 |
| 过时算法 | SHA-1 | 160位 | 低 | 不推荐用于任何安全场景 |
| 安全算法 | SHA-224 | 224位 | 高 | 一般安全场景 |
| 安全算法 | SHA-256 | 256位 | 高 | 推荐的通用算法 |
| 安全算法 | SHA-384 | 384位 | 很高 | 高安全场景 |
| 安全算法 | SHA-512 | 512位 | 很高 | 最高安全场景 |
| 新一代算法 | SHA3-224 | 224位 | 很高 | 未来安全场景 |
| 新一代算法 | SHA3-256 | 256位 | 很高 | 推荐的新一代算法 |
| 新一代算法 | SHA3-384 | 384位 | 极高 | 高安全未来场景 |
| 新一代算法 | SHA3-512 | 512位 | 极高 | 最高安全未来场景 |
| 可变长度 | SHAKE128 | 任意 | 高 | 需要可变长度输出的场景 |
| 可变长度 | SHAKE256 | 任意 | 很高 | 需要可变长度输出的高安全场景 |

**注意**：MD5和SHA-1已经被密码分析学破解，存在碰撞攻击风险，**绝对不能用于密码存储、数字签名等安全相关场景**。

### 1.4 hashlib的工作原理
hashlib的工作流程非常简单：
1. 创建一个哈希对象（指定算法）
2. 向哈希对象中输入数据（可以分多次输入）
3. 获取最终的哈希值

这个过程是单向的，一旦数据被输入到哈希对象中，就无法再提取出来。

## 二、hashlib基础部分

### 2.1 计算字符串的哈希值
这是hashlib最基本的用法，用于计算字符串的哈希值。

**示例：计算字符串的MD5和SHA-256哈希值**
```python
import hashlib

# 原始字符串
data = "Hello, Python hashlib!"
data_bytes = data.encode('utf-8')  # 必须转换为bytes类型

# 1. 计算MD5哈希值
md5_hash = hashlib.md5(data_bytes).hexdigest()
print(f"MD5: {md5_hash}")
print(f"MD5长度: {len(md5_hash)} 字符 (128位)")

# 2. 计算SHA-256哈希值
sha256_hash = hashlib.sha256(data_bytes).hexdigest()
print(f"\nSHA-256: {sha256_hash}")
print(f"SHA-256长度: {len(sha256_hash)} 字符 (256位)")

# 3. 计算SHA-512哈希值
sha512_hash = hashlib.sha512(data_bytes).hexdigest()
print(f"\nSHA-512: {sha512_hash}")
print(f"SHA-512长度: {len(sha512_hash)} 字符 (512位)")

# 4. 演示雪崩效应
data2 = "Hello, Python hashlib?"  # 只改了最后一个字符
sha256_hash2 = hashlib.sha256(data2.encode('utf-8')).hexdigest()
print(f"\n雪崩效应演示:")
print(f"原始: {sha256_hash}")
print(f"修改: {sha256_hash2}")
```

### 2.2 哈希值的不同表示形式
hashlib提供了两种获取哈希值的方法：
- `hexdigest()`：返回十六进制字符串表示（最常用）
- `digest()`：返回原始字节表示

**示例：不同表示形式的哈希值**
```python
import hashlib

data = "test".encode('utf-8')

# 十六进制字符串
hex_hash = hashlib.sha256(data).hexdigest()
print(f"十六进制: {hex_hash}")
print(f"类型: {type(hex_hash)}")
print(f"长度: {len(hex_hash)} 字符")

# 原始字节
byte_hash = hashlib.sha256(data).digest()
print(f"\n原始字节: {byte_hash}")
print(f"类型: {type(byte_hash)}")
print(f"长度: {len(byte_hash)} 字节")

# 字节转十六进制
hex_from_byte = byte_hash.hex()
print(f"\n字节转十六进制: {hex_from_byte}")
print(f"与hexdigest()相同: {hex_from_byte == hex_hash}")
```

### 2.3 分块更新数据
对于大文件或大量数据，不应该一次性读入内存，而应该分块更新哈希对象。

**示例：分块更新数据**
```python
import hashlib

# 创建SHA-256哈希对象
hash_obj = hashlib.sha256()

# 分块更新数据
hash_obj.update(b"Hello, ")
hash_obj.update(b"Python ")
hash_obj.update(b"hashlib!")

# 获取最终哈希值
final_hash = hash_obj.hexdigest()
print(f"分块更新的哈希值: {final_hash}")

# 与一次性更新的结果对比
one_shot_hash = hashlib.sha256(b"Hello, Python hashlib!").hexdigest()
print(f"一次性更新的哈希值: {one_shot_hash}")
print(f"结果相同: {final_hash == one_shot_hash}")
```

### 2.4 计算文件的哈希值
这是hashlib最常用的场景之一，用于验证文件的完整性。

**示例：计算文件的哈希值**
```python
import hashlib

def calculate_file_hash(file_path, algorithm='sha256', block_size=65536):
    """
    计算文件的哈希值
    
    Args:
        file_path: 文件路径
        algorithm: 哈希算法名称
        block_size: 分块大小，默认64KB
    
    Returns:
        十六进制哈希值
    """
    # 创建哈希对象
    hash_obj = hashlib.new(algorithm)
    
    try:
        with open(file_path, 'rb') as f:
            # 分块读取文件
            while chunk := f.read(block_size):
                hash_obj.update(chunk)
        
        return hash_obj.hexdigest()
    
    except FileNotFoundError:
        print(f"文件不存在: {file_path}")
        return None
    except Exception as e:
        print(f"计算哈希值失败: {e}")
        return None

# 使用示例
if __name__ == "__main__":
    # 计算当前Python文件的哈希值
    file_path = __file__
    sha256_hash = calculate_file_hash(file_path)
    print(f"文件 {file_path} 的SHA-256哈希值:")
    print(sha256_hash)
    
    # 计算MD5哈希值
    md5_hash = calculate_file_hash(file_path, 'md5')
    print(f"\nMD5哈希值:")
    print(md5_hash)
```

### 2.5 动态指定哈希算法
使用`hashlib.new()`函数可以动态指定哈希算法，这在需要根据配置选择算法时非常有用。

**示例：动态指定哈希算法**
```python
import hashlib

# 支持的算法列表
print("hashlib支持的算法:")
print(f"保证可用的算法: {hashlib.algorithms_guaranteed}")
print(f"\n当前平台可用的算法: {hashlib.algorithms_available}")

# 动态创建哈希对象
algorithms = ['md5', 'sha1', 'sha256', 'sha512', 'sha3_256']
data = "test data".encode('utf-8')

print("\n不同算法的哈希值:")
for algo in algorithms:
    hash_obj = hashlib.new(algo)
    hash_obj.update(data)
    print(f"{algo}: {hash_obj.hexdigest()}")
```

## 三、hashlib进阶部分

### 3.1 哈希对象的复制
使用`copy()`方法可以创建哈希对象的副本，这在需要计算多个相似数据的哈希值时非常有用。

**示例：哈希对象的复制**
```python
import hashlib

# 创建原始哈希对象
base_hash = hashlib.sha256()
base_hash.update(b"Hello, ")

# 复制哈希对象
hash1 = base_hash.copy()
hash2 = base_hash.copy()

# 分别更新不同的数据
hash1.update(b"World!")
hash2.update(b"Python!")

print(f"hash1: {hash1.hexdigest()}")
print(f"hash2: {hash2.hexdigest()}")

# 原始哈希对象不受影响
print(f"原始哈希对象更新后: {base_hash.copy().update(b'!').hexdigest()}")
```

### 3.2 加盐哈希（Salted Hash）
直接使用哈希函数存储密码是不安全的，因为攻击者可以使用彩虹表攻击。**加盐哈希**通过在密码中添加一个随机的"盐"值，使相同的密码产生不同的哈希值，大大提高了安全性。

**示例：正确的加盐哈希实现**
```python
import hashlib
import secrets

def hash_password(password):
    """
    对密码进行加盐哈希处理
    
    Args:
        password: 原始密码字符串
    
    Returns:
        存储格式: 盐$哈希值
    """
    # 生成16字节的随机盐（使用安全的随机数生成器）
    salt = secrets.token_bytes(16)
    
    # 将盐和密码拼接后计算哈希值
    password_bytes = password.encode('utf-8')
    hash_obj = hashlib.sha256()
    hash_obj.update(salt)
    hash_obj.update(password_bytes)
    password_hash = hash_obj.hexdigest()
    
    # 返回盐和哈希值的组合（盐使用十六进制编码）
    return f"{salt.hex()}${password_hash}"

def verify_password(password, stored_hash):
    """
    验证密码是否正确
    
    Args:
        password: 要验证的密码
        stored_hash: 存储的加盐哈希值
    
    Returns:
        密码正确返回True，否则返回False
    """
    # 分离盐和哈希值
    salt_hex, original_hash = stored_hash.split('$')
    salt = bytes.fromhex(salt_hex)
    
    # 使用相同的盐和算法计算哈希值
    password_bytes = password.encode('utf-8')
    hash_obj = hashlib.sha256()
    hash_obj.update(salt)
    hash_obj.update(password_bytes)
    computed_hash = hash_obj.hexdigest()
    
    # 比较哈希值
    return computed_hash == original_hash

# 使用示例
if __name__ == "__main__":
    # 注册时哈希密码
    password = "my_secure_password123"
    stored_hash = hash_password(password)
    print(f"存储的哈希值: {stored_hash}")
    
    # 登录时验证密码
    test_password1 = "my_secure_password123"
    test_password2 = "wrong_password"
    
    print(f"\n验证正确密码: {verify_password(test_password1, stored_hash)}")
    print(f"验证错误密码: {verify_password(test_password2, stored_hash)}")
    
    # 相同密码产生不同的哈希值
    stored_hash2 = hash_password(password)
    print(f"\n相同密码的不同哈希值:")
    print(f"哈希1: {stored_hash}")
    print(f"哈希2: {stored_hash2}")
    print(f"是否相同: {stored_hash == stored_hash2}")
```

**重要安全提示**：
- 必须使用`secrets`模块生成盐，而不是`random`模块
- 每个密码使用唯一的盐
- 盐和哈希值一起存储
- 即使这样，对于密码存储，仍然推荐使用专门的密码哈希函数（如bcrypt、scrypt、Argon2），而不是普通的哈希函数

### 3.3 PBKDF2密钥派生函数
`hashlib.pbkdf2_hmac()`是Python标准库提供的基于密码的密钥派生函数，专门设计用于密码存储。它通过多次迭代哈希来增加攻击者的计算成本，有效抵抗暴力破解攻击。

**示例：使用PBKDF2哈希密码**
```python
import hashlib
import secrets

def hash_password_pbkdf2(password, iterations=100000):
    """
    使用PBKDF2-HMAC-SHA256哈希密码
    
    Args:
        password: 原始密码
        iterations: 迭代次数，越高越安全但越慢
    
    Returns:
        存储格式: 迭代次数$盐$哈希值
    """
    salt = secrets.token_bytes(16)
    
    # 使用PBKDF2派生密钥
    password_bytes = password.encode('utf-8')
    key = hashlib.pbkdf2_hmac(
        hash_name='sha256',
        password=password_bytes,
        salt=salt,
        iterations=iterations,
        dklen=32  # 派生32字节的密钥
    )
    
    return f"{iterations}${salt.hex()}${key.hex()}"

def verify_password_pbkdf2(password, stored_hash):
    """验证PBKDF2哈希的密码"""
    iterations, salt_hex, original_key = stored_hash.split('$')
    iterations = int(iterations)
    salt = bytes.fromhex(salt_hex)
    
    password_bytes = password.encode('utf-8')
    key = hashlib.pbkdf2_hmac(
        hash_name='sha256',
        password=password_bytes,
        salt=salt,
        iterations=iterations,
        dklen=32
    )
    
    return key.hex() == original_key

# 使用示例
if __name__ == "__main__":
    password = "my_secure_password123"
    stored_hash = hash_password_pbkdf2(password)
    print(f"PBKDF2存储的哈希值: {stored_hash}")
    
    print(f"验证正确密码: {verify_password_pbkdf2(password, stored_hash)}")
    print(f"验证错误密码: {verify_password_pbkdf2('wrong', stored_hash)}")
```

### 3.4 HMAC消息认证码
HMAC（Keyed-Hashing for Message Authentication）是一种基于哈希函数的消息认证码，用于同时验证数据的完整性和真实性。它需要一个密钥，只有拥有密钥的人才能生成和验证HMAC。

**示例：使用HMAC**
```python
import hmac
import hashlib
import secrets

def generate_hmac(message, key, algorithm='sha256'):
    """生成HMAC"""
    message_bytes = message.encode('utf-8')
    hmac_obj = hmac.new(key, message_bytes, algorithm)
    return hmac_obj.hexdigest()

def verify_hmac(message, key, received_hmac, algorithm='sha256'):
    """验证HMAC"""
    computed_hmac = generate_hmac(message, key, algorithm)
    # 使用安全的比较函数，防止时序攻击
    return hmac.compare_digest(computed_hmac, received_hmac)

# 使用示例
if __name__ == "__main__":
    # 生成安全的密钥
    key = secrets.token_bytes(32)
    print(f"密钥: {key.hex()}")
    
    # 原始消息
    message = "这是一条需要验证的消息"
    
    # 生成HMAC
    message_hmac = generate_hmac(message, key)
    print(f"生成的HMAC: {message_hmac}")
    
    # 验证HMAC
    print(f"验证原始消息: {verify_hmac(message, key, message_hmac)}")
    print(f"验证篡改后的消息: {verify_hmac(message + "!", key, message_hmac)}")
    print(f"验证错误密钥: {verify_hmac(message, secrets.token_bytes(32), message_hmac)}")
```

**重要提示**：必须使用`hmac.compare_digest()`函数进行比较，而不是普通的`==`运算符，因为普通比较容易受到时序攻击。

### 3.5 SHAKE可变长度输出算法
SHAKE（SHA-3 Extendable-Output Function）是SHA-3系列中的可变长度输出哈希函数，可以生成任意长度的哈希值。

**示例：使用SHAKE256**
```python
import hashlib

data = "Hello, SHAKE256!".encode('utf-8')

# 创建SHAKE256对象
shake = hashlib.shake_256(data)

# 生成不同长度的输出
print(f"16字节输出: {shake.hexdigest(16)}")
print(f"32字节输出: {shake.hexdigest(32)}")
print(f"64字节输出: {shake.hexdigest(64)}")
print(f"100字节输出: {shake.hexdigest(100)}")

# 注意：每次调用digest()或hexdigest()都会消耗对象
# 如果需要多次生成，应该创建新的对象
shake2 = hashlib.shake_256(data)
print(f"\n再次生成32字节输出: {shake2.hexdigest(32)}")
```

### 3.6 安全最佳实践
1. **永远不要使用MD5和SHA-1**用于安全相关场景
2. **优先使用SHA-256或SHA3-256**作为通用哈希算法
3. **绝对不要直接存储明文密码**，必须使用加盐哈希
4. **对于密码存储，优先使用专门的密码哈希函数**（如bcrypt、scrypt、Argon2），其次是PBKDF2
5. **使用secrets模块生成随机数**，而不是random模块
6. **使用hmac.compare_digest()进行安全比较**
7. **定期更新算法**，随着计算能力的提升，需要使用更长的哈希值和更多的迭代次数

## 四、实战案例：文件完整性校验工具

### 4.1 项目概述
我们将实现一个功能完整的文件完整性校验工具，支持：
- 计算单个文件或整个目录的哈希值
- 生成校验文件（包含所有文件的哈希值）
- 验证文件是否被篡改、删除或新增
- 支持多种哈希算法（SHA-256、SHA-512、SHA3-256）
- 详细的校验报告
- 多线程计算，提高大文件处理速度

### 4.2 完整实现代码
```python
import hashlib
import os
import json
import time
import concurrent.futures
from datetime import datetime

class FileIntegrityChecker:
    def __init__(self, algorithm='sha256', max_workers=4):
        """
        初始化文件完整性校验器
        
        Args:
            algorithm: 哈希算法名称
            max_workers: 最大线程数
        """
        self.algorithm = algorithm
        self.max_workers = max_workers
        
        # 验证算法是否可用
        if algorithm not in hashlib.algorithms_available:
            raise ValueError(f"不支持的算法: {algorithm}")
        
        print(f"文件完整性校验器已初始化")
        print(f"使用算法: {algorithm}")
        print(f"最大线程数: {max_workers}")
    
    def _calculate_file_hash(self, file_path):
        """计算单个文件的哈希值（内部方法）"""
        try:
            hash_obj = hashlib.new(self.algorithm)
            with open(file_path, 'rb') as f:
                while chunk := f.read(65536):
                    hash_obj.update(chunk)
            
            return {
                'path': file_path,
                'hash': hash_obj.hexdigest(),
                'size': os.path.getsize(file_path),
                'modified': os.path.getmtime(file_path)
            }
        except Exception as e:
            return {
                'path': file_path,
                'error': str(e)
            }
    
    def generate_checksum(self, path, output_file=None):
        """
        生成文件或目录的校验文件
        
        Args:
            path: 文件或目录路径
            output_file: 校验文件输出路径
        
        Returns:
            校验数据字典
        """
        print(f"\n开始生成校验数据: {path}")
        start_time = time.time()
        
        # 获取所有文件列表
        file_list = []
        if os.path.isfile(path):
            file_list.append(path)
        elif os.path.isdir(path):
            for root, dirs, files in os.walk(path):
                for file in files:
                    file_path = os.path.join(root, file)
                    file_list.append(file_path)
        else:
            raise ValueError(f"路径不存在: {path}")
        
        print(f"找到 {len(file_list)} 个文件")
        
        # 多线程计算哈希值
        checksums = []
        with concurrent.futures.ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            futures = [executor.submit(self._calculate_file_hash, file_path) for file_path in file_list]
            
            for i, future in enumerate(concurrent.futures.as_completed(futures), 1):
                result = future.result()
                checksums.append(result)
                print(f"\r处理进度: {i}/{len(file_list)}", end='')
        
        print("\n哈希计算完成")
        
        # 构造校验数据
        checksum_data = {
            'algorithm': self.algorithm,
            'generated_at': datetime.now().isoformat(),
            'base_path': os.path.abspath(path),
            'files': checksums
        }
        
        # 保存到文件
        if output_file:
            with open(output_file, 'w', encoding='utf-8') as f:
                json.dump(checksum_data, f, ensure_ascii=False, indent=2)
            print(f"校验数据已保存到: {output_file}")
        
        elapsed_time = time.time() - start_time
        print(f"生成校验数据耗时: {elapsed_time:.2f} 秒")
        
        return checksum_data
    
    def verify_checksum(self, checksum_file, path=None):
        """
        验证文件完整性
        
        Args:
            checksum_file: 校验文件路径
            path: 要验证的路径，默认为校验文件中的base_path
        
        Returns:
            验证结果字典
        """
        print(f"\n开始验证文件完整性: {checksum_file}")
        start_time = time.time()
        
        # 加载校验数据
        with open(checksum_file, 'r', encoding='utf-8') as f:
            checksum_data = json.load(f)
        
        # 验证算法是否匹配
        if checksum_data['algorithm'] != self.algorithm:
            print(f"警告: 校验文件使用的算法是 {checksum_data['algorithm']}，当前使用的是 {self.algorithm}")
            self.algorithm = checksum_data['algorithm']
        
        base_path = path or checksum_data['base_path']
        print(f"基准路径: {base_path}")
        
        # 统计结果
        results = {
            'total': len(checksum_data['files']),
            'passed': 0,
            'failed': 0,
            'missing': 0,
            'new': 0,
            'errors': []
        }
        
        # 获取当前目录的所有文件
        current_files = set()
        if os.path.isdir(base_path):
            for root, dirs, files in os.walk(base_path):
                for file in files:
                    file_path = os.path.join(root, file)
                    current_files.add(file_path)
        
        # 验证每个文件
        for file_info in checksum_data['files']:
            file_path = file_info['path']
            
            # 检查文件是否存在
            if not os.path.exists(file_path):
                results['missing'] += 1
                results['errors'].append({
                    'type': 'missing',
                    'path': file_path
                })
                continue
            
            # 计算当前文件的哈希值
            current_info = self._calculate_file_hash(file_path)
            
            if 'error' in current_info:
                results['errors'].append({
                    'type': 'error',
                    'path': file_path,
                    'message': current_info['error']
                })
                continue
            
            # 比较哈希值
            if current_info['hash'] == file_info['hash']:
                results['passed'] += 1
            else:
                results['failed'] += 1
                results['errors'].append({
                    'type': 'modified',
                    'path': file_path,
                    'expected_hash': file_info['hash'],
                    'actual_hash': current_info['hash']
                })
            
            # 从当前文件列表中移除
            if file_path in current_files:
                current_files.remove(file_path)
        
        # 检查新增文件
        results['new'] = len(current_files)
        for file_path in current_files:
            results['errors'].append({
                'type': 'new',
                'path': file_path
            })
        
        # 输出报告
        print("\n验证结果报告:")
        print(f"总文件数: {results['total']}")
        print(f"通过: {results['passed']}")
        print(f"修改: {results['failed']}")
        print(f"丢失: {results['missing']}")
        print(f"新增: {results['new']}")
        
        if results['errors']:
            print("\n详细错误:")
            for error in results['errors']:
                if error['type'] == 'modified':
                    print(f"  [修改] {error['path']}")
                elif error['type'] == 'missing':
                    print(f"  [丢失] {error['path']}")
                elif error['type'] == 'new':
                    print(f"  [新增] {error['path']}")
                elif error['type'] == 'error':
                    print(f"  [错误] {error['path']}: {error['message']}")
        else:
            print("\n所有文件验证通过！")
        
        elapsed_time = time.time() - start_time
        print(f"验证耗时: {elapsed_time:.2f} 秒")
        
        return results
```

## 五、总结与扩展学习

### 5.1 核心知识点回顾
- `hashlib`是Python标准库中实现加密哈希算法的核心模块
- 哈希函数具有确定性、不可逆性、雪崩效应和抗碰撞性四个核心特性
- MD5和SHA-1已经不安全，推荐使用SHA-256、SHA-512或SHA-3系列算法
- 分块更新数据可以处理大文件，避免内存溢出
- 加盐哈希和PBKDF2可以安全地存储密码
- HMAC用于验证数据的完整性和真实性
- SHAKE算法支持可变长度的输出

### 5.2 Python 3.14.0 hashlib的新特性
1. **性能优化**：SHA-2和SHA-3系列算法的速度提升了15-30%
2. **SHAKE增强**：完善了SHAKE128和SHAKE256的实现和文档
3. **算法检测改进**：提供了更准确的算法可用性检测
4. **错误信息优化**：错误信息更加清晰和详细
5. **安全修复**：修复了多个潜在的安全漏洞
