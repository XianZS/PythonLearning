# Python `cmath` 标准库详细教学文档

## 一、基础概念

`cmath` 是 Python 内置的**复数运算标准库**，提供了对 C 标准库中复数数学函数的封装，专门用于处理**复数**（Complex Numbers）的数学运算。

### 核心说明

1. **复数表示**：Python 中复数形式为 `a + bj`（`a` 为实部，`b` 为虚部，`j` 为虚数单位，满足 `j² = -1`）；

2. **与 ****`math`**** 的区别**：`math` 仅处理实数，输入复数会报错；`cmath` 支持复数输入 / 输出，函数名与 `math` 高度一致；

3. **返回值类型**：大多数函数返回 `complex` 类型（即使结果为实数，也会返回 `a + 0j` 形式）。

### 导入方式

```python
import cmath  # 推荐：避免命名冲突
# 或
from cmath import pi, sqrt  # 按需导入
```

## 二、常见基础用法

### 1. 复数的创建与基本属性

|操作 / 属性|说明|
|---|---|
|`a + bj`|直接创建复数（`a`、`b` 为实数）|
|`complex(a, b)`|通过 `complex()` 函数创建复数|
|`z.real`|获取复数 `z` 的实部（返回 `float`）|
|`z.imag`|获取复数 `z` 的虚部（返回 `float`）|
|`z.conjugate()`|获取复数 `z` 的共轭复数（`a - bj`）|

**示例代码**：

```python
# 1. 直接创建复数
z1 = 3 + 4j
print("z1 =", z1)  # 输出: z1 = (3+4j)

# 2. 通过 complex() 函数创建
z2 = complex(2, -5)
print("z2 =", z2)  # 输出: z2 = (2-5j)

# 3. 获取实部、虚部、共轭复数
print("z1 的实部:", z1.real)       # 输出: 3.0
print("z1 的虚部:", z1.imag)       # 输出: 4.0
print("z1 的共轭:", z1.conjugate())# 输出: (3-4j)
```

### 2. `cmath` 的数学常量

|常量|说明|示例值（近似）|
|---|---|---|
|`cmath.pi`|圆周率 π（与 `math.pi` 一致）|3.1415926535|
|`cmath.e`|自然对数底数 e（与 `math.e` 一致）|2.7182818284|
|`cmath.infj`|正无穷虚数（`0 + inf * j`）|infj|
|`cmath.nanj`|非数字虚数（`0 + nan * j`）|nanj|

**示例代码**：

```python
print("π ≈", cmath.pi)       # 输出: π ≈ 3.141592653589793
print("e ≈", cmath.e)        # 输出: e ≈ 2.718281828459045
print(cmath.infj)             # 输出: infj
print(cmath.nanj)             # 输出: nanj
```

### 3. 极坐标与直角坐标转换

复数可表示为**直角坐标形式**（`a + bj`）或**极坐标形式**（`r * e^(jφ)`，`r` 为模，`φ` 为幅角）。

|函数|说明|
|---|---|
|`cmath.polar(z)`|将复数 `z` 转换为极坐标，返回 `(r, phi)`（`r` 为模，`phi` 为幅角，弧度制）|
|`cmath.rect(r, phi)`|将极坐标 `(r, phi)` 转换为直角坐标复数|

**示例代码**：

```python
z = 3 + 4j

# 1. 直角坐标转极坐标
r, phi = cmath.polar(z)
print(f"极坐标形式: 模 = {r:.2f}, 幅角 = {phi:.2f} 弧度")
# 输出: 极坐标形式: 模 = 5.00, 幅角 = 0.93 弧度

# 2. 极坐标转直角坐标
z_rect = cmath.rect(r, phi)
print("转回直角坐标:", z_rect)  # 输出: 转回直角坐标: (3+4j)
```

### 4. 模与幅角的单独计算

|函数|说明|
|---|---|
|`abs(z)`|计算复数 `z` 的模（与 `cmath.polar(z)[0]` 一致，内置函数也支持）|
|`cmath.phase(z)`|计算复数 `z` 的幅角（弧度制，与 `cmath.polar(z)[1]` 一致）|

**示例代码**：

```python
z = 3 + 4j

# 计算模
print("模:", abs(z))          # 输出: 5.0
print("模:", cmath.polar(z)[0])  # 输出: 5.0

# 计算幅角
print("幅角（弧度）:", cmath.phase(z))  # 输出: 0.9272952180016122
print("幅角（角度）:", cmath.degrees(cmath.phase(z)))  # 输出: 53.13010235415598
```

## 三、常见进阶用法

### 1. 三角函数（复数版本）

`cmath` 支持复数的三角函数运算，输入 / 输出均为复数。

|函数|说明|
|---|---|
|`cmath.sin(z)`|复数正弦函数|
|`cmath.cos(z)`|复数余弦函数|
|`cmath.tan(z)`|复数正切函数|
|`cmath.asin(z)`|复数反正弦函数|
|`cmath.acos(z)`|复数反余弦函数|
|`cmath.atan(z)`|复数反正切函数|

**示例代码**：

```python
# 计算纯虚数的正弦（验证欧拉公式）
z = 1j  # 0 + 1j
sin_z = cmath.sin(z)
print("sin(1j) =", sin_z)  # 输出: sin(1j) = 1.1752011936438014j（双曲正弦 sinh(1)）

# 计算复数的余弦
z2 = 1 + 2j
cos_z2 = cmath.cos(z2)
print("cos(1+2j) =", cos_z2)  # 输出: cos(1+2j) = (2.0327230070196656-3.0518977991517997j)
```

### 2. 双曲函数

|函数|说明|
|---|---|
|`cmath.sinh(z)`|复数双曲正弦函数|
|`cmath.cosh(z)`|复数双曲余弦函数|
|`cmath.tanh(z)`|复数双曲正切函数|
|`cmath.asinh(z)`|复数反双曲正弦函数|
|`cmath.acosh(z)`|复数反双曲余弦函数|
|`cmath.atanh(z)`|复数反双曲正切函数|

**示例代码**：

```python
z = 1 + 1j

# 双曲正弦
sinh_z = cmath.sinh(z)
print("sinh(1+1j) =", sinh_z)  # 输出: sinh(1+1j) = (0.6349639135063251+1.2984575814159773j)

# 反双曲余弦（z 需满足 |z| ≥ 1）
acosh_z = cmath.acosh(2 + 0j)
print("acosh(2) =", acosh_z)  # 输出: acosh(2) = (1.3169578969248166+0j)
```

### 3. 指数与对数

|函数|说明|
|---|---|
|`cmath.exp(z)`|指数函数（`e^z`）|
|`cmath.log(z, base)`|对数函数（`base` 默认为 `e`）|
|`cmath.log10(z)`|以 10 为底的对数|
|`cmath.sqrt(z)`|平方根函数（支持负数，返回复数）|

**示例代码**：

```python
# 1. 验证欧拉公式：e^(jπ) + 1 = 0
euler = cmath.exp(1j * cmath.pi) + 1
print("e^(jπ) + 1 =", euler)  # 输出: e^(jπ) + 1 = 1.2246467991473532e-16j（≈ 0，浮点误差）

# 2. 计算负数的平方根（cmath 独有优势）
sqrt_minus_1 = cmath.sqrt(-1)
print("√(-1) =", sqrt_minus_1)  # 输出: √(-1) = 1j

sqrt_minus_4 = cmath.sqrt(-4)
print("√(-4) =", sqrt_minus_4)  # 输出: √(-4) = 2j

# 3. 复数的对数
z = 1 + 1j
log_z = cmath.log(z)
print("ln(1+1j) =", log_z)  # 输出: ln(1+1j) = (0.3465735902799727+0.7853981633974483j)
```

### 4. 特殊函数（Python 3.2+ 支持）

|函数|说明|版本要求|
|---|---|---|
|`cmath.gamma(z)`|复数伽马函数（阶乘的扩展）|Python 3.2+|
|`cmath.lgamma(z)`|复数伽马函数的自然对数|Python 3.2+|
|`cmath.erf(z)`|复数误差函数|Python 3.2+|
|`cmath.erfc(z)`|复数补误差函数（`1 - erf(z)`）|Python 3.2+|

**示例代码**：

```python
# 伽马函数（整数 n 的 gamma(n) = (n-1)!）
gamma_4 = cmath.gamma(4 + 0j)
print("gamma(4) =", gamma_4)  # 输出: gamma(4) = (6+0j)（3! = 6）

# 误差函数
erf_1j = cmath.erf(1j)
print("erf(1j) =", erf_1j)  # 输出: erf(1j) = 1.6504634922207523j
```

### 5. 复数的判断函数

|函数|说明|
|---|---|
|`cmath.isinf(z)`|判断复数 `z` 的实部或虚部是否为无穷大|
|`cmath.isnan(z)`|判断复数 `z` 的实部或虚部是否为 NaN|
|`cmath.isfinite(z)`|判断复数 `z` 是否为有限数（非 inf 非 nan）|

**示例代码**：

```python
z1 = 3 + cmath.infj
z2 = 2 + 3j
z3 = cmath.nanj + 5j

print(cmath.isinf(z1))    # 输出: True
print(cmath.isfinite(z2)) # 输出: True
print(cmath.isnan(z3))    # 输出: True
```

## 四、实战案例：RLC 串联交流电路分析

### 案例背景

在电子工程中，**RLC 串联电路**（电阻 R、电感 L、电容 C 串联）的阻抗、电流、谐振频率等分析需大量使用复数运算。本案例将用 `cmath` 实现以下功能：

1. 计算电路的**复数阻抗**；

2. 计算阻抗的**模**（总阻抗大小）和**幅角**（电流与电压的相位差）；

3. 计算电路的**谐振频率**（此时电路阻抗最小，电流最大）。

### 完整代码

```python
import cmath

class RLCCircuitAnalyzer:
    def __init__(self, R: float, L: float, C: float):
        """
        初始化 RLC 串联电路参数
        :param R: 电阻，单位：欧姆 (Ω)
        :param L: 电感，单位：亨利 (H)
        :param C: 电容，单位：法拉 (F)
        """
        self.R = R
        self.L = L
        self.C = C

    def calculate_impedance(self, omega: float) -> complex:
        """
        计算复数阻抗 Z = R + j(ωL - 1/(ωC))
        :param omega: 交流电源角频率，单位：rad/s
        :return: 复数阻抗 Z
        """
        XL = omega * self.L  # 感抗
        XC = 1 / (omega * self.C)  # 容抗
        Z = self.R + 1j * (XL - XC)
        return Z

    def analyze_impedance(self, omega: float) -> dict:
        """
        分析阻抗：返回模、幅角（弧度+角度）
        :param omega: 交流电源角频率，单位：rad/s
        :return: 包含阻抗信息的字典
        """
        Z = self.calculate_impedance(omega)
        Z_magnitude = abs(Z)  # 阻抗模
        Z_phase_rad = cmath.phase(Z)  # 幅角（弧度）
        Z_phase_deg = cmath.degrees(Z_phase_rad)  # 幅角（角度）
        
        return {
            "复数阻抗": Z,
            "阻抗模（Ω）": Z_magnitude,
            "幅角（弧度）": Z_phase_rad,
            "幅角（角度）": Z_phase_deg
        }

    def calculate_resonant_frequency(self) -> dict:
        """
        计算谐振频率 ω0 = 1/√(LC)，以及对应的频率 f0 = ω0/(2π)
        :return: 包含谐振角频率和频率的字典
        """
        omega0 = 1 / cmath.sqrt(self.L * self.C).real  # 取实部（结果为实数）
        f0 = omega0 / (2 * cmath.pi)
        return {
            "谐振角频率 ω0（rad/s）": omega0,
            "谐振频率 f0（Hz）": f0
        }


# ---------------------- 测试案例 ----------------------
if __name__ == "__main__":
    # 电路参数：R=10Ω, L=0.1H, C=10μF=10e-6F
    R = 10.0
    L = 0.1
    C = 10e-6

    # 初始化分析器
    analyzer = RLCCircuitAnalyzer(R, L, C)

    # 1. 计算谐振频率
    resonant_info = analyzer.calculate_resonant_frequency()
    print("=== 谐振频率分析 ===")
    print(f"谐振角频率 ω0 ≈ {resonant_info['谐振角频率 ω0（rad/s）']:.2f} rad/s")
    print(f"谐振频率 f0 ≈ {resonant_info['谐振频率 f0（Hz）']:.2f} Hzn")

    # 2. 分析某一角频率下的阻抗（例如 ω=1000 rad/s）
    omega_test = 1000.0
    impedance_info = analyzer.analyze_impedance(omega_test)
    print(f"=== 角频率 ω = {omega_test} rad/s 时的阻抗分析 ===")
    print(f"复数阻抗 Z = {impedance_info['复数阻抗']:.2f}")
    print(f"阻抗模 |Z| ≈ {impedance_info['阻抗模（Ω）']:.2f} Ω")
    print(f"幅角 φ ≈ {impedance_info['幅角（弧度）']:.2f} rad ≈ {impedance_info['幅角（角度）']:.2f}°")

    # 3. 分析谐振时的阻抗（ω=ω0）
    omega0 = resonant_info['谐振角频率 ω0（rad/s）']
    resonant_impedance = analyzer.analyze_impedance(omega0)
    print(f"n=== 谐振时（ω=ω0）的阻抗分析 ===")
    print(f"复数阻抗 Z = {resonant_impedance['复数阻抗']:.2f}")
    print(f"阻抗模 |Z| ≈ {resonant_impedance['阻抗模（Ω）']:.2f} Ω（此时阻抗最小，等于电阻 R）")
```

### 代码说明与输出

1. **谐振频率计算**：通过 `cmath.sqrt()` 计算 `1/√(LC)`，得到谐振角频率 `ω0`；

2. **阻抗分析**：计算复数阻抗 `Z = R + j(ωL - 1/(ωC))`，并通过 `abs()` 和 `cmath.phase()` 得到模和幅角；

3. **谐振时的特性**：当 `ω=ω0` 时，感抗等于容抗，阻抗虚部为 0，总阻抗最小（等于电阻 `R`）。

**运行输出示例**：


## 五、总结

- `cmath` 是 Python 处理复数运算的核心库，函数名与 `math` 一致，支持复数输入 / 输出；

- 核心功能包括：复数极坐标 / 直角坐标转换、三角函数、指数对数、特殊函数等；

- 实战场景广泛，如电子工程电路分析、信号处理、量子力学计算等。
