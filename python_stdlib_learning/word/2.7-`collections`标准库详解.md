# Bilibili Python：`collections`标准库详解

## 课程导入

Python 内置了 `dict`、`list`、`tuple` 等基础数据结构，但在实际开发中，我们经常会遇到一些痛点：

- 统计词频时，普通 `dict` 要写很多 `if key in dict` 的判断；

- 访问字典不存在的键时，直接报 `KeyError`；

- 元组的元素只能用索引访问，代码可读性差；

- 列表从头部添加 / 删除元素很慢（时间复杂度 O \(n\)）。

这时候就需要 **`collections`** 标准库！它是 Python 内置的 “数据结构工具箱”，提供了多个实用的**增强版数据结构**，能让你的代码更简洁、更高效、更易读！

本节课我们重点学习 `collections` 中最常用的 5 个类：`Counter`、`defaultdict`、`namedtuple`、`deque`，最后还有一个综合实战案例！

## 第一部分：`Counter` —— 元素计数器（统计神器）

### 核心知识点

`Counter` 是一个专门用来**统计可迭代对象中元素出现次数**的类，它继承自 `dict`，使用方式和字典类似，但自带 “统计 buff”。

### 常用方法

|方法|说明|
|---|---|
|`Counter\(iterable\)`|统计可迭代对象（列表、字符串、元组等）的元素次数|
|`most\_common\(n\)`|返回出现次数最多的前 n 个元素（列表套元组）|
|`elements\(\)`|返回所有元素的迭代器（按出现次数重复）|
|`subtract\(iterable\)`|减去另一个可迭代对象的元素次数|

### 示例代码

```python
from collections import Counter

# ====================== 1. 基础统计 ======================
# 统计列表中的元素次数
fruits = ["apple", "banana", "apple", "orange", "banana", "apple"]
fruit_counter = Counter(fruits)
print("水果统计：", fruit_counter)  # Counter({'apple': 3, 'banana': 2, 'orange': 1})

# 统计字符串中的字符次数
char_counter = Counter("hello world")
print("字符统计：", char_counter)  # Counter({'l': 3, 'o': 2, 'h': 1, ...})

# ====================== 2. most_common：获取 Top N ======================
print("\n出现次数最多的2个水果：", fruit_counter.most_common(2))  # [('apple', 3), ('banana', 2)]

# ====================== 3. elements：获取所有元素（含重复） ======================
print("\n所有水果（含重复）：", list(fruit_counter.elements()))  # ['apple', 'apple', 'apple', 'banana', 'banana', 'orange']

# ====================== 4. subtract：减去次数 ======================
more_fruits = ["apple", "orange"]
fruit_counter.subtract(more_fruits)
print("\n减去后的统计：", fruit_counter)  # Counter({'apple': 2, 'banana': 2, 'orange': 0})
```

### 内容讲解

- `Counter` 可以直接传入任何可迭代对象，自动统计次数，无需手动写循环判断。

- `most\_common\(n\)` 是最常用的方法，比如统计 “词频 Top 10”“销量最高的 5 个商品”，一行代码搞定。

- `Counter` 支持字典的所有操作（如 `counter\[key\]` 访问次数、`counter\[key\] = 5` 修改次数）。

### 应用场景

1. **文本词频统计**：统计文章中每个单词的出现次数。

2. **投票统计**：统计选举中每个候选人的票数。

3. **商品销量统计**：统计电商平台每个商品的销售数量。

## 第二部分：`defaultdict` —— 带默认值的字典（告别 KeyError）

### 核心知识点

普通 `dict` 访问不存在的键时会报 `KeyError`，而 `defaultdict` 可以在创建时指定一个**默认工厂函数**（如 `list`、`int`、`set`），当访问不存在的键时，会自动用工厂函数创建默认值，避免报错。

### 示例代码

```python
from collections import defaultdict

# ====================== 1. 用 list 作为默认工厂：分组数据 ======================
# 需求：把单词按首字母分组
words = ["apple", "banana", "apricot", "blueberry", "cherry"]
# 默认值是 list（空列表）
word_dict = defaultdict(list)

for word in words:
    first_char = word[0]
    word_dict[first_char].append(word)  # 不用判断 first_char 是否存在！

print("按首字母分组：", dict(word_dict))
# {'a': ['apple', 'apricot'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}

# ====================== 2. 用 int 作为默认工厂：统计次数 ======================
# 需求：统计每个字母的出现次数（比 Counter 更灵活的手动统计）
char_dict = defaultdict(int)  # 默认值是 int（0）
for char in "hello world":
    char_dict[char] += 1  # 不用判断 char 是否存在！

print("\n字母统计：", dict(char_dict))

# ====================== 3. 用 set 作为默认工厂：去重分组 ======================
# 需求：把学生按班级分组，且每个学生不重复
students = [("一班", "张三"), ("二班", "李四"), ("一班", "张三"), ("一班", "王五")]
class_dict = defaultdict(set)  # 默认值是 set（空集合）

for cls, name in students:
    class_dict[cls].add(name)  # 自动去重

print("\n按班级分组（去重）：", dict(class_dict))
# {'一班': {'张三', '王五'}, '二班': {'李四'}}
```

### 内容讲解

- **默认工厂函数**：

    - `list`：默认值是空列表 `\[\]`，适合分组数据。

    - `int`：默认值是 `0`，适合统计次数。

    - `set`：默认值是空集合 `set\(\)`，适合去重分组。

    - 也可以用自定义函数（如 `lambda: \&\#34;默认值\&\#34;`）。

- 对比普通 `dict`：用 `defaultdict` 可以省去大量的 `if key not in dict: dict\[key\] = \[\]` 代码，更简洁。

### 应用场景

1. **数据分组**：把用户按地区分组、把商品按类别分组。

2. **多值映射**：一个键对应多个值（如一个学生对应多个课程）。

3. **手动统计**：需要更灵活的统计逻辑时（比 Counter 更可控）。

## 第三部分：`namedtuple` —— 命名字段的元组（可读性爆表）

### 核心知识点

普通元组的元素只能用**索引**访问（如 `point\[0\]`），代码可读性差，时间久了容易忘记索引代表什么。`namedtuple` 可以创建一个**带字段名的元组子类**，元素既可以用索引访问，也可以用**字段名**访问，代码更清晰！

### 常用属性 / 方法

|属性 / 方法|说明|
|---|---|
|`namedtuple\(typename, field\_names\)`|创建 namedtuple 子类，typename 是类名，field\_names 是字段名列表 / 字符串|
|`\_fields`|获取所有字段名的元组|
|`\_asdict\(\)`|把 namedtuple 转为字典（Python 3\.8\+ 返回 OrderedDict，3\.9\+ 返回普通 dict）|

### 示例代码

```python
from collections import namedtuple

# ====================== 1. 创建 namedtuple 子类 ======================
# 方式1：字段名用列表
Point = namedtuple("Point", ["x", "y"])
# 方式2：字段名用空格分隔的字符串
Student = namedtuple("Student", "name age score")

# ====================== 2. 创建实例 ======================
p = Point(10, 20)
student = Student(name="张三", age=20, score=95)  # 也可以用关键字参数

# ====================== 3. 访问元素 ======================
print("点坐标（索引）：", p[0], p[1])  # 10 20
print("点坐标（字段名）：", p.x, p.y)  # 10 20（可读性更好！）

print("\n学生信息：", student)  # Student(name='张三', age=20, score=95)
print("学生姓名：", student.name)  # 张三
print("学生分数：", student.score)  # 95

# ====================== 4. 常用属性 ======================
print("\nPoint 的字段名：", Point._fields)  # ('x', 'y')
print("Student 转为字典：", student._asdict())  # {'name': '张三', 'age': 20, 'score': 95}
```

### 内容讲解

- `namedtuple` 创建的是**元组的子类**，所以它和普通元组一样是**不可变的**（不能修改字段值，如 `student\.age = 21` 会报错）。

- 优势：用字段名访问元素，代码可读性大大提高，适合表示简单的数据结构（如坐标、学生信息、API 返回值）。

- 对比字典：`namedtuple` 更轻量，占用内存更小，且字段名固定，不会出现拼写错误（字典的键容易拼错）。

### 应用场景

1. **表示数据记录**：如数据库查询结果、CSV 行数据。

2. **API 返回值**：把 API 返回的 JSON 数据转为 namedtuple，访问更方便。

3. **简单数据结构**：如二维坐标、三维向量、RGB 颜色值。

## 第四部分：`deque` —— 双端队列（两端操作都超快）

### 核心知识点

普通 `list` 从**头部**添加 / 删除元素很慢（因为要移动后面的所有元素，时间复杂度 O \(n\)），而 `deque`（double\-ended queue，双端队列）是专门为**两端高效操作**设计的，从头部 / 尾部添加 / 删除元素的时间复杂度都是 O \(1\)，非常快！

### 常用方法

|方法|说明|
|---|---|
|`append\(x\)`|在尾部添加元素|
|`appendleft\(x\)`|在头部添加元素|
|`pop\(\)`|从尾部删除并返回元素|
|`popleft\(\)`|从头部删除并返回元素|
|`maxlen`|固定队列长度（可选），超过长度时，添加新元素会自动删除另一端的元素|

### 示例代码

```python
from collections import deque

# ====================== 1. 基础两端操作 ======================
dq = deque([1, 2, 3])
print("初始队列：", dq)  # deque([1, 2, 3])

# 尾部操作
dq.append(4)
print("尾部添加4：", dq)  # deque([1, 2, 3, 4])
dq.pop()
print("尾部删除：", dq)  # deque([1, 2, 3])

# 头部操作（比 list 快很多！）
dq.appendleft(0)
print("头部添加0：", dq)  # deque([0, 1, 2, 3])
dq.popleft()
print("头部删除：", dq)  # deque([1, 2, 3])

# ====================== 2. 固定长度的队列（滑动窗口） ======================
# maxlen=3：队列最多3个元素，超过时自动删除头部元素
window = deque(maxlen=3)
for i in range(1, 6):
    window.append(i)
    print(f"添加{i}后：", window)
# 输出：
# 添加1后： deque([1], maxlen=3)
# 添加2后： deque([1, 2], maxlen=3)
# 添加3后： deque([1, 2, 3], maxlen=3)
# 添加4后： deque([2, 3, 4], maxlen=3)（自动删除1）
# 添加5后： deque([3, 4, 5], maxlen=3)（自动删除2）
```

### 内容讲解

- **性能对比**：当数据量很大时，`deque` 的 `appendleft`/`popleft` 比 `list` 的 `insert\(0, x\)`/`pop\(0\)` 快几个数量级，一定要用 `deque`！

- `maxlen` 参数：非常实用，比如实现 “滑动窗口”“最近使用记录”，超过长度自动删除旧元素，无需手动判断。

### 应用场景

1. **任务队列**：FIFO（先进先出）队列，处理任务。

2. **栈**：LIFO（后进先出）栈，用 `append`/`pop` 即可。

3. **滑动窗口**：处理数据流时，保留最近的 N 个数据。

4. **最近使用记录**：比如记录用户最近 10 次的搜索词。

## 第五部分：实战案例 —— 简易文本分析与查询记录系统

### 功能需求

结合 `Counter`、`defaultdict`、`namedtuple`、`deque`，实现一个简易系统：

1. **文本分析**：用 `Counter` 统计词频，用 `defaultdict` 按单词长度分组，用 `namedtuple` 表示分析结果。

2. **查询记录**：用 `deque` 记录最近 5 次的查询词，超过 5 次自动删除最早的。

### 完整实战代码

```python
from collections import Counter, defaultdict, namedtuple, deque

# 1. 定义 namedtuple：表示文本分析结果
AnalysisResult = namedtuple("AnalysisResult", ["word_count", "len_groups", "top3_words"])

class TextAnalyzer:
    def __init__(self):
        # 用 deque 记录最近 5 次查询
        self.query_history = deque(maxlen=5)

    def analyze(self, text):
        """分析文本，返回 AnalysisResult"""
        # 预处理：转小写，按空格分割（简单分词）
        words = text.lower().split()
        
        # 1. 用 Counter 统计词频
        word_counter = Counter(words)
        
        # 2. 用 defaultdict 按单词长度分组
        len_groups = defaultdict(list)
        for word in words:
            word_len = len(word)
            len_groups[word_len].append(word)
        
        # 3. 获取 Top 3 高频词
        top3_words = word_counter.most_common(3)
        
        # 返回 namedtuple
        return AnalysisResult(
            word_count=word_counter,
            len_groups=len_groups,
            top3_words=top3_words
        )

    def add_query(self, word):
        """添加查询词到历史记录"""
        self.query_history.append(word)
        print(f"已添加查询词：{word}")

    def show_history(self):
        """显示最近 5 次查询"""
        print("\n===== 最近 5 次查询 =====")
        if not self.query_history:
            print("暂无查询记录")
            return
        for i, word in enumerate(reversed(self.query_history), 1):
            print(f"{i}. {word}")

# ========== 测试使用 ==========
if __name__ == '__main__':
    analyzer = TextAnalyzer()

    # 1. 分析一段文本
    sample_text = "Python is a great language Python is easy to learn and Python is fun"
    result = analyzer.analyze(sample_text)

    print("===== 文本分析结果 =====")
    print("词频统计：", dict(result.word_count))
    print("按长度分组：", dict(result.len_groups))
    print("Top 3 高频词：", result.top3_words)

    # 2. 添加查询词
    analyzer.add_query("Python")
    analyzer.add_query("language")
    analyzer.add_query("easy")
    analyzer.add_query("fun")
    analyzer.add_query("learn")
    analyzer.add_query("great")  # 超过 5 次，自动删除最早的 "Python"

    # 3. 显示查询历史
    analyzer.show_history()
```

### 代码讲解

1. **`AnalysisResult`**** namedtuple**：把分析结果封装成带字段名的元组，访问 `result\.word\_count` 比访问元组索引更清晰。

2. **`analyze`**** 方法**：

    - `Counter` 统计词频，一行代码搞定。

    - `defaultdict\(list\)` 按单词长度分组，无需判断键是否存在。

    - `most\_common\(3\)` 获取 Top 3 高频词。

3. **`query\_history`**** deque**：`maxlen=5` 自动保留最近 5 次查询，添加新查询时自动删除最早的，非常方便。

4. **`show\_history`**** 方法**：用 `reversed` 倒序显示，最近的查询在最上面。

## 课程总结

### 核心知识点回顾

|类|功能|核心优势|
|---|---|---|
|`Counter`|统计元素次数|一行代码统计，`most\_common` 快速获取 Top N|
|`defaultdict`|带默认值的字典|告别 `KeyError`，分组 / 统计更简洁|
|`namedtuple`|命名字段的元组|可读性爆表，轻量不可变|
|`deque`|双端队列|两端操作 O \(1\)，`maxlen` 实现滑动窗口|

### 避坑指南

1. `namedtuple` 是不可变的，不能修改字段值。

2. 从列表头部操作时，一定要用 `deque`，不要用 `list`。

3. `defaultdict` 的默认工厂函数是**不带括号的**（如 `list`，不是 `list\(\)`）。
