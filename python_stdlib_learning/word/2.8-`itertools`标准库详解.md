# B 站 Python 授课：`itertools` 标准库 —— 迭代器的 “瑞士军刀”

## 课程导入

在处理数据、编写循环时，我们经常会遇到这些痛点：

- 想生成无限序列（如 1,2,3\.\.\.），但手动写循环太麻烦；

- 想拼接多个列表、或对列表做排列组合，自己写逻辑容易出错；

- 想对迭代器做切片、过滤，但普通列表切片会占用大量内存。

这时候就需要 **`itertools`** 标准库！它是 Python 内置的 “迭代器工具箱”，提供了大量高效、简洁的迭代器操作函数，能让你的代码更优雅、更高效、更易读！

本节课我们重点学习 `itertools` 中最常用的三类函数：**无限迭代器**、**有限迭代器**、**组合生成器**，最后还有一个综合实战案例！

---

## 第一部分：核心概念

### 1\. 什么是迭代器？

迭代器是一个可以 “记住遍历位置” 的对象，它实现了 `\_\_iter\_\_` 和 `\_\_next\_\_` 方法，能逐个返回元素（用 `next\(\)` 调用）。

- 优势：**惰性计算**（需要时才生成元素），不占用大量内存，适合处理大数据。

- 常见迭代器：列表、元组、字符串、生成器。

### 2\. `itertools` 的特点

- 所有函数返回的都是**迭代器**（不是列表），需要用 `list\(\)` 转换或用 `for` 循环遍历才能看到结果。

- 函数都是 “纯函数”，不修改原迭代器，而是返回新的迭代器。

---

## 第二部分：无限迭代器（生成 “永不停歇” 的序列）

### 1\. `count\(start=0, step=1\)` —— 生成无限递增序列

从 `start` 开始，每次加 `step`，生成无限序列。

### 示例代码

```python
import itertools

# 生成从 10 开始，步长为 2 的序列：10, 12, 14...
counter = itertools.count(10, 2)

# 用 next() 逐个获取（注意：不要直接用 list()，会无限循环！）
print(next(counter))  # 10
print(next(counter))  # 12
print(next(counter))  # 14

# 配合 islice 取前 5 个（后面会讲 islice）
print("\n前5个元素：", list(itertools.islice(counter, 5)))  # [16, 18, 20, 22, 24]
```

### 内容讲解

- 不要直接用 `list\(count\(\)\)`，会导致程序卡死（无限循环）。

- 通常配合 `islice` 或 `for` 循环加 `break` 使用。

### 应用场景

1. **生成唯一 ID**：比如 `count\(1000\)` 生成从 1000 开始的递增 ID。

2. **循环计数**：在 `for` 循环中自动计数，不用手动 `i \+= 1`。

---

### 2\. `cycle\(iterable\)` —— 无限循环遍历可迭代对象

把可迭代对象的元素无限重复循环。

### 示例代码

```python
import itertools

# 循环遍历 ["A", "B", "C"]
cycler = itertools.cycle(["A", "B", "C"])

print(next(cycler))  # A
print(next(cycler))  # B
print(next(cycler))  # C
print(next(cycler))  # A（回到开头）

# 配合 islice 取前 7 个
print("\n前7个元素：", list(itertools.islice(cycler, 7)))  # ['B', 'C', 'A', 'B', 'C', 'A', 'B']
```

### 应用场景

1. **循环切换状态**：比如红绿灯切换（红→绿→黄→红\.\.\.）。

2. **循环分配任务**：把任务轮流分配给多个员工。

---

### 3\. `repeat\(object, times=None\)` —— 重复生成某个对象

重复生成 `object`，如果指定 `times`，则重复 `times` 次，否则无限重复。

### 示例代码

```python
import itertools

# 无限重复 "Hello"
repeater = itertools.repeat("Hello")
print(next(repeater))  # Hello
print(next(repeater))  # Hello

# 重复 3 次 "Python"
print("\n重复3次：", list(itertools.repeat("Python", 3)))  # ['Python', 'Python', 'Python']

# 配合 map 使用：给每个元素乘 2
print("配合map：", list(map(lambda x, y: x * y, [1, 2, 3], itertools.repeat(2))))  # [2, 4, 6]
```

### 应用场景

1. **初始化列表**：比如 `\[0\] \* 10` 可以用 `list\(repeat\(0, 10\)\)` 替代（更清晰）。

2. **配合 map/zip**：给每个元素提供固定参数。

## 第三部分：有限迭代器（处理 “有限长度” 的序列）

### 1\. `chain\(\*iterables\)` —— 拼接多个迭代器

把多个迭代器 “串” 起来，依次遍历。

### 示例代码

```python
import itertools

# 拼接三个列表
list1 = [1, 2, 3]
list2 = ["A", "B"]
list3 = [True, False]

chained = itertools.chain(list1, list2, list3)
print("拼接结果：", list(chained))  # [1, 2, 3, 'A', 'B', True, False]

# 进阶：chain.from_iterable —— 拼接嵌套的迭代器
nested = [[1, 2], ["A", "B"], [True]]
print("嵌套拼接：", list(itertools.chain.from_iterable(nested)))  # [1, 2, 'A', 'B', True]
```

### 内容讲解

- `chain` 直接传入多个迭代器，`chain\.from\_iterable` 传入一个包含迭代器的迭代器（如嵌套列表）。

- 优势：不会生成中间列表，节省内存（尤其是处理大数据时）。

### 应用场景

1. **合并多个数据源**：比如合并两个数据库查询结果、合并多个文件的内容。

2. **扁平化嵌套列表**：把 `\[\[1,2\],\[3,4\]\]` 变成 `\[1,2,3,4\]`。

---

### 2\. `zip\_longest\(\*iterables, fillvalue=None\)` —— 不等长迭代器的 “zip”

普通 `zip` 会以最短的迭代器为准，而 `zip\_longest` 以最长的为准，短的用 `fillvalue` 填充。

### 示例代码

```python
import itertools

list1 = [1, 2, 3]
list2 = ["A", "B"]

# 普通 zip：以短的为准
print("普通zip：", list(zip(list1, list2)))  # [(1, 'A'), (2, 'B')]

# zip_longest：以长的为准，短的用 None 填充
print("zip_longest：", list(itertools.zip_longest(list1, list2)))  # [(1, 'A'), (2, 'B'), (3, None)]

# 指定 fillvalue
print("指定fillvalue：", list(itertools.zip_longest(list1, list2, fillvalue="缺省")))  # [(1, 'A'), (2, 'B'), (3, '缺省')]
```

### 应用场景

1. **处理不等长数据**：比如合并两个列数不同的表格，缺失值用默认值填充。

2. **多数据源对齐**：把时间序列不同步的数据对齐。

---

### 3\. `islice\(iterable, start, stop, step=1\)` —— 迭代器的 “切片”

对迭代器做切片，和列表切片类似，但**不生成中间列表**，节省内存。

### 示例代码

```python
import itertools

# 对 count 生成的无限序列做切片
counter = itertools.count(0, 1)
# 取索引 2 到 7（不包含7），步长 2
sliced = itertools.islice(counter, 2, 7, 2)
print("切片结果：", list(sliced))  # [2, 4, 6]

# 对列表做切片（和 list[1:5] 效果一样，但更省内存）
my_list = [0, 1, 2, 3, 4, 5, 6]
print("列表切片：", list(itertools.islice(my_list, 1, 5)))  # [1, 2, 3, 4]
```

### 内容讲解

- `islice` 不支持负数索引（因为迭代器不知道长度），如果需要从末尾取，得先转成列表。

- 优势：处理大文件或无限序列时，不会把所有元素加载到内存。

### 应用场景

1. **读取大文件的前 N 行**：不用把整个文件加载到内存。

2. **取无限序列的前 N 个元素**：比如配合 `count`、`cycle` 使用。

---

### 4\. `accumulate\(iterable, func=operator\.add\)` —— 生成前缀和（或其他累积操作）

默认生成前缀和，也可以指定 `func` 做其他累积操作（如累乘、最大值）。

### 示例代码

```python
import itertools
import operator

# 默认：前缀和
nums = [1, 2, 3, 4]
print("前缀和：", list(itertools.accumulate(nums)))  # [1, 3, 6, 10]

# 累乘
print("累乘：", list(itertools.accumulate(nums, operator.mul)))  # [1, 2, 6, 24]

# 累积最大值
nums2 = [3, 1, 4, 2, 5]
print("累积最大值：", list(itertools.accumulate(nums2, max)))  # [3, 3, 4, 4, 5]
```

### 应用场景

1. **计算累计销售额**：比如每天的销售额，生成累计到当天的总额。

2. **前缀最大值 / 最小值**：处理时间序列数据，找历史最高值。

## 第四部分：组合生成器（排列组合的 “神器”）

### 1\. `product\(\*iterables, repeat=1\)` —— 笛卡尔积

生成多个迭代器的笛卡尔积（所有可能的组合），`repeat` 表示重复迭代器的次数。

### 示例代码

```python
import itertools

# 两个列表的笛卡尔积
list1 = ["A", "B"]
list2 = [1, 2]
print("笛卡尔积：", list(itertools.product(list1, list2)))  # [('A', 1), ('A', 2), ('B', 1), ('B', 2)]

# 重复 2 次（相当于 product(list1, list1)）
print("重复2次：", list(itertools.product(list1, repeat=2)))  # [('A', 'A'), ('A', 'B'), ('B', 'A'), ('B', 'B')]
```

### 应用场景

1. **生成测试用例**：比如测试多个参数的所有组合。

2. **商品组合推荐**：比如不同颜色、不同尺寸的所有组合。

---

### 2\. `permutations\(iterable, r=None\)` —— 排列

生成可迭代对象中元素的所有排列（顺序不同算不同的），`r` 是排列的长度（默认是迭代器长度）。

### 示例代码

```python
import itertools

# 3个元素的全排列（长度3）
chars = ["A", "B", "C"]
print("全排列：", list(itertools.permutations(chars)))  # [('A','B','C'), ('A','C','B'), ...共6种]

# 排列长度为2
print("长度为2的排列：", list(itertools.permutations(chars, 2)))  # [('A','B'), ('A','C'), ('B','A'), ('B','C'), ('C','A'), ('C','B')]
```

### 内容讲解

- 排列是 “有序” 的：`\(\&\#39;A\&\#39;,\&\#39;B\&\#39;\)` 和 `\(\&\#39;B\&\#39;,\&\#39;A\&\#39;\)` 是不同的。

### 应用场景

1. **生成密码组合**：比如从几个字符中生成所有可能的密码。

2. **排列问题**：比如几个人排队，有多少种排法。

---

### 3\. `combinations\(iterable, r\)` —— 组合（不重复）

生成可迭代对象中元素的所有组合（顺序不同算同一个，元素不重复），`r` 是组合的长度（必填）。

### 示例代码

```python
import itertools

chars = ["A", "B", "C"]
# 组合长度为2（不重复，顺序无关）
print("组合（不重复）：", list(itertools.combinations(chars, 2)))  # [('A','B'), ('A','C'), ('B','C')]
```

### 内容讲解

- 组合是 “无序” 的：`\(\&\#39;A\&\#39;,\&\#39;B\&\#39;\)` 和 `\(\&\#39;B\&\#39;,\&\#39;A\&\#39;\)` 是同一个，只出现一次。

- 元素不重复：同一个元素不会在组合中出现多次。

### 应用场景

1. **抽奖问题**：比如从 10 个人中选 2 个人中奖，有多少种选法。

2. **商品组合**：比如从 5 个商品中选 3 个做套餐。

---

### 4\. `combinations\_with\_replacement\(iterable, r\)` —— 组合（可重复）

和 `combinations` 类似，但元素可以重复出现。

### 示例代码

```python
import itertools

chars = ["A", "B", "C"]
# 组合长度为2（可重复）
print("组合（可重复）：", list(itertools.combinations_with_replacement(chars, 2)))  # [('A','A'), ('A','B'), ('A','C'), ('B','B'), ('B','C'), ('C','C')]
```

### 应用场景

1. **可重复选择**：比如从 3 种饮料中选 2 杯（可以选同一种）。

2. **放回抽样**：统计学中的放回组合问题。

---

## 第五部分：常见应用场景

1. **数据处理**：用 `chain` 合并数据，用 `islice` 切片大文件，用 `accumulate` 计算累计值。

2. **组合数学**：用 `permutations`/`combinations` 解决排列组合问题。

3. **测试用例生成**：用 `product` 生成所有参数组合的测试用例。

4. **循环控制**：用 `count` 自动计数，用 `cycle` 循环切换状态。

## 第六部分：实战案例 —— 简易 “商品组合推荐系统”

### 功能需求

结合 `product`、`combinations`、`islice`，实现一个简易系统：

1. 有不同类别、颜色、尺寸的商品，用 `product` 生成所有可能的单品组合。

2. 从单品中选 2 个做套餐，用 `combinations` 生成所有套餐组合。

3. 用 `islice` 取前 5 个套餐推荐给用户。

### 完整实战代码

```python
import itertools

class ProductRecommender:
    def __init__(self):
        # 商品数据：类别、颜色、尺寸
        self.categories = ["T恤", "衬衫"]
        self.colors = ["红色", "蓝色"]
        self.sizes = ["S", "M", "L"]

    def generate_all_products(self):
        """生成所有单品（类别+颜色+尺寸的笛卡尔积）"""
        products = []
        # 用 product 生成所有组合
        for cat, color, size in itertools.product(self.categories, self.colors, self.sizes):
            product_name = f"{color}{cat}({size})"
            products.append(product_name)
        return products

    def generate_combo_packages(self, products, combo_size=2):
        """生成套餐组合（从单品中选 combo_size 个）"""
        # 用 combinations 生成不重复的组合
        combos = itertools.combinations(products, combo_size)
        return [f"套餐{i+1}: {combo[0]} + {combo[1]}" for i, combo in enumerate(combos)]

    def recommend_top_n(self, combos, n=5):
        """推荐前 n 个套餐（用 islice 切片）"""
        return list(itertools.islice(combos, n))

# ========== 测试使用 ==========
if __name__ == '__main__':
    recommender = ProductRecommender()

    # 1. 生成所有单品
    all_products = recommender.generate_all_products()
    print("===== 所有单品 =====")
    for product in all_products:
        print(product)

    # 2. 生成所有套餐
    all_combos = recommender.generate_combo_packages(all_products)
    print("\n===== 所有套餐（共{}个）=====".format(len(all_combos)))

    # 3. 推荐前 5 个
    top5 = recommender.recommend_top_n(all_combos, 5)
    print("\n===== 推荐前 5 个套餐 =====")
    for combo in top5:
        print(combo)
```

### 代码讲解

1. **`generate\_all\_products`**** 方法**：用 `product` 生成类别、颜色、尺寸的所有组合，生成单品名称。

2. **`generate\_combo\_packages`**** 方法**：用 `combinations` 从单品中选 2 个，生成套餐（不重复，顺序无关）。

3. **`recommend\_top\_n`**** 方法**：用 `islice` 取前 `n` 个套餐，不用生成所有套餐的列表（节省内存）。

4. 运行后会生成所有单品、所有套餐，并推荐前 5 个，非常直观！

## 课程总结

### 核心知识点回顾

|类别|函数|功能|
|---|---|---|
|无限迭代器|`count`|无限递增序列|
||`cycle`|无限循环遍历|
||`repeat`|重复生成对象|
|有限迭代器|`chain`|拼接多个迭代器|
||`zip\_longest`|不等长 zip|
||`islice`|迭代器切片|
||`accumulate`|前缀和 / 累积操作|
|组合生成器|`product`|笛卡尔积|
||`permutations`|排列（有序）|
||`combinations`|组合（无序，不重复）|
||`combinations\_with\_replacement`|组合（无序，可重复）|

### 避坑指南

1. 无限迭代器不要直接用 `list\(\)` 转换，会无限循环。

2. `islice` 不支持负数索引。

3. 组合生成器返回的是迭代器，需要用 `list\(\)` 转换或 `for` 循环遍历。
