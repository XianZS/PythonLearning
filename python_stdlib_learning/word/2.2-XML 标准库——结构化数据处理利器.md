# B站Python授课：`xml` 标准库——结构化数据处理的经典工具

## 课程导入

虽然 JSON 是目前最流行的数据交换格式，但 **XML（eXtensible Markup Language）** 在特定场景下仍不可替代：它结构化更强、支持命名空间、可通过 Schema/DTD 验证数据格式，广泛应用于配置文件（如 Android 布局、Spring 配置）、RSS 订阅、Web 服务（SOAP）等领域。

Python 内置的 `xml` 标准库提供了多种处理 XML 的方式，其中 **`xml.etree.ElementTree`**（简称 ET）是最简洁高效的模块，适合大多数 XML 处理场景。本节课我们将重点学习它。

---

## 第一部分：核心概念与基础解析

### 核心知识点

1. **XML 基本结构**：由标签（Tag）、属性（Attribute）、文本（Text）和子元素（Child Element）组成，例如：

    ```XML
    
    <book id="1">
        <title>Python入门</title>
        <author>张三</author>
    </book>
    ```

    - `<book>` 是标签，`id="1"` 是属性，`<title>` 是 `<book>` 的子元素，`Python入门` 是 `<title>` 的文本。

2. **ElementTree 核心类**：

    - `Element`：代表 XML 中的一个节点（标签），是操作 XML 的基本单元。

    - `ElementTree`：代表整个 XML 文档，用于解析和保存文件。

### 示例代码

```Python

import xml.etree.ElementTree as ET

# 1. 解析 XML 字符串
xml_str = '''
<library>
    <book id="1">
        <title>Python入门</title>
        <author>张三</author>
        <price>99</price>
    </book>
    <book id="2">
        <title>XML教程</title>
        <author>李四</author>
        <price>0</price>
    </book>
</library>
'''
root = ET.fromstring(xml_str)  # 直接解析字符串，返回根元素
print(f"根元素标签：{root.tag}")

# 2. 解析 XML 文件（先准备一个 library.xml 文件，内容同上）
# tree = ET.parse("library.xml")
# root = tree.getroot()  # 获取根元素
```

### 内容讲解

- `ET.fromstring(xml_str)`：适合解析内存中的 XML 字符串，直接返回根元素 `Element`。

- `ET.parse(file_path)`：适合解析 XML 文件，返回 `ElementTree` 对象，需调用 `getroot()` 获取根元素。

- 根元素是整个 XML 文档的入口，所有后续操作都从根元素开始。

### 应用场景

1. **配置文件解析**：解析软件的 XML 格式配置文件（如 `settings.xml`）。

2. **API 响应解析**：解析返回 XML 格式的 Web 服务接口（如部分传统企业 API）。

## 第二部分：遍历与查找 XML 元素

### 核心知识点

获取根元素后，我们需要遍历或查找特定的子元素，ElementTree 提供了三种常用方式：

1. **直接遍历**：用 `for` 循环遍历根元素的直接子元素。

2. **`find()`** **/** **`findall()`**：按标签名查找（`find` 找第一个，`findall` 找所有）。

3. **`iter()`**：递归查找所有层级的元素（适合查找嵌套深的元素）。

同时，通过 `element.get(attr_name)` 获取属性，`element.text` 获取文本内容。

### 示例代码

```Python

import xml.etree.ElementTree as ET

xml_str = '''
<library>
    <book id="1">
        <title>Python入门</title>
        <author>张三</author>
        <price>99</price>
    </book>
    <book id="2">
        <title>XML教程</title>
        <author>李四</author>
        <price>0</price>
    </book>
</library>
'''
root = ET.fromstring(xml_str)

# 1. 直接遍历根元素的直接子元素
print("=== 直接遍历 ===")
for book in root:
    print(f"图书标签：{book.tag}，图书ID：{book.get('id')}")

# 2. find()/findall() 查找
print("\n=== find/findall ===")
first_book = root.find("book")  # 找第一个 <book>
print(f"第一本图书标题：{first_book.find('title').text}")

all_books = root.findall("book")  # 找所有 <book>
for book in all_books:
    title = book.find("title").text
    price = book.find("price").text
    print(f"图书：{title}，价格：{price}")

# 3. iter() 递归查找所有层级
print("\n=== iter() 递归查找 ===")
for title in root.iter("title"):  # 查找所有 <title>，无论嵌套多深
    print(f"标题：{title.text}")
```

### 内容讲解

- `find(tag)`：仅查找**直接子元素**中第一个匹配的标签，找不到返回 `None`。

- `findall(tag)`：查找**直接子元素**中所有匹配的标签，返回列表。

- `iter(tag)`：递归查找**所有层级**（包括子元素的子元素）中匹配的标签，返回迭代器（适合大数据量）。

- `element.get(attr)`：获取属性值，若属性不存在返回 `None`；也可用 `element.attrib` 获取所有属性的字典。

### 应用场景

1. **RSS 订阅解析**：用 `iter()` 查找 RSS XML 中的所有 `<item>` 元素，提取标题和链接。

2. **配置项提取**：从 XML 配置中用 `find()` 查找特定的配置项（如数据库连接信息）。

## 第三部分：修改与保存 XML 文档

### 核心知识点

ElementTree 支持修改 XML 元素的文本、属性，添加/删除子元素，修改后需用 `ElementTree.write()` 保存到文件。

### 示例代码

```Python

import xml.etree.ElementTree as ET

xml_str = '''
<library>
    <book id="1">
        <title>Python入门</title>
        <author>张三</author>
        <price>99</price>
    </book>
</library>
'''
root = ET.fromstring(xml_str)
tree = ET.ElementTree(root)  # 包装成 ElementTree 对象，用于保存

# 1. 修改文本和属性
book = root.find("book")
book.find("price").text = "89"  # 修改价格文本
book.set("category", "编程")    # 添加/修改属性

# 2. 添加子元素
new_book = ET.Element("book", id="2")  # 创建新 <book> 元素，带 id 属性
# 用 SubElement 快速创建子元素（推荐）
ET.SubElement(new_book, "title").text = "XML进阶"
ET.SubElement(new_book, "author").text = "王五"
ET.SubElement(new_book, "price").text = "59"
root.append(new_book)  # 将新 <book> 添加到根元素

# 3. 删除元素
# 先找到要删除的元素，再用 root.remove()
# 例如删除 id="1" 的图书
for book in root.findall("book"):
    if book.get("id") == "1":
        root.remove(book)
        break

# 4. 保存到文件
# 参数：文件路径、编码、是否缩进（xml_declaration 用于添加 XML 声明）
tree.write("modified_library.xml", encoding="utf-8", xml_declaration=True)
print("已保存到 modified_library.xml")
```

### 内容讲解

- **修改文本**：直接赋值 `element.text = "new_text"`。

- **修改属性**：用 `element.set(attr_name, attr_value)`，若属性不存在则添加，存在则覆盖。

- **添加子元素**：

    - 方式1：`ET.Element(tag, attrib)` 创建元素，再用 `root.append(element)` 添加。

    - 方式2：`ET.SubElement(parent, tag, attrib)` 直接在父元素下创建子元素（更简洁）。

- **删除元素**：需先找到目标元素，再用 `parent.remove(element)` 删除（只能删除直接子元素）。

- **保存文件**：`tree.write()` 默认编码为 `us-ascii`，中文需设 `encoding="utf-8"`，`xml_declaration=True` 会在文件开头添加 `<?xml version='1.0' encoding='utf-8'?>`。

### 应用场景

1. **配置文件更新**：修改 XML 配置文件中的参数（如修改数据库端口）并保存。

2. **数据导出**：将程序中的数据生成 XML 格式并保存到文件（如导出报表）。

## 第四部分：创建 XML 文档（从零开始）

### 核心知识点

除了解析和修改现有 XML，我们还可以从零创建一个完整的 XML 文档。创建流程：

1. 创建根元素 `ET.Element(root_tag)`。

2. 用 `ET.SubElement()` 逐层创建子元素。

3. 包装成 `ET.ElementTree(root)` 并保存。

如果需要**美化输出**（缩进格式化），ElementTree 本身不直接支持，可结合 `xml.dom.minidom` 实现。

### 示例代码

```Python

import xml.etree.ElementTree as ET
from xml.dom import minidom

# 1. 从零创建 XML
root = ET.Element("students")  # 根元素 <students>

# 添加第一个学生
student1 = ET.SubElement(root, "student", id="101")
ET.SubElement(student1, "name").text = "赵六"
ET.SubElement(student1, "age").text = "20"
ET.SubElement(student1, "major").text = "计算机科学"

# 添加第二个学生
student2 = ET.SubElement(root, "student", id="102")
ET.SubElement(student2, "name").text = "孙七"
ET.SubElement(student2, "age").text = "21"
ET.SubElement(student2, "major").text = "软件工程"

# 2. 简单保存（无美化）
tree = ET.ElementTree(root)
tree.write("students.xml", encoding="utf-8", xml_declaration=True)

# 3. 美化输出（结合 minidom）
def prettify_xml(element):
    """将 Element 转为美化后的 XML 字符串"""
    rough_string = ET.tostring(element, encoding="utf-8")
    reparsed = minidom.parseString(rough_string)
    return reparsed.toprettyxml(indent="  ")  # 缩进2空格

# 保存美化后的 XML
pretty_xml_str = prettify_xml(root)
with open("students_pretty.xml", "w", encoding="utf-8") as f:
    f.write(pretty_xml_str)
print("已保存美化后的 students_pretty.xml")
```

### 内容讲解

- `ET.tostring(element)`：将 Element 转为二进制字符串，用于 minidom 解析。

- `minidom.parseString()` 解析后调用 `toprettyxml(indent)` 生成美化字符串，缩进更易读。

- 注意：minidom 生成的美化字符串可能会包含多余的空行，简单场景可接受，复杂场景可手动去除。

### 应用场景

1. **数据导出**：将数据库查询结果生成 XML 格式文件（如导出学生信息）。

2. **测试数据生成**：生成测试用的 XML 数据文件，用于单元测试。

## 第五部分：常见应用场景

### 场景1：RSS 订阅解析（模拟）

```Python

import xml.etree.ElementTree as ET

# 模拟 RSS 2.0 XML
rss_xml = '''
<rss version="2.0">
    <channel>
        <title>技术博客</title>
        <link>https://example.com</link>
        <item>
            <title>Python XML 教程</title>
            <link>https://example.com/xml</link>
            <pubDate>2026-04-14</pubDate>
        </item>
        <item>
            <title>Python JSON 教程</title>
            <link>https://example.com/json</link>
            <pubDate>2026-04-13</pubDate>
        </item>
    </channel>
</rss>
'''

root = ET.fromstring(rss_xml)
channel = root.find("channel")
print(f"博客标题：{channel.find('title').text}")
print("=== 最新文章 ===")
for item in channel.iter("item"):
    print(f"标题：{item.find('title').text}")
    print(f"链接：{item.find('link').text}")
    print(f"发布日期：{item.find('pubDate').text}\n")
```

### 场景2：配置文件管理

```Python

import xml.etree.ElementTree as ET

config_path = "app_config.xml"

# 加载配置
def load_config():
    try:
        tree = ET.parse(config_path)
        root = tree.getroot()
        return {
            "db_host": root.find("database/host").text,
            "db_port": int(root.find("database/port").text),
            "log_level": root.find("log/level").text
        }
    except FileNotFoundError:
        # 配置不存在则创建默认配置
        root = ET.Element("config")
        db = ET.SubElement(root, "database")
        ET.SubElement(db, "host").text = "localhost"
        ET.SubElement(db, "port").text = "3306"
        log = ET.SubElement(root, "log")
        ET.SubElement(log, "level").text = "INFO"
        tree = ET.ElementTree(root)
        tree.write(config_path, encoding="utf-8", xml_declaration=True)
        return load_config()

# 使用配置
config = load_config()
print(f"数据库主机：{config['db_host']}，端口：{config['db_port']}")
```

## 实战案例：简单的图书信息管理系统

### 功能需求

1. 用 XML 文件 `books.xml` 存储图书信息（每本图书包含 `id`、`title`、`author`、`price`）。

2. 支持**添加图书**（自动生成唯一 `id`）。

3. 支持**查询所有图书**。

4. 支持**删除图书**（按 `id` 删除）。

5. 所有操作后自动保存 XML 文件。

### 完整代码

```Python

import xml.etree.ElementTree as ET
from xml.dom import minidom
from pathlib import Path

class BookManager:
    def __init__(self, xml_path="books.xml"):
        self.xml_path = Path(xml_path)
        self.root = None
        self.load_or_init()

    def load_or_init(self):
        """加载 XML 或初始化空的 XML"""
        if self.xml_path.exists():
            tree = ET.parse(self.xml_path)
            self.root = tree.getroot()
        else:
            self.root = ET.Element("books")
            self.save_xml()

    def save_xml(self):
        """美化并保存 XML"""
        rough_string = ET.tostring(self.root, encoding="utf-8")
        reparsed = minidom.parseString(rough_string)
        pretty_xml = reparsed.toprettyxml(indent="  ")
        with open(self.xml_path, "w", encoding="utf-8") as f:
            f.write(pretty_xml)

    def get_next_id(self):
        """获取下一个可用的图书 ID（最大 ID + 1）"""
        max_id = 0
        for book in self.root.findall("book"):
            book_id = int(book.get("id"))
            if book_id > max_id:
                max_id = book_id
        return max_id + 1

    def add_book(self, title, author, price):
        """添加图书"""
        book_id = self.get_next_id()
        book = ET.SubElement(self.root, "book", id=str(book_id))
        ET.SubElement(book, "title").text = title
        ET.SubElement(book, "author").text = author
        ET.SubElement(book, "price").text = str(price)
        self.save_xml()
        print(f"已添加图书：{title}（ID：{book_id}）")

    def list_books(self):
        """查询所有图书"""
        if not self.root.findall("book"):
            print("暂无图书")
            return
        print("=== 图书列表 ===")
        for book in self.root.findall("book"):
            book_id = book.get("id")
            title = book.find("title").text
            author = book.find("author").text
            price = book.find("price").text
            print(f"ID：{book_id} | 标题：{title} | 作者：{author} | 价格：{price}")

    def delete_book(self, book_id):
        """按 ID 删除图书"""
        for book in self.root.findall("book"):
            if book.get("id") == str(book_id):
                self.root.remove(book)
                self.save_xml()
                print(f"已删除 ID 为 {book_id} 的图书")
                return
        print(f"未找到 ID 为 {book_id} 的图书")

# 测试使用
if __name__ == "__main__":
    manager = BookManager()
    # 添加图书
    manager.add_book("Python入门", "张三", 99)
    manager.add_book("XML教程", "李四", 0)
    # 列出所有图书
    manager.list_books()
    # 删除图书
    manager.delete_book(1)
    # 再次列出
    manager.list_books()
```

### 代码讲解

1. **`BookManager`** ** 类**：封装所有图书管理功能，代码结构清晰。

2. **`load_or_init()`**：如果 XML 文件存在则加载，不存在则创建空的 `<books>` 根元素。

3. **`save_xml()`**：结合 minidom 美化 XML 后保存，方便阅读。

4. **`get_next_id()`**：遍历现有图书，找到最大 ID 并 +1，确保 ID 唯一。

5. **测试部分**：演示添加、查询、删除功能，运行后会生成 `books.xml` 文件。
