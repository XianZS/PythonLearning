# Python 3.14.0 `queue` 标准库完全学习指南

> 本文档基于 Python 3.14.0 编写，确保内容准确性与时效性。`queue` 模块是 Python 中用于多线程编程的线程安全队列实现，广泛应用于生产者-消费者模式、任务调度等场景。


## 一、概念与核心价值

### 1.1 什么是 `queue` 模块？
`queue` 模块提供了**线程安全**的队列类，用于在多线程环境中安全地传递数据。它内部实现了锁机制，避免了多线程同时访问共享数据时的竞态条件（Race Condition）。

### 1.2 核心队列类型
| 类名          | 特性                     | 适用场景               |
|---------------|--------------------------|------------------------|
| `Queue`       | 先进先出（FIFO）         | 标准任务队列           |
| `LifoQueue`   | 后进先出（LIFO，栈结构） | 深度优先搜索、回溯算法 |
| `PriorityQueue` | 按优先级排序             | 任务调度、紧急事件处理 |


## 二、基础部分：核心类与基本操作

### 2.1 `Queue`（FIFO 队列）

#### 理论讲解
- **初始化**：`Queue(maxsize=0)`，`maxsize` 为队列最大容量（0 表示无限制）。
- **核心方法**：
  - `put(item, block=True, timeout=None)`：放入元素。
  - `get(block=True, timeout=None)`：取出并删除元素。
  - `qsize()`：返回队列近似大小（非绝对准确，因多线程动态变化）。
  - `empty()`：判断队列是否为空。
  - `full()`：判断队列是否已满。

#### 示例代码
```python
import queue

# 1. 创建 FIFO 队列
q = queue.Queue(maxsize=3)

# 2. 放入元素
q.put("任务1")
q.put("任务2")
q.put("任务3")

# 3. 队列状态检查
print("队列是否满:", q.full())  # 输出: True
print("队列大小:", q.qsize())   # 输出: 3

# 4. 取出元素（FIFO 顺序）
while not q.empty():
    print("处理:", q.get())  # 输出: 任务1 → 任务2 → 任务3
```


### 2.2 `LifoQueue`（LIFO 栈）

#### 理论讲解
继承自 `Queue`，但数据结构为**栈**（后进先出）。方法与 `Queue` 完全一致，仅取出顺序不同。

#### 示例代码
```python
import queue

lq = queue.LifoQueue()
lq.put("步骤1")
lq.put("步骤2")
lq.put("步骤3")

while not lq.empty():
    print("回退:", lq.get())  # 输出: 步骤3 → 步骤2 → 步骤1
```


### 2.3 `PriorityQueue`（优先级队列）

#### 理论讲解
- 元素需为**可比较的元组**，格式为 `(priority, data)`，`priority` 越小优先级越高。
- 若优先级相同，按元组后续元素排序（需确保可比较）。

#### 示例代码
```python
import queue

pq = queue.PriorityQueue()

# 放入元组 (优先级, 任务内容)
pq.put((2, "普通任务"))
pq.put((1, "紧急任务"))
pq.put((3, "低优先级任务"))

while not pq.empty():
    priority, task = pq.get()
    print(f"执行 [优先级{priority}]: {task}")
    # 输出: 执行 [优先级1]: 紧急任务 → 执行 [优先级2]: 普通任务 → ...
```


## 三、进阶部分：阻塞、同步与高级技巧

### 3.1 阻塞与非阻塞操作

#### 理论讲解
- `block=True`（默认）：队列满时 `put()` 阻塞，队列空时 `get()` 阻塞。
- `timeout`：设置阻塞超时时间（秒），超时后抛出 `queue.Full` 或 `queue.Empty` 异常。
- `block=False`：非阻塞模式，立即抛出异常（等价于 `timeout=0`）。

#### 示例代码
```python
import queue

q = queue.Queue(maxsize=2)
q.put(1)
q.put(2)

try:
    # 队列已满，尝试非阻塞放入
    q.put(3, block=False)
except queue.Full:
    print("队列已满！")  # 输出: 队列已满！

try:
    # 队列空时，等待 1 秒
    q.get(timeout=1)
    q.get(timeout=1)
    q.get(timeout=1)  # 第三次获取时队列为空
except queue.Empty:
    print("等待超时，队列为空！")  # 输出: 等待超时，队列为空！
```


### 3.2 `join()` 与 `task_done()`：任务同步

#### 理论讲解
- `task_done()`：消费者线程调用，标记队列中一个任务处理完成。
- `join()`：阻塞主线程，直到队列中所有任务都被处理（即所有 `put()` 的任务都调用了 `task_done()`）。

#### 示例代码
```python
import queue
import threading
import time

def worker(q):
    while True:
        item = q.get()
        print(f"处理任务: {item}")
        time.sleep(1)  # 模拟耗时操作
        q.task_done()  # 关键：通知任务完成

q = queue.Queue()

# 启动守护线程（主线程结束时自动退出）
t = threading.Thread(target=worker, args=(q,), daemon=True)
t.start()

# 提交 3 个任务
for i in range(3):
    q.put(f"任务{i}")

print("等待所有任务完成...")
q.join()  # 阻塞直到所有 task_done() 被调用
print("全部任务处理完毕！")
```


### 3.3 多线程安全深度解析
`queue` 模块的线程安全源于内部的**互斥锁（Lock）**和**条件变量（Condition）**：
- 每次 `put()`/`get()` 都会自动获取锁，操作完成后释放。
- 条件变量用于线程间通信（如队列空时通知生产者，队列满时通知消费者）。


## 四、实战案例：多线程生产者-消费者模型

### 需求描述
模拟一个餐厅后厨系统：
- 2 个厨师（生产者）随机生成菜品。
- 3 个服务员（消费者）取餐并配送。
- 队列最大容量为 5，避免菜品堆积。

### 完整代码
```python
import queue
import threading
import time
import random

class Chef(threading.Thread):
    """生产者：厨师"""
    def __init__(self, name, dish_queue):
        super().__init__()
        self.name = name
        self.dish_queue = dish_queue

    def run(self):
        for _ in range(3):  # 每个厨师做 3 道菜
            dish = f"{random.choice(['宫保鸡丁', '鱼香肉丝', '麻婆豆腐'])}"
            try:
                self.dish_queue.put(dish, timeout=1)
                print(f"🍳 {self.name} 制作了: {dish}")
            except queue.Full:
                print(f"⚠️ 队列已满，{self.name} 等待中...")
            time.sleep(random.uniform(0.5, 1.5))

class Waiter(threading.Thread):
    """消费者：服务员"""
    def __init__(self, name, dish_queue):
        super().__init__()
        self.name = name
        self.dish_queue = dish_queue

    def run(self):
        while True:
            try:
                dish = self.dish_queue.get(timeout=2)
                print(f"🍽️ {self.name} 配送了: {dish}")
                time.sleep(random.uniform(1, 2))
            except queue.Empty:
                print(f"🏁 {self.name} 下班了（无餐可送）")
                break
            finally:
                self.dish_queue.task_done()  # 无论成功失败，标记任务完成

if __name__ == "__main__":
    dish_queue = queue.Queue(maxsize=5)

    # 创建生产者（厨师）
    chefs = [Chef(f"厨师{i}", dish_queue) for i in range(2)]
    # 创建消费者（服务员）
    waiters = [Waiter(f"服务员{i}", dish_queue) for i in range(3)]

    # 启动所有线程
    for chef in chefs:
        chef.start()
    for waiter in waiters:
        waiter.start()

    # 等待所有厨师做完菜
    for chef in chefs:
        chef.join()

    # 等待所有菜品配送完成
    dish_queue.join()
    print("\n🎉 今日营业结束！")
```


## 五、学习建议
1. **先基础后进阶**：熟练掌握 `Queue` 的基本操作后，再学习 `PriorityQueue` 和多线程同步。
2. **动手实验**：修改实战案例中的线程数量、队列大小，观察输出变化。
3. **注意陷阱**：
   - `PriorityQueue` 的元素必须是可比较的（避免混合类型）。
   - 守护线程中避免使用 `join()`，否则可能导致死锁。
