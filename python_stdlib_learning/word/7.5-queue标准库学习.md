# Python 3.14 `queue` 标准库完全学习指南

## 一、概念：为什么需要 `queue`？
### 1. 核心定位
`queue` 是 Python 标准库中提供的**线程安全队列实现**，专门用于解决**多线程编程**中的两个核心问题：
- **线程间通信**：安全地在多个线程之间传递数据；
- **解耦与流量控制**：通过“生产者-消费者”模式分离任务生成与处理逻辑，避免线程直接共享复杂变量。

### 2. 关键区分：`queue.Queue` vs `multiprocessing.Queue`
| 维度         | `queue.Queue`                | `multiprocessing.Queue`       |
|--------------|-------------------------------|--------------------------------|
| 适用场景     | 线程间通信                    | 进程间通信                     |
| 底层实现     | 线程锁 + `collections.deque` | 管道 + 序列化（`pickle`）     |
| 性能         | 高（无序列化开销）            | 较低（需序列化数据）           |

### 3. Python 3.14 兼容性说明
`queue` 模块是 Python 中非常稳定的标准库，Python 3.14 未对其进行重大变更，本文档内容完全兼容 Python 3.7+ 版本。


## 二、基础部分：核心队列类型与操作
`queue` 模块提供了 3 种核心队列类型，均支持线程安全的并发访问。

### 1. 三种队列类型
#### 1.1 FIFO 队列：`Queue`（先进先出）
最常用的队列类型，元素按“先放入先取出”的顺序处理。
```python
import queue

# 创建 FIFO 队列（maxsize=0 表示无限大小，>0 表示最大容量）
q = queue.Queue(maxsize=3)

# 放入元素（put(item, block=True, timeout=None)）
q.put("A")
q.put("B")
q.put("C")
# q.put("D")  # 队列已满，会阻塞直到有空间

# 取出元素（get(block=True, timeout=None)）
print(q.get())  # A
print(q.get())  # B
print(q.get())  # C
# print(q.get())  # 队列已空，会阻塞直到有元素
```

#### 1.2 LIFO 队列：`LifoQueue`（后进先出，即栈）
元素按“后放入先取出”的顺序处理。
```python
# 创建 LIFO 队列
lq = queue.LifoQueue()

lq.put("A")
lq.put("B")
lq.put("C")

print(lq.get())  # C
print(lq.get())  # B
print(lq.get())  # A
```

#### 1.3 优先级队列：`PriorityQueue`（按优先级取出）
元素需是**可比较的元组**（格式：`(优先级, 数据)`），优先级数字越小，越先被取出。
```python
# 创建优先级队列
pq = queue.PriorityQueue()

# 放入元素：(优先级, 数据)，优先级越小越优先
pq.put((2, "任务B"))
pq.put((1, "任务A"))
pq.put((3, "任务C"))

print(pq.get())  # (1, '任务A')
print(pq.get())  # (2, '任务B')
print(pq.get())  # (3, '任务C')
```

### 2. 核心基本操作
| 方法/属性               | 说明                                  | 注意事项                                  |
|-------------------------|---------------------------------------|-------------------------------------------|
| `put(item, block=True, timeout=None)` | 放入元素                              | `block=True` 时队列满会阻塞；`timeout` 为超时时间（秒） |
| `get(block=True, timeout=None)` | 取出元素                              | `block=True` 时队列空会阻塞；取出元素会从队列中移除 |
| `put_nowait(item)`      | 非阻塞放入元素（等价于 `put(item, block=False)`） | 队列满时抛出 `queue.Full` 异常          |
| `get_nowait()`          | 非阻塞取出元素（等价于 `get(block=False)`） | 队列空时抛出 `queue.Empty` 异常          |
| `qsize()`               | 返回队列当前大小                      | 多线程下**仅作参考**，不保证精确性       |
| `empty()`               | 判断队列是否为空                      | 多线程下**仅作参考**，不保证精确性       |
| `full()`                | 判断队列是否已满                      | 多线程下**仅作参考**，不保证精确性       |
| `task_done()`           | 标记“一个任务已处理完成”              | 需配合 `join()` 使用，每个 `get()` 后需调用一次 |
| `join()`                | 阻塞直到队列中所有任务被标记为完成    | 需配合 `task_done()` 使用                |

### 3. 基础操作示例：非阻塞与超时
```python
import queue
import time

q = queue.Queue(maxsize=2)

# 1. 非阻塞放入
try:
    q.put_nowait("A")
    q.put_nowait("B")
    q.put_nowait("C")  # 队列满，抛出 Full 异常
except queue.Full:
    print("队列已满，无法放入 C")

# 2. 超时放入
try:
    q.put("C", timeout=1)  # 等待 1 秒，若队列仍满则抛出 Full 异常
except queue.Full:
    print("等待 1 秒后队列仍满，无法放入 C")

# 3. 非阻塞取出
try:
    print(q.get_nowait())  # A
    print(q.get_nowait())  # B
    print(q.get_nowait())  # 队列空，抛出 Empty 异常
except queue.Empty:
    print("队列已空，无法取出元素")

# 4. 超时取出
try:
    q.get(timeout=1)  # 等待 1 秒，若队列仍空则抛出 Empty 异常
except queue.Empty:
    print("等待 1 秒后队列仍空，无法取出元素")
```


## 三、进阶部分：深度技巧与最佳实践
### 1. 线程安全原理解析
`queue.Queue` 的线程安全是通过**内部锁机制**实现的：
- 底层用 `collections.deque` 存储元素（双端队列，插入/删除效率高）；
- 用 `threading.Condition` 实现“队列空/满”的条件等待，避免忙等待（Busy Waiting）。

因此，**多线程环境下可直接使用 `queue.Queue`，无需额外加锁**。

### 2. 生产者-消费者模式完整实现
这是 `queue` 模块的核心应用场景，需配合 `task_done()` 和 `join()` 实现“任务完成等待”。

#### 示例：多生产者 + 多消费者
```python
import queue
import threading
import time
import random

# 共享队列
task_queue = queue.Queue(maxsize=5)

def producer(name, count):
    """生产者：生成任务并放入队列"""
    for i in range(count):
        task = f"{name}-任务{i}"
        try:
            task_queue.put(task, timeout=1)
            print(f"[生产者 {name}] 放入: {task}")
            time.sleep(random.uniform(0.1, 0.5))  # 模拟生产耗时
        except queue.Full:
            print(f"[生产者 {name}] 队列满，等待中...")

def consumer(name):
    """消费者：从队列取出任务并处理"""
    while True:
        try:
            # 非阻塞取出，若队列空则等待 0.5 秒后检查是否退出
            task = task_queue.get(timeout=0.5)
            if task is None:  # 用 None 作为“结束哨兵”
                task_queue.task_done()
                print(f"[消费者 {name}] 收到结束信号，退出")
                break
            print(f"[消费者 {name}] 处理: {task}")
            time.sleep(random.uniform(0.2, 0.6))  # 模拟处理耗时
            task_queue.task_done()  # 标记任务完成
        except queue.Empty:
            continue  # 队列空，继续循环

if __name__ == "__main__":
    # 1. 启动生产者
    producers = [
        threading.Thread(target=producer, args=("P1", 3)),
        threading.Thread(target=producer, args=("P2", 3))
    ]
    for p in producers:
        p.start()

    # 2. 启动消费者
    consumers = [
        threading.Thread(target=consumer, args=("C1",)),
        threading.Thread(target=consumer, args=("C2",))
    ]
    for c in consumers:
        c.start()

    # 3. 等待所有生产者完成
    for p in producers:
        p.join()

    # 4. 放入“结束哨兵”，通知消费者退出
    for _ in consumers:
        task_queue.put(None)

    # 5. 等待队列中所有任务处理完成
    task_queue.join()

    # 6. 等待所有消费者退出
    for c in consumers:
        c.join()

    print("所有任务处理完成！")
```

### 3. 优雅终止线程的技巧
在生产者-消费者模式中，**不要强制终止线程**（如 `thread.terminate()`），推荐用“哨兵值”（如 `None`）通知线程主动退出，如上述示例所示。

### 4. 注意事项（避坑指南）
1. **不要依赖 `qsize()`/`empty()`/`full()` 的精确性**：多线程下，这些方法的返回值可能在判断后立即被其他线程修改，仅作参考。
2. **每个 `get()` 后必须调用 `task_done()`**：否则 `join()` 会永远阻塞。
3. **避免在队列中放入不可序列化的对象**：虽然 `queue.Queue` 本身不需要序列化，但如果后续可能扩展到多进程，提前保持良好习惯。
4. **合理设置 `maxsize`**：避免队列无限增长导致内存溢出，同时避免 `maxsize` 过小导致频繁阻塞。


## 四、实战案例：多线程日志处理系统
### 需求
实现一个简化的多线程日志处理系统：
1. **生产者线程**：模拟生成日志（随机生成日志级别和内容）；
2. **消费者线程**：从队列取出日志，按级别分类处理（如“ERROR”级写入文件，其他级打印到控制台）；
3. 用 `PriorityQueue` 优先处理“ERROR”级日志。

### 代码实现
```python
import queue
import threading
import time
import random
from datetime import datetime

# 日志级别优先级：ERROR(1) > WARNING(2) > INFO(3)
LOG_PRIORITY = {
    "ERROR": 1,
    "WARNING": 2,
    "INFO": 3
}

# 优先级队列：(优先级, 时间戳, 日志内容)
log_queue = queue.PriorityQueue()

def generate_log():
    """模拟生成日志"""
    level = random.choice(list(LOG_PRIORITY.keys()))
    content = f"这是一条{level}级日志，随机数: {random.randint(1, 100)}"
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    return (LOG_PRIORITY[level], timestamp, level, content)

def log_producer(count):
    """日志生产者：生成日志并放入优先级队列"""
    for _ in range(count):
        log = generate_log()
        log_queue.put(log)
        print(f"[生产者] 放入日志: {log[2]} - {log[3]}")
        time.sleep(random.uniform(0.1, 0.3))

def log_consumer():
    """日志消费者：按优先级处理日志"""
    while True:
        try:
            # 取出日志（优先级最高的先取出）
            priority, timestamp, level, content = log_queue.get(timeout=1)
            if level == "EXIT":  # 结束哨兵
                log_queue.task_done()
                print("[消费者] 收到结束信号，退出")
                break
            
            # 分类处理
            if level == "ERROR":
                # ERROR 级写入文件
                with open("error.log", "a", encoding="utf-8") as f:
                    f.write(f"[{timestamp}] [{level}] {content}\n")
                print(f"[消费者] 处理 ERROR 日志（已写入文件）: {content}")
            else:
                # 其他级打印到控制台
                print(f"[消费者] 处理 {level} 日志: [{timestamp}] {content}")
            
            time.sleep(random.uniform(0.2, 0.4))
            log_queue.task_done()
        except queue.Empty:
            continue

if __name__ == "__main__":
    # 1. 清空旧的 error.log
    open("error.log", "w").close()

    # 2. 启动生产者（生成 10 条日志）
    producer_thread = threading.Thread(target=log_producer, args=(10,))
    producer_thread.start()

    # 3. 启动 2 个消费者
    consumer_threads = [
        threading.Thread(target=log_consumer),
        threading.Thread(target=log_consumer)
    ]
    for t in consumer_threads:
        t.start()

    # 4. 等待生产者完成
    producer_thread.join()

    # 5. 放入结束哨兵
    for _ in consumer_threads:
        log_queue.put((0, "", "EXIT", ""))

    # 6. 等待所有日志处理完成
    log_queue.join()

    # 7. 等待消费者退出
    for t in consumer_threads:
        t.join()

    print("\n=== 所有日志处理完成 ===")
    print("ERROR 级日志已保存到 error.log")
```


## 五、总结
1. **核心价值**：`queue` 模块是**多线程编程**的“瑞士军刀”，通过线程安全的队列实现解耦与通信，避免复杂的锁操作。
2. **核心选择**：
   - 普通任务流：`Queue`（FIFO）；
   - 栈场景：`LifoQueue`；
   - 优先级任务：`PriorityQueue`（元素格式：`(优先级, 数据)`）。
3. **最佳实践**：
   - 生产者-消费者模式配合 `task_done()` 和 `join()` 使用；
   - 用“哨兵值”优雅终止线程；
   - 不要依赖 `qsize()`/`empty()`/`full()` 的精确性。
