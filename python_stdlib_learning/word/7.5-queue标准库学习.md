# Python 3.14 `queue` 标准库学习文档

`queue` 是 Python 标准库中专门用于**多线程安全队列**的模块，提供了多种队列实现，核心价值是在并发编程中实现线程间的安全数据传递与任务协作。


## 一、概念与核心原理

### 1.1 队列的基本定义
队列（Queue）是一种**先进先出（FIFO）**的线性数据结构，元素从队尾入队（`put`），从队头出队（`get`）。`queue` 模块扩展了基础队列概念，提供了更多变体。

### 1.2 `queue` 模块的核心价值
`queue` 模块的队列是**线程安全**的：内部通过 `threading.Condition` 实现了锁机制，多个线程可以同时对队列进行 `put`/`get` 操作而不会出现数据竞争。

### 1.3 三种队列类型对比
| 队列类               | 特性                     | 适用场景               |
|----------------------|--------------------------|------------------------|
| `queue.Queue`        | 先进先出（FIFO）         | 普通任务调度、消息传递 |
| `queue.LifoQueue`    | 后进先出（LIFO，类似栈） | 深度优先搜索、回溯场景 |
| `queue.PriorityQueue`| 按优先级出队             | 任务优先级调度、紧急处理 |


## 二、基础部分：核心 API 与使用

### 2.1 通用队列方法（以 `Queue` 为例）
所有队列类共享以下核心方法，我们以 `Queue` 为例详细说明：

#### （1）入队与出队
- `put(item, block=True, timeout=None)`：将元素放入队列
  - `block=True`：队列满时阻塞，直到有空间
  - `timeout`：阻塞超时时间（秒），超时抛出 `queue.Full`
- `get(block=True, timeout=None)`：从队列取出元素
  - `block=True`：队列空时阻塞，直到有元素
  - `timeout`：阻塞超时时间（秒），超时抛出 `queue.Empty`

#### （2）非阻塞版本
- `put_nowait(item)`：等价于 `put(item, block=False)`，队列满直接抛 `Full`
- `get_nowait()`：等价于 `get(block=False)`，队列空直接抛 `Empty`

#### （3）状态查询
- `qsize()`：返回队列当前元素数量（注意：多线程下仅作参考，不保证精确）
- `empty()`：判断队列是否为空（同样仅作参考）
- `full()`：判断队列是否已满（仅作参考）

#### （4）任务完成标记
- `task_done()`：标记队列中一个任务已完成（供 `join()` 使用）
- `join()`：阻塞直到队列中所有任务都被标记为 `task_done()`


### 2.2 FIFO 队列（`Queue`）示例
```python
import queue

# 创建一个FIFO队列，maxsize=3表示最多容纳3个元素
q = queue.Queue(maxsize=3)

# 入队
q.put("任务1")
q.put("任务2")
q.put("任务3")

print("队列是否满：", q.full())  # 输出：True
print("队列大小：", q.qsize())   # 输出：3

# 尝试入队第4个元素（非阻塞，会抛Full异常）
try:
    q.put_nowait("任务4")
except queue.Full:
    print("队列已满，入队失败")

# 出队（FIFO顺序）
print("出队：", q.get())  # 输出：任务1
print("出队：", q.get())  # 输出：任务2
print("队列是否空：", q.empty())  # 输出：False

# 标记任务完成（配合join使用）
q.task_done()
q.task_done()

# 阻塞直到所有任务完成（此时队列还有1个元素未标记done，会阻塞）
# q.join()  # 取消注释会阻塞，因为还有"任务3"未调用task_done()
```


### 2.3 LIFO 队列（`LifoQueue`）示例
`LifoQueue` 实现了**后进先出**（类似栈）的逻辑：
```python
import queue

lq = queue.LifoQueue()

# 入队
lq.put("第一步")
lq.put("第二步")
lq.put("第三步")

# 出队（LIFO顺序）
print(lq.get())  # 输出：第三步
print(lq.get())  # 输出：第二步
print(lq.get())  # 输出：第一步
```


### 2.4 优先级队列（`PriorityQueue`）示例
`PriorityQueue` 按**优先级**出队，优先级越小越先出队。通常传入元组 `(priority, item)`：
```python
import queue

pq = queue.PriorityQueue()

# 入队：(优先级, 任务内容)，优先级数字越小越优先
pq.put((3, "普通任务"))
pq.put((1, "紧急任务"))
pq.put((2, "重要任务"))
pq.put((1, "另一个紧急任务"))  # 同优先级按插入顺序

# 出队（按优先级）
print(pq.get())  # 输出：(1, '紧急任务')
print(pq.get())  # 输出：(1, '另一个紧急任务')
print(pq.get())  # 输出：(2, '重要任务')
print(pq.get())  # 输出：(3, '普通任务')
```

注意：`PriorityQueue` 的元素必须是**可比较**的，若直接传入自定义对象，需实现 `__lt__` 等比较方法。


## 三、进阶部分：高级特性与模式

### 3.1 线程安全机制详解
`queue` 模块的线程安全基于 `threading.Condition` 实现：
- 内部维护一个互斥锁（`Lock`），保证 `put`/`get` 操作的原子性
- 维护两个条件变量（`not_full` 和 `not_empty`）：
  - 队列满时，`put` 线程等待 `not_full` 条件
  - 队列空时，`get` 线程等待 `not_empty` 条件
- 当元素出队后，唤醒等待 `not_full` 的线程；元素入队后，唤醒等待 `not_empty` 的线程

这使得多线程环境下无需手动加锁即可安全使用队列。


### 3.2 生产者-消费者模式（多线程）
生产者-消费者是 `queue` 最经典的应用场景：生产者线程生成任务放入队列，消费者线程从队列取出任务处理。

```python
import queue
import threading
import time
import random

# 任务队列
task_queue = queue.Queue(maxsize=5)

def producer(name):
    """生产者：生成任务"""
    for i in range(3):
        task = f"{name}-任务{i}"
        try:
            task_queue.put(task, block=True, timeout=1)
            print(f"{name} 生产了：{task}")
            time.sleep(random.uniform(0.5, 1))  # 模拟生产耗时
        except queue.Full:
            print(f"{name} 队列满，等待中...")

def consumer(name):
    """消费者：处理任务"""
    while True:
        try:
            # 非阻塞获取，若队列为空则退出（实际场景可改为持久运行）
            task = task_queue.get(block=True, timeout=2)
            print(f"{name} 消费了：{task}")
            time.sleep(random.uniform(1, 1.5))  # 模拟处理耗时
            task_queue.task_done()  # 标记任务完成
        except queue.Empty:
            print(f"{name} 队列空，退出")
            break

# 创建2个生产者、3个消费者
producers = [threading.Thread(target=producer, args=(f"生产者{i}",)) for i in range(2)]
consumers = [threading.Thread(target=consumer, args=(f"消费者{i}",)) for i in range(3)]

# 启动线程
for p in producers:
    p.start()
for c in consumers:
    c.start()

# 等待生产者完成
for p in producers:
    p.join()

# 等待队列中所有任务处理完成
task_queue.join()
print("所有任务处理完毕")
```


### 3.3 队列容量限制与阻塞控制
通过 `maxsize` 限制队列容量可以实现**背压（Backpressure）**：当队列满时，生产者会被阻塞，防止任务堆积过多导致内存溢出。

若需要更灵活的阻塞控制，可以结合 `empty()`/`full()` 与 `time.sleep()` 实现轮询（但推荐直接使用 `put`/`get` 的 `block` 和 `timeout` 参数）。


### 3.4 异常处理与最佳实践
1. **始终处理 `Full`/`Empty` 异常**：在非阻塞或带超时的 `put`/`get` 中，务必捕获异常避免程序崩溃
2. **配对使用 `task_done()` 和 `join()`**：若使用 `join()` 等待任务完成，每个 `get()` 后必须调用 `task_done()`
3. **避免在队列中存储大对象**：队列仅传递引用，大对象建议通过共享内存或文件传递
4. **`qsize()`/`empty()`/`full()` 不保证精确**：多线程下这些方法的返回值可能瞬间失效，仅作参考


## 四、实战案例：多线程日志处理系统

我们将实现一个**多线程日志处理系统**：
- 生产者线程生成模拟日志（带优先级）
- 优先级队列存储日志（错误日志优先处理）
- 消费者线程解析日志并写入文件

```python
import queue
import threading
import time
import random
from datetime import datetime

# 日志优先级：1=ERROR, 2=WARNING, 3=INFO
LOG_PRIORITY = {"ERROR": 1, "WARNING": 2, "INFO": 3}
log_queue = queue.PriorityQueue()

def generate_log():
    """生成模拟日志"""
    log_types = list(LOG_PRIORITY.keys())
    log_type = random.choice(log_types)
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    message = f"这是一条{log_type}日志，内容随机"
    return (LOG_PRIORITY[log_type], timestamp, log_type, message)

def log_producer(count):
    """生产者：生成日志并放入队列"""
    for _ in range(count):
        log = generate_log()
        log_queue.put(log)
        print(f"[生产者] 放入日志：{log[2]} - {log[1]}")
        time.sleep(random.uniform(0.2, 0.5))

def log_consumer(output_file):
    """消费者：从队列取出日志并写入文件"""
    with open(output_file, "a", encoding="utf-8") as f:
        while True:
            try:
                # 超时5秒无日志则退出
                priority, timestamp, log_type, message = log_queue.get(timeout=5)
                log_line = f"[{timestamp}] [{log_type}] {message}\n"
                f.write(log_line)
                f.flush()  # 立即写入磁盘
                print(f"[消费者] 处理日志：{log_type} (优先级:{priority})")
                log_queue.task_done()
                time.sleep(random.uniform(0.3, 0.7))  # 模拟处理耗时
            except queue.Empty:
                print("[消费者] 5秒无日志，退出")
                break

if __name__ == "__main__":
    # 启动1个生产者，生成10条日志
    producer_thread = threading.Thread(target=log_producer, args=(10,))
    # 启动2个消费者，写入不同文件
    consumer_thread1 = threading.Thread(target=log_consumer, args=("log1.txt",))
    consumer_thread2 = threading.Thread(target=log_consumer, args=("log2.txt",))

    producer_thread.start()
    consumer_thread1.start()
    consumer_thread2.start()

    producer_thread.join()
    log_queue.join()
    print("所有日志处理完成")
```

### 案例说明
1. **优先级队列**：ERROR 日志（优先级1）会比 INFO 日志（优先级3）先处理
2. **线程安全**：多个消费者同时写入不同文件，队列保证日志不会重复处理
3. **优雅退出**：消费者通过超时检测自动退出，`join()` 确保所有日志处理完毕


## 五、学习建议
1. **先掌握基础用法**：从 `Queue` 的 `put`/`get` 开始，理解阻塞与非阻塞模式
2. **结合多线程练习**：生产者-消费者模式是最好的实践场景
3. **阅读源码**：`queue` 模块源码简洁（约300行），适合学习线程同步的实现
4. **区分 `queue` 与 `multiprocessing.Queue`**：前者用于线程间通信，后者用于进程间通信
