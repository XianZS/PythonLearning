# Python `fractions` 标准库详细教学文档（适配 Python 3.14）

## 一、基础概念

`fractions` 是 Python 内置的**精确有理数（分数）运算标准库**，核心功能是通过分子、分母的整数运算彻底解决浮点数精度误差问题，是数学教学、财务计算、工程测量等需要精确比例场景的首选工具。

### 核心说明

1. **解决的痛点**：浮点数因二进制存储限制存在精度误差（如 `0.1 + 0.2 ≠ 0.3`），而 `fractions` 基于整数运算保证结果 100% 精确。

2. **核心类**：库的核心是 `Fraction` 类，每个实例代表一个分数，自动进行**约分**，且分子、分母始终保持为互质整数。

3. **版本兼容**：Python 3.14 对 `fractions` 进行了内部性能优化，提升了大分数运算的效率，同时保持了全版本 API 兼容。

### 导入方式

```python
from fractions import Fraction  # 推荐：直接导入核心类
import fractions  # 全局导入（较少用）
```

## 二、常见基础用法

### 1. 创建 `Fraction` 实例的 5 种方式

`Fraction` 支持从多种数据类型创建，覆盖绝大多数使用场景。

|创建方式|示例代码|输出结果|注意事项|
|---|---|---|---|
|从单个整数创建|`Fraction(5)`|`5/1`|分母默认为 1|
|从分子、分母创建|`Fraction(4, 6)`|`2/3`|自动约分，分母不能为 0|
|从字符串创建|`Fraction(&#39;3/4&#39;)`<br>`Fraction(&#39;1.5&#39;)`<br>`Fraction(&#39;1e-2&#39;)`|`3/4`<br>`3/2`<br>`1/100`|支持分数、小数、科学计数法格式|
|从 `Decimal` 创建（推荐）|`from decimal import Decimal`<br>`Fraction(Decimal(&#39;0.1&#39;))`|`1/10`|避免浮点数转分数的精度陷阱|
|从浮点数创建（慎用）|`Fraction(0.1)`|`3602879701896397/36028797018963968`|浮点数本身不精确，转换结果会有偏差|

**示例代码**：

```python
from fractions import Fraction
from decimal import Decimal

# 1. 从整数创建
print(Fraction(5))          # 输出: 5/1

# 2. 从分子分母创建（自动约分）
print(Fraction(4, 6))       # 输出: 2/3
# print(Fraction(1, 0))     # 报错: ZeroDivisionError

# 3. 从字符串创建
print(Fraction('3/4'))      # 输出: 3/4
print(Fraction('1.5'))      # 输出: 3/2
print(Fraction('1e-2'))     # 输出: 1/100

# 4. 从 Decimal 创建（精确转换）
print(Fraction(Decimal('0.1')))  # 输出: 1/10

# 5. 从浮点数创建（精度陷阱演示）
print(Fraction(0.1))        # 输出: 3602879701896397/36028797018963968（非预期）
```

> 新手避坑：**尽量用字符串或 ****`Decimal`**** 转分数**，避免直接用浮点数创建，否则会引入浮点数本身的精度误差。
> 
> 

### 2. 核心属性：分子与分母

每个 `Fraction` 实例都有 `numerator`（分子）和 `denominator`（分母）两个只读属性，且始终互质。

**示例代码**：

```python
frac = Fraction(6, 8)  # 自动约分为 3/4
print("分子:", frac.numerator)    # 输出: 3
print("分母:", frac.denominator)  # 输出: 4
```

### 3. 基本算术运算

`Fraction` 支持所有基础算术运算符（`+`、`-`、`*`、`/`、`**`），运算结果仍为 `Fraction`，保持精确性。

**示例代码**：

```python
a = Fraction(1, 4)  # 1/4
b = Fraction(1, 2)  # 1/2

# 加减乘除
print(a + b)  # 输出: 3/4
print(a - b)  # 输出: -1/4
print(a * b)  # 输出: 1/8
print(a / b)  # 输出: 1/2

# 幂运算
print(a ** 2)  # 输出: 1/16
print(b ** -1) # 输出: 2/1（倒数）
```

### 4. 比较运算

`Fraction` 的比较运算完全精确，无需担心浮点数的比较误差。

**示例代码**：

```python
# 精确比较
print(Fraction(3, 4) == Fraction(6, 8))  # 输出: True（约分后相等）
print(Fraction(1, 3) < Fraction(1, 2))   # 输出: True

# 与整数、浮点数混合比较（自动类型转换）
print(Fraction(3, 4) == 0.75)             # 输出: True
print(Fraction(5, 2) > 2)                  # 输出: True
```

## 三、常见进阶用法

### 1. `limit_denominator()`：近似分数（限制分母大小）

这是 `fractions` 最实用的进阶方法，用于将浮点数或复杂分数转换为**分母不超过指定值的近似分数**，常用于数学近似（如 π 的近似）、工程简化计算。

**示例代码**：

```python
from fractions import Fraction
from math import pi

# 将 π 转换为分母不超过 1000 的近似分数
pi_frac = Fraction(pi).limit_denominator(1000)
print("π 的近似分数:", pi_frac)          # 输出: 355/113（经典近似值）
print("近似值与 π 的误差:", float(pi_frac) - pi)  # 输出: ~2.6676e-7（极小）

# 简化复杂分数
complex_frac = Fraction(12345, 67890)
simple_frac = complex_frac.limit_denominator(100)
print("简化前:", complex_frac)  # 输出: 823/4526
print("简化后:", simple_frac)   # 输出: 18/101（分母≤100的最佳近似）
```

### 2. 分数的格式化输出

结合 Python 字符串格式化，可灵活控制分数的显示方式（分数形式、小数形式、带分数形式）。

**示例代码**：

```python
frac = Fraction(7, 4)  # 7/4 = 1.75

# 基础显示
print(f"分数形式: {frac}")          # 输出: 分数形式: 7/4
print(f"小数形式: {float(frac)}")   # 输出: 小数形式: 1.75

# 自定义带分数显示（如 7/4 → 1又3/4）
whole = frac.numerator // frac.denominator
remainder = frac.numerator % frac.denominator
if whole > 0 and remainder > 0:
    print(f"带分数形式: {whole}又{remainder}/{frac.denominator}")
elif whole > 0:
    print(f"整数形式: {whole}")
else:
    print(f"分数形式: {remainder}/{frac.denominator}")
# 输出: 带分数形式: 1又3/4
```

### 3. 与其他类型的转换

`Fraction` 可灵活转换为 `float`、`int`、`Decimal` 等类型，注意转换规则。

|转换目标|示例代码|输出结果|转换规则|
|---|---|---|---|
|`float`|`float(Fraction(3, 4))`|`0.75`|直接计算分子 / 分母|
|`int`|`int(Fraction(7, 4))`<br>`int(Fraction(1, 2))`|`1`<br>`0`|向零截断（丢弃小数部分）|
|`Decimal`|`from decimal import Decimal`<br>`Decimal(Fraction(3, 4))`|`Decimal(&#39;0.75&#39;)`|精确转换|

**示例代码**：

```python
from fractions import Fraction
from decimal import Decimal

frac = Fraction(7, 4)

# 转 float
print(float(frac))  # 输出: 1.75

# 转 int（向零截断）
print(int(frac))    # 输出: 1
print(int(Fraction(-7, 4)))  # 输出: -1

# 转 Decimal
print(Decimal(frac))  # 输出: 1.75
```

### 4. 结合 `math` 库使用

`math` 库的函数可接受 `Fraction` 作为输入，但需注意：**大多数 ****`math`**** 函数返回 ****`float`**（因涉及无理数运算）。

**示例代码**：

```python
from fractions import Fraction
import math

frac = Fraction(1, 4)

# 计算平方根（返回 float）
print(math.sqrt(frac))  # 输出: 0.5

# 计算正弦（返回 float）
print(math.sin(math.pi * frac))  # 输出: 0.7071067811865476
```

## 四、实战案例：食谱配料精确调整工具

### 需求背景

烘焙食谱中常用分数表示配料（如 “3/2 杯面粉”），调整人数时若用浮点数计算易出现 “0.3333 杯糖” 这类难以称量的结果。本案例用 `fractions` 实现**精确、易读的食谱配料调整**。

### 完整代码

```python
from fractions import Fraction

class RecipeAdjuster:
    def __init__(self, original_servings, ingredients):
        """
        初始化食谱调整器
        :param original_servings: 原食谱份数（整数/分数）
        :param ingredients: 食材字典，格式为 {"食材名": "分数用量"}
        """
        self.original_servings = Fraction(original_servings)
        # 将食材用量统一转换为 Fraction
        self.ingredients = {
            name: Fraction(amount) 
            for name, amount in ingredients.items()
        }
    
    def adjust(self, target_servings):
        """
        调整食谱到目标份数
        :param target_servings: 目标份数（整数/分数）
        :return: 调整后的食材字典（易读格式）
        """
        target_servings = Fraction(target_servings)
        ratio = target_servings / self.original_servings  # 调整比例
        
        adjusted = {}
        for name, amount in self.ingredients.items():
            new_amount = amount * ratio
            adjusted[name] = self._format_fraction(new_amount)
        
        return adjusted
    
    def _format_fraction(self, frac):
        """将 Fraction 格式化为易读的字符串（整数/带分数/真分数）"""
        if frac.denominator == 1:
            return f"{frac.numerator}"  # 整数形式
        whole = frac.numerator // frac.denominator
        remainder = frac.numerator % frac.denominator
        if whole > 0:
            return f"{whole}又{remainder}/{frac.denominator}"  # 带分数
        else:
            return f"{frac.numerator}/{frac.denominator}"  # 真分数


# ---------------------- 测试案例 ----------------------
if __name__ == "__main__":
    # 原食谱：4 人份
    original_recipe = {
        "面粉": "3/2",    # 3/2 杯 = 1.5 杯
        "糖": "1/4",      # 1/4 杯
        "牛奶": "5/4",    # 5/4 杯 = 1.25 杯
        "鸡蛋": "2"       # 2 个
    }
    
    # 初始化调整器
    adjuster = RecipeAdjuster(
        original_servings=4,
        ingredients=original_recipe
    )
    
    # 调整到 6 人份
    target = 6
    adjusted_recipe = adjuster.adjust(target)
    
    # 输出结果
    print(f"📋 原食谱：{adjuster.original_servings} 人份")
    print(f"🎯 调整后：{target} 人份")
    print("=" * 40)
    for name, amount in adjusted_recipe.items():
        unit = "个" if name == "鸡蛋" else "杯"
        print(f"{name}：{amount} {unit}")
```

### 运行输出

```Plain Text

🎯 调整后：6 人份
========================================
面粉：2又1/4 杯
糖：3/8 杯
牛奶：1又7/8 杯
鸡蛋：3 个
```

## 五、总结与避坑指南

### 核心总结

- `fractions` 是 Python 内置的精确分数运算库，通过 `Fraction` 类实现有理数的精确表示与计算，彻底解决浮点数精度误差；

- 核心优势：精确性、自动约分、灵活的类型转换，适用于数学教学、财务计算、烘焙 / 工程比例调整等场景；

- 适用边界：仅处理有理数（分数），无理数运算需结合 `math` 库（返回 `float`）。

### 新手高频避坑

1. **浮点数创建陷阱**：避免直接用 `Fraction(0.1)` 这类浮点数创建，优先用字符串 `Fraction(&#39;0.1&#39;)` 或 `Decimal` 转换；

2. **整数转换规则**：`int(Fraction)` 是**向零截断**，而非四舍五入，需注意；

3. **分母为零**：创建 `Fraction` 时分母不能为零，会抛出 `ZeroDivisionError`；

4. **`math`**** 函数返回值**：`math` 库函数接受 `Fraction` 但返回 `float`，因涉及无理数无法保持分数精确性。
