# B站Python授课：`configparser` 标准库——INI配置文件读写神器

## 课程导入

在开发Python程序时，我们一定会遇到**配置管理**的需求：数据库连接信息、界面主题、日志级别、接口超时时间……如果把这些参数硬编码在代码里，修改一次就要改代码、重新运行，非常不灵活。

**INI格式**是最经典、最简单的配置文件格式，而Python内置的 **`configparser`** 标准库，就是专门用来**读写INI配置文件**的工具，无需安装第三方库，是桌面软件、后端服务、自动化脚本的必备工具！

本节课我们从零学习`configparser`，包含读取、写入、修改、实战，全程可直接复制运行。

---

## 第一部分：核心概念

### 1. INI配置文件结构

INI文件由 **节(Section)** + **键值对(Key=Value)** 组成，支持注释：

```TOML

; 这是注释（分号/井号都可以）
[DATABASE]          ; 节：数据库配置
host = localhost    ; 键值对
port = 3306
user = root

[UI]                ; 节：界面配置
theme = dark
font_size = 14
auto_save = yes
```

- **Section**：用 `[]` 包裹，用于分类配置（必须有）

- **Option**：配置项的键（不区分大小写）

- **Value**：配置项的值（默认都是字符串）

- **注释**：`;` 或 `#` 开头

### 2. 核心类

`configparser.ConfigParser()`：所有配置操作的核心对象

## 第二部分：读取INI配置文件

### 核心知识点

1. 创建解析器对象

2. 加载配置文件

3. 读取配置（支持字符串/整数/浮点数/布尔值）

4. 判断节/配置项是否存在

### 示例代码

```Python

import configparser

# 1. 创建配置解析器对象
conf = configparser.ConfigParser()

# 2. 读取配置文件（提前创建好 config.ini 文件）
conf.read("config.ini", encoding="utf-8")

# ====================== 基础读取 ======================
# 读取字符串：节名 + 键名
db_host = conf.get("DATABASE", "host")
print("数据库地址：", db_host)

# 读取数字（自动类型转换）
db_port = conf.getint("DATABASE", "port")
print("数据库端口：", db_port, type(db_port))

# 读取布尔值（支持 yes/no/true/false/1/0）
auto_save = conf.getboolean("UI", "auto_save")
print("自动保存：", auto_save)

# ====================== 判断配置是否存在 ======================
# 判断节是否存在
print("是否存在DATABASE节：", conf.has_section("DATABASE"))
# 判断配置项是否存在
print("是否存在UI.theme：", conf.has_option("UI", "theme"))

# ====================== 遍历配置 ======================
print("\n所有节：", conf.sections())
print("DATABASE下所有键值对：", dict(conf.items("DATABASE")))
```

### 内容讲解

1. **读取方法**：

    - `get(section, option)`：读取**字符串**（最基础）

    - `getint()`：读取**整数**

    - `getfloat()`：读取**浮点数**

    - `getboolean()`：读取**布尔值**（自动识别 `yes/no`）

2. **编码**：中文配置必须加 `encoding="utf-8"`，否则乱码

3. **遍历**：`sections()` 获取所有节，`items()` 获取节下所有键值对

### 应用场景

1. 程序启动时**加载数据库配置**

2. 读取软件**界面主题、字体大小**

3. 自动化脚本读取**路径、超时时间**等固定参数

## 第三部分：创建 & 写入 & 修改配置文件

### 核心知识点

1. 从零创建INI文件

2. 添加节、添加/修改配置项

3. 保存到文件

4. 删除节/配置项

### 示例代码

```Python

import configparser

# 1. 创建解析器对象
conf = configparser.ConfigParser()

# ====================== 添加配置 ======================
# 添加节
conf.add_section("DATABASE")
conf.add_section("UI")

# 添加键值对
conf.set("DATABASE", "host", "localhost")
conf.set("DATABASE", "port", "3306")
conf.set("DATABASE", "password", "123456")

conf.set("UI", "theme", "dark")
conf.set("UI", "font_size", "14")

# ====================== 修改配置 ======================
# 直接覆盖即可修改
conf.set("DATABASE", "password", "root123")

# ====================== 删除配置 ======================
# conf.remove_option("DATABASE", "password")  # 删除配置项
# conf.remove_section("UI")                   # 删除整个节

# ====================== 保存文件 ======================
with open("config.ini", "w", encoding="utf-8") as f:
    conf.write(f)

print("配置文件已创建/更新完成！")
```

### 内容讲解

1. `add_section(section)`：添加节（**节名不能重复**）

2. `set(section, option, value)`：添加/修改配置项

3. `remove_option/remove_section`：删除配置

4. 必须调用 `write()` 才会真正保存到文件

### 应用场景

1. 程序**首次运行**时自动生成默认配置

2. 用户在软件内修改配置后**保存到文件**

3. 动态生成测试环境/生产环境的配置文件

## 第四部分：进阶实用技巧

### 核心知识点

1. 读取配置时设置**默认值**（防止配置缺失报错）

2. 处理**多行配置值**

3. 兼容大小写

### 示例代码

```Python

import configparser
conf = configparser.ConfigParser()
conf.read("config.ini", encoding="utf-8")

# 1. 带默认值的读取（fallback参数）
# 如果配置不存在，返回默认值，不报错
log_level = conf.get("LOG", "level", fallback="INFO")
print("日志级别：", log_level)

# 2. 多行值（用缩进表示换行）
# INI文件中：
# [OTHER]
# desc = 这是第一行
#   这是第二行
#   这是第三行
desc = conf.get("OTHER", "desc", fallback="无描述")
print("多行描述：\n", desc)
```

### 内容讲解

- `fallback`：配置不存在时返回默认值，**程序更健壮**

- 多行值：第二行开始必须**缩进**，解析器会自动识别为换行

### 应用场景

1. 编写**容错性强**的程序，避免配置缺失导致崩溃

2. 存储长文本描述、备注信息等多行配置

## 第五部分：实战案例 —— 简易程序配置管理器

### 功能需求

1. 程序启动时，自动加载 `app.ini` 配置文件

2. 如果文件不存在，**自动生成默认配置**

3. 支持：查看配置、修改配置、保存配置

4. 读取数据库+界面配置，用于程序启动

### 完整实战代码

```Python

import configparser
from pathlib import Path

class AppConfig:
    def __init__(self, file_path="app.ini"):
        self.file_path = Path(file_path)
        self.conf = configparser.ConfigParser()
        # 加载配置，不存在则初始化
        self.load_config()

    def load_config(self):
        """加载配置，文件不存在则创建默认配置"""
        if self.file_path.exists():
            self.conf.read(self.file_path, encoding="utf-8")
            print("✅ 配置文件加载成功")
        else:
            self.create_default_config()
            print("✅ 生成默认配置文件")

    def create_default_config(self):
        """创建默认配置"""
        # 数据库配置
        self.conf.add_section("DATABASE")
        self.conf.set("DATABASE", "host", "localhost")
        self.conf.set("DATABASE", "port", "3306")
        self.conf.set("DATABASE", "db_name", "python_app")

        # 界面配置
        self.conf.add_section("SETTINGS")
        self.conf.set("SETTINGS", "theme", "light")
        self.conf.set("SETTINGS", "font_size", "14")
        self.conf.set("SETTINGS", "auto_save", "yes")

        self.save_config()

    def save_config(self):
        """保存配置到文件"""
        with open(self.file_path, "w", encoding="utf-8") as f:
            self.conf.write(f)

    def show_all_config(self):
        """显示所有配置"""
        print("\n===== 程序配置 =====")
        for section in self.conf.sections():
            print(f"[{section}]")
            for k, v in self.conf.items(section):
                print(f"  {k} = {v}")

    def update_config(self, section, option, value):
        """修改配置并保存"""
        if not self.conf.has_section(section):
            print(f"❌ 节 {section} 不存在")
            return
        self.conf.set(section, option, value)
        self.save_config()
        print(f"✅ 已修改：{section}.{option} = {value}")

# ========== 测试使用 ==========
if __name__ == '__main__':
    # 初始化配置管理器
    app = AppConfig()

    # 查看所有配置
    app.show_all_config()

    # 修改配置：将主题改为dark
    app.update_config("SETTINGS", "theme", "dark")

    # 再次查看
    app.show_all_config()
```

### 代码讲解

1. **面向对象封装**：把配置操作封装成类，代码整洁、复用性强

2. **自动初始化**：文件不存在时自动生成默认配置，新手零报错

3. **常用功能**：查看、修改、保存一站式搞定

4. 运行后会自动生成 `app.ini`，修改后实时保存

## 课程总结

### 核心知识点回顾

1. **适用场景**：读写 **INI格式** 配置文件，管理程序参数

2. **核心对象**：`configparser.ConfigParser()`

3. **读取**：`get()`/`getint()`/`getboolean()`，支持默认值

4. **写入**：`add_section()` + `set()` + `write()`

5. **优势**：内置库、语法简单、跨平台、适合小型程序配置

### 避坑指南

1. 读写中文必须加 `encoding="utf-8"`

2. 配置值默认是字符串，数字/布尔要手动转换

3. 节名必须先创建，才能添加键值对
