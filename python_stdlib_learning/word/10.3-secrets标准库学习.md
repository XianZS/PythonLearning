# Python标准库secrets完整教学文档
## 一、概念部分

### 1.1 secrets库详细概念
secrets是Python 3.6版本引入的**密码学安全随机数生成标准库**，专门用于生成适合管理密码、账户认证令牌、安全密钥等敏感数据的高安全性随机数。它是Python官方推荐的安全随机数生成工具，完全替代了传统`random`模块在所有安全相关场景的使用。

从技术本质上讲，secrets库是对操作系统提供的**密码学安全伪随机数生成器（CSPRNG, Cryptographically Secure Pseudorandom Random Number Generator）**的高级封装。在不同操作系统上，它会自动调用系统级别的安全随机源：
- Windows系统：调用`CryptGenRandom()` API
- Linux/Unix系统：读取`/dev/urandom`设备
- macOS系统：调用`SecRandomCopyBytes()` API

这些系统级随机源会收集硬件中断、键盘输入、磁盘IO、网络流量等多种不可预测的环境噪声作为熵源，生成的随机数具有密码学级别的不可预测性。

### 1.2 为什么绝对不能用random模块生成敏感数据？
`random`模块实现的是**伪随机数生成器（PRNG）**，它使用确定性算法生成看起来随机的数字序列。只要知道种子值，就可以完全复现整个随机序列，这在安全场景中是致命的缺陷。

| 特性 | random模块 | secrets模块 |
|-----|-----------|------------|
| 随机源 | 基于梅森旋转算法，种子可预测 | 基于操作系统CSPRNG，熵源不可预测 |
| 安全性 | 非密码学安全，可被破解 | 密码学安全，无已知有效攻击 |
| 适用场景 | 游戏、模拟、数据洗牌等非安全场景 | 密码、令牌、密钥等安全敏感场景 |
| 种子控制 | 可手动设置种子 | 种子由操作系统自动管理，无法手动设置 |

**重要警告**：任何使用`random`模块生成密码、密钥或认证令牌的代码都存在严重的安全漏洞，必须立即替换为`secrets`模块。

### 1.3 密码学安全随机数的核心要求
一个合格的密码学安全随机数生成器必须满足以下三个核心条件：
1. **不可预测性**：即使攻击者知道生成器的算法和之前生成的所有随机数，也无法预测下一个生成的随机数
2. **统计均匀性**：生成的随机数在统计上是均匀分布的，没有明显的偏差
3. **前向保密性**：即使攻击者获取了生成器的当前状态，也无法推导出之前生成的随机数

secrets库完全满足以上所有要求，是Python中生成安全随机数的唯一标准选择。

### 1.4 主要应用场景
secrets库在Python项目的安全开发中有着不可替代的作用，主要应用场景包括：
- **用户密码盐值生成**：为每个用户生成唯一的随机盐值，用于密码哈希
- **认证令牌生成**：生成会话令牌、API密钥、访问令牌等
- **一次性密码生成**：生成短信验证码、邮箱验证码、TOTP密钥等
- **加密密钥生成**：生成对称加密算法的密钥、初始化向量(IV)等
- **安全随机选择**：从列表中安全地随机选择元素，如生成随机密码
- **防CSRF令牌生成**：生成Web表单的跨站请求伪造防护令牌
- **密码重置链接生成**：生成安全的一次性密码重置链接

## 二、基础部分

### 2.1 环境准备与模块导入
secrets是Python 3.6及以上版本的标准库，**不需要安装任何第三方包**，直接导入即可使用。

**理论说明**：
- secrets模块提供了简洁统一的API，所有函数都返回密码学安全的随机值
- 所有函数都接受一个可选的`nbytes`参数，指定生成的随机字节数
- 如果不指定`nbytes`参数，会使用一个合理的默认值（通常是32字节）

**示例代码**：
```python
# 导入secrets模块
import secrets
import string  # 用于后续生成密码时提供字符集

# 查看secrets模块的所有可用函数
print("secrets模块可用函数:")
for func in dir(secrets):
    if not func.startswith('_'):
        print(f"  - {func}")
```

### 2.2 生成随机字节（token_bytes）
`token_bytes(nbytes=None)`函数生成指定长度的原始随机字节，这是secrets库最基础的函数，其他所有生成函数都是基于它实现的。

**理论说明**：
- 参数`nbytes`：指定生成的随机字节数，默认值为32字节（256位）
- 返回值：`bytes`类型的随机字节序列
- 适用场景：生成加密密钥、初始化向量等需要原始字节的场景
- 安全建议：对于大多数安全场景，至少使用16字节（128位）的长度，推荐使用32字节（256位）

**示例代码**：
```python
import secrets

# 生成默认长度(32字节)的随机字节
default_bytes = secrets.token_bytes()
print(f"默认长度(32字节)随机字节: {default_bytes}")
print(f"字节长度: {len(default_bytes)} 字节 ({len(default_bytes)*8} 位)\n")

# 生成指定长度(16字节)的随机字节
custom_bytes = secrets.token_bytes(16)
print(f"16字节随机字节: {custom_bytes}")
print(f"字节长度: {len(custom_bytes)} 字节 ({len(custom_bytes)*8} 位)\n")

# 生成64字节(512位)的高安全性随机字节
high_security_bytes = secrets.token_bytes(64)
print(f"64字节高安全性随机字节: {high_security_bytes}")
print(f"字节长度: {len(high_security_bytes)} 字节 ({len(high_security_bytes)*8} 位)")
```

### 2.3 生成十六进制随机字符串（token_hex）
`token_hex(nbytes=None)`函数生成指定长度的十六进制格式随机字符串，每个字节转换为两个十六进制字符。

**理论说明**：
- 参数`nbytes`：指定生成的随机字节数，最终字符串长度为`2 * nbytes`
- 返回值：小写十六进制字符串，只包含0-9和a-f字符
- 适用场景：生成不需要URL编码的令牌、密钥、哈希盐值等
- 优势：十六进制字符串易于打印、存储和传输，不会出现特殊字符问题

**示例代码**：
```python
import secrets

# 生成默认长度(32字节→64字符)的十六进制字符串
default_hex = secrets.token_hex()
print(f"默认长度十六进制字符串: {default_hex}")
print(f"字符串长度: {len(default_hex)} 字符 (对应 {len(default_hex)//2} 字节)\n")

# 生成16字节→32字符的十六进制字符串
short_hex = secrets.token_hex(16)
print(f"16字节→32字符十六进制字符串: {short_hex}")
print(f"字符串长度: {len(short_hex)} 字符\n")

# 生成8字节→16字符的十六进制字符串（适合短信验证码）
sms_code_hex = secrets.token_hex(8)
print(f"8字节→16字符十六进制字符串: {sms_code_hex}")
```

### 2.4 生成URL安全的随机字符串（token_urlsafe）
`token_urlsafe(nbytes=None)`函数生成URL安全的Base64编码随机字符串，这是生成Web应用中令牌的首选函数。

**理论说明**：
- 参数`nbytes`：指定生成的随机字节数，最终字符串长度约为`1.33 * nbytes`
- 返回值：URL安全的Base64字符串，只包含字母、数字、`-`和`_`字符
- 适用场景：生成URL中的令牌、会话ID、密码重置链接、CSRF令牌等
- 优势：不需要额外的URL编码，可以直接嵌入到URL中使用

**示例代码**：
```python
import secrets

# 生成默认长度(32字节)的URL安全字符串
default_urlsafe = secrets.token_urlsafe()
print(f"默认长度URL安全字符串: {default_urlsafe}")
print(f"字符串长度: {len(default_urlsafe)} 字符\n")

# 生成16字节的URL安全字符串（适合会话令牌）
session_token = secrets.token_urlsafe(16)
print(f"16字节会话令牌: {session_token}")
print(f"字符串长度: {len(session_token)} 字符\n")

# 生成32字节的URL安全字符串（适合密码重置链接）
reset_token = secrets.token_urlsafe(32)
print(f"32字节密码重置令牌: {reset_token}")
print(f"密码重置链接示例: https://example.com/reset-password?token={reset_token}")
```

### 2.5 secrets与random的安全性对比演示
下面的代码直观地展示了为什么`random`模块不适合用于安全场景：只要知道种子值，就可以完全复现随机序列。

**理论说明**：
- `random`模块的随机序列完全由种子值决定
- 攻击者可以通过暴力破解种子值来预测所有生成的随机数
- `secrets`模块不允许手动设置种子，种子由操作系统自动管理
- 即使攻击者获取了当前系统状态，也无法预测secrets生成的随机数

**示例代码**：
```python
import random
import secrets

print("=== random模块的可预测性演示 ===")
# 设置固定种子
random.seed(12345)

# 生成5个随机数
print("使用种子12345生成的随机序列:")
for _ in range(5):
    print(f"  {random.random()}")

# 重新设置相同的种子
random.seed(12345)

# 生成完全相同的随机序列
print("\n重新设置相同种子后生成的随机序列:")
for _ in range(5):
    print(f"  {random.random()}")

print("\n=== secrets模块的不可预测性演示 ===")
# 生成5个随机字节序列
print("第一次生成的随机字节序列:")
for _ in range(3):
    print(f"  {secrets.token_hex(4)}")

# 无法复现相同的序列
print("\n第二次生成的随机字节序列:")
for _ in range(3):
    print(f"  {secrets.token_hex(4)}")

print("\n结论: random模块的随机序列可预测，secrets模块的随机序列不可预测")
```

## 三、进阶部分

### 3.1 生成符合复杂度要求的安全密码
生成符合特定复杂度要求的密码是secrets库最常用的功能之一。一个安全的密码应该包含大小写字母、数字和特殊字符，并且长度足够。

**理论说明**：
- 使用`secrets.choice()`函数从字符集中安全地随机选择字符
- 密码长度至少为8位，推荐使用12位以上
- 必须包含多种字符类型，增加密码的熵值
- 避免使用常见单词、生日、手机号等容易被猜测的内容
- 不要自己实现随机选择算法，使用`secrets.choice()`保证安全性

**示例代码**：
```python
import secrets
import string

def generate_secure_password(length: int = 12, 
                             include_uppercase: bool = True,
                             include_lowercase: bool = True,
                             include_digits: bool = True,
                             include_symbols: bool = True) -> str:
    """
    生成符合复杂度要求的安全密码
    
    Args:
        length: 密码长度，默认12位
        include_uppercase: 是否包含大写字母
        include_lowercase: 是否包含小写字母
        include_digits: 是否包含数字
        include_symbols: 是否包含特殊字符
    
    Returns:
        str: 生成的安全密码
    
    Raises:
        ValueError: 如果所有字符集都被排除或长度小于8
    """
    # 验证参数
    if length < 8:
        raise ValueError("密码长度至少为8位")
    
    # 构建字符集
    char_sets = []
    if include_uppercase:
        char_sets.append(string.ascii_uppercase)
    if include_lowercase:
        char_sets.append(string.ascii_lowercase)
    if include_digits:
        char_sets.append(string.digits)
    if include_symbols:
        # 使用常见的特殊字符，避免可能导致问题的字符
        char_sets.append("!@#$%^&*()_+-=[]{}|;:,.<>?")
    
    if not char_sets:
        raise ValueError("至少需要包含一种字符类型")
    
    # 合并所有字符集
    all_chars = ''.join(char_sets)
    
    # 确保密码包含至少一个每种选中的字符类型
    password = []
    for char_set in char_sets:
        # 从每种字符集中至少选一个字符
        password.append(secrets.choice(char_set))
    
    # 填充剩余长度
    for _ in range(length - len(password)):
        password.append(secrets.choice(all_chars))
    
    # 打乱密码顺序（使用secrets的安全打乱方法）
    secrets.SystemRandom().shuffle(password)
    
    # 转换为字符串
    return ''.join(password)

# 测试不同复杂度的密码生成
if __name__ == "__main__":
    print("=== 安全密码生成器 ===")
    
    # 生成默认复杂度的密码(12位，包含所有字符类型)
    default_password = generate_secure_password()
    print(f"默认密码(12位，全字符): {default_password}")
    
    # 生成16位高复杂度密码
    strong_password = generate_secure_password(length=16)
    print(f"强密码(16位，全字符): {strong_password}")
    
    # 生成只包含字母和数字的密码
    alnum_password = generate_secure_password(length=12, include_symbols=False)
    print(f"字母数字密码(12位): {alnum_password}")
    
    # 生成只包含数字的密码(适合手机验证码)
    digit_password = generate_secure_password(length=6, include_uppercase=False, 
                                              include_lowercase=False, include_symbols=False)
    print(f"数字密码(6位): {digit_password}")
```

### 3.2 生成一次性密码（OTP）
一次性密码（One-Time Password）是一种只能使用一次的密码，广泛用于双因素认证（2FA）、短信验证、邮箱验证等场景。

**理论说明**：
- 一次性密码通常是6位或8位数字
- 必须使用密码学安全的随机数生成
- 每个OTP只能使用一次，并且有有效期
- 生成后需要安全地存储和验证
- 不要使用`random.randint()`生成OTP，必须使用`secrets`模块

**示例代码**：
```python
import secrets
import time
from typing import Dict, Tuple

# 存储已生成的OTP：{otp: (expire_time, user_id)}
otp_store: Dict[str, Tuple[int, str]] = {}
# OTP有效期（秒）
OTP_EXPIRE_SECONDS = 300  # 5分钟

def generate_otp(length: int = 6, user_id: str = None) -> str:
    """
    生成一次性密码
    
    Args:
        length: OTP长度，默认6位
        user_id: 关联的用户ID
    
    Returns:
        str: 生成的数字OTP
    
    Raises:
        ValueError: 如果长度不在4-8之间
    """
    if not 4 <= length <= 8:
        raise ValueError("OTP长度必须在4-8位之间")
    
    # 生成指定长度的数字OTP
    # 方法：生成一个0到10^length - 1之间的随机整数，然后补零到指定长度
    otp = str(secrets.randbelow(10 ** length)).zfill(length)
    
    # 存储OTP和过期时间
    expire_time = int(time.time()) + OTP_EXPIRE_SECONDS
    otp_store[otp] = (expire_time, user_id)
    
    return otp

def verify_otp(otp: str, user_id: str = None) -> Tuple[bool, str]:
    """
    验证一次性密码
    
    Args:
        otp: 用户输入的OTP
        user_id: 关联的用户ID
    
    Returns:
        tuple: (验证是否通过, 错误信息)
    """
    # 检查OTP是否存在
    if otp not in otp_store:
        return False, "OTP不存在或已被使用"
    
    expire_time, stored_user_id = otp_store[otp]
    
    # 检查是否过期
    current_time = int(time.time())
    if current_time > expire_time:
        # 删除过期的OTP
        del otp_store[otp]
        return False, "OTP已过期"
    
    # 检查用户ID是否匹配
    if user_id is not None and stored_user_id != user_id:
        return False, "OTP与用户不匹配"
    
    # 验证通过，删除OTP（确保只能使用一次）
    del otp_store[otp]
    
    # 定期清理过期的OTP
    cleanup_expired_otps()
    
    return True, "OTP验证通过"

def cleanup_expired_otps() -> int:
    """
    清理所有过期的OTP
    
    Returns:
        int: 清理的OTP数量
    """
    current_time = int(time.time())
    expired_otps = [otp for otp, (expire_time, _) in otp_store.items() if current_time > expire_time]
    
    for otp in expired_otps:
        del otp_store[otp]
    
    return len(expired_otps)

# 测试
if __name__ == "__main__":
    print("=== 一次性密码(OTP)生成与验证 ===")
    
    # 生成6位OTP
    user_id = "user123"
    otp = generate_otp(6, user_id)
    print(f"生成的6位OTP: {otp}")
    print(f"当前存储的OTP数量: {len(otp_store)}")
    
    # 验证正确的OTP
    is_valid, message = verify_otp(otp, user_id)
    print(f"\n验证正确的OTP: {is_valid}, 信息: {message}")
    print(f"验证后存储的OTP数量: {len(otp_store)}")
    
    # 验证已使用的OTP
    is_valid, message = verify_otp(otp, user_id)
    print(f"\n验证已使用的OTP: {is_valid}, 信息: {message}")
    
    # 生成8位OTP
    otp2 = generate_otp(8)
    print(f"\n生成的8位OTP: {otp2}")
    
    # 验证错误的OTP
    is_valid, message = verify_otp("12345678")
    print(f"验证错误的OTP: {is_valid}, 信息: {message}")
```

### 3.3 生成加密密钥与盐值
生成安全的加密密钥和盐值是密码学应用的基础，secrets库提供了最安全的方式来生成这些敏感数据。

**理论说明**：
- 加密密钥的长度应该与使用的加密算法要求一致
- 盐值应该是每个用户唯一的，长度至少16字节
- 密钥和盐值都应该使用密码学安全的随机数生成
- 永远不要硬编码密钥或盐值在代码中
- 密钥和盐值应该安全地存储在环境变量或密钥管理系统中

**示例代码**：
```python
import secrets
import hashlib
import hmac

def generate_encryption_key(key_length: int = 32) -> bytes:
    """
    生成对称加密算法的密钥
    
    Args:
        key_length: 密钥长度（字节），默认32字节(256位)，适合AES-256
    
    Returns:
        bytes: 生成的密钥
    """
    if key_length not in [16, 24, 32]:
        raise ValueError("AES密钥长度必须是16(128位)、24(192位)或32(256位)字节")
    
    return secrets.token_bytes(key_length)

def generate_salt(salt_length: int = 16) -> str:
    """
    生成密码哈希用的盐值
    
    Args:
        salt_length: 盐值长度（字节），默认16字节
    
    Returns:
        str: 十六进制格式的盐值
    """
    return secrets.token_hex(salt_length)

def generate_iv(iv_length: int = 16) -> bytes:
    """
    生成加密算法的初始化向量(IV)
    
    Args:
        iv_length: IV长度（字节），默认16字节，适合AES
    
    Returns:
        bytes: 生成的IV
    """
    return secrets.token_bytes(iv_length)

def hash_password(password: str, salt: str = None) -> tuple[str, str]:
    """
    使用SHA-256和盐值哈希密码
    
    Args:
        password: 明文密码
        salt: 可选，指定盐值，如果为None则自动生成
    
    Returns:
        tuple: (哈希值, 盐值)
    """
    if salt is None:
        salt = generate_salt()
    
    # 将密码和盐值拼接后哈希
    salted_password = (password + salt).encode('utf-8')

    """
    calculated_hash, _ = hash_password(password, stored_salt)
    # 使用安全比较防止时序攻击
    return hmac.compare_digest(calculated_hash, stored_hash)
```

### 3.4 安全的字符串比较（compare_digest）
`secrets.compare_digest(a, b)`函数是一个安全的字符串比较函数，用于防止**时序攻击（Timing Attack）**。

**理论说明**：
- 普通的`==`运算符在比较字符串时，会从第一个字符开始逐个比较，遇到不相等的字符就立即返回
- 攻击者可以通过测量比较操作的时间差异，推断出字符串的正确字符
- `secrets.compare_digest()`会比较整个字符串的所有字符，无论是否相等，花费的时间都是相同的
- 这个函数与`hmac.compare_digest()`完全相同，效果一致
- 必须用于所有敏感数据的比较，如密码哈希、令牌、签名等

**示例代码**：
```python
import secrets
import time

def unsafe_compare(a: str, b: str) -> bool:
    """不安全的比较方法，容易受到时序攻击"""
    return a == b

def safe_compare(a: str, b: str) -> bool:
    """安全的比较方法，抵抗时序攻击"""
    return secrets.compare_digest(a, b)

# 测试比较时间差异
if __name__ == "__main__":
    print("=== 安全字符串比较演示 ===")
    
    # 生成两个只有最后一个字符不同的长字符串
    str1 = secrets.token_hex(32)  # 64个字符
    str2 = str1[:-1] + 'x'  # 只有最后一个字符不同
    
    print(f"字符串1: {str1}")
    print(f"字符串2: {str2}")
    print(f"两个字符串是否相等: {str1 == str2}\n")
    
    # 测试不安全比较的时间
    iterations = 100000
    start_time = time.perf_counter()
    for _ in range(iterations):
        unsafe_compare(str1, str2)
    unsafe_time = time.perf_counter() - start_time
    
    # 测试安全比较的时间
    start_time = time.perf_counter()
    for _ in range(iterations):
        safe_compare(str1, str2)
    safe_time = time.perf_counter() - start_time
    
    print(f"不安全比较{iterations}次耗时: {unsafe_time:.6f} 秒")
    print(f"安全比较{iterations}次耗时: {safe_time:.6f} 秒")
    print(f"安全比较比不安全比较慢约: {safe_time/unsafe_time:.1f} 倍")
    
    print("\n重要提示:")
    print("1. 安全比较虽然稍慢，但可以有效防止时序攻击")
    print("2. 必须用于所有敏感数据的比较（密码、令牌、签名等）")
    print("3. 永远不要使用普通的==运算符比较敏感数据")
```

### 3.5 安全的随机选择与打乱
secrets库提供了`SystemRandom`类，它是`random.Random`类的子类，使用操作系统的CSPRNG作为随机源，提供了安全版本的随机选择和打乱功能。

**理论说明**：
- `secrets.choice(seq)`：从序列中安全地随机选择一个元素
- `secrets.SystemRandom().shuffle(x)`：安全地打乱序列的顺序
- 这些函数与`random`模块中的对应函数接口相同，但使用安全的随机源
- 适用于需要安全随机选择的场景，如生成密码、抽奖、随机分配等
- 不要使用`random.choice()`或`random.shuffle()`处理安全相关的数据

**示例代码**：
```python
import secrets
import string

def secure_choice_example():
    """安全随机选择示例"""
    print("=== 安全随机选择示例 ===")
    
    # 从列表中随机选择一个元素
    fruits = ["苹果", "香蕉", "橙子", "葡萄", "西瓜"]
    selected_fruit = secrets.choice(fruits)
    print(f"随机选择的水果: {selected_fruit}")
    
    # 从字符集中随机选择多个字符
    chars = string.ascii_letters + string.digits
    random_chars = ''.join(secrets.choice(chars) for _ in range(10))
    print(f"随机生成的10个字符: {random_chars}")
    
    # 生成随机布尔值
    random_bool = secrets.choice([True, False])
    print(f"随机布尔值: {random_bool}")
    
    # 生成指定范围内的随机整数
    # secrets.randbelow(n) 生成[0, n)之间的随机整数
    random_int = secrets.randbelow(100)  # 0-99之间的随机整数
    print(f"0-99之间的随机整数: {random_int}")
    
    # 生成[1, 100]之间的随机整数
    random_int_1_100 = secrets.randbelow(100) + 1
    print(f"1-100之间的随机整数: {random_int_1_100}")

def secure_shuffle_example():
    """安全打乱序列示例"""
    print("\n=== 安全打乱序列示例 ===")
    
    # 打乱列表
    numbers = list(range(1, 11))
    print(f"原始列表: {numbers}")
    
    # 使用secrets的安全打乱方法
    secrets.SystemRandom().shuffle(numbers)
    print(f"打乱后的列表: {numbers}")
    
    # 打乱字符串（需要先转换为列表）
    password = "abcdefghijklmnopqrstuvwxyz"
    password_list = list(password)
    secrets.SystemRandom().shuffle(password_list)
    shuffled_password = ''.join(password_list)
    print(f"原始字符串: {password}")
    print(f"打乱后的字符串: {shuffled_password}")

# 测试
if __name__ == "__main__":
    secure_choice_example()
    secure_shuffle_example()
```

## 四、实战部分-完整的用户认证安全模块

结合前面所学的所有内容，我们来实现一个功能完整、生产级别的用户认证安全模块。这个模块包含用户注册、登录验证、会话管理、密码重置等核心功能，所有敏感数据都使用secrets库生成和保护。

**模块功能**：
- 用户注册：密码加盐哈希存储，每个用户使用唯一盐值
- 用户登录：安全的密码验证，防止时序攻击
- 会话管理：生成安全的会话令牌，支持令牌过期
- 密码重置：生成安全的一次性密码重置链接
- 安全日志：记录所有认证相关的操作
- 防暴力破解：限制登录失败次数

**完整代码**：
```python
import secrets
import hashlib
import hmac
import time
from typing import Dict, Tuple, Optional

# ===================== 全局配置 =====================
# 会话令牌有效期（秒）
SESSION_EXPIRE_SECONDS = 86400  # 24小时
# 密码重置令牌有效期（秒）
RESET_TOKEN_EXPIRE_SECONDS = 1800  # 30分钟
# 密码哈希迭代次数（增加暴力破解难度）
HASH_ITERATIONS = 100000

# ===================== 数据存储（实际项目中使用数据库） =====================
# 用户表：{user_id: {'username': str, 'password_hash': str, 'salt': str, 'failed_attempts': int, 'locked_until': int}}
users: Dict[str, dict] = {}
# 会话表：{session_token: {'user_id': str, 'expire_time': int}}
sessions: Dict[str, dict] = {}
# 密码重置表：{reset_token: {'user_id': str, 'expire_time': int}}
password_resets: Dict[str, dict] = {}

# ===================== 工具函数 =====================
def hash_password(password: str, salt: str = None) -> Tuple[str, str]:
    """
    使用PBKDF2算法哈希密码（比简单的SHA-256更安全）
    
    Args:
        password: 明文密码
        salt: 可选，指定盐值，如果为None则自动生成
    
    Returns:
        tuple: (哈希值, 盐值)
    """
    if salt is None:
        # 生成16字节的随机盐值
        salt = secrets.token_hex(16)
    
    # 使用PBKDF2算法进行密码哈希
    # 迭代次数100000次，使用SHA-256哈希函数
    password_hash = hashlib.pbkdf2_hmac(
        'sha256',
        password.encode('utf-8'),
        salt.encode('utf-8'),
        HASH_ITERATIONS
    ).hex()
    
    return password_hash, salt

def verify_password(password: str, stored_hash: str, stored_salt: str) -> bool:
    """
    安全验证密码
    
    Args:
        password: 用户输入的明文密码
        stored_hash: 存储的密码哈希值
        stored_salt: 存储的盐值
    
    Returns:
        bool: 密码正确返回True，否则返回False
    """
    calculated_hash, _ = hash_password(password, stored_salt)
    # 使用安全比较防止时序攻击
    return hmac.compare_digest(calculated_hash, stored_hash)

def cleanup_expired_data():
    """定期清理过期的会话和密码重置令牌"""
    current_time = int(time.time())
    
    # 清理过期会话
    expired_sessions = [token for token, data in sessions.items() if current_time > data['expire_time']]
    for token in expired_sessions:
        del sessions[token]
    
    # 清理过期密码重置令牌
    expired_resets = [token for token, data in password_resets.items() if current_time > data['expire_time']]
    for token in expired_resets:
        del password_resets[token]
    
    return len(expired_sessions) + len(expired_resets)

def register_user(username: str, password: str) -> Tuple[bool, str]:
    """
    用户注册
    
    Args:
        username: 用户名
        password: 明文密码
    
    Returns:
        tuple: (注册是否成功, 信息)

        if user_data['username'] == username:
            return False, "用户名已存在"

    if len(password) < 8:
        return False, "密码长度至少为8位"
    
    # 生成用户ID
    user_id = secrets.token_hex(8)
    
    # 哈希密码
    password_hash, salt = hash_password(password)
    
    # 存储用户信息
    users[user_id] = {
        'username': username,
        'password_hash': password_hash,
        'salt': salt,
        'failed_attempts': 0,
        'locked_until': 0
    }
    
    print(f"[安全日志] 用户注册成功: {username} (ID: {user_id})")
    return True, f"用户注册成功，用户ID: {user_id}"

def login_user(username: str, password: str) -> Tuple[bool, str, Optional[str]]:
    """
    用户登录
    
    Args:
        username: 用户名
        password: 明文密码
    
    Returns:
        tuple: (登录是否成功, 信息, 会话令牌)
    """
    # 查找用户
    user_id = None
    user_data = None
    for uid, data in users.items():
        if data['username'] == username:
            user_id = uid
            user_data = data
            break
    
    if not user_id:
        return False, "用户名不存在", None
    
    # 检查账户是否被锁定
    current_time = int(time.time())
    if user_data['locked_until'] > current_time:
        lock_remaining = user_data['locked_until'] - current_time
        return False, f"账户已锁定，请在{lock_remaining}秒后再试", None
    
    # 验证密码
    if verify_password(password, user_data['password_hash'], user_data['salt']):
        # 登录成功，重置失败尝试次数
        user_data['failed_attempts'] = 0
        
        # 生成会话令牌
        session_token = secrets.token_urlsafe(32)
        expire_time = current_time + SESSION_EXPIRE_SECONDS
        
        # 存储会话
        sessions[session_token] = {
            'user_id': user_id,
            'expire_time': expire_time
        }
        
        print(f"[安全日志] 用户登录成功: {username}")
        return True, "登录成功", session_token
    else:
        # 登录失败，增加失败尝试次数
        user_data['failed_attempts'] += 1
        
        # 如果失败次数超过5次，锁定账户15分钟
        if user_data['failed_attempts'] >= 5:
            user_data['locked_until'] = current_time + 900  # 15分钟
            print(f"[安全警告] 用户{username}登录失败次数过多，账户已锁定15分钟")
            return False, "登录失败次数过多，账户已锁定15分钟", None
        
        print(f"[安全日志] 用户{username}登录失败，失败次数: {user_data['failed_attempts']}")
        return False, f"密码错误，还有{5 - user_data['failed_attempts']}次尝试机会", None

def verify_session(session_token: str) -> Tuple[bool, str, Optional[str]]:
    """
    验证会话令牌
    
    Args:
        session_token: 会话令牌
    
    Returns:
        tuple: (验证是否成功, 信息, 用户ID)
    """
    if session_token not in sessions:
        return False, "会话不存在或已过期", None
    
    session_data = sessions[session_token]
    current_time = int(time.time())
    
    if current_time > session_data['expire_time']:
        del sessions[session_token]
        return False, "会话已过期", None
    
    # 清理过期数据
    cleanup_expired_data()
    
    return True, "会话验证通过", session_data['user_id']

    """
    用户登出
    
    Args:
        session_token: 会话令牌
    
    Returns:
        tuple: (登出是否成功, 信息)

        return True, "登出成功"

        return False, "会话不存在"
```

## 五、最佳实践与常见误区

### 5.1 必须使用secrets的场景
以下所有场景**绝对不能使用random模块**，必须使用secrets模块：
- 生成用户密码和密码重置令牌
- 生成会话ID和认证令牌
- 生成API密钥和访问令牌
- 生成加密密钥和初始化向量
- 生成密码哈希的盐值
- 生成一次性密码（OTP）和验证码
- 生成CSRF防护令牌
- 任何与安全相关的随机数生成

### 5.2 密钥/令牌长度建议
| 应用场景 | 推荐最小长度 | 推荐安全长度 |
|---------|-------------|-------------|
| 短信验证码 | 6位数字 | 6-8位数字 |
| 密码盐值 | 16字节 | 32字节 |
| 会话令牌 | 16字节 | 32字节 |
| API密钥 | 32字节 | 64字节 |
| AES加密密钥 | 16字节(128位) | 32字节(256位) |
| 密码重置令牌 | 32字节 | 64字节 |
| CSRF令牌 | 16字节 | 32字节 |

**安全原则**：在性能允许的情况下，优先使用更长的密钥和令牌。

### 5.3 常见安全误区
1. **使用random模块生成敏感数据**：这是最常见也是最危险的错误，random模块的随机数可预测
2. **使用固定盐值**：所有用户使用相同的盐值，攻击者可以生成彩虹表进行破解
3. **使用短密钥/令牌**：过短的密钥和令牌容易被暴力破解
4. **使用普通==比较敏感数据**：容易受到时序攻击，必须使用`secrets.compare_digest()`
5. **自己实现随机数生成算法**：永远不要自己发明或修改随机数生成算法
6. **硬编码密钥/令牌**：密钥和令牌绝对不能硬编码在代码中或提交到版本控制系统
7. **令牌永不过期**：所有令牌都应该有合理的有效期，降低泄露后的风险

### 5.4 生产环境注意事项
1. **密钥管理**：使用专门的密钥管理系统（如AWS KMS、HashiCorp Vault）存储密钥和敏感配置
2. **HTTPS传输**：所有认证令牌和敏感数据都必须通过HTTPS协议传输
3. **日志安全**：不要在日志中记录密码、令牌、密钥等敏感数据
4. **定期轮换**：定期轮换API密钥、加密密钥等长期使用的敏感数据
5. **监控告警**：监控异常的认证失败和令牌使用情况，及时发现攻击行为
6. **安全审计**：定期审计代码和系统配置，确保没有安全漏洞
