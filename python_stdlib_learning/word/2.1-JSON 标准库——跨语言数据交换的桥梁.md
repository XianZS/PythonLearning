# B站Python授课：`json` 标准库——跨语言数据交换的桥梁

## 课程导入

在现代开发中，**数据交换**是核心需求：前后端API通信、配置文件存储、不同编程语言间传递数据……而 **JSON（JavaScript Object Notation）** 是目前最流行的轻量级数据交换格式，它语法简洁、跨语言兼容（几乎所有编程语言都支持）、人类可读。

Python 内置的 `json` 标准库，专门用于 **JSON 数据与 Python 对象的相互转换**（序列化与反序列化），是处理 API 响应、配置文件、数据持久化的必备工具。

---

## 第一部分：核心概念与数据类型映射

### 核心知识点

在使用 `json` 库前，必须先明确 **JSON 数据类型** 与 **Python 数据类型** 的对应关系，这是避免转换错误的关键：

|JSON 数据类型|Python 数据类型|
|---|---|
|object（对象）|dict（字典）|
|array（数组）|list/tuple（列表/元组）|
|string（字符串）|str（字符串）|
|number（数字）|int/float（整数/浮点数）|
|true/false|True/False|
|null|None|

## 第二部分：序列化（Python → JSON）

### 核心知识点

**序列化**：将 Python 对象转换为 JSON 格式的字符串或文件。`json` 库提供两个核心函数：

- `json.dumps(obj)`：将 Python 对象转为 **JSON 字符串**（适合内存中处理、API 响应）。

- `json.dump(obj, fp)`：将 Python 对象直接写入 **文件对象**（适合持久化存储）。

### 常用函数与示例代码

```Python

import json

# 1. 准备 Python 对象（字典、列表混合）
data = {
    "name": "张三",
    "age": 25,
    "is_student": False,
    "hobbies": ["编程", "读书", "跑步"],
    "address": {
        "city": "西安",
        "district": "未央区"
    },
    "score": None
}

# 2. dumps：转为 JSON 字符串
json_str = json.dumps(data)
print("默认序列化（无格式）：")
print(json_str)  # 输出紧凑字符串，中文会转成 Unicode 编码

# 3. dumps 常用参数（美化输出、中文显示、键排序）
json_str_pretty = json.dumps(
    data,
    indent=2,          # 缩进2空格，美化输出
    ensure_ascii=False, # 不转义中文，直接显示
    sort_keys=True      # 按字典键的字母顺序排序
)
print("\n美化后序列化：")
print(json_str_pretty)

# 4. dump：直接写入文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)
print("\n已写入 data.json 文件")
```

### 内容讲解

- **关键参数解析**：

    - `indent`：设置缩进空格数（如 `2` 或 `4`），让 JSON 更易读（生产环境可省略，节省空间）。

    - `ensure_ascii`：默认为 `True`，会将中文转成 `\uXXXX` 格式；设为 `False` 可直接显示中文（**必须配合文件 ** **`encoding="utf-8"`** ** 使用**）。

    - `sort_keys`：默认为 `False`，设为 `True` 时会按字典键的字母顺序排序（方便对比 JSON 差异）。

- **避坑提示**：Python 的 `tuple` 序列化后会变成 JSON 的 `array`（列表），反序列化时默认转回 `list`（不会恢复为 `tuple`）。

### 应用场景

1. **API 响应生成**：后端用 `dumps` 将字典转为 JSON 字符串，返回给前端。

2. **配置文件保存**：将用户设置（如主题、快捷键）用 `dump` 写入 `config.json`，下次启动时读取。

## 第三部分：反序列化（JSON → Python）

### 核心知识点

**反序列化**：将 JSON 字符串或文件转换为 Python 对象。对应两个核心函数：

- `json.loads(s)`：将 **JSON 字符串** 转为 Python 对象（适合解析 API 响应字符串）。

- `json.load(fp)`：从 **文件对象** 读取 JSON 并转为 Python 对象（适合读取配置文件）。

### 常用函数与示例代码

```Python

import json

# 1. loads：从 JSON 字符串解析
json_str = '''
{
    "name": "李四",
    "age": 30,
    "is_student": true,
    "hobbies": ["音乐", "旅行"],
    "score": null
}
'''
data_from_str = json.loads(json_str)
print("从字符串解析的 Python 对象：")
print(data_from_str)
print(f"姓名：{data_from_str['name']}，年龄：{data_from_str['age']}")
print(f"hobbies 类型：{type(data_from_str['hobbies'])}")  # 输出：<class 'list'>

# 2. load：从文件读取
with open("data.json", "r", encoding="utf-8") as f:
    data_from_file = json.load(f)
print("\n从文件读取的 Python 对象：")
print(data_from_file)
```

### 内容讲解

- **自动类型转换**：

    - JSON 的 `true`/`false` → Python 的 `True`/`False`。

    - JSON 的 `null` → Python 的 `None`。

    - JSON 的 `array` → Python 的 `list`（即使原先是 `tuple`，反序列化后也是 `list`）。

- **避坑提示**：JSON 字符串必须用**双引号**（`"`）包裹键和字符串值，单引号（`'`）会报错（这是 JSON 语法规范，不是 Python 的问题）。

### 应用场景

1. **API 响应解析**：用 `requests` 库调用接口后，用 `loads` 或 `response.json()` 解析返回的 JSON 数据。

2. **配置文件加载**：程序启动时用 `load` 读取 `config.json`，恢复用户设置。

## 第四部分：进阶：处理自定义对象

### 核心知识点

默认情况下，`json` 库无法直接序列化**自定义类的实例**（会报错 `TypeError: Object of type X is not JSON serializable`）。解决方法有两种：

1. **自定义 ** **`JSONEncoder`** ** 子类**：重写 `default()` 方法，将自定义对象转为可序列化的字典。

2. **使用 ** **`default`** ** 参数**：在 `dumps`/`dump` 中传入一个函数，将自定义对象转为字典。

反序列化时，可用 `object_hook` 参数将字典转回自定义对象。

### 常用函数与示例代码

```Python

import json

# 1. 定义自定义类
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Person(name={self.name}, age={self.age})"

# 2. 方法1：自定义 JSONEncoder
class PersonEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, Person):
            # 将 Person 对象转为字典（可序列化）
            return {"__type__": "Person", "name": obj.name, "age": obj.age}
        # 其他类型用默认处理
        return super().default(obj)

# 3. 方法2：使用 default 参数（更简洁）
def person_to_dict(obj):
    if isinstance(obj, Person):
        return {"__type__": "Person", "name": obj.name, "age": obj.age}
    raise TypeError(f"Object of type {type(obj)} is not JSON serializable")

# 4. 序列化自定义对象
person = Person("王五", 28)
# 用自定义 Encoder
json_str1 = json.dumps(person, cls=PersonEncoder, ensure_ascii=False)
# 用 default 参数
json_str2 = json.dumps(person, default=person_to_dict, ensure_ascii=False)
print("自定义对象序列化结果：")
print(json_str1)

# 5. 反序列化：用 object_hook 转回 Person 对象
def dict_to_person(d):
    if d.get("__type__") == "Person":
        return Person(d["name"], d["age"])
    return d  # 其他字典保持不变

person_from_json = json.loads(json_str1, object_hook=dict_to_person)
print("\n反序列化后的对象：")
print(person_from_json)
print(f"类型：{type(person_from_json)}")  # 输出：<class '__main__.Person'>
```

### 内容讲解

- **序列化关键**：通过 `__type__` 标记对象类型，反序列化时根据标记判断如何转换。

- **反序列化关键**：`object_hook` 会遍历 JSON 解析出的所有字典，对每个字典调用转换函数，符合条件的转为自定义对象。

### 应用场景

1. **简单对象持久化**：将自定义的 `User`、`Product` 等对象存入 JSON 文件（复杂对象建议用数据库）。

2. **轻量级对象传输**：前后端传输简单自定义对象时，用这种方式转换（复杂对象建议用 `pydantic` 库）。

## 第五部分：常见应用场景实战

### 场景1：配置文件管理

```Python

import json
from pathlib import Path

# 配置文件路径
config_path = Path("config.json")

# 默认配置
default_config = {
    "theme": "dark",
    "font_size": 14,
    "auto_save": True,
    "shortcuts": {"save": "Ctrl+S", "open": "Ctrl+O"}
}

# 加载配置（如果文件不存在则创建默认配置）
def load_config():
    if config_path.exists():
        with open(config_path, "r", encoding="utf-8") as f:
            return json.load(f)
    else:
        save_config(default_config)
        return default_config

# 保存配置
def save_config(config):
    with open(config_path, "w", encoding="utf-8") as f:
        json.dump(config, f, indent=2, ensure_ascii=False)

# 使用示例
config = load_config()
print(f"当前主题：{config['theme']}")
# 修改配置
config["font_size"] = 16
save_config(config)
print("配置已更新")
```

### 场景2：API 数据解析（模拟）

```Python

import json

# 模拟 API 返回的 JSON 字符串
api_response = '''
{
    "code": 200,
    "message": "success",
    "data": {
        "total": 2,
        "items": [
            {"id": 1, "title": "Python 入门", "price": 99},
            {"id": 2, "title": "JSON 教程", "price": 0}
        ]
    }
}
'''

# 解析 API 响应
result = json.loads(api_response)
if result["code"] == 200:
    print("API 请求成功！")
    items = result["data"]["items"]
    for item in items:
        print(f"课程：{item['title']}，价格：{item['price']}")
else:
    print(f"API 请求失败：{result['message']}")
```

## 课程总结与实战练习

### 核心回顾

1. **数据类型映射**：牢记 JSON 与 Python 的类型对应关系。

2. **序列化**：`dumps` 转字符串（`indent`/`ensure_ascii` 美化输出），`dump` 写入文件。

3. **反序列化**：`loads` 解析字符串，`load` 读取文件。

4. **自定义对象**：用 `default`/`JSONEncoder` 序列化，`object_hook` 反序列化。

5. **避坑要点**：JSON 用双引号，中文需设 `ensure_ascii=False` + 文件 `utf-8` 编码。

### 实战练习

写一个“待办事项管理系统”，实现以下功能：

1. 用 JSON 文件 `todos.json` 存储待办事项（每个事项包含 `id`、`title`、`completed` 字段）。

2. 支持添加待办事项（自动生成唯一 `id`）。

3. 支持查询所有待办事项（区分已完成/未完成）。

4. 支持标记待办事项为已完成。

5. 所有操作后自动保存到 JSON 文件。
