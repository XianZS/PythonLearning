# Python标准库hmac完整教学文档

## 一、概念部分

### 1.1 hmac库详细概念
hmac是Python标准库中用于实现**HMAC（Keyed-Hash Message Authentication Code，带密钥的哈希消息认证码）**算法的核心模块。它基于hashlib库提供的哈希函数，实现了一种同时验证消息**完整性**和**真实性**的密码学技术。

从技术本质上讲，HMAC是一种将**密钥**与**哈希函数**结合的消息认证机制。它不是一种新的哈希算法，而是一种哈希算法的使用模式。hmac库对HMAC标准（RFC 2104）进行了Python语言封装，处理了密钥填充、哈希计算、安全比较等底层细节，使开发者无需深入了解密码学原理，就能安全地实现消息认证功能。

### 1.2 HMAC的核心理论基础
#### HMAC解决的问题
普通哈希函数（如SHA-256）只能验证消息的**完整性**（即消息在传输过程中没有被篡改），但无法验证消息的**真实性**（即消息确实来自声称的发送者）。因为任何人都可以计算消息的哈希值，攻击者可以篡改消息并重新计算哈希值，接收者无法发现。

HMAC通过引入**共享密钥**解决了这个问题：只有拥有密钥的发送者才能生成正确的HMAC值，接收者使用相同的密钥重新计算HMAC值并进行比较，从而同时验证消息的完整性和真实性。

#### HMAC的工作原理
HMAC通过两次哈希计算实现，其数学表达式为：
```
HMAC(K, M) = H((K ⊕ opad) || H((K ⊕ ipad) || M))
```
其中：
- `K`：共享密钥
- `M`：要认证的消息
- `H`：底层哈希函数（如SHA-256）
- `ipad`：内部填充值（0x36重复64次）
- `opad`：外部填充值（0x5C重复64次）
- `⊕`：按位异或运算
- `||`：字符串拼接

简单来说，HMAC的工作流程是：
1. 如果密钥长度大于哈希函数的块大小，先对密钥进行哈希处理
2. 将密钥与ipad进行异或运算，得到内部密钥
3. 将内部密钥与消息拼接后进行第一次哈希计算
4. 将密钥与opad进行异或运算，得到外部密钥
5. 将外部密钥与第一次哈希的结果拼接后进行第二次哈希计算
6. 最终结果即为HMAC值

这种双重哈希结构使HMAC具有比简单的"密钥+消息"哈希更高的安全性，能够抵抗多种密码学攻击。

### 1.3 应用场景
hmac库在Python项目中有着极其广泛的应用，主要包括：
- **API接口签名认证**：几乎所有主流开放平台（微信支付、支付宝、AWS、GitHub等）都使用HMAC进行API请求的身份验证和防篡改
- **Webhook验证**：验证Webhook请求是否来自合法的发送方，防止恶意请求
- **Cookie/Session签名**：对Cookie和Session数据进行签名，防止用户篡改
- **消息队列消息验证**：确保消息在队列传输过程中没有被篡改或伪造
- **文件完整性与来源验证**：比普通哈希更安全的文件验证方式，确保文件不仅完整而且来自可信来源
- **一次性密码（OTP）**：HOTP（基于HMAC的一次性密码）和TOTP（基于时间的一次性密码）算法的基础
- **跨域资源共享（CORS）**：某些CORS实现使用HMAC验证请求的合法性

### 1.4 HMAC与其他技术的对比
| 技术 | 核心要素 | 验证内容 | 安全性 | 适用场景 |
|-----|---------|---------|-------|---------|
| 普通哈希 | 消息 | 完整性 | 低 | 非安全场景的文件校验 |
| HMAC | 消息+共享密钥 | 完整性+真实性 | 中高 | 双方共享密钥的内部系统、API认证 |
| 数字签名 | 消息+公私钥对 | 完整性+真实性+不可否认性 | 高 | 公开系统、电子合同、金融交易 |

**重要提示**：HMAC依赖于共享密钥的安全性。如果密钥泄露，攻击者可以生成任意消息的合法HMAC值，整个认证机制将失效。

## 二、基础部分

### 2.1 计算最简单的HMAC值
这是hmac最基础的用法，演示了如何计算一个字符串的HMAC值。

**理论说明**：
- 使用`hmac.new(key, msg=None, digestmod=None)`创建HMAC对象
- `key`：共享密钥，必须是bytes类型
- `msg`：要认证的消息，可选，必须是bytes类型
- `digestmod`：底层哈希算法，可以是字符串（如'sha256'）或hashlib模块中的哈希对象
- 使用`hexdigest()`方法获取十六进制格式的HMAC值
- 使用`digest()`方法获取原始字节格式的HMAC值

**示例代码**：
```python
import hmac
import hashlib

# 共享密钥（必须是bytes类型）
secret_key = b"my_secure_secret_key_123"

# 要认证的消息（必须是bytes类型）
message = b"Hello, HMAC!"

# 创建HMAC对象，使用SHA-256算法
hmac_obj = hmac.new(secret_key, message, hashlib.sha256)

# 获取十六进制格式的HMAC值
hmac_hex = hmac_obj.hexdigest()

print(f"密钥: {secret_key.decode('utf-8')}")
print(f"消息: {message.decode('utf-8')}")
print(f"HMAC-SHA256值: {hmac_hex}")
print(f"HMAC值长度: {len(hmac_hex)} 个字符 (对应 {len(hmac_hex)//2} 字节)")
```

### 2.2 使用不同的哈希算法
hmac库支持所有hashlib库支持的哈希算法，可以根据安全需求和性能要求选择合适的算法。

**理论说明**：
- 可以通过字符串指定算法，如`'md5'`、`'sha1'`、`'sha256'`、`'sha512'`、`'blake2b'`等
- 也可以直接传入hashlib模块中的哈希函数，如`hashlib.sha256`
- **安全警告**：MD5和SHA-1算法已经被破解，存在已知的碰撞攻击，绝对不能用于安全相关的场景
- 推荐使用SHA-256、SHA-512或BLAKE2b算法，这些算法目前被认为是安全的

**示例代码**：
```python
import hmac

secret_key = b"my_secure_secret_key_123"
message = b"my_secure_secret_key_123"

# 常用算法列表
algorithms = ['md5', 'sha1', 'sha256', 'sha512', 'blake2b']

for algo in algorithms:
    # 创建HMAC对象
    hmac_obj = hmac.new(secret_key, message, algo)
    hmac_hex = hmac_obj.hexdigest()
    
    print(f"HMAC-{algo.upper()}:")
    print(f"  值: {hmac_hex}")
    print(f"  长度: {len(hmac_hex)} 字符 ({len(hmac_hex)//2} 字节)\n")
```

### 2.3 可更新的HMAC对象
与hashlib的哈希对象一样，HMAC对象也是可更新的，可以分多次输入数据，这在处理大文件或流式数据时非常有用。

**理论说明**：
- 使用`update(msg)`方法向HMAC对象添加数据，数据必须是bytes类型
- 多次调用`update()`方法的效果等同于将所有数据拼接后一次性输入
- 可以在任何时候调用`digest()`或`hexdigest()`获取当前的HMAC值
- 调用`digest()`或`hexdigest()`后，HMAC对象的状态不会被重置，可以继续调用`update()`添加更多数据

**示例代码**：
```python
import hmac
import hashlib

secret_key = b"my_secure_secret_key_123"

# 创建HMAC对象
hmac_obj = hmac.new(secret_key, digestmod=hashlib.sha256)

# 分多次输入数据
hmac_obj.update(b"Hello, ")
hmac_obj.update(b"this is ")
hmac_obj.update(b"a test ")
hmac_obj.update(b"message.")

# 获取HMAC值
hmac1 = hmac_obj.hexdigest()
print(f"分多次输入的HMAC值: {hmac1}")

# 一次性输入相同的数据
hmac_obj2 = hmac.new(secret_key, b"Hello, this is a test message.", hashlib.sha256)
hmac2 = hmac_obj2.hexdigest()
print(f"一次性输入的HMAC值: {hmac2}")

print(f"两者是否相等: {hmac1 == hmac2}\n")

# 继续添加数据
hmac_obj.update(b" More data added.")
hmac3 = hmac_obj.hexdigest()
print(f"添加更多数据后的HMAC值: {hmac3}")
```

### 2.4 HMAC值的安全比较
这是HMAC使用中最重要的安全注意事项之一：绝对不能使用普通的`==`运算符比较HMAC值，因为它容易受到**时序攻击（Timing Attack）**。

**理论说明**：
- 普通的`==`运算符在比较字符串时，会从第一个字符开始逐个比较，遇到不相等的字符就立即返回
- 攻击者可以通过测量比较操作的时间差异，推断出HMAC值的正确字符
- hmac库提供了`hmac.compare_digest(a, b)`方法，专门用于安全比较HMAC值
- 这个方法会比较整个字符串的所有字符，无论是否相等，花费的时间都是相同的
- `secrets.compare_digest()`方法与`hmac.compare_digest()`完全相同，效果一致

**示例代码**：
```python
import hmac
import hashlib
import time

def unsafe_compare(a: str, b: str) -> bool:
    """不安全的比较方法，容易受到时序攻击"""
    return a == b

def safe_compare(a: str, b: str) -> bool:
    """安全的比较方法，抵抗时序攻击"""
    return hmac.compare_digest(a, b)

# 测试比较时间差异
if __name__ == "__main__":
    secret_key = b"test_key"
    
    # 生成两个只有最后一个字符不同的HMAC值
    hmac1 = hmac.new(secret_key, b"message1", hashlib.sha256).hexdigest()
    hmac2 = hmac.new(secret_key, b"message2", hashlib.sha256).hexdigest()
    
    print(f"HMAC1: {hmac1}")
    print(f"HMAC2: {hmac2}\n")
    
    # 测试不安全比较的时间
    start_time = time.perf_counter()
    for _ in range(100000):
        unsafe_compare(hmac1, hmac2)
    unsafe_time = time.perf_counter() - start_time
    
    # 测试安全比较的时间
    start_time = time.perf_counter()
    for _ in range(100000):
        safe_compare(hmac1, hmac2)
    safe_time = time.perf_counter() - start_time
    
    print(f"不安全比较10万次耗时: {unsafe_time:.6f} 秒")
    print(f"安全比较10万次耗时: {safe_time:.6f} 秒")
    print(f"安全比较比不安全比较慢约: {safe_time/unsafe_time:.1f} 倍")
    print("\n重要提示：安全比较虽然稍慢，但可以有效防止时序攻击，必须用于所有HMAC值的比较！")
```

## 三、进阶部分

### 3.1 大文件的HMAC计算
当需要验证大文件的HMAC值时，不能一次性将整个文件读入内存，否则会导致内存溢出。需要分块读取文件并逐步更新HMAC对象。

**理论说明**：
- 分块大小通常选择4KB、8KB或64KB，这是磁盘IO的常见块大小
- 以二进制模式打开文件，避免文本模式下的换行符转换问题
- 这种方法可以处理任意大小的文件，内存占用始终保持在分块大小左右
- 特别适合验证下载的软件包、镜像文件等大文件的完整性和来源

**示例代码**：
```python
import hmac
import hashlib
import os

def calculate_file_hmac(file_path: str, secret_key: bytes, algorithm: str = 'sha256', chunk_size: int = 65536) -> str:
    """
    计算大文件的HMAC值
    
    Args:
        file_path: 文件路径
        secret_key: 共享密钥（bytes类型）
        algorithm: 哈希算法名称
        chunk_size: 分块大小，默认64KB
    
    Returns:
        str: 十六进制格式的HMAC值
    
    Raises:
        FileNotFoundError: 文件不存在
        PermissionError: 没有读取文件的权限
    """
    hmac_obj = hmac.new(secret_key, digestmod=algorithm)
    
    with open(file_path, 'rb') as f:
        while chunk := f.read(chunk_size):
            hmac_obj.update(chunk)
    
    return hmac_obj.hexdigest()

# 测试：计算当前Python脚本自身的HMAC值
if __name__ == "__main__":
    script_path = __file__
    secret_key = b"my_file_verification_key"
    file_size = os.path.getsize(script_path)
    
    print(f"计算文件: {script_path}")
    print(f"文件大小: {file_size} 字节")
    
    file_hmac = calculate_file_hmac(script_path, secret_key, 'sha256')
    print(f"\n文件HMAC-SHA256值: {file_hmac}")
    
    # 验证文件
    received_hmac = file_hmac  # 模拟从可信来源获取的HMAC值
    is_valid = hmac.compare_digest(file_hmac, received_hmac)
    print(f"文件验证结果: {'通过' if is_valid else '失败'}")
```

### 3.2 基于HMAC的API签名生成
这是项目中最常见的HMAC应用场景。API签名可以确保请求来自合法的客户端，并且在传输过程中没有被篡改。

**理论说明**：
- API签名的核心思想是：客户端将请求参数按照一定规则拼接成字符串，使用密钥计算HMAC值作为签名
- 服务端收到请求后，按照相同的规则拼接参数，计算HMAC值并与收到的签名进行比较
- 签名生成规则通常包括：
  1. 将所有请求参数按照参数名的字典序排序
  2. 将排序后的参数拼接成"key1=value1&key2=value2"的格式
  3. 可选：添加时间戳和随机数（nonce）防止重放攻击
  4. 使用密钥计算拼接字符串的HMAC值
  5. 将签名添加到请求头或请求参数中

**示例代码**：
```python
import hmac
import hashlib
import time
import uuid
import urllib.parse

def generate_api_signature(secret_key: str, params: dict, timestamp: int = None, nonce: str = None) -> tuple[str, int, str]:
    """
    生成API请求签名
    
    Args:
        secret_key: 共享密钥（字符串类型）
        params: 请求参数字典
        timestamp: 时间戳（秒），如果为None则自动生成
        nonce: 随机数，如果为None则自动生成
    
    Returns:
        tuple: (签名, 时间戳, 随机数)
    """
    # 生成时间戳和随机数
    timestamp = timestamp or int(time.time())
    nonce = nonce or str(uuid.uuid4())
    
    # 将时间戳和随机数添加到参数中
    params_with_auth = params.copy()
    params_with_auth['timestamp'] = str(timestamp)
    params_with_auth['nonce'] = nonce
    
    # 按照参数名的字典序排序
    sorted_params = sorted(params_with_auth.items(), key=lambda x: x[0])
    
    # 拼接成查询字符串格式
    query_string = urllib.parse.urlencode(sorted_params)
    
    # 计算HMAC-SHA256签名
    secret_key_bytes = secret_key.encode('utf-8')
    query_string_bytes = query_string.encode('utf-8')
    signature = hmac.new(secret_key_bytes, query_string_bytes, hashlib.sha256).hexdigest()
    
    return signature, timestamp, nonce

# 测试
if __name__ == "__main__":
    # 客户端密钥（实际项目中应从配置文件或环境变量获取）
    client_secret = "my_api_client_secret_123456"
    
    # 请求参数
    request_params = {
        'user_id': '12345',
        'action': 'get_user_info',
        'page': '1',
        'page_size': '10'
    }
    
    # 生成签名
    signature, timestamp, nonce = generate_api_signature(client_secret, request_params)
    
    print("API请求签名生成结果:")
    print(f"  时间戳: {timestamp}")
    print(f"  随机数: {nonce}")
    print(f"  签名: {signature}")
    print("\n客户端应将以下参数添加到请求中:")
    print(f"  timestamp={timestamp}")
    print(f"  nonce={nonce}")
    print(f"  signature={signature}")
```

### 3.3 基于HMAC的API签名验证
与签名生成相对应，服务端需要验证客户端发送的签名是否正确。同时，为了防止重放攻击，还需要验证时间戳和随机数。

**理论说明**：
- 服务端验证流程：
  1. 从请求中获取所有参数，包括时间戳、随机数和签名
  2. 验证时间戳是否在允许的时间范围内（如前后5分钟），防止重放攻击
  3. 验证随机数是否已经使用过，防止重放攻击
  4. 按照与客户端相同的规则拼接参数，计算HMAC值
  5. 使用安全比较方法比较计算出的签名与收到的签名
- 随机数缓存：可以使用Redis等缓存系统存储已经使用过的随机数，设置过期时间与时间戳有效期相同

**示例代码**：
```python
import hmac
import hashlib
import time
import uuid
import urllib.parse
from typing import Optional

# 模拟随机数缓存（实际项目中应使用Redis等分布式缓存）
nonce_cache = set()
# 签名有效期（秒）
SIGNATURE_EXPIRE_SECONDS = 300  # 5分钟

def generate_api_signature(secret_key: str, params: dict, timestamp: int = None, nonce: str = None) -> tuple[str, int, str]:
    """
    生成API请求签名
    
    Args:
        secret_key: 共享密钥（字符串类型）
        params: 请求参数字典
        timestamp: 时间戳（秒），如果为None则自动生成
        nonce: 随机数，如果为None则自动生成
    
    Returns:
        tuple: (签名, 时间戳, 随机数)
    """
    # 生成时间戳和随机数
    timestamp = timestamp or int(time.time())
    nonce = nonce or str(uuid.uuid4())
    
    # 复制参数并删除可能存在的signature参数（关键修复！）
    params_with_auth = params.copy()
    if 'signature' in params_with_auth:
        del params_with_auth['signature']
    
    # 将时间戳和随机数添加到参数中
    params_with_auth['timestamp'] = str(timestamp)
    params_with_auth['nonce'] = nonce
    
    # 按照参数名的字典序排序
    sorted_params = sorted(params_with_auth.items(), key=lambda x: x[0])
    
    # 拼接成查询字符串格式
    query_string = urllib.parse.urlencode(sorted_params)
    
    # 计算HMAC-SHA256签名
    secret_key_bytes = secret_key.encode('utf-8')
    query_string_bytes = query_string.encode('utf-8')
    signature = hmac.new(secret_key_bytes, query_string_bytes, hashlib.sha256).hexdigest()
    
    return signature, timestamp, nonce

def verify_api_signature(secret_key: str, params: dict) -> tuple[bool, str]:
    """
    验证API请求签名
    
    Args:
        secret_key: 共享密钥（字符串类型）
        params: 请求参数字典，必须包含timestamp、nonce和signature
    
    Returns:
        tuple: (验证是否通过, 错误信息)
    """
    # 检查必要参数是否存在
    required_params = ['timestamp', 'nonce', 'signature']
    for param in required_params:
        if param not in params:
            return False, f"缺少必要参数: {param}"
    
    # 提取参数
    timestamp = params['timestamp']
    nonce = params['nonce']
    received_signature = params['signature']
    
    # 验证时间戳格式
    try:
        timestamp_int = int(timestamp)
    except ValueError:
        return False, "时间戳格式错误"
    
    # 验证时间戳是否在有效期内
    current_time = int(time.time())
    if abs(current_time - timestamp_int) > SIGNATURE_EXPIRE_SECONDS:
        return False, "签名已过期"
    
    # 验证随机数是否已经使用过
    if nonce in nonce_cache:
        return False, "随机数已使用，可能是重放攻击"
    
    # 移除签名参数，准备重新计算签名
    params_without_sign = params.copy()
    del params_without_sign['signature']
    
    # 按照参数名的字典序排序
    sorted_params = sorted(params_without_sign.items(), key=lambda x: x[0])
    
    # 拼接成查询字符串格式
    query_string = urllib.parse.urlencode(sorted_params)
    
    # 计算HMAC-SHA256签名
    secret_key_bytes = secret_key.encode('utf-8')
    query_string_bytes = query_string.encode('utf-8')
    calculated_signature = hmac.new(secret_key_bytes, query_string_bytes, hashlib.sha256).hexdigest()
    
    # 安全比较签名
```

### 3.4 HMAC密钥管理最佳实践
密钥是HMAC安全的核心，如果密钥泄露，整个认证机制将失效。因此，正确的密钥管理至关重要。

**理论说明**：

- **密钥生成**：使用密码学安全的随机数生成器生成密钥，如`secrets.token_bytes()`
- **密钥长度**：密钥长度至少应与底层哈希算法的输出长度相同。例如，使用SHA-256时，密钥至少应为32字节
- **密钥存储**：绝对不要将密钥硬编码在代码中或提交到版本控制系统。应使用环境变量、配置文件或专门的密钥管理系统（如AWS KMS、HashiCorp Vault）存储密钥
- **密钥轮换**：定期轮换密钥，降低密钥泄露的风险。可以实现双密钥机制，在不中断服务的情况下完成密钥轮换
- **环境隔离**：不同的环境（开发、测试、生产）应使用不同的密钥，防止测试环境的密钥泄露影响生产环境

**示例代码**：
```python
import secrets
import os
from typing import Optional

def generate_secure_key(length: int = 32) -> bytes:
    """
    生成密码学安全的随机密钥
    
    Args:
        length: 密钥长度（字节），默认32字节（256位）
    
    Returns:
        bytes: 生成的密钥
    """
    return secrets.token_bytes(length)

def get_secret_key(env_var: str = 'HMAC_SECRET_KEY') -> bytes:
    """
    从环境变量获取密钥
    
    Args:
        env_var: 环境变量名称
    
    Returns:
        bytes: 密钥
    
    Raises:
        ValueError: 如果环境变量未设置
    """
    key_hex = os.getenv(env_var)
    if not key_hex:
        raise ValueError(f"环境变量 {env_var} 未设置")
    
    # 将十六进制字符串转换为bytes
    try:
        return bytes.fromhex(key_hex)
    except ValueError:
        raise ValueError(f"环境变量 {env_var} 不是有效的十六进制字符串")

# 密钥轮换示例
class KeyManager:
    """密钥管理器，支持双密钥轮换"""
    
    def __init__(self, current_key: bytes, previous_key: Optional[bytes] = None):
        self.current_key = current_key
        self.previous_key = previous_key
    
    def sign(self, message: bytes) -> str:
        """使用当前密钥签名"""
        return hmac.new(self.current_key, message, hashlib.sha256).hexdigest()
    
    def verify(self, message: bytes, signature: str) -> bool:
        """验证签名，同时尝试当前密钥和上一个密钥"""
        # 先尝试当前密钥
        current_signature = hmac.new(self.current_key, message, hashlib.sha256).hexdigest()
        if hmac.compare_digest(current_signature, signature):
            return True
        
        # 如果有上一个密钥，尝试上一个密钥
        if self.previous_key:
            previous_signature = hmac.new(self.previous_key, message, hashlib.sha256).hexdigest()
            if hmac.compare_digest(previous_signature, signature):
                return True
        
        return False

# 测试

    new_signature = key_manager.sign(message)
```

```python
# 公共配置与工具函数
import hmac
import hashlib
import time
import uuid
import urllib.parse
import json
from typing import Dict, Tuple, Optional

# ===================== 全局配置 =====================
# 共享密钥（实际生产环境应从安全配置源获取）
SHARED_SECRET = "my_secure_file_transfer_secret_2026"
# 签名有效期（秒）
SIGNATURE_EXPIRE_SECONDS = 300  # 5分钟
# 哈希算法
HASH_ALGORITHM = hashlib.sha256

# ===================== 签名生成函数 =====================
def generate_signature(secret: str, method: str, path: str, params: Dict[str, str] = None, body: bytes = None) -> Tuple[str, int, str]:
    """
    生成请求签名
    
    Args:
        secret: 共享密钥
        method: HTTP方法（GET/POST）
        path: 请求路径
        params: URL查询参数
        body: 请求体字节
    
    Returns:
        (签名, 时间戳, 随机数)
    """
    # 生成时间戳和随机数
    timestamp = int(time.time())
    nonce = str(uuid.uuid4())
    
    # 准备签名数据
    signature_parts = [
        method.upper(),
        path,
        str(timestamp),
        nonce
    ]
    
    # 添加查询参数（排序后拼接）
    if params:
        sorted_params = sorted(params.items(), key=lambda x: x[0])
        query_string = urllib.parse.urlencode(sorted_params)
        signature_parts.append(query_string)
    else:
        signature_parts.append("")
    
    # 添加请求体哈希
    if body:
        body_hash = HASH_ALGORITHM(body).hexdigest()
        signature_parts.append(body_hash)
    else:
        signature_parts.append("")
    
    # 拼接所有部分
    signature_string = "\n".join(signature_parts)
    
    # 计算HMAC签名
    secret_bytes = secret.encode("utf-8")
    signature_bytes = signature_string.encode("utf-8")
    signature = hmac.new(secret_bytes, signature_bytes, HASH_ALGORITHM).hexdigest()
    
    return signature, timestamp, nonce

# ===================== 签名验证函数 =====================
def verify_signature(secret: str, method: str, path: str, params: Dict[str, str] = None, body: bytes = None,
                    timestamp: str = None, nonce: str = None, signature: str = None) -> Tuple[bool, str]:
    """
    验证请求签名
    
    Args:
        secret: 共享密钥
        method: HTTP方法
        path: 请求路径
        params: URL查询参数
        body: 请求体字节
        timestamp: 请求头中的时间戳
        nonce: 请求头中的随机数
        signature: 请求头中的签名
    
    Returns:
        (验证是否通过, 错误信息)
    """
    # 检查必要参数
    if not all([timestamp, nonce, signature]):
        return False, "缺少认证头信息（X-Timestamp, X-Nonce, X-Signature）"
    
    # 验证时间戳格式
    try:
        timestamp_int = int(timestamp)
    except ValueError:
        return False, "时间戳格式错误"
    
    # 验证时间戳有效期
    current_time = int(time.time())
    if abs(current_time - timestamp_int) > SIGNATURE_EXPIRE_SECONDS:
        return False, f"签名已过期（有效期{SIGNATURE_EXPIRE_SECONDS}秒）"
    
    # 验证随机数是否已使用（由调用方传入已使用的nonce集合）
    # 这里只做格式验证，实际的重复检查在服务端完成
    if len(nonce) < 10:
        return False, "随机数格式无效"
    
    # 重新计算签名
    signature_parts = [
        method.upper(),
        path,
        timestamp,
        nonce
    ]
    
    if params:
        sorted_params = sorted(params.items(), key=lambda x: x[0])
        query_string = urllib.parse.urlencode(sorted_params)
        signature_parts.append(query_string)
    else:
        signature_parts.append("")
    
    if body:
        body_hash = HASH_ALGORITHM(body).hexdigest()
        signature_parts.append(body_hash)
    else:
        signature_parts.append("")
    
    signature_string = "\n".join(signature_parts)
    secret_bytes = secret.encode("utf-8")
    signature_bytes = signature_string.encode("utf-8")
    calculated_signature = hmac.new(secret_bytes, signature_bytes, HASH_ALGORITHM).hexdigest()
    
    # 安全比较签名
    if not hmac.compare_digest(calculated_signature, signature):
        return False, "签名验证失败"
    
    return True, "签名验证通过"

# ===================== 响应工具函数 =====================
def json_response(status_code: int, data: dict) -> Tuple[bytes, Dict[str, str]]:
    """生成JSON响应"""
    body = json.dumps(data, ensure_ascii=False).encode("utf-8")
    headers = {
        "Content-Type": "application/json; charset=utf-8",
        "Content-Length": str(len(body))
    }
    return body, headers
```

```python
        self.base_url = base_url.rstrip("/")
        self.secret = secret
    
    def upload_file(self, local_file_path: str, remote_filename: str = None) -> dict:
        """
        上传文件
        
        Args:
            local_file_path: 本地文件路径
            remote_filename: 远程文件名，默认使用本地文件名
        
        Returns:
            服务端响应字典
        """
        if not os.path.exists(local_file_path) or not os.path.isfile(local_file_path):
            raise FileNotFoundError(f"本地文件不存在：{local_file_path}")
        
        # 读取文件内容
        with open(local_file_path, "rb") as f:
            file_content = f.read()
        
        # 确定远程文件名
        if not remote_filename:
            remote_filename = os.path.basename(local_file_path)
        
        # 构建请求参数
        params = {"filename": remote_filename}
        query_string = urllib.parse.urlencode(params)
        url = f"{self.base_url}/upload?{query_string}"
        
        # 生成签名
        signature, timestamp, nonce = generate_signature(
            secret=self.secret,
            method="POST",
            path="/upload",
            params=params,
            body=file_content
        )
        
        # 构建请求头
        headers = {
            "X-Timestamp": str(timestamp),
            "X-Nonce": nonce,
            "X-Signature": signature,
            "Content-Type": "application/octet-stream",
            "Content-Length": str(len(file_content))
        }
        
        # 发送请求
        req = urllib.request.Request(url, data=file_content, headers=headers, method="POST")
        
        try:
            with urllib.request.urlopen(req) as response:
                response_body = response.read().decode("utf-8")
                return {"status_code": response.getcode(), "data": response_body}
        except urllib.error.HTTPError as e:
            error_body = e.read().decode("utf-8")
            return {"status_code": e.code, "error": error_body}
    
    def download_file(self, remote_filename: str, local_save_path: str = None) -> dict:
        """
        下载文件
        
        Args:
            remote_filename: 远程文件名
            local_save_path: 本地保存路径，默认保存到当前目录
        
        Returns:
            服务端响应字典
        """
        # 构建请求参数
        params = {"filename": remote_filename}
        query_string = urllib.parse.urlencode(params)
        url = f"{self.base_url}/download?{query_string}"
        
        # 生成签名
        signature, timestamp, nonce = generate_signature(
            secret=self.secret,
            method="GET",
            path="/download",
            params=params,
            body=None
        )
        
        # 构建请求头
        headers = {
            "X-Timestamp": str(timestamp),
            "X-Nonce": nonce,
            "X-Signature": signature
        }
        
        # 发送请求
        req = urllib.request.Request(url, headers=headers, method="GET")
        
        try:
            with urllib.request.urlopen(req) as response:
                file_content = response.read()
                
                # 确定本地保存路径
                if not local_save_path:
                    local_save_path = remote_filename
                
                # 保存文件
                with open(local_save_path, "wb") as f:
                    f.write(file_content)
                
                return {
                    "status_code": response.getcode(),
                    "success": True,
                    "filename": remote_filename,
                    "save_path": os.path.abspath(local_save_path),
                    "size": len(file_content)
                }
        except urllib.error.HTTPError as e:
            error_body = e.read().decode("utf-8")
            return {"status_code": e.code, "error": error_body}
    
    def health_check(self) -> dict:
        """健康检查"""
        url = f"{self.base_url}/health"
        try:
            with urllib.request.urlopen(url) as response:
                response_body = response.read().decode("utf-8")
                return {"status_code": response.getcode(), "data": response_body}
        except urllib.error.HTTPError as e:
            error_body = e.read().decode("utf-8")
            return {"status_code": e.code, "error": error_body}
```

### 核心技术点解析
1. **纯标准库实现**：使用`http.server`实现HTTP服务，`urllib.request`实现HTTP客户端，完全不依赖第三方库
2. **完整的签名机制**：签名包含HTTP方法、请求路径、时间戳、随机数、查询参数和请求体哈希，确保请求的完整性和真实性
3. **双重防重放**：
   - 时间戳验证：签名仅在5分钟内有效
   - 随机数验证：每个随机数只能使用一次，过期后自动清理
4. **请求体验证**：对POST请求的整个请求体计算哈希并包含在签名中，防止请求体被篡改
5. **安全比较**：使用`hmac.compare_digest()`进行签名比较，防止时序攻击
6. **自动缓存清理**：使用后台线程定期清理过期的随机数，防止内存泄漏


## 五、注意事项与最佳实践

### 5.1 算法选择建议
1. **必须使用安全的哈希算法**：绝对不要使用MD5或SHA-1算法，这些算法已经被破解，存在已知的碰撞攻击
2. **推荐算法**：优先使用SHA-256、SHA-512或BLAKE2b算法，这些算法目前被认为是安全的
3. **算法一致性**：客户端和服务端必须使用完全相同的哈希算法，否则签名验证会失败
4. **不要自定义算法**：不要自己发明或修改HMAC算法，使用标准的实现即可

### 5.2 安全最佳实践
1. **使用安全比较**：始终使用`hmac.compare_digest()`或`secrets.compare_digest()`比较HMAC值，绝对不要使用普通的`==`运算符
2. **密钥安全**：
   - 使用密码学安全的随机数生成器生成密钥
   - 密钥长度至少与哈希算法的输出长度相同
   - 绝对不要将密钥硬编码在代码中或提交到版本控制系统
   - 定期轮换密钥，实现双密钥轮换机制
   - 不同环境使用不同的密钥
3. **防止重放攻击**：
   - 使用时间戳验证，设置合理的签名有效期（通常5-15分钟）
   - 使用随机数（nonce）验证，确保每个请求的随机数唯一
   - 使用缓存系统存储已使用的随机数，设置与签名有效期相同的过期时间
4. **HTTPS传输**：HMAC只能验证消息的完整性和真实性，不能加密消息内容。在生产环境中必须使用HTTPS协议，防止消息被窃听
5. **请求体验证**：对于POST请求，必须对整个请求体进行哈希计算并包含在签名中，防止请求体被篡改

### 5.3 常见错误与陷阱
1. **编码问题**：确保客户端和服务端使用相同的编码（通常是UTF-8），否则会导致签名不匹配
2. **参数排序**：客户端和服务端必须按照完全相同的规则对参数进行排序，通常是按照参数名的字典序
3. **请求体处理**：服务端必须使用原始请求体计算签名，不能使用解析后的JSON数据，因为JSON解析和重新序列化可能会改变原始字节
4. **时间同步**：客户端和服务端的时间必须同步，否则时间戳验证会失败。建议使用NTP服务同步时间
5. **错误信息泄露**：不要在错误信息中泄露过多的细节，如"签名不匹配"而不是"签名应该是xxx"，防止攻击者获取有用信息

### 5.4 性能优化技巧
1. **缓存验证结果**：对于频繁访问的相同请求，可以缓存验证结果，但要注意缓存时间不能超过签名有效期
2. **批量处理**：对于批量请求，可以设计专门的批量签名机制，减少签名计算的次数
3. **硬件加速**：现代CPU支持SHA指令集，可以显著提高SHA系列算法的计算速度
4. **异步处理**：在高并发场景下，可以将签名验证过程异步化，提高系统吞吐量
