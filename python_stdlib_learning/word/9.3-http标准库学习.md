# Python 3.14.0 http标准库完整学习文档

## 一、http标准库核心概念
### 1.1 什么是http标准库
Python的`http`标准库是**HTTP协议的原生实现**，提供了处理HTTP通信的底层基础组件。它不是一个单一的模块，而是一个包含多个子模块的包，分别负责HTTP协议的不同方面。与第三方库（如`requests`）相比，`http`库更接近协议本身，能让你深入理解HTTP的工作原理。

### 1.2 Python 3.14.0 http库的完整结构
| 子模块 | 主要功能 | 典型使用场景 |
|--------|----------|--------------|
| `http.client` | HTTP/HTTPS客户端实现 | 发送原始HTTP请求、底层网络控制 |
| `http.server` | HTTP服务器实现 | 快速搭建简单Web服务器、API服务 |
| `http.cookies` | Cookie解析与创建 | 处理HTTP请求/响应中的Cookie头 |
| `http.cookiejar` | Cookie持久化与自动管理 | 自动处理会话Cookie、跨请求保持状态 |
| `http.HTTPStatus` | HTTP状态码枚举 | 提高代码可读性、避免硬编码状态码 |

> **重要说明**：`urllib`库是基于`http`库构建的更高层次封装，而`requests`等第三方库又进一步封装了`urllib`。学习`http`标准库是理解所有Python HTTP工具的基础。

## 二、基础部分：核心模块详解与示例

### 2.1 http.HTTPStatus：状态码的优雅处理
`http.HTTPStatus`是Python 3.5引入的枚举类，在Python 3.14.0中已包含所有RFC标准定义的HTTP状态码。它解决了硬编码状态码可读性差的问题。

**示例代码：**
```python
import http

# 1. 基本使用
print(f"成功响应: {http.HTTPStatus.OK}")  # 输出: HTTPStatus.OK
print(f"状态码值: {http.HTTPStatus.NOT_FOUND.value}")  # 输出: 404
print(f"状态码短语: {http.HTTPStatus.NOT_FOUND.phrase}")  # 输出: Not Found
print(f"详细描述: {http.HTTPStatus.NOT_FOUND.description}")  # 输出: 请求的资源不存在

# 2. 状态码分类判断
status = http.HTTPStatus.CREATED
print(f"是否成功: {200 <= status.value < 300}")  # 输出: True
print(f"是否客户端错误: {400 <= status.value < 500}")  # 输出: False

# 3. 根据数值获取状态码对象
status_obj = http.HTTPStatus(403)
print(f"403对应的状态: {status_obj.name}")  # 输出: FORBIDDEN
```

### 2.2 http.client：基础HTTP客户端
`http.client`实现了HTTP/1.1协议的客户端，支持持久连接、分块传输、HTTPS等特性。它是所有Python HTTP客户端的底层基础。

#### 2.2.1 最简单的GET请求
```python
import http.client

# 1. 创建连接对象（此时并未建立实际网络连接）
conn = http.client.HTTPConnection("www.example.com", port=80, timeout=10)

try:
    # 2. 发送请求（此时才建立连接）
    conn.request("GET", "/")
    
    # 3. 获取响应对象
    response = conn.getresponse()
    
    # 4. 处理响应
    print(f"状态码: {response.status} {response.reason}")
    print("\n响应头:")
    for name, value in response.getheaders():
        print(f"{name}: {value}")
    
    # 5. 读取响应体（注意：响应体只能读取一次）
    body = response.read()
    print(f"\n响应体长度: {len(body)} 字节")
    print(body.decode("utf-8")[:300])  # 只打印前300个字符

finally:
    # 6. 关闭连接
    conn.close()
```

### 2.3 http.cookies：Cookie的解析与创建
`http.cookies`模块提供了`SimpleCookie`类，专门用于处理HTTP协议中的Cookie头。

**示例代码：**
```python
import http.cookies

# 1. 创建Cookie
cookie = http.cookies.SimpleCookie()

# 设置基本Cookie
cookie["user_id"] = "12345"
cookie["username"] = "python_learner"

# 设置Cookie属性
cookie["user_id"]["expires"] = "Wed, 01 Jan 2030 00:00:00 GMT"
cookie["user_id"]["path"] = "/"
cookie["user_id"]["domain"] = ".example.com"
cookie["user_id"]["secure"] = True  # 仅HTTPS传输
cookie["user_id"]["httponly"] = True  # 禁止JavaScript访问

# 2. 输出Cookie头（用于HTTP响应）
print("Set-Cookie头:")
print(cookie.output())
print()

# 3. 解析Cookie头（用于HTTP请求）
cookie_header = "user_id=12345; username=python_learner; session_id=abcdef123456"
parsed_cookie = http.cookies.SimpleCookie(cookie_header)

print("解析后的Cookie:")
for key, morsel in parsed_cookie.items():
    print(f"{key}: {morsel.value}")
```

### 2.4 http.server：快速搭建HTTP服务器
`http.server`模块提供了构建HTTP服务器的基础类，核心是`HTTPServer`（服务器类）和`BaseHTTPRequestHandler`（请求处理类）。

#### 2.4.1 最简单的Web服务器
```python
from http.server import HTTPServer, BaseHTTPRequestHandler

class MyRequestHandler(BaseHTTPRequestHandler):
    # 处理GET请求
    def do_GET(self):
        # 设置响应状态码
        self.send_response(http.HTTPStatus.OK)
        
        # 设置响应头
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.end_headers()  # 结束响应头，必须调用
        
        # 发送响应体
        response = """
        <!DOCTYPE html>
        <html>
        <head>
            <title>Python HTTP服务器</title>
        </head>
        <body>
            <h1>Hello from Python 3.14.0 http.server!</h1>
            <p>这是一个使用标准库搭建的简单Web服务器</p>
            <p>请求路径: {}</p>
        </body>
        </html>
        """.format(self.path)
        
        self.wfile.write(response.encode("utf-8"))

if __name__ == "__main__":
    # 服务器地址（空字符串表示监听所有接口）
    server_address = ("", 8000)
    
    # 创建服务器实例
    httpd = HTTPServer(server_address, MyRequestHandler)
    
    print(f"服务器启动成功，访问地址: http://localhost:8000")
    print("按 Ctrl+C 停止服务器")
    
    try:
        # 启动服务器（永久运行）
        httpd.serve_forever()
    except KeyboardInterrupt:
        print("\n服务器已停止")
        httpd.shutdown()
```

## 三、进阶部分：高级特性与最佳实践

### 3.1 http.client高级用法
#### 3.1.1 持久连接（HTTP/1.1 Keep-Alive）
`http.client`默认支持HTTP/1.1持久连接，可以在一个TCP连接上发送多个请求，显著提高性能。

```python
import http.client

conn = http.client.HTTPSConnection("httpbin.org")

try:
    # 第一个请求
    conn.request("GET", "/get?request=1")
    response1 = conn.getresponse()
    print(f"第一个请求状态: {response1.status}")
    response1.read()  # 必须读取完响应体才能发送下一个请求
    
    # 第二个请求（复用同一个TCP连接）
    conn.request("GET", "/get?request=2")
    response2 = conn.getresponse()
    print(f"第二个请求状态: {response2.status}")
    response2.read()
    
    # 检查连接是否仍然打开
    print(f"连接是否打开: {not conn.closed}")  # 输出: True

finally:
    conn.close()
```

#### 3.1.2 分块传输编码处理
`http.client`自动处理分块传输编码（`Transfer-Encoding: chunked`），你无需手动解析分块数据。

```python
import http.client

conn = http.client.HTTPSConnection("httpbin.org")

try:
    # 这个端点会返回分块数据
    conn.request("GET", "/stream/3")
    response = conn.getresponse()
    
    print(f"状态码: {response.status}")
    print(f"是否分块传输: {response.chunked}")  # 输出: True
    
    # 逐块读取数据
    while True:
        chunk = response.read(1024)
        if not chunk:
            break
        print(f"收到块: {chunk.decode('utf-8').strip()}")

finally:
    conn.close()
```

#### 3.1.3 异常处理最佳实践
`http.client`定义了多种异常类，用于处理不同类型的HTTP错误。

```python
import http.client
import socket

try:

```

### 3.2 http.cookiejar：自动Cookie管理
`http.cookiejar`模块提供了`CookieJar`类，能够自动从响应中提取Cookie，并在后续请求中自动发送，实现会话保持。

```python
import http.client
import http.cookiejar

# 创建CookieJar对象
cookie_jar = http.cookiejar.CookieJar()

conn = http.client.HTTPSConnection("httpbin.org")

try:
    # 1. 第一个请求：服务器设置Cookie
    conn.request("GET", "/cookies/set?name=python&version=3.14.0")
    response = conn.getresponse()
    
    # 从响应中提取Cookie并保存到CookieJar
    cookie_jar.extract_cookies(response, conn)
    
    print("收到的Cookie:")
    for cookie in cookie_jar:
        print(f"{cookie.name}: {cookie.value}")
    
    # 2. 第二个请求：自动携带Cookie
    headers = {}
    cookie_jar.add_cookie_header(headers)  # 将Cookie添加到请求头
    
    conn.request("GET", "/cookies", headers=headers)
    response = conn.getresponse()
    
    print("\n第二个请求的响应（包含Cookie）:")
    print(response.read().decode("utf-8"))

finally:
    conn.close()
```

### 3.3 http.server高级用法
#### 3.3.1 处理多种HTTP方法
```python
from http.server import HTTPServer, BaseHTTPRequestHandler
import json
import http

class APIServerHandler(BaseHTTPRequestHandler):
    # 辅助方法：发送JSON响应
    def send_json(self, data, status_code=http.HTTPStatus.OK):
        self.send_response(status_code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.end_headers()
        self.wfile.write(json.dumps(data, ensure_ascii=False, indent=2).encode("utf-8"))
    
    # 辅助方法：读取请求体中的JSON数据
    def get_json_body(self):
        content_length = int(self.headers.get("Content-Length", 0))
        if content_length == 0:
            return None
        body = self.rfile.read(content_length)
        return json.loads(body.decode("utf-8"))
    
    def do_GET(self):
        if self.path == "/":
            self.send_json({"message": "欢迎使用Python API服务器", "endpoints": ["/api/users", "/api/info"]})
        elif self.path == "/api/info":
            self.send_json({
                "server": "Python http.server",
                "version": "3.14.0",
                "status": "running"
            })
        else:
            self.send_json({"error": "资源不存在"}, http.HTTPStatus.NOT_FOUND)
    
    def do_POST(self):
        if self.path == "/api/users":
            try:
                user_data = self.get_json_body()
                if not user_data or "name" not in user_data:
                    self.send_json({"error": "无效的请求数据"}, http.HTTPStatus.BAD_REQUEST)
                    return
                
                # 模拟创建用户
                user_id = 1
                new_user = {"id": user_id, "name": user_data["name"], "email": user_data.get("email", "")}
                
                self.send_json({"message": "用户创建成功", "user": new_user}, http.HTTPStatus.CREATED)
            except json.JSONDecodeError:
                self.send_json({"error": "无效的JSON格式"}, http.HTTPStatus.BAD_REQUEST)
        else:
            self.send_json({"error": "资源不存在"}, http.HTTPStatus.NOT_FOUND)

if __name__ == "__main__":
    server = HTTPServer(("", 8000), APIServerHandler)
    print("API服务器启动在 http://localhost:8000")
    server.serve_forever()
```

## 四、实战案例：简易HTTP文件传输系统
我们将使用`http`标准库实现一个完整的文件传输系统，包含服务器端和客户端，支持文件上传、下载、列表和删除功能。

### 4.1 文件服务器实现
```python
from http.server import HTTPServer, BaseHTTPRequestHandler
import os
import json
import http
import urllib.parse

class FileServerHandler(BaseHTTPRequestHandler):
    # 文件存储目录
    STORAGE_DIR = "file_storage"
    
    def __init__(self, *args, **kwargs):
        # 确保存储目录存在
        os.makedirs(self.STORAGE_DIR, exist_ok=True)
        super().__init__(*args, **kwargs)
    
    def send_json(self, data, status_code=http.HTTPStatus.OK):
        self.send_response(status_code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.end_headers()
        self.wfile.write(json.dumps(data, ensure_ascii=False, indent=2).encode("utf-8"))
    
    def do_GET(self):
        parsed_path = urllib.parse.urlparse(self.path)
        path = parsed_path.path
        
        if path == "/files":
            # 列出所有文件
            files = []
            for filename in os.listdir(self.STORAGE_DIR):
                file_path = os.path.join(self.STORAGE_DIR, filename)
                if os.path.isfile(file_path):
                    files.append({
                        "name": filename,
                        "size": os.path.getsize(file_path),
                        "modified": os.path.getmtime(file_path)
                    })
            self.send_json({"files": files})
        
        elif path.startswith("/download/"):
            # 下载文件
            filename = urllib.parse.unquote(path[len("/download/"):])
            file_path = os.path.join(self.STORAGE_DIR, filename)
            
            if not os.path.isfile(file_path):
                self.send_json({"error": "文件不存在"}, http.HTTPStatus.NOT_FOUND)
                return
            
            # 发送文件
            self.send_response(http.HTTPStatus.OK)
            self.send_header("Content-Type", "application/octet-stream")
            self.send_header("Content-Disposition", f"attachment; filename*=UTF-8''{urllib.parse.quote(filename)}")
            self.send_header("Content-Length", str(os.path.getsize(file_path)))
            self.end_headers()
            
            with open(file_path, "rb") as f:
                self.wfile.write(f.read())
        
        else:
            self.send_json({"error": "无效的路径"}, http.HTTPStatus.NOT_FOUND)
    
    def do_POST(self):
        if self.path == "/upload":
            # 上传文件
            filename = self.headers.get("X-Filename")
            if not filename:
                self.send_json({"error": "缺少X-Filename请求头"}, http.HTTPStatus.BAD_REQUEST)
                return
            
            filename = urllib.parse.unquote(filename)
            file_path = os.path.join(self.STORAGE_DIR, filename)
            
            # 读取文件内容
            content_length = int(self.headers.get("Content-Length", 0))
            file_content = self.rfile.read(content_length)
            
            # 保存文件
            with open(file_path, "wb") as f:
                f.write(file_content)
            
            self.send_json({
                "message": "文件上传成功",
                "filename": filename,
                "size": len(file_content)
            }, http.HTTPStatus.CREATED)
        
        else:
            self.send_json({"error": "无效的路径"}, http.HTTPStatus.NOT_FOUND)
    
    def do_DELETE(self):
        if self.path.startswith("/delete/"):
            # 删除文件
            filename = urllib.parse.unquote(path[len("/delete/"):])
            file_path = os.path.join(self.STORAGE_DIR, filename)
            
            if not os.path.isfile(file_path):
                self.send_json({"error": "文件不存在"}, http.HTTPStatus.NOT_FOUND)
                return
            
            os.remove(file_path)
            self.send_json({"message": f"文件 {filename} 删除成功"})
        
        else:
            self.send_json({"error": "无效的路径"}, http.HTTPStatus.NOT_FOUND)

def run_server(host="", port=8000):
    server = HTTPServer((host, port), FileServerHandler)
    print(f"文件服务器启动在 http://{host}:{port}")
    print(f"文件存储目录: {os.path.abspath(FileServerHandler.STORAGE_DIR)}")
    print("可用API:")
    print("  GET    /files          - 列出所有文件")
    print("  GET    /download/<文件名> - 下载文件")
    print("  POST   /upload         - 上传文件（需要X-Filename头）")
    print("  DELETE /delete/<文件名>   - 删除文件")
    server.serve_forever()

if __name__ == "__main__":
    run_server()
```

### 4.2 文件客户端实现
```python
import http.client
import json
import os
import urllib.parse

class FileClient:
    def __init__(self, host, port):
        self.host = host
        self.port = port
        self.conn = http.client.HTTPConnection(host, port)
    
    def list_files(self):
        """获取服务器上的文件列表"""
        self.conn.request("GET", "/files")
        response = self.conn.getresponse()
        return json.loads(response.read().decode("utf-8"))
    
    def upload_file(self, local_path):
        """上传本地文件到服务器"""
        if not os.path.isfile(local_path):
            raise FileNotFoundError(f"本地文件不存在: {local_path}")
        
        filename = os.path.basename(local_path)
        encoded_filename = urllib.parse.quote(filename)
        
        with open(local_path, "rb") as f:
            file_content = f.read()
        
        headers = {
            "X-Filename": encoded_filename,
            "Content-Length": str(len(file_content))
        }
        
        self.conn.request("POST", "/upload", body=file_content, headers=headers)
        response = self.conn.getresponse()
        return json.loads(response.read().decode("utf-8"))
    
    def download_file(self, filename, save_path=None):
        """从服务器下载文件"""
        if save_path is None:
            save_path = filename
        
        encoded_filename = urllib.parse.quote(filename)
        self.conn.request("GET", f"/download/{encoded_filename}")
        response = self.conn.getresponse()
        
        if response.status != 200:
            return json.loads(response.read().decode("utf-8"))
        
        with open(save_path, "wb") as f:
            f.write(response.read())
        
        return {"message": f"文件下载成功，保存为: {save_path}"}
    
    def delete_file(self, filename):
        """从服务器删除文件"""
        encoded_filename = urllib.parse.quote(filename)
        self.conn.request("DELETE", f"/delete/{encoded_filename}")
        response = self.conn.getresponse()
        return json.loads(response.read().decode("utf-8"))
    
    def close(self):
        """关闭连接"""
        self.conn.close()

def main():
    # 创建客户端
    client = FileClient("localhost", 8000)
    
    try:
        # 1. 列出初始文件
        print("=== 初始文件列表 ===")
        print(json.dumps(client.list_files(), indent=2, ensure_ascii=False))
        
        # 2. 创建测试文件并上传
        test_filename = "test_file.txt"
        with open(test_filename, "w", encoding="utf-8") as f:
            f.write("这是一个测试文件\n")
            f.write("使用Python 3.14.0 http标准库创建\n")
            f.write("文件传输系统演示\n")
        
        print("\n=== 上传文件 ===")
        result = client.upload_file(test_filename)
        print(json.dumps(result, indent=2, ensure_ascii=False))
        
        # 3. 再次列出文件
        print("\n=== 上传后的文件列表 ===")
        print(json.dumps(client.list_files(), indent=2, ensure_ascii=False))
        
        # 4. 下载文件
        print("\n=== 下载文件 ===")
        result = client.download_file(test_filename, "downloaded_test_file.txt")
        print(json.dumps(result, indent=2, ensure_ascii=False))
        
        # 5. 删除文件
        print("\n=== 删除文件 ===")
        result = client.delete_file(test_filename)
        print(json.dumps(result, indent=2, ensure_ascii=False))
        
        # 6. 最终文件列表
        print("\n=== 删除后的文件列表 ===")
        print(json.dumps(client.list_files(), indent=2, ensure_ascii=False))
    
    finally:
        client.close()
        # 清理本地测试文件
        if os.path.exists(test_filename):
            os.remove(test_filename)
        if os.path.exists("downloaded_test_file.txt"):
            os.remove("downloaded_test_file.txt")

if __name__ == "__main__":
    main()
```

## 五、总结与扩展学习
### 5.1 核心要点总结
- `http`标准库是Python处理HTTP协议的底层基础，提供了客户端、服务器、Cookie处理等完整功能
- `http.client`适合需要精细控制HTTP请求的场景，但日常开发中更推荐使用`requests`库
- `http.server`适合快速搭建简单的Web服务和API，但生产环境应使用专业的Web框架
- `http.cookies`和`http.cookiejar`提供了完整的Cookie处理能力，是实现会话管理的基础
- Python 3.14.0的`http`库完全兼容HTTP/1.1标准，支持持久连接、分块传输等现代特性

### 5.2 扩展学习方向
1. **更高层次的HTTP客户端**：学习`urllib.request`和`requests`库，它们提供了更友好的API和更强大的功能
2. **异步HTTP**：学习`aiohttp`库，用于构建高性能的异步HTTP客户端和服务器
3. **Web框架**：学习FastAPI、Flask、Django等现代Web框架，用于开发复杂的Web应用
4. **HTTP/2和HTTP/3**：了解新一代HTTP协议的特性和Python实现
5. **网络安全**：学习HTTPS、TLS、OAuth2等网络安全相关知识
