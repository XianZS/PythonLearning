# Python 3.14.0 http标准库完整学习文档

## 一、http核心概念

### 1.1 什么是http标准库
`http`是Python标准库中**最底层的HTTP协议实现**，提供了对HTTP/1.1和HTTP/2协议的完整支持。它定义了HTTP客户端和服务器的基本接口，处理HTTP消息的解析、构造和传输，是所有Python HTTP相关库（包括`urllib`、`requests`、`aiohttp`等）的基础。

Python 3.14.0对`http`库进行了重大升级，包括：
- 原生支持HTTP/2协议（无需第三方依赖）
- 优化了HTTP/1.1连接池性能
- 增强了TLS 1.3安全性
- 修复了多个长期存在的协议解析漏洞
- 提供了更详细的错误信息和调试能力

### 1.2 http库与urllib、requests的关系
这三个库处于不同的抽象层次，各司其职：

| 库 | 抽象层次 | 特点 | 适用场景 |
|----|----------|------|----------|
| `http` | 底层 | 直接操作HTTP协议细节，API繁琐但灵活 | 需要精细控制HTTP协议、编写HTTP服务器 |
| `urllib` | 中层 | 基于`http`构建，提供URL处理和基本请求功能 | 无第三方依赖环境、简单网络请求 |
| `requests` | 高层 | 基于`urllib3`构建，API简洁友好 | 大多数日常开发场景 |

**重要区别**：`http`库**不会自动处理**重定向、Cookie、编码解码、连接池管理等功能，这些都需要开发者自己实现。这既是它的缺点（使用复杂），也是它的优点（完全可控）。

### 1.3 http库的子模块结构
Python 3.14.0的`http`包包含5个核心子模块：

| 子模块 | 主要功能 |
|--------|----------|
| `http.client` | HTTP客户端实现，用于发送HTTP请求和接收响应 |
| `http.server` | HTTP服务器实现，用于创建自定义HTTP服务器 |
| `http.cookies` | Cookie处理工具，用于解析和构造HTTP Cookie |
| `http.cookiejar` | Cookie持久化管理，与`urllib.request`配合使用 |
| `http.status` | HTTP状态码常量定义，避免硬编码数字 |

### 1.4 HTTP协议基础回顾
HTTP是一个**无状态、基于请求-响应模型**的应用层协议：
1. 客户端向服务器发送请求（包含方法、URL、头、体）
2. 服务器处理请求并返回响应（包含状态码、头、体）
3. 连接关闭（HTTP/1.0）或保持打开（HTTP/1.1 Keep-Alive）

HTTP请求方法：GET、POST、PUT、DELETE、HEAD、OPTIONS、PATCH等
HTTP状态码：1xx（信息）、2xx（成功）、3xx（重定向）、4xx（客户端错误）、5xx（服务器错误）

## 二、http基础部分

### 2.1 HTTP客户端基础（http.client）
`http.client.HTTPConnection`和`http.client.HTTPSConnection`是HTTP客户端的核心类，分别用于HTTP和HTTPS连接。

**示例：发送最简单的GET请求**
```python
import http.client

# 创建HTTPS连接对象（指定主机和端口，HTTPS默认443）
conn = http.client.HTTPSConnection("www.example.com")

# 发送GET请求
conn.request("GET", "/")

# 获取响应对象
response = conn.getresponse()

# 处理响应
print(f"状态码: {response.status} {response.reason}")
print(f"HTTP版本: {response.version}")
print("\n响应头:")
for name, value in response.getheaders():
    print(f"{name}: {value}")

# 读取响应体
body = response.read().decode("utf-8")
print(f"\n响应体前500字符:\n{body[:500]}")

# 关闭连接
conn.close()
```

**示例：发送POST请求**
```python
import http.client
import json

# 创建连接
conn = http.client.HTTPSConnection("httpbin.org")

# 构造请求体
data = json.dumps({
    "name": "Python",
    "version": "3.14.0"
})

# 构造请求头
headers = {
    "Content-Type": "application/json",
    "User-Agent": "Python-http.client/3.14"
}

# 发送POST请求
conn.request("POST", "/post", body=data, headers=headers)

# 获取响应
response = conn.getresponse()
print(f"状态码: {response.status}")
print(f"响应体:\n{response.read().decode('utf-8')}")

conn.close()
```

**HTTPConnection常用方法**：
- `request(method, url, body=None, headers={})`：发送HTTP请求
- `getresponse()`：获取响应对象
- `close()`：关闭连接
- `connect()`：手动建立连接（通常由`request()`自动调用）

**HTTPResponse常用方法**：
- `read([amt])`：读取响应体，返回bytes类型
- `getheader(name, default=None)`：获取指定响应头的值
- `getheaders()`：获取所有响应头，返回列表
- `status`：HTTP状态码
- `reason`：状态码描述
- `version`：HTTP协议版本

### 2.2 HTTP状态码（http.status）
`http.status`模块提供了所有标准HTTP状态码的**命名常量**，使用它们可以让代码更易读、更易维护。

**示例：使用HTTP状态码常量**
```python
import http.status

# 常用状态码
print(f"200 OK: {http.status.HTTP_200_OK}")
print(f"404 Not Found: {http.status.HTTP_404_NOT_FOUND}")
print(f"500 Internal Server Error: {http.status.HTTP_500_INTERNAL_SERVER_ERROR}")
print(f"301 Moved Permanently: {http.status.HTTP_301_MOVED_PERMANENTLY}")

# 状态码分类判断
def is_success(status_code):
    return 200 <= status_code < 300

def is_redirect(status_code):
    return 300 <= status_code < 400

def is_client_error(status_code):
    return 400 <= status_code < 500

def is_server_error(status_code):
    return 500 <= status_code < 600

# 测试
status = http.status.HTTP_200_OK
print(f"\n状态码 {status} 是成功状态: {is_success(status)}")
```

Python 3.14.0新增了多个HTTP/3和最新RFC定义的状态码常量，如`HTTP_103_EARLY_HINTS`、`HTTP_425_TOO_EARLY`等。

### 2.3 HTTP消息与头处理
HTTP请求和响应的头信息由`http.client.HTTPMessage`对象表示，它是一个类似字典的结构，但支持**大小写不敏感**的键访问。

**示例：操作HTTP头**
```python
import http.client

conn = http.client.HTTPSConnection("www.baidu.com")
conn.request("GET", "/")
response = conn.getresponse()

# HTTPMessage对象
headers = response.headers

# 访问头信息（大小写不敏感）
print(f"Content-Type: {headers['Content-Type']}")
print(f"content-type: {headers['content-type']}")  # 同样有效
print(f"Server: {headers.get('Server', '未知')}")

# 遍历所有头
print("\n所有响应头:")
for name, value in headers.items():
    print(f"{name}: {value}")

# 转换为普通字典
headers_dict = dict(headers)
print(f"\n字典形式: {headers_dict.keys()}")

conn.close()
```

### 2.4 简单HTTP服务器（http.server）
`http.server`模块提供了基础的HTTP服务器实现，最常用的是`SimpleHTTPRequestHandler`，它可以快速搭建一个静态文件服务器。

**示例：一行代码启动静态文件服务器**
```bash
# 在命令行执行，将当前目录作为根目录
python -m http.server 8000
```

**示例：自定义简单HTTP服务器**
```python
from http.server import HTTPServer, SimpleHTTPRequestHandler

# 自定义请求处理器
class MyHTTPRequestHandler(SimpleHTTPRequestHandler):
    # 自定义响应头
    def end_headers(self):
        self.send_header("X-Powered-By", "Python 3.14 http.server")
        super().end_headers()
    
    # 自定义日志格式
    def log_message(self, format, *args):
        print(f"[{self.log_date_time_string()}] {self.client_address[0]} {format % args}")

# 启动服务器
if __name__ == "__main__":
    server_address = ("", 8000)  # 监听所有接口，端口8000
    httpd = HTTPServer(server_address, MyHTTPRequestHandler)
    print(f"HTTP服务器已启动，监听端口 8000")
    print(f"访问地址: http://localhost:8000")
    print("按 Ctrl+C 停止服务器")
    
    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        print("\n服务器正在关闭...")
        httpd.shutdown()
        print("服务器已关闭")
```

## 三、http进阶部分

### 3.1 高级HTTP客户端功能

#### 3.1.1 持久连接（Keep-Alive）
HTTP/1.1默认开启持久连接，允许在同一个TCP连接上发送多个HTTP请求，减少连接建立的开销。

**示例：使用持久连接发送多个请求**
```python
import http.client

# 创建连接
conn = http.client.HTTPSConnection("httpbin.org")

# 发送第一个请求
conn.request("GET", "/get?a=1")
response = conn.getresponse()
print(f"第一个请求状态码: {response.status}")
response.read()  # 必须读取完响应体才能发送下一个请求

# 发送第二个请求（复用同一个连接）
conn.request("GET", "/get?b=2")
response = conn.getresponse()
print(f"第二个请求状态码: {response.status}")
response.read()

# 检查连接是否保持打开
print(f"连接是否关闭: {conn.sock is None}")

# 手动关闭连接
conn.close()
print(f"连接是否关闭: {conn.sock is None}")
```

**注意**：必须完全读取前一个响应的内容，才能发送下一个请求，否则会导致连接异常。

#### 3.1.2 流式响应处理
对于大文件或流式数据，不应该一次性读取整个响应体，而应该分块读取，避免内存溢出。

**示例：分块下载大文件**
```python
import http.client

def download_large_file(url, save_path):
    # 解析URL
    from urllib.parse import urlparse
    parsed = urlparse(url)
    
    # 创建连接
    conn = http.client.HTTPSConnection(parsed.netloc)
    conn.request("GET", parsed.path)
    response = conn.getresponse()
    
    if response.status != 200:
        raise Exception(f"下载失败，状态码: {response.status}")
    
    # 获取文件大小
    file_size = int(response.getheader("Content-Length", 0))
    print(f"文件大小: {file_size / 1024 / 1024:.2f} MB")
    
    # 分块下载
    downloaded_size = 0
    chunk_size = 1024 * 1024  # 1MB
    
    with open(save_path, "wb") as f:
        while True:
            chunk = response.read(chunk_size)
            if not chunk:
                break
            
            downloaded_size += len(chunk)
            f.write(chunk)
            
            # 显示进度
            progress = (downloaded_size / file_size) * 100 if file_size > 0 else 0
            print(f"\r下载进度: {downloaded_size / 1024 / 1024:.2f} MB / {file_size / 1024 / 1024:.2f} MB ({progress:.2f}%)", end="")
    
    print("\n下载完成！")
    conn.close()

# 下载Python 3.14.0源码
download_large_file(
    "https://www.python.org/ftp/python/3.14.0/Python-3.14.0.tgz",
    "Python-3.14.0.tgz"
)
```

### 3.2 自定义HTTP服务器
`BaseHTTPRequestHandler`是所有HTTP请求处理器的基类，通过重写它的方法可以实现完全自定义的HTTP服务器。

**示例：实现一个简单的API服务器**
```python
from http.server import HTTPServer, BaseHTTPRequestHandler
import json
import time

class APIRequestHandler(BaseHTTPRequestHandler):
    # 处理GET请求
    def do_GET(self):
        if self.path == "/":
            self.send_response(200)
            self.send_header("Content-Type", "text/html; charset=utf-8")
            self.end_headers()
            self.wfile.write("<h1>欢迎使用Python HTTP API服务器</h1>".encode("utf-8"))
        
        elif self.path == "/api/time":
            # 返回当前时间
            data = {
                "timestamp": time.time(),
                "datetime": time.ctime(),
                "timezone": time.tzname
            }
            self._send_json_response(data)
        
        elif self.path == "/api/headers":
            # 返回请求头信息
            data = dict(self.headers)
            self._send_json_response(data)
        
        else:
            self._send_error(404, "Not Found", "请求的资源不存在")
    
    # 处理POST请求
    def do_POST(self):
        if self.path == "/api/echo":
            # 读取请求体
            content_length = int(self.headers.get("Content-Length", 0))
            body = self.rfile.read(content_length).decode("utf-8")
            
            try:
                data = json.loads(body)
                response = {
                    "status": "success",
                    "received_data": data,
                    "message": "数据已成功接收"
                }
                self._send_json_response(response)
            except json.JSONDecodeError:
                self._send_error(400, "Bad Request", "无效的JSON数据")
        
        else:
            self._send_error(404, "Not Found", "请求的资源不存在")
    
    # 发送JSON响应
    def _send_json_response(self, data, status_code=200):
        self.send_response(status_code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.end_headers()
        self.wfile.write(json.dumps(data, ensure_ascii=False, indent=2).encode("utf-8"))
    
    # 发送错误响应
    def _send_error(self, status_code, reason, message):
        self.send_response(status_code, reason)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.end_headers()
        self.wfile.write(f"""
        <html>
            <head><title>{status_code} {reason}</title></head>
            <body>
                <h1>{status_code} {reason}</h1>
                <p>{message}</p>
            </body>
        </html>
        """.encode("utf-8"))
    
    # 自定义日志格式
    def log_message(self, format, *args):
        print(f"[{self.log_date_time_string()}] {self.client_address[0]} {self.command} {self.path} - {format % args}")

if __name__ == "__main__":
    server_address = ("", 8001)
    httpd = HTTPServer(server_address, APIRequestHandler)
    print(f"API服务器已启动，监听端口 8001")
    print(f"测试地址:")
    print(f"  http://localhost:8001/")
    print(f"  http://localhost:8001/api/time")
    print(f"  http://localhost:8001/api/headers")
    print("按 Ctrl+C 停止服务器")
    
    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        print("\n服务器正在关闭...")
        httpd.shutdown()
        print("服务器已关闭")
```

### 3.3 Cookies处理（http.cookies）
`http.cookies`模块提供了`SimpleCookie`类，用于解析和构造HTTP Cookie。

**示例：在客户端和服务器之间传递Cookie**
```python
# 服务器端：设置Cookie
from http.server import HTTPServer, BaseHTTPRequestHandler
from http.cookies import SimpleCookie

class CookieHandler(BaseHTTPRequestHandler):
    def do_GET(self):
        # 解析客户端发送的Cookie
        cookie = SimpleCookie(self.headers.get("Cookie", ""))
        
        if "visit_count" in cookie:
            # 已有Cookie，增加访问次数
            visit_count = int(cookie["visit_count"].value) + 1
        else:
            # 没有Cookie，初始化访问次数
            visit_count = 1
        
        # 创建新的Cookie
        cookie = SimpleCookie()
        cookie["visit_count"] = visit_count
        cookie["visit_count"]["expires"] = 3600 * 24 * 7  # 7天过期
        cookie["visit_count"]["path"] = "/"
        
        # 发送响应
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        # 将Cookie添加到响应头
        for morsel in cookie.values():
            self.send_header("Set-Cookie", morsel.OutputString())
        self.end_headers()
        
        self.wfile.write(f"""
        <html>
            <body>
                <h1>欢迎访问</h1>
                <p>这是你第 {visit_count} 次访问本页面</p>
            </body>
        </html>
        """.encode("utf-8"))

if __name__ == "__main__":
    server_address = ("", 8002)
    httpd = HTTPServer(server_address, CookieHandler)
    print(f"Cookie测试服务器已启动，访问 http://localhost:8002")
    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        httpd.shutdown()
```

**客户端使用Cookie示例**：
```python
import http.client
from http.cookies import SimpleCookie

# 创建连接
conn = http.client.HTTPSConnection("localhost", 8002)

# 第一次请求（没有Cookie）
conn.request("GET", "/")
response = conn.getresponse()
print(f"第一次请求状态码: {response.status}")

# 解析服务器设置的Cookie
cookie = SimpleCookie(response.getheader("Set-Cookie", ""))
print(f"收到的Cookie: {cookie}")

# 第二次请求（带上Cookie）
headers = {"Cookie": cookie.output(header="", sep=";")}
conn.request("GET", "/", headers=headers)
response = conn.getresponse()
print(f"第二次请求状态码: {response.status}")
print(f"响应体:\n{response.read().decode('utf-8')}")

conn.close()
```

### 3.4 HTTP/2支持（Python 3.14新增）
Python 3.14.0首次在标准库中**原生支持HTTP/2协议**，无需安装任何第三方依赖。HTTP/2相比HTTP/1.1具有多路复用、头部压缩、服务器推送等优势。

**示例：发送HTTP/2请求**
```python
import http.client

# 创建HTTP/2连接
conn = http.client.HTTP2Connection("http2.github.io")

# 发送GET请求
conn.request("GET", "/")

# 获取响应
response = conn.getresponse()
print(f"状态码: {response.status} {response.reason}")
print(f"HTTP版本: {response.version}")  # 输出: 20
print("\n响应头:")
for name, value in response.getheaders():
    print(f"{name}: {value}")

# 读取响应体
body = response.read().decode("utf-8")
print(f"\n响应体前500字符:\n{body[:500]}")

conn.close()
```

**注意**：HTTP/2只支持HTTPS连接，且要求服务器支持ALPN扩展。Python 3.14.0的`HTTP2Connection`会自动处理ALPN协商和HTTP/2帧的解析。

### 3.5 线程池HTTP服务器
默认的`HTTPServer`是单线程的，一次只能处理一个请求。`ThreadingHTTPServer`使用线程池处理请求，可以同时处理多个客户端连接。

**示例：线程池HTTP服务器**
```python
from http.server import HTTPServer, ThreadingHTTPServer, SimpleHTTPRequestHandler
import time

class SlowRequestHandler(SimpleHTTPRequestHandler):
    def do_GET(self):
        # 模拟耗时操作
        time.sleep(2)
        super().do_GET()

if __name__ == "__main__":
    # 单线程服务器（一次只能处理一个请求）
    # httpd = HTTPServer(("", 8003), SlowRequestHandler)
    
    # 线程池服务器（可以同时处理多个请求）
    httpd = ThreadingHTTPServer(("", 8003), SlowRequestHandler)
    
    print(f"线程池HTTP服务器已启动，监听端口 8003")
    print("同时打开多个浏览器标签访问，观察响应时间")
    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        httpd.shutdown()
```

## 四、实战案例：轻量级HTTP文件服务器带上传功能

### 4.1 项目概述
我们将使用`http.server`模块实现一个功能完整的轻量级文件服务器，支持：
- 文件浏览和下载
- 文件上传（支持多文件）
- 目录创建
- 文件删除
- 响应式Web界面
- 安全限制（防止路径遍历攻击）

### 4.2 完整实现代码
```python
from http.server import HTTPServer, BaseHTTPRequestHandler
import os
import urllib.parse
import html
import mimetypes

class FileServerHandler(BaseHTTPRequestHandler):
    # 服务器根目录
    ROOT_DIR = os.path.abspath("./file_server_root")
    # 最大上传文件大小（100MB）
    MAX_UPLOAD_SIZE = 100 * 1024 * 1024
    
    def __init__(self, *args, **kwargs):
        # 确保根目录存在
        os.makedirs(self.ROOT_DIR, exist_ok=True)
        super().__init__(*args, **kwargs)
    
    def do_GET(self):
        # 解析请求路径
        parsed_path = urllib.parse.urlparse(self.path)
        path = parsed_path.path
        
        # 安全检查：防止路径遍历攻击
        real_path = os.path.abspath(os.path.join(self.ROOT_DIR, path.lstrip("/")))
        if not real_path.startswith(self.ROOT_DIR):
            self._send_error(403, "Forbidden", "禁止访问")
            return
        
        # 处理文件下载
        if os.path.isfile(real_path):
            self._serve_file(real_path)
            return
        
        # 处理目录浏览
        if os.path.isdir(real_path):
            self._list_directory(real_path, path)
            return
        
        # 路径不存在
        self._send_error(404, "Not Found", "文件或目录不存在")
    
    def do_POST(self):
        # 解析请求路径
        parsed_path = urllib.parse.urlparse(self.path)
        path = parsed_path.path
        
        # 安全检查
        real_path = os.path.abspath(os.path.join(self.ROOT_DIR, path.lstrip("/")))
        if not real_path.startswith(self.ROOT_DIR):
            self._send_error(403, "Forbidden", "禁止访问")
            return
        
        # 处理文件上传
        if path.endswith("/upload"):
            self._handle_upload(real_path)
            return
        
        # 处理目录创建
        if path.endswith("/mkdir"):
            self._handle_mkdir(real_path)
            return
        
        # 处理文件删除
        if path.endswith("/delete"):
            self._handle_delete(real_path)
            return
        
        self._send_error(404, "Not Found", "请求的资源不存在")
    
    def _serve_file(self, file_path):
        """提供文件下载"""
        # 获取文件MIME类型
        mime_type, _ = mimetypes.guess_type(file_path)
        if mime_type is None:
            mime_type = "application/octet-stream"
        
        # 发送响应头
        self.send_response(200)
        self.send_header("Content-Type", mime_type)
        self.send_header("Content-Length", str(os.path.getsize(file_path)))
        # 添加下载头
        filename = os.path.basename(file_path)
        self.send_header("Content-Disposition", f"attachment; filename*=UTF-8''{urllib.parse.quote(filename)}")
        self.end_headers()
        
        # 发送文件内容
        with open(file_path, "rb") as f:
            self.wfile.write(f.read())

    def _handle_upload(self, dir_path):
        """处理文件上传"""
        # 检查内容长度
        content_length = int(self.headers.get("Content-Length", 0))
        if content_length > self.MAX_UPLOAD_SIZE:
            self._send_error(413, "Payload Too Large", "文件大小超过限制")
            return
        
        # 读取请求体
        content_type = self.headers.get("Content-Type", "")
        if not content_type.startswith("multipart/form-data"):
            self._send_error(400, "Bad Request", "无效的请求格式")
            return
        
        # 解析multipart/form-data
        boundary = content_type.split("boundary=")[1].encode("utf-8")
        body = self.rfile.read(content_length)
        
        # 分割部分
        parts = body.split(b"--" + boundary)
        for part in parts:
            if not part or part == b"--\r\n":
                continue
            
            # 解析头部和内容
            header_part, content_part = part.split(b"\r\n\r\n", 1)
            headers = header_part.decode("utf-8")
            
            # 提取文件名
            if 'filename="' in headers:
                filename = headers.split('filename="')[1].split('"')[0]
                if not filename:
                    continue
                
                # 安全检查：防止路径遍历
                filename = os.path.basename(filename)
                file_path = os.path.join(dir_path, filename)
                
                # 保存文件
                with open(file_path, "wb") as f:
                    f.write(content_part.rstrip(b"\r\n"))
        
        # 重定向回目录页面
        self.send_response(303)
        self.send_header("Location", self.path.rsplit("/", 1)[0])
        self.end_headers()
    
    def _handle_mkdir(self, dir_path):
        """处理目录创建"""
        content_length = int(self.headers.get("Content-Length", 0))
        body = self.rfile.read(content_length).decode("utf-8")
        params = urllib.parse.parse_qs(body)
        
        if "dirname" not in params:
            self._send_error(400, "Bad Request", "缺少目录名参数")
            return
        
        dirname = params["dirname"][0]
        # 安全检查：防止路径遍历
        dirname = os.path.basename(dirname)
        new_dir_path = os.path.join(dir_path, dirname)
        
        try:
            os.makedirs(new_dir_path, exist_ok=True)
        except Exception as e:
            self._send_error(500, "Internal Server Error", f"创建目录失败: {str(e)}")
            return
        
        # 重定向回目录页面
        self.send_response(303)
        self.send_header("Location", self.path.rsplit("/", 1)[0])
        self.end_headers()
    
    def _handle_delete(self, path):
        """处理文件/目录删除"""
        # 获取要删除的路径
        delete_path = path.rsplit("/", 1)[0]
        real_delete_path = os.path.abspath(os.path.join(self.ROOT_DIR, delete_path.lstrip("/")))
        
        # 安全检查
        if not real_delete_path.startswith(self.ROOT_DIR) or real_delete_path == self.ROOT_DIR:
            self._send_error(403, "Forbidden", "禁止删除")
            return
        
        try:
            if os.path.isdir(real_delete_path):
                # 删除空目录
                os.rmdir(real_delete_path)
            else:
                # 删除文件
                os.remove(real_delete_path)
        except Exception as e:
            self._send_error(500, "Internal Server Error", f"删除失败: {str(e)}")
            return
        
        # 重定向回上级目录
        parent_path = os.path.dirname(delete_path.rstrip("/"))
        self.send_response(303)
        self.send_header("Location", parent_path)
        self.end_headers()
    
    def _send_error(self, status_code, reason, message):
        """发送错误响应"""
        self.send_response(status_code, reason)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.end_headers()
        self.wfile.write(f"""
        <html>
            <head><title>{status_code} {reason}</title></head>
            <body>
                <h1>{status_code} {reason}</h1>
                <p>{message}</p>
                <p><a href="/">返回首页</a></p>
            </body>
        </html>
        """.encode("utf-8"))
    
    def log_message(self, format, *args):
        print(f"[{self.log_date_time_string()}] {self.client_address[0]} {self.command} {self.path} - {format % args}")

if __name__ == "__main__":
```

## 五、总结与扩展学习

### 5.1 核心知识点回顾
- `http`库是Python标准库中最底层的HTTP协议实现，是所有HTTP相关库的基础
- `http.client`提供了HTTP/1.1和HTTP/2客户端实现，支持持久连接和流式处理
- `http.server`提供了HTTP服务器实现，可以快速搭建自定义服务器
- `http.cookies`提供了Cookie解析和构造功能
- `http.status`提供了标准HTTP状态码常量，避免硬编码
- Python 3.14.0新增了原生HTTP/2支持，大幅提升了网络性能

### 5.2 Python 3.14.0 http库的新特性
1. **原生HTTP/2支持**：无需第三方依赖即可使用HTTP/2协议
2. **TLS 1.3增强**：默认启用TLS 1.3，提供更好的安全性和性能
3. **连接池优化**：改进了HTTP/1.1连接池的管理，减少了连接泄漏
4. **错误信息改进**：提供了更详细的协议解析错误信息
5. **安全修复**：修复了多个HTTP请求走私和头注入漏洞
