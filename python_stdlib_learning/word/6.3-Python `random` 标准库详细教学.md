# Python `random` 标准库详细教学文档

## 一、基础概念

`random` 是 Python 内置的**伪随机数生成标准库**，基于业界主流的 ** 梅森旋转算法（MT19937）** 实现，提供了全场景的随机数生成、序列随机操作、概率分布模拟等功能，是 Python 中处理随机需求的核心工具。

### 核心说明

1. **伪随机数本质**：`random` 生成的是确定性的伪随机序列 —— 序列由初始种子（seed）唯一决定，相同种子会生成完全一致的随机序列，并非密码学安全的真随机数。

2. **适用场景**：数据模拟、随机抽样、游戏开发、教学演示、统计实验、非加密级别的随机需求。

3. **安全红线**：**禁止用于密码学、加密、高安全级别的验证码 / 抽奖 / 密钥生成等场景**，此类场景请使用 Python 内置的`secrets`库。

4. **版本兼容**：文档所有函数均标注最低 Python 版本要求，适配 Python 3.6+ 主流版本，同步覆盖 Python 3.12 最新稳定版的新增特性。

### 导入方式

```python
import random  # 推荐：全局导入，避免命名冲突
# 或
from random import randint, choice, seed  # 按需导入高频函数
```

## 二、常见基础用法

### 1. 基础随机数生成（浮点数 + 整数）

这是`random`库最核心、最常用的基础功能，覆盖日常绝大多数随机数需求。

|函数|核心说明|版本要求|
|---|---|---|
|`random.random()`|生成 `[0.0, 1.0)` 范围内的均匀分布浮点数，无输入参数|全版本|
|`random.uniform(a, b)`|生成 `[a, b]` 闭区间内的均匀分布浮点数，a、b 无大小顺序要求|全版本|
|`random.randint(a, b)`|生成 `[a, b]` 闭区间内的随机整数，要求 `a ≤ b`|全版本|
|`random.randrange(stop)`<br>`random.randrange(start, stop[, step])`|生成 `[start, stop)` 左闭右开区间内的随机整数，完全匹配`range()`的规则，支持步长设置|全版本|

**示例代码**：

```python
# 1. [0.0, 1.0) 随机浮点数
print("random() 结果:", random.random())
# 输出示例: random() 结果: 0.3744478345132635

# 2. 自定义区间随机浮点数
print("uniform(1, 10) 结果:", random.uniform(1, 10))  # [1,10]区间
print("uniform(10, 1) 结果:", random.uniform(10, 1))  # 支持倒序参数，结果一致
# 输出示例: uniform(1, 10) 结果: 7.21854328971385

# 3. 闭区间随机整数
print("randint(1, 10) 结果:", random.randint(1, 10))  # 包含1和10
# 输出示例: randint(1, 10) 结果: 5

# 4. 左闭右开区间随机整数（支持步长）
print("randrange(10) 结果:", random.randrange(10))  # [0,9]区间
print("randrange(1, 10) 结果:", random.randrange(1, 10))  # [1,9]区间
print("randrange(0, 10, 2) 结果:", random.randrange(0, 10, 2))  # 0-9的随机偶数
# 输出示例: randrange(0, 10, 2) 结果: 4
```

> 新手避坑：`randint(a,b)` 是**闭区间**（包含 b），`randrange(start,stop)` 是**左闭右开**（不包含 stop），二者区间规则完全不同，切勿混用。

### 2. 序列的基础随机操作

针对列表、元组、字符串等序列类型的随机操作，是抽奖、抽样、随机排序的核心功能。

|函数|核心说明|版本要求|
|---|---|---|
|`random.choice(seq)`|从非空序列中随机返回 1 个元素，序列为空会抛出`IndexError`|全版本|
|`random.choices(seq, weights=None, cum_weights=None, k=1)`|从序列中**有放回**地随机抽取 k 个元素，支持自定义权重，返回长度为 k 的列表|Python 3.6+|
|`random.sample(population, k, counts=None)`|从序列中**无放回**地随机抽取 k 个不重复元素，k 不可超过序列总长度，`counts`支持设置元素重复次数|Python 3.6+，counts 参数 3.9 + 新增|
|`random.shuffle(x, random=None)`|**原地打乱**可变序列 x 的顺序（如列表），无返回值；不可变序列（元组、字符串）无法使用|全版本|

**示例代码**：

```python
# 测试用序列
user_list = ["张三", "李四", "王五", "赵六", "钱七"]
prize_list = ["一等奖", "二等奖", "三等奖", "谢谢参与"]

# 1. 随机选单个元素
print("随机选中用户:", random.choice(user_list))
# 输出示例: 随机选中用户: 李四

# 2. 有放回加权抽样（适合带概率的抽奖）
# 权重：一等奖10%、二等奖20%、三等奖30%、谢谢参与40%
result = random.choices(prize_list, weights=[1, 2, 3, 4], k=5)
print("5次抽奖结果:", result)
# 输出示例: 5次抽奖结果: ['谢谢参与', '二等奖', '三等奖', '谢谢参与', '一等奖']

# 3. 无放回抽样（适合不重复中奖）
win_users = random.sample(user_list, k=3)  # 从5人中抽3人，不重复
print("不重复中奖用户:", win_users)
# 输出示例: 不重复中奖用户: ['王五', '张三', '钱七']

# 4. 原地打乱序列
print("打乱前列表:", user_list)
random.shuffle(user_list)  # 原地修改，无返回值
print("打乱后列表:", user_list)
# 输出示例: 打乱后列表: ['赵六', '钱七', '李四', '张三', '王五']
```

> 新手避坑：`random.shuffle()` 是**原地修改**，返回值为`None`，切勿写成 `new_list = random.shuffle(user_list)`，否则会得到`None`。

### 3. 随机种子与结果复现

随机种子是控制伪随机序列的核心，设置固定种子后，每次运行都会生成完全一致的随机序列，适用于调试、实验复现、公平公开的抽奖场景。

|函数|核心说明|版本要求|
|---|---|---|
|`random.seed(a=None, version=2)`|设置随机数生成器的种子，`a`支持整数、字符串、字节等类型，默认`None`时使用系统时间作为种子|全版本，version 参数 3.2 + 新增|

**示例代码**：

```python
# 设置固定种子
random.seed(123456)

# 第一次生成随机数
print("第一次randint:", random.randint(1, 100))
print("第一次random:", random.random())
# 固定输出: 第一次randint: 54，第一次random: 0.959135039878719

# 重置相同种子
random.seed(123456)

# 第二次生成随机数，和第一次完全一致
print("第二次randint:", random.randint(1, 100))
print("第二次random:", random.random())
# 固定输出: 第二次randint: 54，第二次random: 0.959135039878719
```

## 三、常见进阶用法

### 1. 常用概率分布随机数生成

针对统计模拟、数据分析、机器学习、金融建模等专业场景，`random`库提供了主流概率分布的随机数生成函数，覆盖绝大多数科研和工程需求。

|函数|核心说明|适用场景|版本要求|
|---|---|---|---|
|`random.gauss(mu=0.0, sigma=1.0)`|正态（高斯）分布，`mu`为均值，`sigma`为标准差|学生成绩、身高体重、测量误差等自然现象模拟|全版本|
|`random.normalvariate(mu, sigma)`|正态分布，功能与`gauss`一致，多线程场景下更安全|多线程环境下的正态分布模拟|全版本|
|`random.expovariate(lambd)`|指数分布，`lambd`为速率参数（1 / 均值），生成非负数|顾客到达间隔、设备故障时间、等待时长模拟|全版本|
|`random.poissonvariate(mu)`|泊松分布，`mu`为单位时间内事件的平均发生次数|单位时间内进店人数、网站访问量、事故发生次数模拟|Python 3.11+|
|`random.betavariate(alpha, beta)`|贝塔分布，取值范围固定为`[0, 1]`|概率值建模、A/B 测试转化率模拟、贝叶斯统计|全版本|
|`random.triangular(low=0.0, high=1.0, mode=None)`|三角分布，`low/high`为上下限，`mode`为峰值|有明确上下限和最可能值的场景，如项目工期、成本估算|全版本|
|`random.lognormvariate(mu, sigma)`|对数正态分布，取对数后符合正态分布|收入分布、房价分布、股票收益率模拟|全版本|

**示例代码**：

```python
# 1. 正态分布：模拟班级学生成绩（均值80，标准差10）
score = random.gauss(mu=80, sigma=10)
print(f"学生成绩: {score:.1f}分")
# 输出示例: 学生成绩: 78.5分

# 2. 指数分布：模拟顾客到达间隔（平均5分钟来1个顾客）
interval = random.expovariate(lambd=1/5)
print(f"顾客到达间隔: {interval:.1f}分钟")
# 输出示例: 顾客到达间隔: 3.2分钟

# 3. 泊松分布：模拟每分钟进店人数（平均每分钟3人）
customer_count = random.poissonvariate(mu=3)
print(f"每分钟进店人数: {customer_count}人")
# 输出示例: 每分钟进店人数: 4人

# 4. 贝塔分布：模拟商品转化率（alpha=2, beta=8，均值20%）
conversion_rate = random.betavariate(alpha=2, beta=8)
print(f"商品转化率: {conversion_rate:.2%}")
# 输出示例: 商品转化率: 18.35%
```

### 2. 高级随机状态管理

相比`seed()`只能重置初始状态，`getstate()`和`setstate()`可以保存和恢复随机数生成器的任意中间状态，实现更精细的随机序列控制。

|函数|核心说明|版本要求|
|---|---|---|
|`random.getstate()`|返回当前随机数生成器的内部状态，为一个元组对象|全版本|
|`random.setstate(state)`|将生成器状态恢复到`getstate()`保存的状态|全版本|

**示例代码**：

```python
# 生成3个随机数，记录中间状态
print("第一组随机数:")
print(random.randint(1, 100))
# 保存当前状态
state_backup = random.getstate()
print(random.randint(1, 100))
print(random.randint(1, 100))
# 输出示例: 第一组随机数: 34、67、89

# 恢复到保存的状态，后续生成的随机数会完全重复
print("n恢复状态后生成的随机数:")
random.setstate(state_backup)
print(random.randint(1, 100))
print(random.randint(1, 100))
# 固定输出: 恢复状态后生成的随机数: 67、89（和保存状态后的序列完全一致）
```

#### （2）多线程场景的随机数安全

`random`库的全局实例**不是线程安全的**，多线程同时调用时可能出现重复随机数、序列混乱的问题。解决方案：为每个线程创建独立的`random.Random()`实例。

**示例代码**：

```python
import threading

# 线程函数：每个线程使用独立的随机生成器
def thread_random_task(thread_name):
    # 为当前线程创建独立的Random实例，设置独立种子
    thread_rng = random.Random(thread_name)
    print(f"{thread_name} 生成的随机数: {thread_rng.randint(1, 100)}")

# 启动3个线程
for i in range(3):
    t = threading.Thread(target=thread_random_task, args=(f"线程{i+1}",))
    t.start()
```

#### （3）不可变序列的打乱

`random.shuffle()`仅支持可变序列，如需打乱元组、字符串等不可变序列，可通过`random.sample()`实现。

**示例代码**：

```python
# 打乱字符串
str_data = "abcdefg"
shuffled_str = ''.join(random.sample(str_data, k=len(str_data)))
print("打乱后的字符串:", shuffled_str)
# 输出示例: 打乱后的字符串: dgbacef

# 打乱元组
tuple_data = (1, 2, 3, 4, 5)
shuffled_tuple = tuple(random.sample(tuple_data, k=len(tuple_data)))
print("打乱后的元组:", shuffled_tuple)
# 输出示例: 打乱后的元组: (3, 5, 1, 2, 4)
```

## 四、实战案例：多功能年会抽奖系统

本案例综合运用`random`库的核心功能，实现一个贴近真实业务场景的年会抽奖系统，覆盖 B 站观众高频需求的抽奖场景，所有功能可直接运行复用。

### 功能需求

1. 基础抽奖：从员工名单中无放回抽取一、二、三等奖，保证不重复中奖

2. 加权锦鲤抽奖：设置不同部门的中奖权重，实现差异化中奖概率

3. 公平可复现抽奖：支持设置固定种子，抽奖过程全程可复现，避免黑箱

4. 颁奖顺序打乱：随机打乱中奖名单的颁奖顺序

### 完整代码

```python
import random

class AnnualLotterySystem:
    def __init__(self, staff_list, seed=None):
        """
        初始化抽奖系统
        :param staff_list: 参与抽奖的员工列表，格式为 [{"name": "姓名", "department": "部门"}, ...]
        :param seed: 随机种子，设置后可复现抽奖结果，默认None
        """
        self.staff_list = staff_list
        # 设置种子，保证抽奖可复现
        if seed is not None:
            random.seed(seed)
        # 记录已中奖员工，避免重复中奖
        self.won_staff = set()

    def base_lottery(self, prize_config):
        """
        基础无放回抽奖
        :param prize_config: 奖项配置，格式为 {"一等奖": 1, "二等奖": 3, "三等奖": 5}
        :return: 抽奖结果字典
        """
        lottery_result = {}
        # 按奖项等级从高到低抽取
        for prize_name, count in sorted(prize_config.items(), key=lambda x: x[1]):
            # 过滤未中奖的员工
            available_staff = [staff for staff in self.staff_list if staff["name"] not in self.won_staff]
            if len(available_staff) < count:
                raise ValueError(f"剩余参与人数不足，无法抽取{count}个{prize_name}")
            
            # 无放回抽取中奖员工
            win_staff = random.sample(available_staff, k=count)
            lottery_result[prize_name] = win_staff
            # 记录已中奖员工
            for staff in win_staff:
                self.won_staff.add(staff["name"])
        
        return lottery_result

    def weighted_lottery(self, prize_name, weight_config, count=1):
        """
        带权重的锦鲤抽奖
        :param prize_name: 奖项名称
        :param weight_config: 部门权重配置，格式为 {"技术部": 1, "市场部": 2, "行政部": 3}
        :param count: 中奖人数
        :return: 中奖员工列表
        """
        # 为每个员工设置对应部门的权重
        staff_weights = []
        available_staff = [staff for staff in self.staff_list if staff["name"] not in self.won_staff]
        for staff in available_staff:
            staff_weights.append(weight_config.get(staff["department"], 1))
        
        # 有放回加权抽取，去重保证不重复中奖
        win_staff = []
        while len(win_staff) < count:
            selected = random.choices(available_staff, weights=staff_weights, k=1)[0]
            if selected not in win_staff:
                win_staff.append(selected)
        
        # 记录已中奖员工
        for staff in win_staff:
            self.won_staff.add(staff["name"])
        
        return {prize_name: win_staff}

    def shuffle_award_order(self, lottery_result):
        """
        打乱中奖名单的颁奖顺序
        :param lottery_result: 抽奖结果字典
        :return: 打乱后的颁奖顺序列表
        """
        # 提取所有中奖员工
        all_winner = []
        for prize_name, staff_list in lottery_result.items():
            for staff in staff_list:
                all_winner.append({"prize": prize_name, "name": staff["name"], "department": staff["department"]})
        
        # 打乱颁奖顺序
        random.shuffle(all_winner)
        return all_winner


# ---------------------- 测试与运行 ----------------------
if __name__ == "__main__":
    # 1. 准备参与抽奖的员工数据
    staff_data = [
        {"name": "张三", "department": "技术部"},
        {"name": "李四", "department": "技术部"},
        {"name": "王五", "department": "市场部"},
        {"name": "赵六", "department": "市场部"},
        {"name": "钱七", "department": "行政部"},
        {"name": "孙八", "department": "行政部"},
        {"name": "周九", "department": "财务部"},
        {"name": "吴十", "department": "财务部"},
    ]

    # 2. 初始化抽奖系统，设置固定种子保证可复现（种子可自定义）
    lottery_system = AnnualLotterySystem(staff_data, seed=20240601)

    # 3. 基础奖项抽奖
    prize_setting = {
        "一等奖": 1,
        "二等奖": 2,
        "三等奖": 3
    }
    base_result = lottery_system.base_lottery(prize_setting)
    print("="*50)
    print("【基础奖项抽奖结果】")
    for prize, winners in base_result.items():
        print(f"{prize}: {[f'{w["name"]}({w["department"]})' for w in winners]}")

    # 4. 加权锦鲤大奖抽奖（行政部权重最高，技术部最低）
    weight_setting = {
        "技术部": 1,
        "市场部": 2,
        "财务部": 3,
        "行政部": 4
    }
    koi_result = lottery_system.weighted_lottery("锦鲤大奖", weight_setting, count=1)
    print("n【锦鲤大奖抽奖结果】")
    for prize, winners in koi_result.items():
        print(f"{prize}: {[f'{w["name"]}({w["department"]})' for w in winners]}")

    # 5. 打乱颁奖顺序
    # 合并所有抽奖结果
    all_result = {**base_result, **koi_result}
    award_order = lottery_system.shuffle_award_order(all_result)
    print("n【打乱后的颁奖顺序】")
    for idx, winner in enumerate(award_order, 1):
        print(f"第{idx}位颁奖: {winner['name']} - {winner['prize']}({winner['department']})")
    print("="*50)
```

## 五、总结与避坑指南

### 核心总结

- `random` 是 Python 内置的全场景伪随机数生成库，基于梅森旋转算法，覆盖从基础随机数到专业概率分布的全功能需求；

- 核心优势：原生内置无需安装、API 简单易用、功能全面、适配绝大多数非加密随机场景；

- 核心局限：伪随机特性决定其不适合密码学、高安全级别场景，此类场景必须使用`secrets`库。

### 新手高频避坑指南

1. **区间规则混淆**：`randint(a,b)`是闭区间（包含 b），`randrange(start,stop)`是左闭右开（不包含 stop），切勿混用；

2. **shuffle 返回值误用**：`shuffle()`是原地修改，返回值为`None`，不可赋值给新变量；

3. **无放回抽样超限**：`sample()`的 k 值不可超过总体长度，无放回抽样无法抽取超过总数的元素；

4. **安全场景误用**：绝对不要用`random`生成验证码、密钥、高安全抽奖的随机数，必须用`secrets`库；

5. **多线程安全问题**：多线程场景不要使用全局`random`实例，需为每个线程创建独立的`Random()`实例；

6. **种子设置时机**：种子仅需设置一次，多次重复设置会重置随机序列，导致随机数重复。
