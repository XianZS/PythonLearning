# 2_Python 运算符核心类型及使用规则详解

你想系统了解Python中常见的运算符类型，以及对应的表达式写法和使用规则，这是编写条件判断、数值计算、逻辑处理等代码的核心基础。

Python的运算符可按功能分为6大类，每类都有对应的表达式（由运算符+操作数组成的可计算式子），下面结合示例详细说明：

### 一、算术运算符（处理数值计算）

用于整数、浮点数的加减乘除等运算，是最基础的运算符。

|运算符|名称|表达式示例|说明|结果|
|---|---|---|---|---|
|`+`|加法|`10 + 5`|两数相加|15|
|`-`|减法|`10 - 5`|两数相减|5|
|`*`|乘法|`10 * 5`|两数相乘|50|
|`/`|除法|`10 / 5`|结果为浮点数|2.0|
|`//`|整除|`10 // 3`|向下取整（忽略小数部分）|3|
|`%`|取模（余数）|`10 % 3`|返回除法余数|1|
|`**`|幂运算|`2 ** 3`|2的3次方|8|
**注意**：浮点数运算存在精度问题（如`0.1 + 0.2 = 0.30000000000000004`），需精确计算可使用`decimal`模块。

### 二、赋值运算符（给变量赋值/更新值）

将右边表达式的结果赋给左边变量，基础是`=`，其余是“运算+赋值”的简写。

|运算符|表达式示例|等价写法|说明|
|---|---|---|---|
|`=`|`x = 10`|-|直接赋值|
|`+=`|`x += 5`|`x = x + 5`|加后赋值|
|`-=`|`x -= 5`|`x = x - 5`|减后赋值|
|`*=`|`x *= 5`|`x = x * 5`|乘后赋值|
|`/=`|`x /= 5`|`x = x / 5`|除后赋值|
|`//=`|`x //= 3`|`x = x // 3`|整除后赋值|
|`%=`|`x %= 3`|`x = x % 3`|取模后赋值|
|`**=`|`x **= 3`|`x = x ** 3`|幂运算后赋值|

### 三、比较运算符（判断条件真假）

用于比较两个值的关系，**返回布尔值（True/False）**，是if/while语句的核心。

|运算符|名称|表达式示例|结果|
|---|---|---|---|
|`==`|等于|`10 == 10`|True|
|`!=`|不等于|`10 != 5`|True|
|`>`|大于|`10 > 5`|True|
|`<`|小于|`10 < 5`|False|
|`>=`|大于等于|`10 >= 10`|True|
|`<=`|小于等于|`10 <= 5`|False|
**关键提醒**：`==`是“判断相等”，`=`是“赋值”，新手极易混淆！

### 四、逻辑运算符（组合多个条件）

用于将多个布尔值（或比较表达式）组合判断，返回布尔值，支持“短路求值”（只要能确定结果就停止计算）。

|运算符|名称|表达式示例|说明|结果|
|---|---|---|---|---|
|`and`|逻辑与|`(10 > 5) and (5 < 3)`|两边都为True，结果才为True|False|
|`or`|逻辑或|`(10 > 5) or (5 < 3)`|只要一边为True，结果就为True|True|
|`not`|逻辑非|`not (10 > 5)`|取反（True变False，False变True）|False|

### 五、成员运算符（判断元素是否在容器中）

专门用于列表、字符串、字典、集合等容器类型，返回布尔值。

|运算符|名称|表达式示例|说明|结果|
|---|---|---|---|---|
|`in`|存在|`5 in [1, 2, 5]`|判断元素是否在容器中|True|
|`not in`|不存在|`6 not in [1,2,5]`|判断元素是否不在容器中|True|
**注意**：字典的`in`仅判断**键**，不判断值（如`"name" in {"name":"小明"}` → True）。

### 六、身份运算符（判断对象是否为同一个）

判断两个变量是否指向**内存中的同一个对象**（区别于`==`判断“值相等”）。

|运算符|名称|表达式示例|说明|结果|
|---|---|---|---|---|
|`is`|是同一个对象|`a = 10; b = 10; a is b`|变量指向同一内存地址|True|
|`is not`|不是同一个对象|`a = [1]; b = [1]; a is b`|列表是新对象，即使值相同，地址也不同|False|

### 综合示例代码

下面的代码整合了所有常见运算符，你可以直接运行查看效果：

```Python

# 1. 算术运算符
print("算术运算：")
print(10 + 5)    # 15
print(10 // 3)   # 3
print(10 % 3)    # 1
print(2 ** 3)    # 8

# 2. 赋值运算符
print("\n赋值运算：")
x = 10
x += 5
print(x)  # 15
x *= 2
print(x)  # 30

# 3. 比较运算符
print("\n比较运算：")
print(10 == 10)  # True
print(10 != 5)   # True

# 4. 逻辑运算符
print("\n逻辑运算：")
print((10 > 5) and (5 < 3))  # False
print((10 > 5) or (5 < 3))   # True
print(not (10 > 5))          # False

# 5. 成员运算符
print("\n成员运算：")
print(5 in [1, 2, 5])        # True
print("a" in "abc")          # True
print("name" in {"name":"小明"})  # True

# 6. 身份运算符
print("\n身份运算：")
a = 10
b = 10
print(a is b)    # True（小整数池优化）
c = [1]
d = [1]
print(c is d)    # False（列表是新对象）
print(c == d)    # True（值相等）
```

### 总结

1. Python运算符核心分为6大类，**算术、赋值、比较、逻辑**是日常使用最频繁的；

2. `==`判断“值相等”，`is`判断“内存地址相等”，二者不可混用；

3. 表达式由“运算符+操作数”组成，会返回一个具体值（数值/布尔值等），是代码逻辑的基础单元。
