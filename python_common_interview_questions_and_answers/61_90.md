## 61. Python 中 append、insert 和 extend 有什么区别?
三者都是列表添加元素的方法，差异在添加方式与参数：
- `append(obj)`：在列表末尾追加**一个整体元素**，参数可以是任意类型，整体作为单个元素加入。
  ```python
  lst = [1,2]
  lst.append([3,4])
  print(lst)  # [1, 2, [3, 4]]
  ```
- `insert(index, obj)`：在指定索引位置插入**一个整体元素**，第一个参数为索引，第二个为待插入元素。
  ```python
  lst = [1,2]
  lst.insert(1, 'a')
  print(lst)  # [1, 'a', 2]
  ```
- `extend(iterable)`：在列表末尾追加可迭代对象的**所有元素**，参数必须是可迭代对象，元素逐个拆分加入。
  ```python
  lst = [1,2]
  lst.extend([3,4])
  print(lst)  # [1, 2, 3, 4]
  ```

## 62. Python 中 remove、del 和 pop 有什么区别?
三者都是列表删除操作，核心差异在删除依据、参数与返回值：
- `remove(value)`：按**元素值**删除第一个匹配项，无返回值；元素不存在抛出 `ValueError`。
  ```python
  lst = [1,2,3,2]
  lst.remove(2)
  print(lst)  # [1, 3, 2]
  ```
- `del`：Python 关键字，按**索引/切片**删除元素，也可删除整个变量，无返回值；索引不存在抛出 `IndexError`。
  ```python
  lst = [1,2,3]
  del lst[1]
  print(lst)  # [1, 3]
  ```
- `pop(index=-1)`：按**索引**删除元素，默认删除最后一个，返回被删除的元素；索引不存在抛出 `IndexError`。
  ```python
  lst = [1,2,3]
  val = lst.pop()   # 返回 3
  val = lst.pop(0)  # 返回 1
  ```

## 63. Python 中的 != 和 is not 运算符有什么区别?
二者判断维度完全不同：
- `!=`：**值比较运算符**，判断两个对象的**内容是否不相等**，不比较内存地址。
- `is not`：**身份运算符**，判断两个对象的**内存地址是否不同**（即是否不是同一个对象），本质比较 `id()` 是否不同。

```python
a = [1,2,3]
b = [1,2,3]
print(a != b)      # False，值相等
print(a is not b)  # True，不是同一个对象

c = 100
d = 100
print(c is not d)  # False，小整数驻留机制，指向同一对象
```

## 64. Python 的 iterables 和 iterators 有什么区别?
- **可迭代对象（Iterable）**：实现了 `__iter__()` 方法的对象，可被遍历（列表、元组、字典、字符串、生成器等）。可重复遍历，每次遍历生成新迭代器。
- **迭代器（Iterator）**：同时实现了 `__iter__()` 和 `__next__()` 方法的带状态对象，调用 `__next__()` 返回下一个值并更新状态，遍历结束抛出 `StopIteration`。只能遍历一次，遍历后即耗尽。

关系：迭代器一定是可迭代对象，可迭代对象不一定是迭代器；`iter(可迭代对象)` 会返回迭代器。

```python
lst = [1,2,3]   # 可迭代对象
it = iter(lst)  # 迭代器
print(next(it)) # 1
print(next(it)) # 2
```

## 65. Python 中的 Map 函数有什么作用? 怎么使用?
`map()` 是内置高阶函数，将函数依次作用于可迭代对象的每个元素，返回一个迭代器（Python 3）。

语法：`map(function, iterable1, iterable2, ...)`
- `function`：处理函数，支持普通函数或 lambda
- `iterable`：一个或多个可迭代对象

```python
# 单个可迭代对象
lst = [1,2,3,4]
res = map(lambda x: x**2, lst)
print(list(res))  # [1, 4, 9, 16]

# 多个可迭代对象
lst1 = [1,2,3]
lst2 = [10,20,30]
res = map(lambda x,y: x+y, lst1, lst2)
print(list(res))  # [11, 22, 33]
```
> 注意：多个可迭代对象长度不同时，以最短的为准。

## 66. Python 中的 Filter 函数有什么作用? 怎么使用?
`filter()` 是内置高阶函数，根据判断函数过滤可迭代对象，保留返回 `True` 的元素，返回迭代器。

语法：`filter(function, iterable)`
- `function`：判断函数，接收一个参数返回布尔值；为 `None` 时过滤所有假值
- `iterable`：待过滤的可迭代对象

```python
# 过滤偶数
lst = [1,2,3,4,5,6]
res = filter(lambda x: x%2 == 0, lst)
print(list(res))  # [2, 4, 6]

# 过滤空值
lst = ['a', '', 'b', None, 'c']
res = filter(None, lst)
print(list(res))  # ['a', 'b', 'c']
```

## 67. Python 中 reduce 函数有什么作用? 怎么使用?
`reduce()` 对可迭代对象的元素做累积运算：将函数依次作用于“前两个元素的结果”和“下一个元素”，最终返回单一值。

> 注意：Python 3 中 `reduce` 移入 `functools` 模块，使用前需导入。

语法：`reduce(function, iterable[, initializer])`
- `function`：接收两个参数的函数
- `initializer`：可选初始值，作为第一个参与运算的值

```python
from functools import reduce
lst = [1,2,3,4]

# 累加求和
res = reduce(lambda x,y: x+y, lst)
print(res)  # 10，等价于 ((1+2)+3)+4

# 带初始值
res = reduce(lambda x,y: x+y, lst, 10)
print(res)  # 20，等价于 (((10+1)+2)+3)+4
```

## 68. 什么是 Python 的 pickling 和 unpickling?
二者是 Python 的序列化与反序列化操作：
- **Pickling（序列化）**：将 Python 对象（列表、字典、类实例等）转换为二进制字节流，用于文件存储或网络传输。
- **Unpickling（反序列化）**：将二进制字节流还原为原始 Python 对象。

核心通过 `pickle` 模块实现，常用方法：
- `dump(obj, file)` / `load(file)`：写入/读取文件
- `dumps(obj)` / `loads(bytes)`：转字节串 / 从字节串还原

```python
import pickle
data = {'name': 'Tom', 'age': 20}

# 序列化到文件
with open('data.pkl', 'wb') as f:
    pickle.dump(data, f)

# 反序列化
with open('data.pkl', 'rb') as f:
    res = pickle.load(f)
```

注意事项：
1. Python 专属格式，不跨语言，版本间可能不兼容。
2. 安全风险：禁止反序列化不可信来源的数据，可能执行恶意代码。

## 69. 什么是 Python 的生成器?
生成器（Generator）是特殊的迭代器，惰性计算、按需生成值，极大节省内存。

两种创建方式：
1. **生成器表达式**：将列表推导式的 `[]` 换成 `()`
```python
g = (x for x in range(10))
```
2. **生成器函数**：函数中使用 `yield` 关键字，调用函数不立即执行，返回生成器对象；每次 `next()` 执行到 `yield` 处返回值并暂停，下次调用从暂停处继续。

```python
def gen(n):
    for i in range(n):
        yield i * 2

g = gen(5)
print(next(g))  # 0
print(next(g))  # 2
```

特点：惰性求值、只能遍历一次、内存占用极低，适合大数据、无限序列场景。

## 70. 什么是 Python 的 Lambda 函数，有哪些应用场景?
Lambda 即匿名函数，是一行式的简洁函数定义，适合简单、一次性使用的逻辑。

语法：`lambda 参数列表: 表达式`
- 支持多个参数，用逗号分隔
- 只能有一个表达式，表达式结果即返回值，无需 `return`

核心应用场景：
1. 作为高阶函数参数，搭配 `map`、`filter`、`sorted`、`reduce` 使用
```python
lst = [(1,3), (2,1), (3,2)]
res = sorted(lst, key=lambda x: x[1])
```
2. 简单回调函数、闭包中的简短逻辑
3. 临时使用、无需复用的简单函数

> 注意：复杂逻辑建议用 `def` 定义普通函数，保证可读性。

## 71. Python 的迭代器和生成器有什么区别?
生成器是迭代器的一种，属于包含关系，核心差异：
1. **创建方式**
   - 迭代器：通过类实现 `__iter__` + `__next__` 创建，或用 `iter()` 转换可迭代对象。
   - 生成器：通过生成器函数（`yield`）或生成器表达式创建，语法更简洁。
2. **状态维护**
   - 自定义迭代器需手动维护状态、处理 `StopIteration`。
   - 生成器自动维护状态，`yield` 自动暂停/恢复，自动抛出结束异常。
3. **灵活性**：迭代器可实现复杂迭代逻辑；生成器适合简单序列生成，代码更精简。
4. **范围**：所有生成器都是迭代器，迭代器不一定是生成器。

## 72. Python 正则表达式中 match 和 search 有什么区别?
二者都是 `re` 模块的匹配方法，核心差异在匹配范围：
- `re.match(pattern, string)`：只从字符串**起始位置**匹配，开头不匹配直接返回 `None`，只返回第一个结果。
- `re.search(pattern, string)`：在整个字符串中搜索，找到第一个匹配项即返回，无需从开头匹配。

匹配成功返回 `Match` 对象，失败返回 `None`。

```python
import re
s = 'abc123def'
print(re.match(r'\d+', s))    # None，开头不是数字
print(re.search(r'\d+', s))   # 匹配到 '123'
print(re.match(r'abc', s))    # 匹配成功
```

## 73. Python 的 `__init__` 和 `__new__` 方法有什么区别?
二者都是类的构造相关魔法方法，执行顺序与作用完全不同：
1. **作用不同**
   - `__new__`：**构造方法**，负责创建并返回实例对象，是类级方法，第一个参数为 `cls`（类本身）。
   - `__init__`：**初始化方法**，负责给已创建的实例初始化属性，是实例级方法，第一个参数为 `self`（实例对象）。
2. **执行顺序**：创建对象时先执行 `__new__` 创建实例，再执行 `__init__` 初始化。
3. **返回值**：`__new__` 必须返回类的实例，否则 `__init__` 不会执行；`__init__` 无返回值（只能返回 None）。
4. **场景**：`__new__` 用于控制实例创建（单例模式、不可变类定制）；`__init__` 用于常规属性初始化。

```python
class Person:
    def __new__(cls, name):
        print("调用 __new__")
        return super().__new__(cls)
    def __init__(self, name):
        print("调用 __init__")
        self.name = name
```

## 74. Python 函数参数 `*args` 和 `**kwargs` 有什么区别? 怎么使用?
二者都用于接收可变数量参数，差异在参数类型：
- `*args`：接收任意数量的**位置参数**，打包成元组。`args` 是约定名称，可自定义。
- `**kwargs`：接收任意数量的**关键字参数**，打包成字典。`kwargs` 是约定名称，可自定义。

```python
def func(a, *args, **kwargs):
    print("普通参数:", a)
    print("位置参数元组:", args)
    print("关键字参数字典:", kwargs)

func(1, 2, 3, name='Tom', age=20)
# 普通参数: 1
# 位置参数元组: (2, 3)
# 关键字参数字典: {'name': 'Tom', 'age': 20}
```

补充用法：
1. 解包传参：`*` 解包列表/元组为位置参数，`**` 解包字典为关键字参数
2. 参数定义顺序：普通参数 → `*args` → 默认参数 → `**kwargs`

## 75. Python 2 和 Python 3 有什么区别?
Python 2 与 Python 3 是不兼容的大版本，核心差异：
1. **编码**
   - Python 2：默认 ASCII 编码，字符串分 `str` 和 `unicode`，中文易乱码。
   - Python 3：默认 UTF-8，字符串统一为 `str`（Unicode），新增 `bytes` 字节类型。
2. **语法**
   - `print`：Python 2 是语句 `print 'hello'`；Python 3 是函数 `print('hello')`。
   - 除法：Python 2 中 `3/2=1`（地板除）；Python 3 中 `/` 是真除法，`//` 是地板除。
   - `range`：Python 2 中 `range` 返回列表，`xrange` 返回迭代器；Python 3 统一为迭代器，移除 `xrange`。
3. **面向对象**：Python 2 有经典类/新式类之分；Python 3 全部为新式类，统一 MRO 规则。
4. **其他**：Python 3 新增 `nonlocal`、`map/filter/zip` 返回迭代器、`input` 行为变更等。

> Python 2 已于 2020 年停止维护，推荐使用 Python 3。

## 76. 什么是 "猴子补丁"(monkey patching) ?
猴子补丁指在**程序运行时动态修改类、模块或方法的行为**，无需修改原始源码，是动态语言的特性。

```python
class A:
    def func(self):
        print("原始方法")

def new_func(self):
    print("补丁方法")

# 运行时替换类方法
A.func = new_func
a = A()
a.func()  # 输出 "补丁方法"
```

应用场景：临时修复第三方库 Bug、测试时 Mock 替换方法、动态扩展功能。
> 注意：会增加代码隐晦度和维护成本，非必要不建议大量使用。

## 77. Python 在什么情况下会出现 KeyError、TypeError、ValueError?
三者是常见内置异常，触发场景：
1. **KeyError**：字典中访问不存在的键时抛出。
   ```python
   d = {'a':1}
   print(d['b'])  # KeyError
   ```
2. **TypeError**：操作/函数接收到的参数类型错误时抛出。
   常见场景：不同类型非法运算、参数数量不符、对非可迭代对象迭代等。
   ```python
   len(123)  # TypeError
   ```
3. **ValueError**：参数类型正确但值不合法时抛出。
   ```python
   int('abc')       # ValueError
   [1,2].remove(3)  # ValueError
   ```

## 78. 什么是 Python 中的模块和包?
- **模块（Module）**：一个 `.py` 文件就是一个模块，可定义变量、函数、类，供其他文件导入复用，实现代码拆分与模块化。
  导入方式：`import module`、`from module import func`、`import module as alias`。

- **包（Package）**：包含 `__init__.py` 的文件夹，用于组织多个相关模块，形成层级命名空间，避免模块名冲突。Python 3.3+ 支持无 `__init__.py` 的命名空间包，但常规包仍推荐保留，用于初始化和定义 `__all__`。

## 79. Python 的类和对象有什么区别?
1. **定义不同**
   - 类（Class）：对一类事物的抽象描述，是模板/蓝图，定义了对象共有的属性和方法。
   - 对象（Object/实例）：类的具体实例，是真实存在的个体。
2. **关系**：类是抽象模板，对象是类的实例化产物；一个类可实例化多个对象，每个对象拥有独立属性。
3. **内存**：类占一份代码空间，每个对象占独立内存存储自身属性。

```python
class Person:  # 类
    def __init__(self, name):
        self.name = name

p1 = Person('Tom')   # 对象1
p2 = Person('Jerry') # 对象2
```

## 80. 什么是 Python 类中的 self?
`self` 是类中实例方法的第一个参数，代表**当前实例对象本身**。

作用：
1. 在类内部通过 `self` 访问实例的属性和方法，区分实例属性与局部变量。
2. 调用实例方法时，Python 自动将调用该方法的实例作为第一个参数传给 `self`，无需手动传参。

> 注意：`self` 不是关键字，只是约定俗成的名称；类方法第一个参数是 `cls`，静态方法无默认首参数。

## 81. 什么是 Python 的 OOPS (面向对象编程) ?
OOPS（Object-Oriented Programming System）即面向对象编程，是以对象为基本单元、将数据与操作数据的方法封装在一起的编程范式。

四大核心特性：
1. **封装**：绑定数据与方法，隐藏内部细节，只暴露必要接口。
2. **继承**：子类复用父类属性方法，支持扩展与重写。
3. **多态**：同一接口可对应不同实现，调用时按对象类型自动适配。
4. **抽象**：提取事物共同特征，忽略非核心细节，定义统一规范。

优势：代码复用性高、可维护性强、扩展性好，适合大型复杂项目。

## 82. 什么是 Python 面向对象的抽象特性?
抽象指隐藏事物的复杂实现细节，只对外暴露核心功能接口，使用者无需关心内部逻辑。

Python 实现抽象的方式：
1. **抽象类与抽象方法**：通过 `abc` 模块实现。抽象类不能实例化，子类必须实现所有抽象方法，否则也无法实例化。
2. 普通类封装也属于抽象，通过私有属性/方法隐藏内部细节。

```python
from abc import ABC, abstractmethod
class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass  # 抽象方法，仅声明无实现

class Dog(Animal):
    def speak(self):
        print("汪汪叫")
```
作用：定义统一接口规范，强制子类遵循约定，提升代码规范性。

## 83. 什么是 Python 面向对象的封装特性?
封装指将数据与操作数据的方法绑定，隐藏内部实现与数据，仅通过公开接口访问，保障数据安全与易用性。

Python 封装层级：
1. **公有成员**：普通命名，类内外均可直接访问。
2. **受保护成员**：单下划线开头（如 `_name`），约定类内部和子类可访问，外部不建议访问。
3. **私有成员**：双下划线开头（如 `__age`），Python 会做名称改写（`_类名__属性名`），外部无法直接访问，只能通过类内部方法访问。

```python
class Person:
    def __init__(self, name, age):
        self.name = name        # 公有
        self._age = age         # 受保护
        self.__password = 123   # 私有
    def get_password(self):
        return self.__password  # 公开接口访问私有属性
```

## 84. 什么是 Python 面向对象的多态特性?
多态指“一个接口，多种实现”：同一个方法名，不同对象调用会产生不同执行结果。

Python 是动态语言，天然支持多态（鸭子类型）：只要对象拥有对应方法即可调用，不严格限制类型。

```python
class Dog:
    def speak(self):
        print("汪汪叫")
class Cat:
    def speak(self):
        print("喵喵叫")

def animal_speak(animal):
    animal.speak()

animal_speak(Dog())  # 汪汪叫
animal_speak(Cat())  # 喵喵叫
```

优势：提升代码灵活性与扩展性，减少分支判断，符合开闭原则。

## 85. Python 是否支持多重继承?
Python 支持多重继承，即一个子类可同时继承多个父类，拥有所有父类的属性与方法。

```python
class A: pass
class B: pass
class C(A, B):  # 同时继承 A 和 B
    pass
```

核心问题：**方法解析顺序（MRO）**。多个父类有同名方法时，Python 通过 C3 算法确定调用优先级，可通过 `类名.__mro__` 查看。

> 注意：多重继承会增加代码复杂度，易出现命名冲突，使用需谨慎，优先考虑组合模式。

## 86. 为什么 Python 执行速度慢，如何改进?
速度慢的核心原因：
1. 解释型语言，逐行解释执行，无编译优化。
2. CPython 存在 GIL 全局解释器锁，多线程无法利用多核并行计算。
3. 动态类型，运行时频繁检查类型，无法做编译期优化。
4. 一切皆对象，每个数据都有额外元数据开销。

提速方案：
1. 优先使用内置函数与数据结构（底层 C 实现）。
2. CPU 密集型用多进程，绕过 GIL 利用多核。
3. 核心逻辑用 C 扩展（Cython、ctypes）。
4. 使用 PyPy 解释器，JIT 即时编译加速。
5. 数值计算用 NumPy、Pandas 等向量化库。
6. IO 密集型用 asyncio 异步编程，减少等待损耗。

## 87. 如何分析 Python 代码的执行性能?
常用性能分析工具，从粗到精定位瓶颈：
1. **time / timeit**：简单计时，测试单段代码执行耗时。
2. **cProfile**：官方内置工具，统计每个函数的调用次数、总耗时、单次耗时，定位最慢函数。
   用法：`python -m cProfile -s cumulative test.py`
3. **line_profiler**：逐行统计代码执行时间，定位具体慢的代码行。
4. **memory_profiler**：分析内存占用，定位内存泄漏与高内存点。
5. **py-spy**：采样型分析工具，无需修改代码，可附加到运行进程，适合线上环境。

分析思路：先用 cProfile 定位慢函数，再用 line_profiler 定位具体行，针对性优化。

## 88. Python 中如何读取大文件，例如内存只有 4G，如何读取一个大小为 8G 的文件
核心思路：**分块读取、逐行处理**，避免一次性加载全部内容。

常用方案：
1. **逐行迭代读取（最常用）**
文件对象本身是可迭代对象，for 循环逐行读取，每次仅加载一行。
```python
with open('big_file.txt', 'r', encoding='utf-8') as f:
    for line in f:
        process(line)  # 处理每一行
```
适合按行处理的文本文件，内存占用极低。

2. **指定字节分块读取**
适合无换行符的二进制文件或大文件，每次读取固定大小。
```python
chunk_size = 1024 * 1024  # 每次读 1MB
with open('big_file', 'rb') as f:
    while True:
        chunk = f.read(chunk_size)
        if not chunk:
            break
        process(chunk)
```

> 注意：避免使用 `read()`、`readlines()`，处理完的数据及时释放，不要全部存入列表。

## 89. Python 的 re 模块中 split()、sub()、subn() 方法有什么作用?
三者都是正则字符串处理方法：
1. **`re.split(pattern, string)`**：按正则匹配的内容分割字符串，返回列表，支持多分隔符。
   ```python
   import re
   s = 'a,b;c d'
   res = re.split(r'[,; ]', s)  # ['a', 'b', 'c', 'd']
   ```
2. **`re.sub(pattern, repl, string)`**：替换匹配正则的内容，返回新字符串；`repl` 可以是字符串或函数。
   ```python
   s = 'a1b2c3'
   res = re.sub(r'\d', '*', s)  # 'a*b*c'
   ```
3. **`re.subn(pattern, repl, string)`**：功能同 `sub`，区别是返回元组 `(替换后的字符串, 替换次数)`。
   ```python
   res, n = re.subn(r'\d', '*', s)  # ('a*b*c', 3)
   ```

## 90. Python 的 namedtuple 有什么作用? 怎么使用?
`namedtuple`（命名元组）是 `collections` 模块的工具，是元组子类，给每个位置赋予名称，可通过属性名访问元素，同时保留元组不可变特性。

作用：解决普通元组只能按索引访问的问题，提升可读性；比字典更轻量，适合存储固定结构的数据。

```python
from collections import namedtuple
# 定义：类型名 + 字段名列表
Point = namedtuple('Point', ['x', 'y'])
p = Point(10, 20)

print(p.x)   # 10，按属性名访问
print(p[0])  # 10，也支持索引访问
```

常用方法：`_fields` 查看所有字段、`_asdict()` 转字典、`_replace()` 生成新实例并替换字段。

## 91. Python 中如何实现多线程?
主要通过 `threading` 模块实现，两种常用方式：
1. **函数式创建**
```python
import threading
def task(name):
    print(f"线程{name}执行")

t1 = threading.Thread(target=task, args=('A',))
t2 = threading.Thread(target=task, args=('B',))
t1.start()
t2.start()
t1.join()  # 等待线程结束
t2.join()
```

2. **继承 Thread 类**
```python
class MyThread(threading.Thread):
    def __init__(self, name):
        super().__init__()
        self.name = name
    def run(self):  # 重写 run 方法
        print(f"线程{self.name}执行")

t = MyThread('C')
t.start()
```

> 注意：CPython 受 GIL 限制，多线程不适合 CPU 密集型任务，适合 IO 密集型场景；多线程共享全局变量需加锁防止数据竞争。

## 92. 请介绍 Python 中多线程和多进程的应用场景，以及优缺点?
### 多线程
- 原理：同一进程内的多个线程，共享进程内存空间，切换开销小。
- 优点：创建/切换开销低、资源占用少、线程间通信方便。
- 缺点：CPython 受 GIL 限制，CPU 密集型无法并行加速；共享资源需加锁，易引发死锁。
- 适用场景：网络爬虫、文件读写、数据库操作等 IO 密集型任务。

### 多进程
- 原理：每个进程有独立内存空间与 GIL，真正实现多核并行。
- 优点：可利用多核 CPU、进程间独立稳定性高、适合 CPU 密集型。
- 缺点：进程创建/切换开销大、进程间通信复杂。
- 适用场景：数值计算、图像处理、大数据处理等 CPU 密集型任务。

总结：IO 密集型用多线程，CPU 密集型用多进程。

## 93. 请解释 Python 线程池的工作原理?
线程池是线程复用机制：预先创建一定数量的线程放入池中，任务提交后分配给空闲线程执行，执行完毕线程不销毁，继续等待下一个任务。

工作流程：
1. 初始化：创建指定数量的工作线程，同时维护一个任务队列。
2. 提交任务：用户将任务提交到任务队列。
3. 调度执行：空闲线程从队列取任务执行。
4. 线程复用：任务执行完线程不退出，回到池中等待新任务。
5. 关闭回收：所有任务结束后关闭线程池，回收资源。

Python 主要通过 `concurrent.futures.ThreadPoolExecutor` 实现：
```python
from concurrent.futures import ThreadPoolExecutor
def task(n):
    return n * n

with ThreadPoolExecutor(max_workers=5) as executor:
    futures = [executor.submit(task, i) for i in range(10)]
    for f in futures:
        print(f.result())
```

优势：避免频繁创建销毁线程的开销、控制线程数量防止资源耗尽、简化多线程编码。
