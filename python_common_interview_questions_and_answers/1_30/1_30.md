## 1. 什么是Python的赋值和算术运算符？
- **算术运算符**：用于执行基础数学运算，包括 `+`（加）、`-`（减）、`*`（乘）、`/`（浮点除）、`//`（整除/向下取整）、`%`（取余）、`**`（幂运算）。
- **赋值运算符**：用于给变量赋值，基础赋值为 `=`；复合赋值运算符会先执行运算再赋值，如 `+=`、`-=`、`*=`、`/=`、`//=`、`%=`、`**=`。

```python
# 算术运算符示例
a, b = 10, 3
print(a + b)   # 13
print(a // b)  # 3（整除）
print(a % b)   # 1（取余）
print(a ** b)  # 1000（幂运算）

# 复合赋值示例
c = 5
c += 2  # 等价于 c = c + 2
print(c)  # 7
```

## 2. 什么是Python的逻辑运算符？
逻辑运算符用于布尔逻辑运算，支持**短路特性**（左侧能确定结果时，不再计算右侧），且返回决定结果的操作数本身（不一定是布尔值）：
- `and`：逻辑与，全为真则返回最后一个真值，有假则返回第一个假值
- `or`：逻辑或，有真则返回第一个真值，全假则返回最后一个假值
- `not`：逻辑非，取反，返回布尔值

```python
print(3 and 0)   # 0（有假返假）
print(3 or 0)    # 3（有真返真）
print(not True)  # False
```

## 3. 什么是Python的成员运算符？
用于判断元素是否存在于序列/容器（字符串、列表、元组、集合、字典等）中：
- `in`：元素存在则返回 `True`
- `not in`：元素不存在则返回 `True`
> 字典中默认判断的是**键（key）**是否存在。

```python
lst = [1, 2, 3]
print(2 in lst)        # True
print('a' in 'apple')  # True
print('name' in {'name': 'Tom'})  # True（判断键）
```

## 4. 什么是Python的身份运算符？
用于比较两个对象的**内存地址是否相同**（即是否为同一个对象）：
- `is`：是同一个对象返回 `True`
- `is not`：不是同一个对象返回 `True`

> 核心区别：`==` 比较**值是否相等**，`is` 比较**身份（内存地址）是否相同**。

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True（值相等）
print(a is b)   # False（不是同一个对象）

c = a
print(a is c)   # True（指向同一内存地址）
```

## 5. 什么是Python的位运算符？
将数字转为二进制，按二进制位进行运算：
- `&` 按位与：对应位都为1则为1
- `|` 按位或：对应位有一个为1则为1
- `^` 按位异或：对应位不同则为1
- `~` 按位取反：所有位取反（含符号位），结果为 `-(x+1)`
- `<<` 左移：左移n位，右侧补0，等价于乘以 `2^n`
- `>>` 右移：右移n位，左侧补符号位，等价于除以 `2^n`

```python
a = 6  # 0110
b = 3  # 0011
print(a & b)  # 2（0010）
print(a | b)  # 7（0111）
print(a << 1) # 12（1100）
```

## 6. 如何在Python中使用多进制数字？
Python支持直接书写不同进制的整数，也可通过内置函数做进制转换：
- 二进制：`0b`/`0B` 开头
- 八进制：`0o`/`0O` 开头
- 十六进制：`0x`/`0X` 开头
- 转换函数：`bin()` 转二进制、`oct()` 转八进制、`hex()` 转十六进制

```python
# 直接表示多进制
bin_num = 0b1010  # 十进制10
oct_num = 0o12    # 十进制10
hex_num = 0xA     # 十进制10

# 十进制转其他进制
print(bin(10))  # '0b1010'
print(hex(10))  # '0xa'
```

## 8. 为什么Python不建议使用下划线开头的标识符？
下划线开头的标识符在Python中有约定的特殊语义，随意使用会破坏语义、引发意外行为：
1. **单下划线开头**（如 `_var`）：约定为“内部/私有”，`from module import *` 不会导入该名称。
2. **双下划线开头**（如 `__var`）：触发**名称修饰（name mangling）**，自动重命名为 `_类名__var`，用于类的私有属性，避免子类命名冲突。
3. **双下划线首尾**（如 `__init__`）：是Python内置魔术方法的格式，自定义命名禁止使用，避免与内置机制冲突。

## 9. Python如何声明多个变量并赋值？

3. **解包赋值**：将可迭代对象的元素赋值给多个变量


## 10. 什么是Python元组的解封装？
元组解封装（解包）指将元组的元素依次赋值给多个变量，变量数量需与元素数匹配；也可通过 `*` 接收剩余元素为列表。列表、字符串等可迭代对象均支持解包。

```python
# 基础解包
t = (1, 2, 3)
a, b, c = t

# 带*接收剩余元素
t2 = (1, 2, 3, 4, 5)
first, *middle, last = t2
print(middle)  # [2, 3, 4]

# 经典应用：交换变量
x, y = 10, 20
x, y = y, x
```

## 13. Python有哪些局限性？
1. **运行速度慢**：解释型语言，逐行执行，效率低于C/C++等编译型语言。
2. **GIL全局解释器锁**：多线程无法真正利用多核CPU，CPU密集型任务性能受限。
3. **代码保密性差**：解释型语言分发源码，反编译难度低。
4. **动态类型风险**：运行时才暴露类型错误，大型项目维护成本高。
5. **移动端开发薄弱**：无成熟的原生移动端开发方案。

## 14. 请解释Python代码的执行过程？
Python属于“半编译半解释”，执行分为两个核心阶段：
1. **编译为字节码**：解释器将 `.py` 源码编译为字节码（`.pyc` 文件，存于 `__pycache__`），同时做语法检查，语法错误在此阶段抛出。
2. **字节码解释执行**：Python虚拟机（PVM）逐行解释字节码，翻译为机器码交给CPU执行。

> 字节码是平台无关的，因此Python具备跨平台性；源码未修改时会复用 `.pyc`，提升启动速度。

## 17. Python中break、continue、pass有什么作用？
均用于循环流程控制：
- `break`：终止**整个当前循环**，跳出循环体，执行循环后续代码；嵌套循环中只跳出最近一层。
- `continue`：跳过**本次循环**剩余代码，直接进入下一次循环判断，不终止循环。
- `pass`：空占位语句，不执行任何逻辑，仅用于保证语法完整（如空函数、空分支）。

```python
# break
for i in range(5):
    if i == 3:
        break
    print(i)  # 输出 0 1 2

# continue
for i in range(5):
    if i == 2:
        continue
    print(i)  # 输出 0 1 3 4

# pass 占位
def func():
    pass
```

## 18. Python中如何实现switch语句？
Python原生无switch-case，常用三种实现方式：
1. **if-elif-else**：适合分支少的场景，最通用。
2. **字典映射**：适合分支多的场景，键对应case，值对应执行函数。
3. **match-case**：Python3.10+新增的模式匹配语法，功能更强。

```python
# 字典映射实现
def case1(): return "周一"
def case2(): return "周二"
def default(): return "其他"

switch = {1: case1, 2: case2}
result = switch.get(3, default)()
```

## 19. Python的range函数如何运用？请举例说明
`range()` 生成整数序列的可迭代对象，常用于控制循环次数，语法：`range(start, stop, step)`
- `start`：起始值，默认0
- `stop`：结束值（左闭右开，不包含），必填
- `step`：步长，默认1，可为负数

```python
# 1个参数：0~4
for i in range(5):
    print(i)

# 2个参数：2~5
for i in range(2, 6):
    print(i)

# 3个参数：步长2，1,3,5,7,9
for i in range(1, 10, 2):
    print(i)

# 倒序
for i in range(5, 0, -1):
    print(i)
```

## 22. Python3中is和==有什么区别？
- `==`：**值比较**，调用对象的 `__eq__` 方法，判断两个对象的内容是否相等。
- `is`：**身份比较**，比较两个对象的内存地址（`id()` 返回值），判断是否为同一个对象。

> 注意：小整数（-5~256）、短字符串会被Python缓存复用，此时 `is` 也返回True，属于优化机制，不可依赖。

```python
a = [1,2,3]
b = [1,2,3]
print(a == b)  # True（值相等）
print(a is b)  # False（不是同一对象）
```

## 23. Python中any()和all()方法有什么作用？
均为内置函数，用于判断可迭代对象的布尔值：
- `all(iterable)`：所有元素都为真（或迭代器为空），返回True；有一个假则返回False。
- `any(iterable)`：有一个元素为真，返回True；全为假（或迭代器为空）返回False。

> 0、None、空字符串、空列表等会被判定为False。

```python
print(all([1, True, 'a']))  # True
print(any([0, False, '']))  # False
print(all([]))  # True（空集逻辑）
print(any([]))  # False
```

## 24. 说明Python3中装饰器的用法
装饰器本质是**闭包函数**，在不修改原函数代码的前提下，为函数扩展额外功能（日志、计时、权限校验等），符合开闭原则。
通过 `@装饰器名` 语法糖简化调用，原理是将原函数作为参数传入装饰器，返回包装后的新函数。

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} 耗时：{time.time()-start}")
        return res
    return wrapper

@timer  # 等价于 func = timer(func)
def func():
    time.sleep(1)
```

## 25. 说明Python3中yield的用法
`yield` 用于定义**生成器函数**，调用生成器函数不会立即执行代码，而是返回生成器对象；迭代时执行代码，遇到 `yield` 暂停并返回值，下次迭代从暂停处继续。
核心作用是**惰性求值**，节省内存，适合处理大数据序列。

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield b
        a, b = b, a + b

# 迭代生成器
for num in fib(5):
    print(num)  # 1 1 2 3 5
```

## 26. 说明Python中enumerate()的用法
内置函数，将可迭代对象组合为“索引+元素”的序列，遍历场景下可同时获取下标与值。
语法：`enumerate(iterable, start=0)`，`start` 可指定索引起始值。

```python
lst = ['a', 'b', 'c']
for index, value in enumerate(lst, start=1):
    print(index, value)
# 输出：
# 1 a
# 2 b
# 3 c
```

## 27. 解释Python中//、%和**运算符
- `//`：**地板除法（整除）**，向下取整（向负无穷取整），负数场景与 `int()` 截断取整结果不同。
- `%`：**取模运算**，返回除法余数，满足公式 `a = (a // b) * b + a % b`，余数符号与除数一致。
- `**`：**幂运算符**，计算a的b次方，优先级高于一元负号。

```python
print(-10 // 3)  # -4（向下取整）
print(-10 % 3)   # 2（余数与除数同号）
print(2 ** 3)    # 8
```

## 31. 如何在Python中管理内存？
Python由解释器自动管理内存，核心机制：
1. **引用计数**：每个对象维护引用计数，计数为0时释放内存；引用增加/减少对应赋值、销毁等操作。
2. **垃圾回收**：通过标记-清除解决循环引用问题；分代回收（0/1/2三代）优化回收效率，存活越久的对象回收频率越低。
3. **内存池**：小内存（<256KB）由内存池管理，避免频繁向系统申请释放；大内存直接由系统分配。

开发者层面：避免循环引用、及时释放无用引用、使用生成器减少内存占用、通过`gc`模块调试内存问题。

## 33. Python程序退出时，是否释放所有内存分配？
从**操作系统层面**：进程结束后，系统会回收进程全部内存。
从**Python解释器层面**：不会将所有内存归还给操作系统：
1. 循环引用且关联全局变量的对象，可能无法及时回收。
2. C扩展申请的内存，需扩展自身管理，Python解释器不负责释放。
3. Python内存池中的内存会保留复用，不会立即归还系统。

## 34. 什么是Python的负索引？
Python的序列（列表、元组、字符串等）支持负索引，从序列末尾向前计数：最后一个元素索引为`-1`，倒数第二个为`-2`，以此类推。
作用：无需计算序列长度，便捷获取末尾元素。

```python
lst = [10, 20, 30]
print(lst[-1])   # 30
print(lst[-2:])  # [20, 30]
```

## 35. Python是否区分大小写？

## 39. Python的pass语句有什么作用？

## 42. Python是否有main函数？
Python没有C/Java那样的内置`main`函数作为程序入口，程序默认从上到下逐行执行。
行业通用写法是通过 `if __name__ == '__main__':` 模拟入口：
- 脚本直接运行时，`__name__` 值为 `'__main__'`，该代码块执行。
- 脚本作为模块被导入时，`__name__` 为模块名，该代码块不执行。

```python
def main():
    print("主逻辑")

if __name__ == '__main__':
    main()
```

## 43. Python中如何使用索引反转字符串？
最简洁高效的方式是**切片步长设为-1**，格式 `s[::-1]`。
原理：切片 `s[start:end:step]`，step为-1表示从后往前遍历，省略起止则取整个字符串。

```python
s = "python"
reverse_s = s[::-1]
print(reverse_s)  # 'nohtyp'
```

## 44. 为什么Python中没有函数重载？
函数重载指同名函数通过参数数量/类型区分不同实现，Python不支持原生重载，原因：
1. Python是动态类型语言，参数无类型声明，运行时才确定类型，无法通过类型区分重载。
2. Python中同名函数，后定义的会完全覆盖前定义的，无法共存。

替代方案：函数内部判断参数类型/数量；或使用`functools.singledispatch`实现单分派泛函数。

## 45. 你知道哪些Python魔术方法？
魔术方法是双下划线首尾的特殊方法，由解释器自动调用，实现类的特殊行为。常见分类：
- 构造析构：`__new__`（创建对象）、`__init__`（初始化）、`__del__`（销毁）
- 字符串表示：`__str__`（print调用）、`__repr__`（repr调用）
- 运算符重载：`__add__`（+）、`__eq__`（==）、`__len__`（len()）
- 属性访问：`__getattr__`（访问不存在属性）、`__setattr__`（设置属性）
- 容器行为：`__getitem__`（[]取值）、`__iter__`（迭代）

```python
class Person:
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return f"Person({self.name})"
```

## 46. 请介绍Python中变量的作用域？
变量作用域指变量可被访问的范围，Python遵循**LEGB查找规则**，优先级从高到低：
1. **L（Local）局部作用域**：函数内部定义的变量
2. **E（Enclosing）嵌套作用域**：嵌套函数中外层函数的作用域
3. **G（Global）全局作用域**：模块顶层定义的变量
4. **B（Built-in）内置作用域**：Python内置名称，如`print`、`len`

修改跨作用域变量：函数内改全局变量用`global`声明；内层函数改外层函数变量用`nonlocal`声明。

## 49. __init__方法在Python中有什么作用？
`__init__` 是类的**初始化构造方法**，创建实例对象时自动调用，用于给实例绑定初始属性。
- 第一个参数必须是`self`，代表实例本身。
- 无返回值，仅做初始化；真正创建实例的是`__new__`方法。
- 子类继承时通常需调用父类`__init__`，保证父类属性初始化。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Tom", 18)
```

## 50. 什么是鸭子类型（duck typing）？
鸭子类型是Python动态类型的核心设计理念：**不关注对象的类型，只关注对象是否具备所需的方法/属性**。只要对象实现了对应方法，就可以被调用，无需继承特定类或实现接口。
核心理念：“如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子”。

```python
class Duck:
    def say(self): print("嘎嘎嘎")
class Cat:
    def say(self): print("喵喵喵")

def animal_say(animal):
    animal.say()  # 不关心类型，只要有say方法即可

animal_say(Duck())
animal_say(Cat())
```

## 52. 说明Python中的zip函数
内置函数，将多个可迭代对象对应位置的元素打包为元组，返回zip迭代器。
- 元素数量以最短的可迭代对象为准，长的多余元素被舍弃。
- 可通过 `*zip()` 解包还原序列。

```python
lst1 = [1, 2, 3]
lst2 = ['a', 'b']
# 打包，以短的为准
print(list(zip(lst1, lst2)))  # [(1, 'a'), (2, 'b')]

# 解包
z = zip(lst1, lst2)
a, b = zip(*z)
print(a)  # (1, 2)
```

## 53. 如何使用Python的random模块生成随机数、实现随机乱序和随机抽样？
`random`是标准库随机数模块，核心功能：
1. **生成随机数**
   - `random.random()`：[0.0, 1.0) 随机浮点数
   - `random.randint(a, b)`：[a, b] 随机整数
   - `random.uniform(a, b)`：[a, b] 随机浮点数
2. **随机乱序**
   - `random.shuffle(seq)`：原地打乱可变序列
3. **随机抽样**
   - `random.choice(seq)`：随机抽1个元素
   - `random.sample(pop, k)`：无放回抽k个元素
   - `random.choices(pop, k=n)`：有放回抽n个元素

```python
import random

lst = [1,2,3,4,5]
print(random.randint(1, 10))  # 1~10随机整数
random.shuffle(lst)           # 打乱列表
print(random.sample(lst, 3))  # 无放回抽3个
```
