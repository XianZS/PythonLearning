audioop --- 处理原始音频数据¶

从 3.11 版起已弃用，已在 3.13 版中移除.

此模块已不再是 Python 标准库的一部分。它在 Python 3.11 中被弃用后又在 Python 3.13 中被移除。移除计划是在 PEP 594 确定的。

提供 audioop 模块的最后一个 Python 版本是 Python 3.12.
