## ⚙️ 环境说明

本机开发环境：

| 项目 | 值 |
| --- | --- |
| `conda` 环境 | `lpfd` |
| `Python` 版本 | 3.14.6（`/home/byqh/miniconda3/envs/lpfd/bin/python`） |
| 官方文档版本 | `Python` 3.14 中文翻译版 |
| 操作系统 | `Linux`（`WSL2`） |

激活与验证：

```bash

conda create -n lpfd python=3.14

# 激活环境
conda activate lpfd

# 验证环境
python --version   # 期望输出 Python 3.14.x
```
