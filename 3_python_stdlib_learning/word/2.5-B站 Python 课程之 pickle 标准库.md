# B 站 Python 授课：`pickle` 标准库 ——Python 对象的 “打包神器”

## 课程导入

之前我们学过用 `json` 存数据，但 `json` 有个局限：只能存简单类型（字典、列表、字符串、数字），如果要存**Python 自定义类的实例、函数、甚至复杂的嵌套对象**，`json` 就无能为力了。

这时候就需要 **`pickle`** 标准库！它是 Python 专属的**序列化工具**，能把几乎任意 Python 对象转换成**二进制字节流**（打包），也能把字节流还原回对象（拆包），是保存程序状态、缓存复杂数据的利器。

本节课我们从零学习 `pickle`，包含基础操作、文件读写、自定义对象、安全避坑，最后还有一个超实用的实战案例！

---

## 第一部分：核心概念

### 1\. 什么是序列化 / 反序列化？

- **序列化（Pickling）**：把 Python 对象转换成**二进制字节流**（可以存到文件或网络传输）。

- **反序列化（Unpickling）**：把二进制字节流还原回原来的 Python 对象。

### 2\. pickle 的特点

|特点|说明|
|---|---|
|**Python 专属**|只能在 Python 之间使用，**不能跨语言**（Java/JavaScript 读不了）。|
|**支持几乎所有对象**|列表、字典、类实例、函数、甚至嵌套对象都能存。|
|**二进制格式**|生成的是字节流，不是文本，人类不可读。|

---

## 第二部分：基础操作：内存中的序列化与反序列化

### 核心知识点

- `pickle\.dumps\(obj\)`：把对象序列化为**字节串**（bytes），适合内存中处理。

- `pickle\.loads\(bytes\_data\)`：把字节串反序列化为 Python 对象。

### 示例代码

```python
import pickle

# 1. 准备一个复杂一点的 Python 对象
data = {
    "name": "张三",
    "age": 25,
    "hobbies": ["编程", "读书", "跑步"],
    "scores": (90, 85, 95),  # 元组也能存
    "is_student": True
}

# ====================== 序列化：对象 → 字节串 ======================
bytes_data = pickle.dumps(data)
print("序列化后的字节串（前50个字符）：", bytes_data[:50])
print("字节串类型：", type(bytes_data))  # <class 'bytes'>

# ====================== 反序列化：字节串 → 对象 ======================
restored_data = pickle.loads(bytes_data)
print("\n还原后的对象：", restored_data)
print("还原后的类型：", type(restored_data))  # <class 'dict'>
print("还原后的 hobbies：", restored_data["hobbies"])
```

### 内容讲解

1. `dumps\(\)`：把对象 “打包” 成字节流，你可以把这个字节流存到数据库、通过网络发送，或者暂时存在内存里。

2. `loads\(\)`：把字节流 “拆包” 回原来的对象，类型、内容完全不变（连元组、布尔值都能完美还原）。

### 小试牛刀

试试序列化一个列表、一个集合，看看能不能完美还原？

## 第三部分：文件操作：把对象存到硬盘

### 核心知识点

- `pickle\.dump\(obj, file\)`：把对象直接序列化到**文件对象**（存到硬盘）。

- `pickle\.load\(file\)`：从文件对象中反序列化出对象（从硬盘读取）。

- ⚠️ **关键**：文件必须用**二进制模式**打开（`wb` 写入，`rb` 读取）！

### 示例代码

```python
import pickle

# 1. 准备要保存的对象（比如一个游戏角色的信息）
game_data = {
    "player": "李四",
    "level": 15,
    "gold": 9999,
    "inventory": ["铁剑", "盾牌", "血瓶x5"]
}

# ====================== 序列化到文件 ======================
with open("game_save.pkl", "wb") as f:  # wb = 二进制写入
    pickle.dump(game_data, f)
print("✅ 游戏存档已保存到 game_save.pkl")

# ====================== 从文件反序列化 ======================
with open("game_save.pkl", "rb") as f:  # rb = 二进制读取
    loaded_data = pickle.load(f)
print("\n✅ 存档已加载！")
print("玩家：", loaded_data["player"])
print("等级：", loaded_data["level"])
print("背包：", loaded_data["inventory"])
```

### 内容讲解

1. **文件模式**：

    - 写入：`wb`（write binary），必须用二进制，否则会报错。

    - 读取：`rb`（read binary），同理。

2. `dump\(\)` 和 `load\(\)` 配合 `with` 语句使用，自动关闭文件，安全又方便。

## 第四部分：进阶：序列化自定义类的实例

### 核心知识点

`pickle` 最强大的地方是能存**自定义类的实例**！但要注意：反序列化时，**类的定义必须存在**（否则会报错）。

### 示例代码

```python
import pickle

# 1. 定义一个类
class Student:
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score

    def say_hello(self):
        print(f"大家好，我是{self.name}，今年{self.age}岁，分数{self.score}")

# 2. 创建实例
student = Student("王五", 20, 92)

# ====================== 序列化实例 ======================
with open("student.pkl", "wb") as f:
    pickle.dump(student, f)
print("✅ 学生实例已保存")

# ====================== 反序列化实例 ======================
# ⚠️ 注意：这里 Student 类必须已经定义过，否则会报错！
with open("student.pkl", "rb") as f:
    loaded_student = pickle.load(f)

print("\n✅ 学生实例已加载！")
print("姓名：", loaded_student.name)
print("分数：", loaded_student.score)
loaded_student.say_hello()  # 方法也能正常调用！
```

### 内容讲解

1. **类定义必须存在**：反序列化时，Python 需要知道怎么 “重建” 这个对象，所以类的代码必须在反序列化之前定义（或者导入）。

2. **方法也能还原**：不仅是属性，连类的方法都能正常调用，非常强大！

## 第五部分：安全警告：pickle 是把双刃剑

### 核心知识点

⚠️ **非常重要**：`pickle` **不安全**！绝对不要加载来自**不可信源**的 pickle 文件！

因为反序列化时，pickle 会执行对象中的恶意代码，可能导致你的电脑被控制、数据被窃取。

### 危险示例（不要运行！）

```python
import pickle
import os

# 恶意代码：执行系统命令（比如删除文件、打开计算器）
class Evil:
    def __reduce__(self):
        # 这里的命令会在反序列化时执行！
        return (os.system, ("echo 恶意代码已执行！",))

# 生成恶意 pickle 文件
evil_data = pickle.dumps(Evil())
# 如果有人加载这个 evil_data，就会执行命令！
# pickle.loads(evil_data)
```

### 避坑指南

1. 只加载**自己生成的**、或者**完全信任的** pickle 文件。

2. 如果需要跨网络传输数据，优先用 `json`（安全），不要用 `pickle`。

## 第六部分：常见应用场景

### 1\. 程序状态保存

- 游戏存档（保存玩家等级、装备、进度）。

- 编辑器草稿（保存未完成的文档、画布状态）。

### 2\. 复杂数据缓存

- 机器学习模型训练后，把模型对象存成 pickle 文件，下次直接加载，不用重新训练。

- 爬虫爬取的复杂嵌套数据，暂时存成 pickle，避免重复爬取。

### 3\. 短时间内的 Python 间数据传输

- 同一个项目的不同 Python 脚本之间，传递复杂对象（比如大型字典、类实例）。

## 第七部分：实战案例 —— 简易游戏存档系统

### 功能需求

1. 定义一个 `GamePlayer` 类，包含玩家姓名、等级、金币、背包。

2. 支持**保存存档**：把玩家对象存到 `player\_save\.pkl`。

3. 支持**加载存档**：从文件中读取玩家对象，恢复游戏状态。

4. 支持**显示玩家信息**、**升级**、**添加道具**。

### 完整实战代码

```python
import pickle
from pathlib import Path

class GamePlayer:
    def __init__(self, name):
        self.name = name
        self.level = 1
        self.gold = 100
        self.inventory = ["新手木剑", "布衣"]

    def show_info(self):
        """显示玩家信息"""
        print("\n===== 玩家信息 =====")
        print(f"姓名：{self.name}")
        print(f"等级：{self.level}")
        print(f"金币：{self.gold}")
        print(f"背包：{', '.join(self.inventory)}")

    def level_up(self):
        """升级"""
        self.level += 1
        self.gold += 50
        print(f"\n🎉 恭喜！{self.name} 升到了 {self.level} 级，获得 50 金币！")

    def add_item(self, item):
        """添加道具"""
        self.inventory.append(item)
        print(f"\n🎒 获得道具：{item}")

    def save_game(self, file_path="player_save.pkl"):
        """保存存档"""
        with open(file_path, "wb") as f:
            pickle.dump(self, f)
        print(f"\n💾 存档已保存到 {file_path}")

    @staticmethod
    def load_game(file_path="player_save.pkl"):
        """加载存档"""
        if not Path(file_path).exists():
            print(f"\n❌ 存档文件 {file_path} 不存在，创建新玩家！")
            return None
        with open(file_path, "rb") as f:
            player = pickle.load(f)
        print(f"\n✅ 存档已加载！欢迎回来，{player.name}！")
        return player

# ========== 游戏流程演示 ==========
if __name__ == '__main__':
    # 1. 尝试加载存档
    player = GamePlayer.load_game()

    # 2. 如果没有存档，创建新玩家
    if not player:
        name = input("请输入你的角色名：")
        player = GamePlayer(name)

    # 3. 显示初始信息
    player.show_info()

    # 4. 模拟游戏操作
    player.level_up()
    player.add_item("铁剑")
    player.add_item("血瓶x3")
    player.gold += 100  # 模拟打怪获得金币

    # 5. 显示更新后的信息
    player.show_info()

    # 6. 保存存档
    player.save_game()
```

### 代码讲解

1. **面向对象设计**：把玩家的属性和方法封装在 `GamePlayer` 类里，代码整洁。

2. **静态方法加载存档**：`load\_game` 是静态方法，直接返回玩家对象，方便调用。

3. **存档不存在时创建新玩家**：容错性好，新手也能直接运行。

4. 运行后会生成 `player\_save\.pkl`，下次运行会自动加载上次的进度！

## 课程总结

### 核心知识点回顾

1. **核心功能**：

    - `dumps\(\)`/`loads\(\)`：内存中序列化 / 反序列化。

    - `dump\(\)`/`load\(\)`：文件中序列化 / 反序列化（必须二进制模式）。

2. **优势**：支持几乎所有 Python 对象（包括自定义类实例）。

3. **安全警告**：绝对不要加载不可信的 pickle 文件！

4. **适用场景**：程序状态保存、复杂数据缓存、Python 间数据传输。

### 避坑指南

1. 文件必须用 `wb`/`rb` 二进制模式打开。

2. 反序列化自定义对象时，类定义必须存在。

3. 安全第一，不信任的 pickle 文件别加载！
