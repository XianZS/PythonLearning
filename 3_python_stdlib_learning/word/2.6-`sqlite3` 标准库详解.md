# B 站 Python 授课：`sqlite3` 标准库 —— 零安装的轻量级数据库神器

## 课程导入

在开发中，我们经常需要**持久化存储数据**：比如待办事项、用户信息、游戏存档…… 如果用文件存（如 JSON、CSV），查询和修改起来很麻烦；如果用 MySQL、PostgreSQL，又需要安装服务器、配置环境，对新手不友好。

这时候就需要 **`sqlite3`** 标准库！它是 Python 内置的**轻量级关系型数据库**，**零安装、零配置**，一个文件就是一个数据库，支持标准 SQL 语法，是小型应用、原型开发、桌面软件的首选数据存储方案！

本节课我们从零学习 `sqlite3`，包含连接数据库、创建表、增删改查（CRUD）、进阶技巧，最后还有一个超实用的待办事项实战案例！

## 第一部分：核心概念与基础连接

### 1\. 什么是 SQLite？

- **文件型数据库**：整个数据库就是一个 `\.db` 文件（比如 `mydb\.db`），可以直接复制、移动。

- **零服务器**：不需要安装任何服务器软件，Python 内置支持。

- **标准 SQL**：支持常见的 SQL 语法（SELECT、INSERT、UPDATE、DELETE），学习成本低。

### 2\. 基础操作步骤

1. **连接数据库**：`sqlite3\.connect\(\)`，连接不存在的文件会自动创建。

2. **创建游标**：`cursor\(\)`，用于执行 SQL 语句。

3. **执行 SQL**：`execute\(\)` 或 `executemany\(\)`。

4. **提交事务**：`commit\(\)`，修改数据（增删改）必须提交才会生效。

5. **关闭连接**：`close\(\)`，释放资源。

### 示例代码

```python
import sqlite3

# ====================== 1. 连接数据库 ======================
# 连接到 test.db 文件（如果不存在会自动创建）
# 也可以用 :memory: 创建内存数据库（程序关闭后数据消失）
conn = sqlite3.connect("test.db")

# ====================== 2. 创建游标 ======================
cursor = conn.cursor()

# ====================== 3. 执行 SQL（示例：创建一个测试表） ======================
# 先删除已存在的 test_table（方便重复测试）
cursor.execute("DROP TABLE IF EXISTS test_table")

# 创建表：id（主键，自增）、name（文本）、age（整数）
cursor.execute('''
    CREATE TABLE test_table (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        age INTEGER
    )
''')

# ====================== 4. 提交事务（创建表不需要，但修改数据必须） ======================
conn.commit()

# ====================== 5. 关闭连接 ======================
cursor.close()
conn.close()

print("✅ 数据库连接成功，test_table 已创建！")
```

### 进阶：用 `with` 语句自动管理连接

```python
import sqlite3

# with 语句会自动提交事务（如果没有报错），出错会自动回滚
with sqlite3.connect("test.db") as conn:
    cursor = conn.cursor()
    # 执行 SQL...
    # 不需要手动 commit！with 会自动处理
# 也不需要手动 close！with 会自动关闭
print("✅ with 语句执行完成！")
```

### 内容讲解

- `connect\(\&\#34;test\.db\&\#34;\)`：连接文件数据库，`connect\(\&\#34;:memory:\&\#34;\)` 连接内存数据库（适合临时测试）。

- `PRIMARY KEY AUTOINCREMENT`：主键，自动递增，插入数据时不用手动指定 id。

- `NOT NULL`：表示该字段不能为空，插入数据时必须提供。

## 第二部分：核心操作：增删改查（CRUD）

### 1\. 插入数据（INSERT）

⚠️ **关键**：必须用**参数化查询**（`?` 占位符），**不要用字符串拼接**，防止 SQL 注入！

### 示例代码

```python
import sqlite3

with sqlite3.connect("test.db") as conn:
    cursor = conn.cursor()

    # ====================== 插入单条数据 ======================
    # 方式1：用 ? 占位符，参数是元组
    cursor.execute("INSERT INTO test_table (name, age) VALUES (?, ?)", ("张三", 25))
    
    # 方式2：用命名参数（:name），参数是字典
    cursor.execute("INSERT INTO test_table (name, age) VALUES (:name, :age)", 
                   {"name": "李四", "age": 30})

    # ====================== 批量插入（executemany，比循环高效） ======================
    users = [("王五", 28), ("赵六", 22), ("孙七", 35)]
    cursor.executemany("INSERT INTO test_table (name, age) VALUES (?, ?)", users)

print("✅ 数据插入成功！")
```

### 2\. 查询数据（SELECT）

### 示例代码

```python
import sqlite3

with sqlite3.connect("test.db") as conn:
    cursor = conn.cursor()

    # ====================== 查询所有数据 ======================
    cursor.execute("SELECT * FROM test_table")
    all_users = cursor.fetchall()  # 获取所有结果
    print("所有用户：")
    for user in all_users:
        print(user)  # (id, name, age)

    # ====================== 查询单条数据 ======================
    cursor.execute("SELECT * FROM test_table WHERE id = ?", (1,))
    user1 = cursor.fetchone()  # 获取第一条结果
    print("\nID为1的用户：", user1)

    # ====================== 查询指定字段 ======================
    cursor.execute("SELECT name, age FROM test_table WHERE age > 25")
    older_users = cursor.fetchmany(2)  # 获取前2条结果
    print("\n年龄大于25的前2个用户：")
    for user in older_users:
        print(user)
```

### 3\. 更新数据（UPDATE）

### 示例代码

```python
import sqlite3

with sqlite3.connect("test.db") as conn:
    cursor = conn.cursor()

    # 更新 ID 为 1 的用户的年龄
    cursor.execute("UPDATE test_table SET age = ? WHERE id = ?", (26, 1))
    
    # 检查更新结果
    cursor.execute("SELECT * FROM test_table WHERE id = ?", (1,))
    print("更新后的用户：", cursor.fetchone())

print("✅ 数据更新成功！")
```

### 4\. 删除数据（DELETE）

### 示例代码

```python
import sqlite3

with sqlite3.connect("test.db") as conn:
    cursor = conn.cursor()

    # 删除 ID 为 2 的用户
    cursor.execute("DELETE FROM test_table WHERE id = ?", (2,))
    
    # 检查删除结果
    cursor.execute("SELECT * FROM test_table")
    print("\n删除后的所有用户：")
    for user in cursor.fetchall():
        print(user)

print("✅ 数据删除成功！")
```

### 内容讲解

- **查询结果获取**：

    - `fetchone\(\)`：取一条结果（适合查单条）。

    - `fetchall\(\)`：取所有结果（适合查全部）。

    - `fetchmany\(n\)`：取前 n 条结果（适合分页）。

- **参数化查询**：即使只有一个参数，也要用元组 `\(1,\)`（注意逗号），否则会报错。

## 第三部分：进阶实用技巧

### 1\. 让查询结果返回字典（默认是元组）

默认查询结果是元组，用索引访问不够直观，可以设置 `row\_factory` 让结果返回字典。

### 示例代码

```python
import sqlite3

# 定义一个函数，将元组转为字典
def dict_factory(cursor, row):
    d = {}
    for idx, col in enumerate(cursor.description):
        d[col[0]] = row[idx]
    return d

with sqlite3.connect("test.db") as conn:
    conn.row_factory = dict_factory  # 设置 row_factory
    cursor = conn.cursor()

    cursor.execute("SELECT * FROM test_table")
    all_users = cursor.fetchall()
    print("字典格式的用户：")
    for user in all_users:
        print(f"ID: {user['id']}, 姓名: {user['name']}, 年龄: {user['age']}")
```

### 2\. 获取最后插入的 ID

插入数据后，有时候需要知道刚插入的记录的 ID（比如关联其他表），用 `lastrowid`。

### 示例代码

```python
import sqlite3

with sqlite3.connect("test.db") as conn:
    cursor = conn.cursor()
    cursor.execute("INSERT INTO test_table (name, age) VALUES (?, ?)", ("周八", 27))
    last_id = cursor.lastrowid
    print(f"刚插入的记录 ID：{last_id}")
```

## 第四部分：常见应用场景

## 第五部分：实战案例 —— 简易待办事项管理系统

### 功能需求

1. 创建 `todos` 表，包含 `id`（主键）、`title`（标题）、`completed`（是否完成，0/1）、`create\_time`（创建时间）。

2. 支持**添加待办**。

3. 支持**查看所有待办**（区分已完成 / 未完成）。

4. 支持**标记待办为完成**。

5. 支持**删除待办**。

### 完整实战代码

```python
import sqlite3
from datetime import datetime

class TodoManager:
    def __init__(self, db_path="todos.db"):
        self.db_path = db_path
        self.conn = None
        self.connect()
        self.create_table()

    def connect(self):
        """连接数据库"""
        self.conn = sqlite3.connect(self.db_path)
        # 设置返回字典格式
        self.conn.row_factory = lambda cursor, row: {col[0]: row[idx] for idx, col in enumerate(cursor.description)}

    def create_table(self):
        """创建待办表"""
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute('''
                CREATE TABLE IF NOT EXISTS todos (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    title TEXT NOT NULL,
                    completed INTEGER DEFAULT 0,
                    create_time TEXT NOT NULL
                )
            ''')

    def add_todo(self, title):
        """添加待办"""
        create_time = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute("INSERT INTO todos (title, create_time) VALUES (?, ?)", 
                           (title, create_time))
            print(f"✅ 已添加待办：{title}")

    def list_todos(self):
        """查看所有待办"""
        cursor = self.conn.cursor()
        cursor.execute("SELECT * FROM todos ORDER BY create_time DESC")
        todos = cursor.fetchall()
        
        if not todos:
            print("📭 暂无待办事项")
            return
        
        print("\n===== 待办事项列表 =====")
        for todo in todos:
            status = "✅ 已完成" if todo["completed"] else "⬜ 未完成"
            print(f"[{todo['id']}] {status} | {todo['title']} | 创建时间：{todo['create_time']}")

    def mark_completed(self, todo_id):
        """标记为完成"""
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute("UPDATE todos SET completed = 1 WHERE id = ?", (todo_id,))
            if cursor.rowcount > 0:
                print(f"✅ 已标记 ID 为 {todo_id} 的待办为完成")
            else:
                print(f"❌ 未找到 ID 为 {todo_id} 的待办")

    def delete_todo(self, todo_id):
        """删除待办"""
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute("DELETE FROM todos WHERE id = ?", (todo_id,))
            if cursor.rowcount > 0:
                print(f"✅ 已删除 ID 为 {todo_id} 的待办")
            else:
                print(f"❌ 未找到 ID 为 {todo_id} 的待办")

    def close(self):
        """关闭连接"""
        if self.conn:
            self.conn.close()

# ========== 测试使用 ==========
if __name__ == '__main__':
    manager = TodoManager()

    # 添加待办
    manager.add_todo("学习 SQLite3")
    manager.add_todo("完成实战案例")
    manager.add_todo("整理笔记")

    # 查看所有待办
    manager.list_todos()

    # 标记完成
    manager.mark_completed(1)

    # 再次查看
    manager.list_todos()

    # 删除待办
    manager.delete_todo(3)

    # 最终查看
    manager.list_todos()

    manager.close()
```

### 代码讲解

1. **面向对象封装**：把所有待办操作封装在 `TodoManager` 类里，代码整洁、复用性强。

2. **字典格式结果**：用 `row\_factory` 让查询结果返回字典，通过键名访问更直观。

3. **时间记录**：添加待办时自动记录创建时间，用 `datetime` 生成格式化时间。

4. **事务自动管理**：用 `with self\.conn` 自动提交事务，代码更安全。

5. 运行后会生成 `todos\.db`，可以重复添加、标记、删除待办！

## 课程总结

### 核心知识点回顾

1. **基础步骤**：`connect\(\)` → `cursor\(\)` → `execute\(\)` → `commit\(\)` → `close\(\)`。

2. **CRUD 操作**：

    - 增：`INSERT`，用 `executemany` 批量插入。

    - 删：`DELETE`。

    - 改：`UPDATE`。

    - 查：`SELECT`，用 `fetchone\(\)`/`fetchall\(\)`/`fetchmany\(\)` 获取结果。

3. **安全**：必须用参数化查询（`?` 占位符），防止 SQL 注入。

4. **进阶**：`row\_factory` 返回字典，`lastrowid` 获取最后插入的 ID。

### 避坑指南

1. 修改数据（增删改）必须 `commit\(\)`，否则数据不会保存（用 `with` 语句可以自动提交）。

2. 参数化查询的参数必须是元组，单个参数要加逗号 `\(1,\)`。

3. SQLite 是动态类型，但建议还是按规范定义字段类型。
