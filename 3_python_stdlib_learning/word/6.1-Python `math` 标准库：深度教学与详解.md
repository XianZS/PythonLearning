# Python `math` 标准库详细教学文档

## 一、基础概念

`math` 是 Python 内置的标准库，提供了对 C 标准库中数学函数的封装，主要用于处理**浮点数**的数学运算（复数运算需使用 `cmath` 库）。

### 核心注意事项

1. 所有三角函数默认使用**弧度制**；

2. 大多数函数返回 `float` 类型（阶乘、组合数等特殊函数返回 `int`）；

3. 不支持复数输入，否则会抛出 `TypeError`。

### 导入方式

```python
import math  # 推荐：避免命名冲突
# 或
from math import pi, sqrt  # 按需导入
```

## 二、常见基础用法

### 1. 数学常量

|常量|说明|示例值（近似）|
|---|---|---|
|`math.pi`|圆周率 π|3.1415926535|
|`math.e`|自然对数底数 e|2.7182818284|
|`math.tau`|2π（Python 3.6+ 新增）|6.2831853071|
|`math.inf`|正无穷大|inf|
|`math.nan`|非数字（Not a Number）|nan|

**示例代码**：

```python
print("π ≈", math.pi)       # 输出: π ≈ 3.141592653589793
print("e ≈", math.e)        # 输出: e ≈ 2.718281828459045
print("τ ≈", math.tau)      # 输出: τ ≈ 6.283185307179586
print(math.inf > 1e100)     # 输出: True
print(math.nan == math.nan) # 输出: False（nan 与任何值都不相等）
```

### 2. 基本数值运算

|函数|说明|
|---|---|
|`math.ceil(x)`|向上取整（返回 ≥ x 的最小整数）|
|`math.floor(x)`|向下取整（返回 ≤ x 的最大整数）|
|`math.trunc(x)`|截断整数部分（直接去掉小数）|
|`math.fabs(x)`|绝对值（返回浮点数）|
|`math.fmod(x, y)`|浮点数取模（x % y 的浮点数版本）|
|`math.pow(x, y)`|x 的 y 次方（返回浮点数）|
|`math.sqrt(x)`|平方根（x ≥ 0）|
|`math.exp(x)`|e 的 x 次方|
|`math.log(x, base)`|对数（base 默认为 e）|
|`math.log10(x)`|以 10 为底的对数|
|`math.log2(x)`|以 2 为底的对数（Python 3.3+ 新增）|

**示例代码**：

```python
x = 3.7
print(math.ceil(x))   # 输出: 4
print(math.floor(x))  # 输出: 3
print(math.trunc(x))  # 输出: 3

print(math.fabs(-5.2))       # 输出: 5.2
print(math.fmod(7, 3))       # 输出: 1.0（7 = 3*2 + 1）
print(math.pow(2, 3))        # 输出: 8.0
print(math.sqrt(16))         # 输出: 4.0
print(math.exp(1))           # 输出: 2.718281828459045
print(math.log(100, 10))     # 输出: 2.0
print(math.log2(8))          # 输出: 3.0
```

### 3. 三角函数（弧度制）

|函数|说明|
|---|---|
|`math.sin(x)`|正弦函数|
|`math.cos(x)`|余弦函数|
|`math.tan(x)`|正切函数|
|`math.asin(x)`|反正弦函数（返回 [-π/2, π/2]）|
|`math.acos(x)`|反余弦函数（返回 [0, π]）|
|`math.atan(x)`|反正切函数（返回 [-π/2, π/2]）|
|`math.atan2(y, x)`|反正切函数（考虑象限，返回 [-π, π]）|
|`math.degrees(x)`|弧度转角度|
|`math.radians(x)`|角度转弧度|

**示例代码**：

```python
# 角度转弧度
angle_deg = 30
angle_rad = math.radians(angle_deg)
print(f"{angle_deg}° = {angle_rad} 弧度")  # 输出: 30° = 0.5235987755982988 弧度

# 三角函数计算
print(math.sin(angle_rad))  # 输出: 0.49999999999999994（≈ 0.5）
print(math.cos(angle_rad))  # 输出: 0.8660254037844387（≈ √3/2）
print(math.tan(angle_rad))  # 输出: 0.5773502691896257（≈ 1/√3）

# 反三角函数
print(math.degrees(math.asin(0.5)))  # 输出: 30.0
print(math.degrees(math.atan2(1, 1)))# 输出: 45.0（点 (1,1) 与 x 轴夹角）
```

## 三、常见进阶用法

### 1. 特殊函数

|函数|说明|版本要求|
|---|---|---|
|`math.erf(x)`|误差函数（统计学常用）|-|
|`math.erfc(x)`|补误差函数（1 - erf (x)）|-|
|`math.gamma(x)`|伽马函数（阶乘的扩展）|-|
|`math.lgamma(x)`|伽马函数的自然对数|-|
|`math.factorial(x)`|阶乘（x 为非负整数）|-|
|`math.comb(n, k)`|组合数 C (n, k) = n!/(k!(n-k)!)|Python 3.10+|
|`math.perm(n, k=None)`|排列数 P (n, k) = n!/(n-k)!（k=None 时为 n!）|Python 3.10+|
|`math.gcd(a, b)`|最大公约数（a, b 为非负整数）|Python 3.5+|
|`math.lcm(a, b)`|最小公倍数（a, b 为非负整数）|Python 3.9+|

**示例代码**：

```python
# 阶乘、组合数、排列数
print(math.factorial(5))        # 输出: 120
print(math.comb(5, 2))          # 输出: 10（从5个中选2个的组合数）
print(math.perm(5, 2))          # 输出: 20（从5个中选2个的排列数）

# 最大公约数、最小公倍数
print(math.gcd(12, 18))         # 输出: 6
print(math.lcm(12, 18))         # 输出: 36

# 误差函数（示例：统计学中计算正态分布概率）
print(math.erf(1 / math.sqrt(2)))  # 输出: 0.6826894921370859（≈ 68.27%）
```

### 2. 浮点数处理与工具函数

|函数|说明|版本要求|
|---|---|---|
|`math.isinf(x)`|判断是否为无穷大|-|
|`math.isnan(x)`|判断是否为 NaN|-|
|`math.isfinite(x)`|判断是否为有限数（非 inf 非 nan）|-|
|`math.isclose(a, b, ...)`|判断两个浮点数是否 “接近”（避免精度误差）|Python 3.5+|
|`math.copysign(x, y)`|返回 x 的绝对值，符号与 y 相同|-|
|`math.frexp(x)`|分解为 (尾数，指数)，x = 尾数 * 2^ 指数|-|
|`math.ldexp(x, i)`|计算 x * (2^i)|-|
|`math.modf(x)`|返回 (小数部分，整数部分)|-|
|`math.fsum(iterable)`|精确浮点数求和（比内置 sum 更准）|-|
|`math.nextafter(x, y)`|返回 x 向 y 方向的下一个浮点数|Python 3.9+|
|`math.ulp(x)`|返回 x 的最小精度单位（Unit in the Last Place）|Python 3.9+|
|`math.sumprod(p, q)`|点积计算：sum (p [i] * q [i] for i)|Python 3.12+|

**示例代码**：

```python
# 浮点数精度判断
a = 0.1 + 0.2
b = 0.3
print(a == b)                  # 输出: False（浮点数精度误差）
print(math.isclose(a, b))      # 输出: True（默认容差 1e-09）

# 精确求和
nums = [0.1] * 10
print(sum(nums))               # 输出: 0.9999999999999999
print(math.fsum(nums))         # 输出: 1.0

# 浮点数分解
x = 10.5
frac, int_part = math.modf(x)
print(f"小数部分: {frac}, 整数部分: {int_part}")  # 输出: 小数部分: 0.5, 整数部分: 10.0

mantissa, exponent = math.frexp(x)
print(f"{x} = {mantissa} * 2^{exponent}")  # 输出: 10.5 = 0.65625 * 2^4

# 点积（Python 3.12+）
# print(math.sumprod([1, 2, 3], [4, 5, 6]))  # 输出: 32（1*4 + 2*5 + 3*6）
```

## 四、实战案例：几何计算工具箱

实现一个包含常用几何计算功能的小工具，综合运用 `math` 库的多个函数。

### 功能需求

1. 计算两点间的欧几里得距离；

2. 计算圆的面积和周长；

3. 用海伦公式计算三角形面积；

4. 计算两点相对于原点的夹角。

### 完整代码

```python
import math

class GeometryToolkit:
    @staticmethod
    def distance(x1: float, y1: float, x2: float, y2: float) -> float:
        """计算两点 (x1,y1) 和 (x2,y2) 之间的欧几里得距离"""
        return math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
    
    @staticmethod
    def circle(radius: float) -> tuple[float, float]:
        """计算圆的面积和周长，返回 (area, perimeter)"""
        if radius < 0:
            raise ValueError("半径不能为负数")
        area = math.pi * radius**2
        perimeter = 2 * math.pi * radius
        return area, perimeter
    
    @staticmethod
    def triangle_area(a: float, b: float, c: float) -> float:
        """用海伦公式计算三角形面积，a, b, c 为三边长"""
        # 检查是否能构成三角形
        if a <= 0 or b <= 0 or c <= 0:
            raise ValueError("边长必须为正数")
        if a + b <= c or a + c <= b or b + c <= a:
            raise ValueError("两边之和必须大于第三边")
        
        s = (a + b + c) / 2  # 半周长
        return math.sqrt(s * (s - a) * (s - b) * (s - c))
    
    @staticmethod
    def angle_between(x1: float, y1: float, x2: float, y2: float) -> tuple[float, float]:
        """计算两点 (x1,y1) 和 (x2,y2) 相对于原点的夹角，返回 (弧度, 角度)"""
        angle1 = math.atan2(y1, x1)
        angle2 = math.atan2(y2, x2)
        angle_rad = angle2 - angle1
        # 归一化到 [-π, π]
        angle_rad = math.atan2(math.sin(angle_rad), math.cos(angle_rad))
        angle_deg = math.degrees(angle_rad)
        return angle_rad, angle_deg


# ---------------------- 测试案例 ----------------------
if __name__ == "__main__":
    toolkit = GeometryToolkit()
    
    # 1. 计算两点距离
    dist = toolkit.distance(0, 0, 3, 4)
    print(f"两点 (0,0) 到 (3,4) 的距离: {dist}")  # 输出: 5.0
    
    # 2. 计算圆的面积和周长
    radius = 5
    area, perimeter = toolkit.circle(radius)
    print(f"半径为 {radius} 的圆: 面积 ≈ {area:.2f}, 周长 ≈ {perimeter:.2f}")
    # 输出: 半径为 5 的圆: 面积 ≈ 78.54, 周长 ≈ 31.42
    
    # 3. 计算三角形面积（海伦公式）
    try:
        tri_area = toolkit.triangle_area(3, 4, 5)
        print(f"边长为 3,4,5 的三角形面积: {tri_area}")  # 输出: 6.0
    except ValueError as e:
        print(f"三角形计算错误: {e}")
    
    # 4. 计算两点夹角
    angle_rad, angle_deg = toolkit.angle_between(1, 0, 0, 1)
    print(f"点 (1,0) 到 (0,1) 的夹角: {angle_rad:.2f} 弧度 ≈ {angle_deg:.1f}°")
    # 输出: 点 (1,0) 到 (0,1) 的夹角: 1.57 弧度 ≈ 90.0°
```

## 五、总结

- `math` 库是 Python 处理数学运算的基础工具，覆盖了从基础运算到高级特殊函数的功能；

- 使用时注意浮点数精度问题，可通过 `math.isclose()` 或 `math.fsum()` 缓解；

- 关注版本新增功能（如 `math.comb`、`math.lcm`、`math.sumprod` 等），确保代码兼容性。
