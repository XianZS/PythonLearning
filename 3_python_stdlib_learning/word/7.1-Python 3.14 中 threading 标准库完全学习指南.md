# `threading` 标准库完全学习指南

## 一、概念：线程与 `threading` 基础

### 1. 线程与进程的区别

- **进程**：操作系统分配资源的最小单位，每个进程有独立的内存空间。

- **线程**：CPU 调度的最小单位，是进程内的执行流，同一进程的多个线程共享内存空间。

### 2. Python 中的 GIL（全局解释器锁-互斥锁）

CPython 解释器中存在 **GIL**，同一时刻只有一个线程能执行 Python 字节码。这意味着：

- **CPU 密集型任务**（如复杂计算）：多线程无法实现真正并行，甚至可能因线程切换开销变慢，建议用 `multiprocessing`。

- **I/O 密集型任务**（如网络请求、文件读写）：I/O 操作会释放 GIL，多线程可显著提升效率，这是 `threading` 的核心适用场景。

### 3. `threading` 模块定位

`threading` 是 Python 标准库中用于**多线程编程**的高层接口，提供了线程创建、同步、通信等完整功能。

## 二、基础部分：核心用法

### 1. 线程创建的两种方式

#### 方式 1：直接实例化 `Thread` 类（推荐，简单场景）

```python
import threading
import time

def task(name, delay):
    """线程执行的任务"""
    print(f"线程 {name} 启动")
    time.sleep(delay)  # 模拟 I/O 操作
    print(f"线程 {name} 结束（耗时 {delay}s）")

# 创建线程：target 是任务函数，args 是参数元组
t1 = threading.Thread(target=task, args=("A", 2))
t2 = threading.Thread(target=task, args=("B", 1))

# 启动线程（调用 start() 后才会真正执行）
t1.start()
t2.start()

# 等待线程结束（join() 会阻塞主线程，直到子线程执行完毕）
t1.join()
t2.join()

print("所有线程执行完毕")
```

#### 方式 2：继承 `Thread` 类，重写 `run()` 方法（复杂场景）

```python
class MyThread(threading.Thread):
    def __init__(self, name, delay):
        super().__init__()  # 必须调用父类构造函数
        self.name = name
        self.delay = delay

    def run(self):
        """线程执行的逻辑（start() 会自动调用 run()）"""
        print(f"线程 {self.name} 启动")
        time.sleep(self.delay)
        print(f"线程 {self.name} 结束")

t1 = MyThread("A", 2)
t2 = MyThread("B", 1)
t1.start()
t2.start()
t1.join()
t2.join()
```

### 2. 核心基础属性与方法

|属性 / 方法|说明|
|---|---|
|`threading.current_thread()`|获取当前执行的线程对象|
|`threading.active_count()`|获取当前活跃的线程数量|
|`thread.name`|线程名（可通过构造函数或 `name` 参数设置）|
|`thread.is_alive()`|判断线程是否仍在运行|

## 三、进阶部分：深度技巧与线程同步

多线程的核心问题是**共享资源竞争**，需通过同步机制保证数据一致性。

### 1. 互斥锁 `Lock`：解决资源竞争

```python
import threading

# 共享资源
count = 0
# 创建互斥锁
lock = threading.Lock()

def add():
    global count
    for _ in range(1000000):
        # 获取锁（with 语句会自动释放锁，避免死锁）
        with lock:
            count += 1

t1 = threading.Thread(target=add)
t2 = threading.Thread(target=add)
t1.start()
t2.start()
t1.join()
t2.join()

print(f"最终 count: {count}")  # 无锁时结果可能小于 2000000，加锁后正确
```

### 2. 可重入锁 `RLock`：同一线程可多次获取

`RLock` 允许同一线程多次获取锁（需对应多次释放），适合嵌套调用场景：

```python
rlock = threading.RLock()

def func1():
    with rlock:
        print("func1 获取锁")
        func2()  # 嵌套调用，再次获取锁

def func2():
    with rlock:
        print("func2 获取锁")

t = threading.Thread(target=func1)
t.start()
t.join()
```

### 3. 条件变量 `Condition`：线程间通信

用于 “生产者 - 消费者” 场景，线程可等待条件满足后再执行：

```python
import threading
import queue
import time

# 任务队列（最大容量 5）
task_queue = queue.Queue(maxsize=5)
# 创建条件变量（关联锁）
cond = threading.Condition()

def producer():
    """生产者：生产任务"""
    for i in range(10):
        with cond:
            # 队列满时等待消费者通知
            while task_queue.full():
                cond.wait()
            task_queue.put(i)
            print(f"生产者生产任务 {i}")
            cond.notify()  # 通知消费者
        time.sleep(0.5)

def consumer():
    """消费者：消费任务"""
    for i in range(10):
        with cond:
            # 队列空时等待生产者通知
            while task_queue.empty():
                cond.wait()
            task = task_queue.get()
            print(f"消费者消费任务 {task}")
            cond.notify()  # 通知生产者
        time.sleep(1)

t_prod = threading.Thread(target=producer)
t_cons = threading.Thread(target=consumer)
t_prod.start()
t_cons.start()
t_prod.join()
t_cons.join()
```

### 4. 信号量 `Semaphore`：控制并发数量

限制同时执行的线程数（如数据库连接池）：

```python
import threading
import time

# 允许最多 3 个线程同时执行
sem = threading.Semaphore(3)

def task(name):
    with sem:
        print(f"线程 {name} 获得许可，开始执行")
        time.sleep(2)
        print(f"线程 {name} 执行完毕")

threads = [threading.Thread(target=task, args=(i,)) for i in range(5)]
for t in threads:
    t.start()
for t in threads:
    t.join()
```

### 5. 守护线程 `daemon`：随主线程自动退出

守护线程会在主线程结束时自动终止（适合后台任务）：

```python
import threading
import time

def daemon_task():
    while True:
        print("守护线程运行中...")
        time.sleep(1)

# 设置为守护线程（必须在 start() 前设置）
t = threading.Thread(target=daemon_task, daemon=True)
t.start()

time.sleep(3)
print("主线程结束，守护线程将自动退出")
```

### 6. 线程异常处理

子线程的异常默认不会传播到主线程，需在 `run()` 中捕获：

```python
class MyThread(threading.Thread):
    def run(self):
        try:
            print("线程开始执行")
            1 / 0  # 模拟异常
        except Exception as e:
            print(f"线程捕获异常: {e}")

t = MyThread()
t.start()
t.join()
print("主线程继续执行")
```

## 四、实战案例：多线程图片下载器

### 需求

实现一个多线程图片下载器，利用 `threading` 提升网络 I/O 效率，结合 `Queue` 管理任务、`Lock` 保证打印安全。

### 代码实现

```python
import threading
import requests
import os
from queue import Queue

# ---------------------- 配置 ----------------------
# 示例图片 URL 列表（可替换为实际 URL）
IMAGE_URLS = [
    "https://picsum.photos/200/300?random=1",
    "https://picsum.photos/200/300?random=2",
    "https://picsum.photos/200/300?random=3",
    "https://picsum.photos/200/300?random=4",
    "https://picsum.photos/200/300?random=5",
]
# 下载线程数
THREAD_COUNT = 3
# 保存目录
SAVE_DIR = "downloaded_images"
os.makedirs(SAVE_DIR, exist_ok=True)

# ---------------------- 初始化 ----------------------
# 任务队列：存储待下载的 URL
url_queue = Queue()
for url in IMAGE_URLS:
    url_queue.put(url)

# 打印锁：避免多线程打印混乱
print_lock = threading.Lock()

# ---------------------- 下载任务 ----------------------
def download_worker(thread_name):
    while not url_queue.empty():
        url = url_queue.get()
        try:
            # 打印下载开始
            with print_lock:
                print(f"[{thread_name}] 开始下载: {url}")
            
            # 发送请求（模拟 I/O 操作）
            response = requests.get(url, timeout=10)
            response.raise_for_status()  # 检查请求是否成功
            
            # 保存图片
            filename = f"image_{hash(url) % 10000}.jpg"
            save_path = os.path.join(SAVE_DIR, filename)
            with open(save_path, "wb") as f:
                f.write(response.content)
            
            # 打印下载完成
            with print_lock:
                print(f"[{thread_name}] 下载完成: {filename}")
        
        except Exception as e:
            with print_lock:
                print(f"[{thread_name}] 下载失败 {url}: {str(e)}")
        
        finally:
            # 标记任务完成（队列计数减 1）
            url_queue.task_done()

# ---------------------- 启动线程 ----------------------
print(f"启动 {THREAD_COUNT} 个下载线程，共 {len(IMAGE_URLS)} 张图片n")
threads = []
for i in range(THREAD_COUNT):
    t = threading.Thread(
        target=download_worker,
        args=(f"线程-{i+1}",)
    )
    threads.append(t)
    t.start()

# 等待队列中所有任务完成
url_queue.join()
print("n所有图片下载完成！")
```

## 五、总结

1. **适用场景**：`threading` 适合 **I/O 密集型任务**，CPU 密集型任务建议用 `multiprocessing`。

2. **核心要点**：

    - 线程创建用 `Thread` 类，启动用 `start()`，等待用 `join()`。

    - 共享资源竞争用 `Lock`/`RLock`，线程通信用 `Condition`，并发控制用 `Semaphore`。

    - 子线程异常需在内部捕获，守护线程随主线程自动退出。
