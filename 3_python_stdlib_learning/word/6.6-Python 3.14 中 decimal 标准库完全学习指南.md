# Python 3.14 `decimal` 标准库完全学习指南

## 一、概念：为什么需要 `decimal`？

计算机中二进制浮点数（`float`）存在**十进制精度丢失**问题 —— 例如 `0.1 + 0.2` 在 Python 中结果是 `0.30000000000000004`，这对金融、会计、税务等需要**绝对精确十进制计算**的场景是致命的。

`decimal` 是 Python 标准库中用于**十进制浮点运算**的模块，核心优势：

- 以十进制为基础进行计算，完全模拟人类的数学运算逻辑；

- 精度可由用户自定义（而非固定的二进制位数）；

- 支持明确的舍入规则（如 “四舍五入”“向下取整” 等）；

- 提供信号处理机制（如除零、无效操作的可控处理）。

适用场景：金融计算、货币交易、科学实验数据处理、会计系统等。

## 二、基础部分：核心用法

### 1. 导入与基本构造

```python
from decimal import Decimal, getcontext, ROUND_HALF_UP
```

Python 3.14 中，`Decimal` 支持以下 4 种核心构造方式（**强烈推荐用字符串构造**）：

|构造方式|示例|结果说明|
|---|---|---|
|字符串（推荐）|`Decimal(&#39;0.1&#39;) + Decimal(&#39;0.2&#39;)`|精确得到 `Decimal(&#39;0.3&#39;)`，无精度丢失|
|整数|`Decimal(100)`|等价于 `Decimal(&#39;100&#39;)`|
|浮点数（不推荐）|`Decimal(0.1)`|会保留浮点数的二进制误差，得到长小数|
|元组（高级）|`Decimal((0, (1, 2, 3), -2))`|表示 `1.23`（符号 0 正 / 1 负，数字元组，指数）|

### 2. 核心上下文控制：`getcontext()`

`decimal` 通过 “上下文”（Context）管理全局精度、舍入规则等设置：

```python
# 查看当前上下文
print(getcontext())

# 设置全局有效数字精度（注意：是有效数字，不是小数位数！）
getcontext().prec = 4  # 后续计算保留4位有效数字

# 设置全局舍入模式（此处为“四舍五入”）
getcontext().rounding = ROUND_HALF_UP
```

常见舍入模式：

- `ROUND_HALF_UP`：四舍五入（最常用）；

- `ROUND_FLOOR`：向下取整；

- `ROUND_CEILING`：向上取整；

- `ROUND_HALF_EVEN`：银行家舍入（四舍六入五成双）。

### 3. 基本运算与比较

`Decimal` 支持所有常规数学运算，结果受上下文精度控制：

```python
a = Decimal('1')
b = Decimal('3')

print(a + b)  # 4
print(a - b)  # -2
print(a * b)  # 3
print(a / b)  # 0.3333（受 prec=4 影响）

# 比较运算（值相等即 True，与小数位数无关）
print(Decimal('0.3') == Decimal('0.30'))  # True
print(Decimal('0.5') > Decimal('0.499'))   # True
```

## 三、进阶部分：深度技巧

### 1. 临时上下文管理：`localcontext()`

如果只想在局部修改精度 / 舍入规则，用 `localcontext()` 实现 “临时生效，用完即恢复”：

```python
from decimal import localcontext

print("全局精度下的计算:", Decimal('1') / Decimal('3'))  # 0.3333

with localcontext() as ctx:
    ctx.prec = 2  # 临时设置精度为2位有效数字
    print("临时精度下的计算:", Decimal('1') / Decimal('3'))  # 0.33

print("恢复全局精度后的计算:", Decimal('1') / Decimal('3'))  # 0.3333
```

### 2. 固定小数位：`quantize()`（金融场景核心）

金融计算通常需要**固定小数位数**（如人民币保留 2 位），用 `quantize()` 实现：

```python
# 格式：Decimal.quantize(目标小数位模板, 舍入模式)
amount = Decimal('123.456')

# 保留2位小数，四舍五入
print(amount.quantize(Decimal('0.00'), rounding=ROUND_HALF_UP))  # 123.46

# 保留到整数位
print(amount.quantize(Decimal('1'), rounding=ROUND_HALF_UP))  # 123
```

### 3. 信号与异常处理

`decimal` 支持对 “除零”“无效操作” 等异常进行**可控处理**（默认抛出异常，可改为返回特殊值）：

```python
from decimal import DivisionByZero, InvalidOperation

# 关闭“除零”异常，改为返回 Infinity
getcontext().traps[DivisionByZero] = False
print(Decimal('1') / Decimal('0'))  # Infinity

# 关闭“无效操作”异常（如 0/0），改为返回 NaN
getcontext().traps[InvalidOperation] = False
print(Decimal('0') / Decimal('0'))  # NaN
```

### 4. 数学函数与特殊值

`Decimal` 内置常用数学函数，精度受上下文控制：

```python
print(Decimal('4').sqrt())       # 2（平方根）
print(Decimal('2').exp())        # 7.389（自然指数，受 prec 影响）
print(Decimal('100').log10())    # 2（常用对数）
```

特殊值处理：

- `Decimal(&#39;Infinity&#39;)`：正无穷；

- `Decimal(&#39;-Infinity&#39;)`：负无穷；

- `Decimal(&#39;NaN&#39;)`：Not a Number（注意：`NaN` 不等于任何值，包括自己）。

## 四、实战案例：电商购物车精确结账系统

### 需求

实现一个电商购物车结账功能，要求：

1. 精确计算商品总价、折扣、税费（9%）；

2. 所有金额保留 2 位小数，四舍五入；

3. 支持 “满 100 减 10” 的满减折扣。

### 代码实现

```python
from decimal import Decimal, getcontext, ROUND_HALF_UP

# 全局配置：精度设为10（足够处理中间计算），舍入模式为四舍五入
getcontext().prec = 10
getcontext().rounding = ROUND_HALF_UP


def precise_checkout(cart, discount_threshold=100, discount_amount=10, tax_rate=Decimal('0.09')):
    """
    精确结账函数
    :param cart: 购物车列表，格式 [(商品名, 单价字符串, 数量), ...]
    :param discount_threshold: 满减门槛
    :param discount_amount: 满减金额
    :param tax_rate: 税率
    :return: 最终应付金额（保留2位小数）
    """
    # 1. 计算每个商品的小计
    print("=== 商品明细 ===")
    subtotals = []
    for name, price_str, quantity in cart:
        price = Decimal(price_str)
        subtotal = price * quantity
        subtotals.append(subtotal)
        print(f"{name}: {price} × {quantity} = {subtotal.quantize(Decimal('0.00'))}")

    # 2. 计算商品总价
    total = sum(subtotals)
    print(f"n商品总价: {total.quantize(Decimal('0.00'))}")

    # 3. 应用满减折扣
    if total >= discount_threshold:
        discounted_total = total - discount_amount
        print(f"满足满减条件！立减 {discount_amount}，折扣后: {discounted_total.quantize(Decimal('0.00'))}")
    else:
        discounted_total = total
        print(f"不满足满减条件（需满 {discount_threshold}）")

    # 4. 计算税费
    tax = discounted_total * tax_rate
    print(f"税费（{tax_rate * 100}%）: {tax.quantize(Decimal('0.00'))}")

    # 5. 计算最终应付金额
    final_amount = discounted_total + tax
    final_rounded = final_amount.quantize(Decimal('0.00'))
    print(f"n最终应付: {final_rounded}")
    return final_rounded


# 测试购物车
if __name__ == "__main__":
    cart_example = [
        ("无线鼠标", "89.90", 1),
        ("鼠标垫", "12.50", 2),
        ("USB分线器", "25.80", 1)
    ]
    precise_checkout(cart_example)
```

### 运行结果

```Plain Text

无线鼠标: 89.90 × 1 = 89.90
鼠标垫: 12.50 × 2 = 25.00
USB分线器: 25.80 × 1 = 25.80

商品总价: 140.70
满足满减条件！立减 10，折扣后: 130.70
税费（9.0%）: 11.76

最终应付: 142.46
```

## 五、总结

`decimal` 是 Python 中处理**精确十进制计算**的首选模块，Python 3.14 进一步优化了其性能和稳定性。核心要点：

- 始终用**字符串**构造 `Decimal`，避免浮点数精度污染；

- 区分 “有效数字精度（`prec`）” 和 “固定小数位（`quantize`）”；

- 金融场景优先用 `quantize()` 控制小数位，配合 `ROUND_HALF_UP` 舍入。
