# Python `re` 标准库教学文档

## 一、基础概念与使用场景

### 1\. 基础概念

正则表达式（Regular Expression，简称 regex）是一种用于**描述字符串匹配规则**的符号语言，而 `re` 是 Python 标准库中专门处理正则表达式的核心模块，提供了字符串匹配、提取、替换、分割等功能，是文本处理的“精准手术刀”。

其核心逻辑是：用特殊符号（如 `\\d` 匹配数字、`\*` 匹配多次、`^` 匹配开头）组合成“模式字符串”，再用该模式去匹配目标文本，实现复杂的文本操作。

### 2\. 使用场景

- **表单验证**：校验邮箱、手机号、身份证号、密码强度等；

- **日志分析**：从海量日志中提取 IP、时间、状态码、错误信息等；

- **网络爬虫**：从 HTML/XML 中提取链接、标题、数据字段等；

- **文本清洗**：去除多余空白、敏感词替换、格式统一；

- **数据提取**：从非结构化文本（如合同、报告）中抽取关键信息。

## 二、基础用法

### 2\.1 `re\.match\(\)`：从字符串开头匹配

从目标字符串的**起始位置**开始匹配模式，仅匹配开头，匹配成功返回 `Match` 对象，失败返回 `None`。

#### 语法规范

```Python
re.match(pattern, string, flags=0)
```

- `pattern`：正则表达式模式字符串；

- `string`：待匹配的目标字符串；

- `flags`：可选，匹配修饰符（如 `re\.I` 忽略大小写）。

#### 示例代码

```Python
import re

# 匹配开头是否为"Python"
text1 = "Python is great"
text2 = "I love Python"

match1 = re.match(r"Python", text1)
match2 = re.match(r"Python", text2)

print("match1结果:", match1)  # 输出: <re.Match object; span=(0, 6), match='Python'>
print("match2结果:", match2)  # 输出: None

# 若匹配成功，可通过group()获取匹配内容
if match1:
    print("匹配到的内容:", match1.group())  # 输出: Python
```

### 2\.2 `re\.search\(\)`：搜索第一个匹配项

在整个字符串中**搜索第一个**匹配模式的位置，匹配成功返回 `Match` 对象，失败返回 `None`（不限制开头）。

#### 语法规范

```Python
re.search(pattern, string, flags=0)
```

#### 示例代码

```Python
import re

# 搜索字符串中的数字
text = "我的手机号是13812345678，QQ号是123456789"

# 匹配11位数字（手机号）
match = re.search(r"\d{11}", text)

if match:
    print("找到匹配:", match.group())  # 输出: 13812345678
    print("匹配位置:", match.span())   # 输出: (7, 18)
```

### 2\.3 `re\.findall\(\)`：查找所有匹配项

返回字符串中**所有与模式匹配的子串**，结果为列表（无匹配则返回空列表）。

#### 语法规范

```Python
re.findall(pattern, string, flags=0)
```

#### 示例代码

```Python
import re

# 提取所有邮箱地址
text = "联系我们：support@example.com 或 sales@company.org"

# 邮箱正则模式（简化版）
pattern = r"\w+@\w+\.\w+"
emails = re.findall(pattern, text)

print("提取到的邮箱:", emails)  # 输出: ['support@example.com', 'sales@company.org']
```

### 2\.4 `re\.finditer\(\)`：查找所有匹配项（迭代器）

与 `findall\(\)` 类似，但返回的是**迭代器**，每个元素是 `Match` 对象（适合处理大量匹配结果，节省内存）。

#### 语法规范

```Python
re.finditer(pattern, string, flags=0)
```

#### 示例代码

```Python
import re

# 提取所有数字并展示位置
text = "商品价格：苹果15元，香蕉8元，橙子20元"

pattern = r"\d+"
for match in re.finditer(pattern, text):
    print(f"匹配内容: {match.group()}, 位置: {match.span()}")
```

**输出结果**：

```Plaintext
匹配内容: 15, 位置: (8, 10)
匹配内容: 8, 位置: (15, 16)
匹配内容: 20, 位置: (21, 23)
```

### 2\.5 `re\.sub\(\)`：替换匹配项

将字符串中**所有匹配模式的子串**替换为指定内容，返回替换后的新字符串。

#### 语法规范

```Python
re.sub(pattern, repl, string, count=0, flags=0)
```

- `repl`：替换的内容（可以是字符串或函数）；

- `count`：可选，替换的最大次数（默认0，替换所有）。

#### 示例代码

```Python
import re

# 1. 简单替换：将数字替换为"*"
text1 = "手机号：13812345678，身份证号：110101199001011234"
result1 = re.sub(r"\d", "*", text1)
print("简单替换结果:", result1)
# 输出: 手机号：***********，身份证号：******************

# 2. 函数替换：将价格翻倍
text2 = "苹果15元，香蕉8元"
def double_price(match):
    price = int(match.group())
    return str(price * 2)

result2 = re.sub(r"\d+", double_price, text2)
print("函数替换结果:", result2)  # 输出: 苹果30元，香蕉16元
```

### 2\.6 `re\.split\(\)`：按模式分割字符串

根据正则表达式模式**分割字符串**，返回分割后的列表（类似 `str\.split\(\)`，但支持复杂分隔符）。

#### 语法规范

```Python
re.split(pattern, string, maxsplit=0, flags=0)
```

- `maxsplit`：可选，最大分割次数（默认0，分割所有）。

#### 示例代码

```Python
import re

# 按多种分隔符分割（逗号、分号、空格）
text = "a,b;c d,e;;f"
result = re.split(r"[,; ]+", text)  # +表示匹配1次或多次分隔符
print("分割结果:", result)  # 输出: ['a', 'b', 'c', 'd', 'e', 'f']
```

### 2\.7 `re\.compile\(\)`：预编译正则模式

将正则表达式模式**预编译为 ****`Pattern`**** 对象**，适合多次使用同一模式的场景（提升性能）。

#### 语法规范

```Python
pattern_obj = re.compile(pattern, flags=0)
```

预编译后，可通过 `pattern\_obj\.match\(\)`、`pattern\_obj\.search\(\)` 等方法调用（参数与 `re` 模块函数一致，仅无需再传 `pattern`）。

#### 示例代码

```Python
import re

# 预编译邮箱匹配模式
email_pattern = re.compile(r"\w+@\w+\.\w+")

# 多次使用该模式
text1 = "联系：support@example.com"
text2 = "反馈：feedback@test.org"

print(email_pattern.findall(text1))  # 输出: ['support@example.com']
print(email_pattern.findall(text2))  # 输出: ['feedback@test.org']
```

## 三、进阶用法

### 3\.1 分组（捕获组与非捕获组）

用 `\(\)` 将模式的一部分括起来形成“分组”，可单独提取分组内容；若用 `\(?:\)` 则为“非捕获组”，仅用于组合模式，不单独提取。

#### 语法规范

- 捕获组：`\(pattern\)`，通过 `match\.group\(n\)` 提取（`n` 从1开始）；

- 非捕获组：`\(?:pattern\)`，不占用分组索引；

- 命名捕获组：`\(?P\&lt;name\&gt;pattern\)`，通过 `match\.group\(\&\#39;name\&\#39;\)` 提取。

#### 示例代码

```Python
import re

# 1. 捕获组：提取手机号的前3位（运营商号段）和后8位
text = "手机号：13812345678"
pattern = r"(\d{3})(\d{8})"
match = re.search(pattern, text)

if match:
    print("完整匹配:", match.group(0))  # 输出: 13812345678（group(0)是完整匹配）
    print("号段:", match.group(1))       # 输出: 138
    print("后8位:", match.group(2))      # 输出: 12345678

# 2. 命名捕获组：提取邮箱的用户名和域名
email = "user@example.com"
pattern = r"(?P<username>\w+)@(?P<domain>\w+\.\w+)"
match = re.search(pattern, email)

if match:
    print("用户名:", match.group('username'))  # 输出: user
    print("域名:", match.group('domain'))      # 输出: example.com

# 3. 非捕获组：仅组合模式，不提取
text = "颜色：红色、蓝色、绿色"
pattern = r"颜色：(?:红色|蓝色|绿色)"  # (?:...)不占用分组
match = re.search(pattern, text)
print("非捕获组匹配:", match.group())  # 输出: 颜色：红色
```

### 3\.2 贪婪匹配与非贪婪匹配

- **贪婪匹配**：默认模式，尽可能多匹配字符（用 `\*`、`\+`、`?`、`\{m,n\}`）；

- **非贪婪匹配**：在量词后加 `?`，尽可能少匹配字符（用 `\*?`、`\+?`、`??`、`\{m,n\}?`）。

#### 示例代码

```Python
import re

text = "<div>内容1</div><div>内容2</div>"

# 1. 贪婪匹配：匹配最长的子串
pattern_greedy = r"<div>.*</div>"
result_greedy = re.findall(pattern_greedy, text)
print("贪婪匹配结果:", result_greedy)
# 输出: ['<div>内容1</div><div>内容2</div>']

# 2. 非贪婪匹配：匹配最短的子串
pattern_lazy = r"<div>.*?</div>"
result_lazy = re.findall(pattern_lazy, text)
print("非贪婪匹配结果:", result_lazy)
# 输出: ['<div>内容1</div>', '<div>内容2</div>']
```

### 3\.3 匹配修饰符（flags）

通过 `flags` 参数调整匹配规则，常用修饰符如下：

|修饰符|作用说明|
|---|---|
|`re\.I`|忽略大小写（`IGNORECASE`）|
|`re\.M`|多行模式，`^` 匹配每行开头，`$` 匹配每行结尾（`MULTILINE`）|
|`re\.S`|让 `\.` 匹配包括换行符在内的所有字符（`DOTALL`）|
|`re\.X`|忽略模式中的空白和注释（`VERBOSE`，适合写复杂正则）|

#### 示例代码

```Python
import re

# 1. re.I：忽略大小写
text1 = "Python python PYTHON"
result1 = re.findall(r"python", text1, re.I)
print("忽略大小写结果:", result1)  # 输出: ['Python', 'python', 'PYTHON']

# 2. re.M：多行模式
text2 = """第一行
第二行
第三行"""
result2 = re.findall(r"^第.*行", text2, re.M)
print("多行模式结果:", result2)  # 输出: ['第一行', '第二行', '第三行']

# 3. re.S：让.匹配换行符
text3 = "开始\n中间\n结束"
result3 = re.search(r"开始.*结束", text3, re.S)
print("re.S匹配结果:", result3.group())  # 输出: 开始\n中间\n结束

# 4. re.X：忽略空白和注释（写复杂正则更清晰）
pattern = r"""
    \w+          # 用户名
    @            # @符号
    \w+\.\w+     # 域名
"""
email = "user@example.com"
result4 = re.search(pattern, email, re.X)
print("re.X匹配结果:", result4.group())  # 输出: user@example.com
```

### 3\.4 零宽断言

零宽断言是一种“不消耗字符”的匹配，仅用于**指定位置的前后条件**，常用的有：

- **正向先行断言**：`\(?=pattern\)`，匹配后面紧跟 `pattern` 的位置；

- **负向先行断言**：`\(?\!pattern\)`，匹配后面不紧跟 `pattern` 的位置；

- **正向后行断言**：`\(?\&lt;=pattern\)`，匹配前面紧跟 `pattern` 的位置；

- **负向后行断言**：`\(?\&lt;\!pattern\)`，匹配前面不紧跟 `pattern` 的位置。

#### 示例代码

```Python
import re

# 1. 正向先行断言：匹配后面是"元"的数字
text1 = "苹果15元，香蕉8斤，橙子20元"
pattern1 = r"\d+(?=元)"
result1 = re.findall(pattern1, text1)
print("正向先行断言结果:", result1)  # 输出: ['15', '20']

# 2. 正向后行断言：匹配前面是"价格："的数字
text2 = "名称：苹果，价格：15，库存：100"
pattern2 = r"(?<=价格：)\d+"
result2 = re.findall(pattern2, text2)
print("正向后行断言结果:", result2)  # 输出: ['15']

# 3. 负向先行断言：匹配后面不是"斤"的数字
pattern3 = r"\d+(?!斤)"
result3 = re.findall(pattern3, text1)
print("负向先行断言结果:", result3)  # 输出: ['15', '20']
```

### 3\.5 回溯引用

在模式中用 `\\1`、`\\2` 等**引用前面的捕获组**，适合匹配重复的内容。

#### 示例代码

```Python
import re

# 1. 匹配重复的单词（如"好好"、"天天"）
text1 = "好好学Python，天天向上"
pattern1 = r"(\w)\1"  # \1引用第一个捕获组（即前面的\w）
result1 = re.findall(pattern1, text1)
print("重复单词匹配:", result1)  # 输出: ['好', '天']

# 2. 替换重复的内容为单个（如"aabbcc"→"abc"）
text2 = "aabbccddeeff"
pattern2 = r"(\w)\1+"
result2 = re.sub(pattern2, r"\1", text2)
print("替换重复内容:", result2)  # 输出: abcdef
```

## 四、实战案例：日志分析与信息提取工具

### 1\. 需求描述

开发一个**日志分析工具**，用于处理 Nginx 访问日志，实现以下功能：

- 提取每条日志的 IP、时间、请求方法、URL、状态码、响应大小；

- 统计状态码分布（如 200、404、500 的数量）；

- 提取所有 404 错误的 URL；

- 提取响应时间超过 1 秒的请求（假设日志包含响应时间字段）。

### 2\. 日志样本（模拟 Nginx 日志）

```Plaintext
192.168.1.100 - - [20/May/2024:10:30:45 +0800] "GET /index.html HTTP/1.1" 200 1234 "-" "Mozilla/5.0" 0.5
10.0.0.5 - - [20/May/2024:10:30:46 +0800] "POST /api/login HTTP/1.1" 200 567 "-" "PostmanRuntime/7.0" 1.2
192.168.1.101 - - [20/May/2024:10:30:47 +0800] "GET /not-found HTTP/1.1" 404 152 "-" "Chrome/125.0" 0.3
172.16.0.20 - - [20/May/2024:10:30:48 +0800] "GET /api/data HTTP/1.1" 500 89 "-" "Firefox/126.0" 2.1
192.168.1.100 - - [20/May/2024:10:30:49 +0800] "GET /static/logo.png HTTP/1.1" 200 4567 "-" "Safari/17.0" 0.8
```

### 3\. 完整代码实现

```Python
import re
from collections import defaultdict

class LogAnalyzer:
    def __init__(self, log_text):
        self.log_text = log_text
        # 定义 Nginx 日志的正则模式（包含命名捕获组）
        self.log_pattern = re.compile(r"""
            (?P<ip>\d+\.\d+\.\d+\.\d+)    # IP地址
            \s-\s-\s                       # 固定分隔符
            \[(?P<time>[^\]]+)\]           # 时间（匹配到]为止）
            \s"                            # 空格+引号
            (?P<method>\w+)                # 请求方法（GET/POST等）
            \s(?P<url>[^\s]+)              # URL
            \sHTTP/[\d.]+                  # HTTP版本
            "\s                            # 引号+空格
            (?P<status>\d+)                # 状态码
            \s(?P<size>\d+|-)              # 响应大小（-表示无）
            \s"[^"]+"\s"                   # 忽略referer
            (?P<user_agent>[^"]+)          # User-Agent
            "\s(?P<response_time>[\d.]+)   # 响应时间（秒）
        """, re.X)  # 用re.X忽略模式中的空白和注释

    def extract_all_logs(self):
        """提取所有日志的结构化信息"""
        logs = []
        for match in self.log_pattern.finditer(self.log_text):
            log_entry = match.groupdict()
            # 转换类型（状态码、响应大小、响应时间转为数字）
            log_entry['status'] = int(log_entry['status'])
            log_entry['size'] = int(log_entry['size']) if log_entry['size'] != '-' else 0
            log_entry['response_time'] = float(log_entry['response_time'])
            logs.append(log_entry)
        return logs

    def count_status_distribution(self, logs):
        """统计状态码分布"""
        status_count = defaultdict(int)
        for log in logs:
            status_count[log['status']] += 1
        return dict(status_count)

    def get_404_urls(self, logs):
        """获取所有404错误的URL"""
        return [log['url'] for log in logs if log['status'] == 404]

    def get_slow_requests(self, logs, threshold=1.0):
        """获取响应时间超过阈值的请求"""
        return [
            {
                'url': log['url'],
                'response_time': log['response_time'],
                'ip': log['ip']
            }
            for log in logs
            if log['response_time'] > threshold
        ]

    def generate_report(self):
        """生成完整分析报告"""
        logs = self.extract_all_logs()
        if not logs:
            return "未解析到有效日志"

        report = "="*60 + "\n"
        report += "日志分析报告\n"
        report += "="*60 + "\n\n"

        # 1. 总请求数
        report += f"1. 总请求数: {len(logs)}\n\n"

        # 2. 状态码分布
        status_dist = self.count_status_distribution(logs)
        report += "2. 状态码分布:\n"
        for status, count in sorted(status_dist.items()):
            report += f"   {status}: {count}次\n"
        report += "\n"

        # 3. 404 URL
        urls_404 = self.get_404_urls(logs)
        report += f"3. 404错误URL（共{len(urls_404)}个）:\n"
        for url in urls_404:
            report += f"   - {url}\n"
        report += "\n"

        # 4. 慢请求（>1秒）
        slow_reqs = self.get_slow_requests(logs, threshold=1.0)
        report += f"4. 慢请求（响应时间>1秒，共{len(slow_reqs)}个）:\n"
        for req in slow_reqs:
            report += f"   - URL: {req['url']}, 响应时间: {req['response_time']}s, IP: {req['ip']}\n"

        report += "\n" + "="*60
        return report

# 实战案例使用
if __name__ == "__main__":
    # 模拟日志文本
    nginx_logs = """192.168.1.100 - - [20/May/2024:10:30:45 +0800] "GET /index.html HTTP/1.1" 200 1234 "-" "Mozilla/5.0" 0.5
10.0.0.5 - - [20/May/2024:10:30:46 +0800] "POST /api/login HTTP/1.1" 200 567 "-" "PostmanRuntime/7.0" 1.2
192.168.1.101 - - [20/May/2024:10:30:47 +0800] "GET /not-found HTTP/1.1" 404 152 "-" "Chrome/125.0" 0.3
172.16.0.20 - - [20/May/2024:10:30:48 +0800] "GET /api/data HTTP/1.1" 500 89 "-" "Firefox/126.0" 2.1
192.168.1.100 - - [20/May/2024:10:30:49 +0800] "GET /static/logo.png HTTP/1.1" 200 4567 "-" "Safari/17.0" 0.8"""

    # 分析日志并生成报告
    analyzer = LogAnalyzer(nginx_logs)
    print(analyzer.generate_report())
```

## 五、总结

- `re` 模块的核心是“模式匹配”，通过 `match\(\)`、`search\(\)`、`findall\(\)`、`sub\(\)` 等函数实现文本的匹配、提取、替换；

- 分组、贪婪/非贪婪、修饰符、零宽断言是进阶核心，能解决复杂的文本处理需求；

- 实战中，正则表达式需结合具体场景设计，优先保证准确性，再考虑性能（复杂正则可通过 `re\.compile\(\)` 预编译优化）。
