# Python 3.14 `fractions` 标准库完全学习指南

## 一、概念：为什么需要 `fractions`？

`fractions` 是 Python 标准库中用于 ** 精确处理有理数（分数）** 的模块。它的核心价值是解决浮点数的精度误差问题 —— 例如 `0.1` 在二进制浮点数中是无限循环小数，直接计算会产生微小误差，而 `Fraction` 可以用分子 / 分母的形式精确表示任何有理数。

适用场景：精确计算（如金融、食谱配比）、概率统计、数学教学等。

## 二、基础部分：核心用法

### 1. 导入与基本构造

```python
from fractions import Fraction
```

Python 3.14 中，`Fraction` 支持以下 6 种构造方式：

|构造方式|示例|结果|说明|
|---|---|---|---|
|分子 + 分母|`Fraction(1, 2)`|`1/2`|自动约分（如 `Fraction(2,4)` → `1/2`）|
|单个整数|`Fraction(5)`|`5/1`|分母默认为 1|
|浮点数|`Fraction(0.5)`|`1/2`|注意：`Fraction(0.1)` 会因浮点数精度产生长分数|
|字符串（分数 / 小数）|`Fraction(&#39;1/3&#39;)` / `Fraction(&#39;0.25&#39;)`|`1/3` / `1/4`|**推荐**：避免浮点数精度问题|
|具有 `as_integer_ratio()` 的对象（3.14 新增）|`Fraction(decimal.Decimal(&#39;0.1&#39;))`|`1/10`|支持 `decimal.Decimal` 等类型|
|`from_number()` 构造器（3.14 新增）|`Fraction.from_number(0.1)`|`1/10`|更安全的类型转换方式|

### 2. 核心属性

```python
frac = Fraction(3, 6)  # 自动约分为 1/2
print(frac.numerator)   # 输出：1（分子）
print(frac.denominator) # 输出：2（分母）
```

### 3. 基本运算与比较

`Fraction` 支持所有常规数学运算，结果自动约分：

```python
a = Fraction(1, 3)
b = Fraction(1, 6)

print(a + b)  # 1/2
print(a - b)  # 1/6
print(a * b)  # 1/18
print(a / b)  # 2/1（除法结果仍为 Fraction）

print(a > b)  # True
print(a == Fraction(2, 6))  # True（自动约分后比较）
```

## 三、进阶部分：深度技巧

### 1. 限制分母：`limit_denominator()`

用于将分数近似为指定最大分母的最简分数，适合处理浮点数转分数的精度问题：

```python
# 0.1 的浮点数实际是近似值，直接转 Fraction 会得到长分数
print(Fraction(0.1))  # 3602879701896397/36028797018963968

# 限制分母最大为 10，得到近似值 1/10
print(Fraction(0.1).limit_denominator(10))  # 1/10
```

### 2. 类型转换

```python
frac = Fraction(3, 2)

print(float(frac))  # 1.5（转浮点数）
print(int(frac))    # 1（转整数，截断小数部分）
```

### 3. 格式化输出（Python 3.12+ 支持）

可以像浮点数一样格式化 `Fraction`：

```python
frac = Fraction(1, 3)
print(f"{frac:.2f}")  # 0.33（保留两位小数）
print(f"{frac:%}")     # 33.333333%（百分比格式）
```

### 4. 注意事项

- 避免直接用浮点数构造 `Fraction`（除非你清楚精度问题），优先用字符串或 `from_number()`。

- `Fraction` 是不可变类型（immutable），运算后会返回新对象。

## 四、实战案例：食谱分量计算器

假设你有一个食谱，需要根据人数调整分量。我们用 `Fraction` 实现精确计算：

```python
from fractions import Fraction

def adjust_recipe(ingredients, original_servings, target_servings):
    """
    调整食谱分量
    :param ingredients: 字典，格式 {食材名: 分量（Fraction/字符串/数字）}
    :param original_servings: 原食谱份数
    :param target_servings: 目标份数
    :return: 调整后的食材字典
    """
    ratio = Fraction(target_servings, original_servings)
    adjusted = {}
    for name, amount in ingredients.items():
        # 统一转换为 Fraction
        if isinstance(amount, str):
            frac_amount = Fraction(amount)
        else:
            frac_amount = Fraction.from_number(amount)
        # 计算调整后的分量，限制分母为 8（适合厨房量杯）
        adjusted[name] = (frac_amount * ratio).limit_denominator(8)
    return adjusted

# 示例：原食谱 2 人份，调整为 5 人份
recipe = {
    "面粉": "1/2",  # 杯
    "牛奶": "3/4",  # 杯
    "糖": 2,        # 勺
    "鸡蛋": 1       # 个
}

adjusted = adjust_recipe(recipe, original_servings=2, target_servings=5)

# 输出结果
print("调整后的食谱（5人份）：")
for name, amount in adjusted.items():
    print(f"{name}: {amount}")
```

**运行结果**：

```Plain Text
调整后的食谱（5人份）：
面粉: 5/4
牛奶: 15/8
糖: 5/1
鸡蛋: 5/2
```
