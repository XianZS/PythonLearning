# B站Python授课：`os` 标准库从入门到实战

## 课程导入

`os` 库是 Python 与**操作系统交互的核心标准库**，能实现文件/目录管理、环境变量操作、进程调用等功能，是自动化脚本、跨平台开发的必备工具。

注意：`os` 库跨平台（Windows/macOS/Linux），但部分函数存在系统差异，代码中会重点说明。

## 第一部分：路径操作（`os.path` 模块）

### 核心知识点

`os.path` 是 `os` 库下的子模块，专门用于处理文件路径，解决不同系统路径分隔符（Windows用`\`，macOS/Linux用`/`）的兼容问题。

### 常用函数与示例代码

```Python

import os

# 1. 获取绝对路径
current_file = "test.txt"
abs_path = os.path.abspath(current_file)
print(f"绝对路径：{abs_path}")

# 2. 路径拼接（自动适配系统分隔符）
dir_path = "/home/user"
file_name = "data.csv"
full_path = os.path.join(dir_path, file_name)
print(f"拼接路径：{full_path}")

# 3. 拆分路径与文件名
dir_name = os.path.dirname(full_path)
base_name = os.path.basename(full_path)
print(f"目录部分：{dir_name}，文件名：{base_name}")

# 4. 判断路径是否存在、是文件还是目录
print(f"路径是否存在：{os.path.exists(full_path)}")
print(f"是否为文件：{os.path.isfile(full_path)}")
print(f"是否为目录：{os.path.isdir(dir_path)}")

# 5. 获取文件大小（字节）
if os.path.isfile(current_file):
    size = os.path.getsize(current_file)
    print(f"文件大小：{size} 字节")
```

### 内容讲解

- `os.path.abspath()`：将相对路径转为绝对路径，常用于定位项目内的文件。

- `os.path.join()`：**最常用函数**，避免手动拼接路径导致的跨平台错误。

- `os.path.exists()`：先判断再操作，防止“文件不存在”报错。

### 应用场景

1. 读取项目配置文件：通过 `os.path.join()` 拼接配置文件路径，确保代码在任何系统都能找到文件。

2. 批量处理图片：先判断目录是否存在，再遍历处理。

## 第二部分：文件与目录管理

### 核心知识点

直接通过 `os` 库创建、删除、遍历文件和目录，实现自动化文件整理。

### 常用函数与示例代码

```Python

import os

# 1. 创建目录（单级/多级）
os.mkdir("single_dir")  # 创建单级目录，若目录已存在会报错
os.makedirs("multi_dir/sub_dir", exist_ok=True)  # 递归创建多级目录，exist_ok=True避免报错

# 2. 删除文件/目录
os.remove("test.txt")  # 删除文件，文件不存在会报错
os.rmdir("single_dir")  # 删除空目录，非空目录会报错
os.removedirs("multi_dir/sub_dir")  # 递归删除空目录（从子目录到父目录）

# 3. 遍历目录（两种方式）
# 方式1：listdir（仅列出当前目录下的文件/目录名）
print("当前目录内容：", os.listdir("."))

# 方式2：walk（递归遍历所有子目录，返回(目录路径, 子目录列表, 文件列表)）
for root, dirs, files in os.walk("."):
    print(f"当前目录：{root}")
    print(f"子目录：{dirs}")
    print(f"文件：{files}\n")
```

### 内容讲解

- `os.makedirs(..., exist_ok=True)`：推荐用这个创建目录，避免重复创建报错。

- `os.rmdir()` 只能删空目录，若要删除非空目录，需结合 `shutil` 库（后续课程补充）。

- `os.walk()`：**批量处理文件的神器**，能深度遍历所有子目录。

### 应用场景

1. 自动整理下载文件夹：遍历 `Downloads` 目录，按文件后缀（如 `.jpg`、`.pdf`）移动到对应文件夹。

2. 批量删除临时文件：遍历项目目录，删除所有 `.log` 结尾的文件。

## 第三部分：环境变量与系统操作

### 核心知识点

操作系统环境变量、获取系统信息、切换工作目录，实现跨平台脚本适配。

### 常用函数与示例代码

```Python

import os

# 1. 获取/设置环境变量
# 获取环境变量（第二个参数为默认值，若变量不存在则返回默认值）
path_env = os.environ.get("PATH", "未找到PATH")
print(f"PATH环境变量：{path_env}")

# 设置临时环境变量（仅对当前Python进程有效）
os.environ["MY_VAR"] = "test_value"
print(f"自定义环境变量：{os.environ['MY_VAR']}")

# 2. 获取系统信息
print(f"操作系统类型：{os.name}")  # nt=Windows, posix=macOS/Linux
print(f"当前工作目录：{os.getcwd()}")  # 类似shell的pwd命令

# 3. 切换工作目录
os.chdir("multi_dir")  # 类似shell的cd命令
print(f"切换后工作目录：{os.getcwd()}")

# 4. 执行系统命令（简单场景用，复杂场景推荐subprocess库）
os.system("echo Hello from os.system")  # Windows用"echo Hello"，macOS/Linux通用
```

### 内容讲解

- `os.environ`：是一个字典-like对象，存储当前系统的环境变量。

- `os.name`：用于判断操作系统，实现跨平台逻辑（如Windows用 `dir`，Linux用 `ls`）。

- `os.system()`：执行shell命令，但无法获取命令输出，复杂场景推荐用 `subprocess` 库。

### 应用场景

1. 开发/生产环境切换：通过环境变量 `APP_ENV` 判断，加载不同配置文件。

2. 调用外部工具：如用 `os.system("git pull")` 自动拉取代码（简单场景可用）。
