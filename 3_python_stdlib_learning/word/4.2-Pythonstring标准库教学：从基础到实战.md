# Python `string` 标准库教学文档

## 一、基础概念与使用场景

### 1. 基础概念

`string` 是 Python 标准库中专门用于**字符串处理辅助**的模块，它提供了一系列**预定义字符常量**、**字符串模板工具**和**简单格式化函数**，是对 Python 原生字符串方法（如 `str.upper()`、`str.split()`）的补充。

注意：`string` 模块的功能更偏向 “工具集”，而非核心字符串操作 —— 日常开发中大部分字符串处理直接用原生字符串方法即可，`string` 模块主要用于特定场景下的效率提升。

### 2. 使用场景

- **快速访问字符集合**：如大小写字母、数字、标点符号等预定义常量；

- **安全的字符串模板替换**：避免 `str.format()` 或 f-string 的代码注入风险（适合用户输入模板的场景）；

- **简单的单词格式化**：如批量将句子中每个单词首字母大写；

- **生成随机字符串**：结合 `random` 模块快速生成密码、验证码等。

## 二、基础用法

### 2.1 预定义字符常量

`string` 模块提供了一系列常用字符集合的常量，无需手动定义即可直接使用。

#### 语法规范

直接通过 `string.常量名` 访问，返回一个字符串。

#### 常用常量与示例代码

|常量名|描述|示例代码|输出结果||
|---|---|---|---|---|
|`ascii_letters`|所有大小写字母（a-z + A-Z）|`print(string.ascii_letters)`|`abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ`||
|`ascii_lowercase`|所有小写字母（a-z）|`print(string.ascii_lowercase)`|`abcdefghijklmnopqrstuvwxyz`||
|`ascii_uppercase`|所有大写字母（A-Z）|`print(string.ascii_uppercase)`|`ABCDEFGHIJKLMNOPQRSTUVWXYZ`||
|`digits`|所有数字（0-9）|`print(string.digits)`|`0123456789`||
|`punctuation`|所有标点符号（如 `!@#$%` 等）|`print(string.punctuation)`|`!&#34;#$%&amp;&#39;()*+,-./:;&lt;=&gt;?@[]^_`{|}~`|
|`whitespace`|所有空白字符（空格、制表符、换行等）|`print(repr(string.whitespace))`|`&#39; tnrx0bx0c&#39;`||

### 2.2 `string.capwords()`：单词首字母大写

将字符串中每个单词的首字母转为大写，其余字母转为小写（类似 “标题化” 处理）。

#### 语法规范

```python
string.capwords(s, sep=None)
```

- `s`：待处理的字符串；

- `sep`：单词分隔符（可选，默认为所有空白字符）。

#### 示例代码

```python
import string

text = "hello WORLD from PYTHON"
result = string.capwords(text)
print(result)  # 输出: Hello World From Python

# 自定义分隔符（如用逗号分隔）
text2 = "apple,banana,orange"
result2 = string.capwords(text2, sep=",")
print(result2)  # 输出: Apple,Banana,Orange
```

### 2.3 `string.Template`：安全字符串模板

提供一种**简单、安全**的字符串替换方式，适合处理用户提供的模板（避免 `str.format()` 可能导致的代码注入）。

#### 语法规范

1. 定义模板：`template = string.Template(&#34;包含 $占位符 的字符串&#34;)`；

2. 替换内容：

    - `template.substitute(占位符1=值1, 占位符2=值2)`：严格替换，缺少占位符会报错；

    - `template.safe_substitute(...)`：安全替换，缺少占位符时保留原占位符，不报错。

#### 示例代码

```python
from string import Template

# 1. 基础替换
template = Template("大家好，我是 $name，今年 $age 岁！")
result = template.substitute(name="张三", age=25)
print(result)  # 输出: 大家好，我是 张三，今年 25 岁！

# 2. 安全替换（缺少占位符时不报错）
result_safe = template.safe_substitute(name="李四")
print(result_safe)  # 输出: 大家好，我是 李四，今年 $age 岁！
```

## 三、进阶用法

### 3.1 自定义 `Template` 分隔符

默认的 `Template` 用 `$` 作为占位符前缀，可通过继承 `string.Template` 类自定义分隔符。

#### 语法规范

继承 `Template` 类，重写 `delimiter`（分隔符）和 `idpattern`（占位符名称的正则匹配规则）。

#### 示例代码

```python
from string import Template

# 自定义模板类：用 % 作为分隔符
class MyTemplate(Template):
    delimiter = "%"  # 自定义分隔符
    idpattern = r"[a-zA-Z_]+"  # 占位符名称规则：字母/下划线开头

# 使用自定义模板
template = MyTemplate("欢迎来到 %site，作者是 %author！")
result = template.substitute(site="B站", author="Python老师")
print(result)  # 输出: 欢迎来到 B站，作者是 Python老师！
```

### 3.2 结合 `random` 生成随机字符串

利用 `string` 的字符常量 + `random` 模块，快速生成密码、验证码等随机字符串。

#### 语法规范

1. 定义字符集合：如 `string.ascii_letters + string.digits`；

2. 用 `random.choice()` 随机选取字符，拼接成字符串。

#### 示例代码：生成随机密码

```python
import string
import random

def generate_password(length=12):
    """生成指定长度的随机密码（包含字母、数字、标点）"""
    # 定义密码字符集合：大小写字母 + 数字 + 标点
    chars = string.ascii_letters + string.digits + string.punctuation
    # 随机选取 length 个字符并拼接
    password = "".join(random.choice(chars) for _ in range(length))
    return password

# 生成一个 12 位的密码
print(generate_password(12))  # 输出示例: 8@Lk2pQ!zX90
```

### 3.3 `string.Formatter`：高级字符串格式化

`string.Formatter` 是 `str.format()` 的底层实现，可通过继承它自定义格式化规则（如处理特殊格式的日期、货币等）。

#### 语法规范

继承 `string.Formatter` 类，重写 `format_field()` 方法（控制单个字段的格式化逻辑）。

#### 示例代码：自定义货币格式化

```python
from string import Formatter

class CurrencyFormatter(Formatter):
    def format_field(self, value, format_spec):
        # 自定义格式规则：如果格式说明符是 "currency"，则格式化为货币
        if format_spec == "currency":
            return f"${value:.2f}"  # 保留两位小数，加 $ 前缀
        # 其他情况用默认格式化
        return super().format_field(value, format_spec)

# 使用自定义 Formatter
formatter = CurrencyFormatter()
result = formatter.format("商品价格: {price:currency}", price=19.9)
print(result)  # 输出: 商品价格: $19.90
```

## 四、实战案例：用户信息注册工具

### 1. 需求描述

开发一个简单的用户信息注册工具，包含以下功能：

- 验证用户名是否合法（仅允许字母、数字、下划线）；

- 生成随机初始密码；

- 格式化用户姓名（首字母大写）；

- 用模板生成欢迎消息。

### 2. 完整代码实现

```python
import string
import random
from string import Template

class UserRegistrationTool:
    def __init__(self):
        # 定义合法用户名字符集合
        self.valid_username_chars = set(
            string.ascii_letters + string.digits + "_"
        )
    
    def validate_username(self, username):
        """验证用户名是否合法（仅允许字母、数字、下划线）"""
        if not username:
            return False, "用户名不能为空"
        for char in username:
            if char not in self.valid_username_chars:
                return False, f"用户名包含非法字符: '{char}'"
        return True, "用户名合法"
    
    def generate_initial_password(self, length=10):
        """生成随机初始密码"""
        chars = string.ascii_letters + string.digits + string.punctuation
        return "".join(random.choice(chars) for _ in range(length))
    
    def format_name(self, name):
        """格式化姓名：首字母大写"""
        return string.capwords(name)
    
    def generate_welcome_message(self, name, username):
        """生成欢迎消息"""
        template = Template(
            "🎉 欢迎 $formatted_name 加入我们！n"
            "您的用户名是: $usernamen"
            "请妥善保管您的初始密码。"
        )
        formatted_name = self.format_name(name)
        return template.safe_substitute(
            formatted_name=formatted_name,
            username=username
        )

# 工具使用示例
if __name__ == "__main__":
    tool = UserRegistrationTool()
    
    # 模拟用户输入
    raw_name = "li si"
    username = "lisi_2024"
    
    # 1. 验证用户名
    is_valid, msg = tool.validate_username(username)
    print(f"[用户名验证] {msg}")
    
    # 2. 生成初始密码
    if is_valid:
        password = tool.generate_initial_password()
        print(f"[初始密码] {password}")
        
        # 3. 生成欢迎消息
        welcome_msg = tool.generate_welcome_message(raw_name, username)
        print("n[欢迎消息]n" + welcome_msg)
```

### 3. 运行结果示例

```Plain Text

[初始密码] 7@xQ2pL!z9

[欢迎消息]
🎉 欢迎 Li Si 加入我们！
您的用户名是: lisi_2024
请妥善保管您的初始密码。
```

## 五、总结

- `string` 模块的核心价值在于**预定义字符常量**和**安全模板替换**，日常开发中需结合原生字符串方法使用；

- `Template` 适合处理用户输入的模板，避免代码注入风险；

- 结合 `random` 模块可快速生成随机字符串，是密码、验证码开发的常用技巧。
