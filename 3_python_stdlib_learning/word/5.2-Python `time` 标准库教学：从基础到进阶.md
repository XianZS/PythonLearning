# Python `time` 标准库教学文档

## 一、基础概念与使用场景

### 1. 基础概念

`time` 是 Python 处理时间的**底层标准库**，核心围绕 **Unix 时间戳**（从 1970 年 1 月 1 日 00:00:00 UTC 到现在的秒数，浮点数）展开，提供时间获取、格式化、程序暂停、性能计时等功能，更偏向 “系统级时间操作”，与面向对象的 `datetime` 模块互补（`datetime` 适合复杂日期逻辑，`time` 适合底层时间控制）。

### 2. 使用场景

- **性能测试**：精确测量代码块的执行时间（区分 “实际时间” 和 “CPU 时间”）；

- **任务调度**：控制循环 / 任务的执行间隔（如爬虫延迟、定时重试）；

- **时间戳处理**：日志记录、数据存储中用时间戳标记时间点（跨平台兼容）；

- **简单时间格式化**：快速生成可读时间字符串（无需复杂日期逻辑）。

## 二、基础用法

### 2.1 获取当前时间戳：`time.time()`

返回自 Unix 纪元以来的**秒数（浮点数）**，是时间操作的基础，用于记录时间点、计算时间差。

#### 语法规范

```python
time.time()
```

- 无参数；

- 返回值：浮点数，精确到微秒（取决于系统精度）。

#### 示例代码

```python
import time

timestamp = time.time()
print("当前时间戳:", timestamp)  # 输出示例: 当前时间戳: 1716186645.123456
```

### 2.2 程序暂停：`time.sleep()`

让程序**暂停执行指定秒数**，常用于控制任务间隔、模拟网络延迟、避免请求过快。

#### 语法规范

```python
time.sleep(secs)
```

- `secs`：暂停的秒数（可以是整数或浮点数，如 `0.5` 表示暂停 500 毫秒）。

#### 示例代码

```python
import time

print("开始执行...")
time.sleep(2)  # 暂停 2 秒
print("2 秒后继续执行！")
```

### 2.3 时间戳转可读字符串：`time.ctime()`

将时间戳转换为**本地时间的可读字符串**（格式固定：`Weekday Month Day HH:MM:SS Year`），无需自定义格式。

#### 语法规范

```python
time.ctime([secs])
```

- `secs`：可选，时间戳（浮点数）；不传则使用当前时间。

#### 示例代码

```python
import time

# 1. 当前时间转可读字符串
current_str = time.ctime()
print("当前时间:", current_str)  # 输出示例: 当前时间: Mon May 20 14:30:45 2024

# 2. 指定时间戳转可读字符串
timestamp = 1716186645.123456
specified_str = time.ctime(timestamp)
print("指定时间:", specified_str)
```

### 2.4 结构化时间对象：`time.localtime()` 与 `time.gmtime()`

将时间戳转换为**结构化时间对象**（`struct_time`），方便单独提取年、月、日、时、分、秒等信息：

- `localtime()`：返回**本地时间**的 `struct_time`；

- `gmtime()`：返回**UTC 时间**的 `struct_time`（无时区偏移）。

#### 语法规范

```python
time.localtime([secs])
time.gmtime([secs])
```

- `secs`：可选，时间戳；不传则使用当前时间。

#### `struct_time` 对象的核心属性

|属性名|含义|取值范围|
|---|---|---|
|`tm_year`|年|如 2024|
|`tm_mon`|月|1~12|
|`tm_mday`|日|1~31|
|`tm_hour`|时|0~23|
|`tm_min`|分|0~59|
|`tm_sec`|秒|0~61（闰秒）|
|`tm_wday`|星期几|0~6（0 = 周一）|
|`tm_yday`|一年中的第几天|1~366|

#### 示例代码

```python
import time

# 1. 本地结构化时间
local_struct = time.localtime()
print("本地结构化时间:", local_struct)
print("年:", local_struct.tm_year)
print("月:", local_struct.tm_mon)
print("日:", local_struct.tm_mday)
print("时:", local_struct.tm_hour)

# 2. UTC 结构化时间
utc_struct = time.gmtime()
print("nUTC 结构化时间:", utc_struct)
print("UTC 时:", utc_struct.tm_hour)  # 与本地时间可能有时差
```

### 2.5 结构化时间转字符串：`time.strftime()`

将 `struct_time` 对象**格式化为自定义字符串**，格式码与 `datetime` 模块一致（常用 `%Y`、`%m`、`%d`、`%H`、`%M`、`%S`）。

#### 语法规范

```python
time.strftime(format[, t])
```

- `format`：格式化字符串（如 `&#34;%Y-%m-%d %H:%M:%S&#34;`）；

- `t`：可选，`struct_time` 对象；不传则使用当前本地时间。

#### 示例代码

```python
import time

# 1. 格式化当前时间
current_struct = time.localtime()
formatted1 = time.strftime("%Y-%m-%d %H:%M:%S", current_struct)
formatted2 = time.strftime("%Y年%m月%d日 %A", current_struct)
print("格式化 1:", formatted1)  # 输出示例: 格式化 1: 2024-05-20 14:30:45
print("格式化 2:", formatted2)  # 输出示例: 格式化 2: 2024年05月20日 Monday

# 2. 不传 t 参数，直接格式化当前时间
formatted3 = time.strftime("%H:%M:%S")
print("当前时间:", formatted3)
```

### 2.6 字符串转结构化时间：`time.strptime()`

将**时间字符串解析为 ****`struct_time`**** 对象**，是 `strftime()` 的逆操作，需保证格式字符串与时间字符串完全匹配。

#### 语法规范

```python
time.strptime(string[, format])
```

- `string`：时间字符串；

- `format`：对应的格式化字符串。

#### 示例代码

```python
import time

date_str = "2024-10-01 09:30:00"
struct_time = time.strptime(date_str, "%Y-%m-%d %H:%M:%S")
print("解析后的 struct_time:", struct_time)
print("年:", struct_time.tm_year)  # 输出: 年: 2024
print("月:", struct_time.tm_mon)   # 输出: 月: 10
```

## 三、进阶用法

### 3.1 高精度性能计时：`time.perf_counter()` 与 `time.process_time()`

- `time.perf_counter()`：返回**系统级高精度时间**（包含程序休眠时间），适合测量代码块的 “墙上时间”（实际经过的时间）；

- `time.process_time()`：返回**进程的 CPU 执行时间**（不包含休眠时间），适合测量代码的 “CPU 消耗”。

#### 语法规范

```python
time.perf_counter()
time.process_time()
```

- 无参数；

- 返回值：浮点数（秒），本身无意义，需计算两次调用的差值。

#### 示例代码

```python
import time

# 1. perf_counter：测量实际经过时间（包含 sleep）
start_perf = time.perf_counter()
time.sleep(1)  # 暂停 1 秒
end_perf = time.perf_counter()
print(f"perf_counter 耗时: {end_perf - start_perf:.4f}秒")  # 输出约 1.0000 秒

# 2. process_time：测量 CPU 执行时间（不包含 sleep）
start_proc = time.process_time()
time.sleep(1)  # 暂停 1 秒（CPU 不工作）
# 模拟一段 CPU 工作
for _ in range(1000000):
    pass
end_proc = time.process_time()
print(f"process_time 耗时: {end_proc - start_proc:.4f}秒")  # 输出远小于 1 秒
```

### 3.2 结构化时间转时间戳：`time.mktime()`

将**本地时间的 ****`struct_time`**** 对象转回时间戳**，是 `time.localtime()` 的逆操作。

#### 语法规范

```python
time.mktime(t)
```

- `t`：本地时间的 `struct_time` 对象；

- 返回值：浮点数，时间戳。

#### 示例代码

```python
import time

# 先创建一个 struct_time
date_str = "2024-10-01 09:30:00"
struct_time = time.strptime(date_str, "%Y-%m-%d %H:%M:%S")

# 转回时间戳
timestamp = time.mktime(struct_time)
print("转回的时间戳:", timestamp)  # 输出示例: 转回的时间戳: 1727748600.0

# 验证：用 ctime 转回去
print("验证:", time.ctime(timestamp))  # 输出示例: 验证: Tue Oct  1 09:30:00 2024
```

### 3.3 访问 `struct_time` 的完整属性

`struct_time` 是一个命名元组，除了通过属性访问，也可以通过索引访问（但推荐用属性，可读性更好）。

#### 示例代码

```python
import time

struct_time = time.localtime()

# 1. 通过属性访问（推荐）
print("年:", struct_time.tm_year)
print("星期几（0=周一）:", struct_time.tm_wday)
print("一年中的第几天:", struct_time.tm_yday)

# 2. 通过索引访问（不推荐，可读性差）
print("年（索引 0）:", struct_time[0])
print("月（索引 1）:", struct_time[1])
```

### 3.4 时区相关：`time.tzname` 与 `time.tzset()`（Unix）

- `time.tzname`：返回本地时区的名称元组（`(本地标准时区名, 本地夏令时时区名)`）；

- `time.tzset()`：根据环境变量 `TZ` 重置本地时区（**仅 Unix 系统可用**，Windows 不支持）。

#### 示例代码

```python
import time

# 查看本地时区名称
print("本地时区名称:", time.tzname)  # 输出示例: ('CST', 'CST')（中国标准时间）

# Unix 系统下可通过 TZ 环境变量改变时区（Windows 不支持）
# import os
# os.environ['TZ'] = 'UTC'
# time.tzset()
```

## 四、实战案例：代码性能测试与定时任务工具

### 1. 需求描述

开发一个工具，实现以下功能：

- 测试任意代码块的**实际执行时间**（`perf_counter`）和**CPU 消耗时间**（`process_time`）；

- 定时执行任务（循环 + `sleep`），并记录每次执行的时间戳和可读时间；

- 统计任务执行的总次数和总耗时；

- 支持自定义任务间隔和执行次数。

### 2. 完整代码实现

```python
import time
from typing import Callable, Optional

class PerformanceTester:
    """代码性能测试器"""
    @staticmethod
    def test_code_block(code_func: Callable, run_times: int = 1) -> dict:
        """
        测试代码块的性能
        :param code_func: 无参数的函数，封装要测试的代码
        :param run_times: 执行次数（默认 1 次）
        :return: 性能统计字典
        """
        total_perf_time = 0.0
        total_proc_time = 0.0

        for i in range(run_times):
            # 测量 perf_counter（实际时间）
            start_perf = time.perf_counter()
            # 测量 process_time（CPU 时间）
            start_proc = time.process_time()
            
            # 执行代码
            code_func()
            
            # 计算耗时
            end_perf = time.perf_counter()
            end_proc = time.process_time()
            
            perf_duration = end_perf - start_perf
            proc_duration = end_proc - start_proc
            
            total_perf_time += perf_duration
            total_proc_time += proc_duration
            
            print(f"第{i+1}次执行 | 实际耗时: {perf_duration:.6f}s | CPU 耗时: {proc_duration:.6f}s")

        return {
            "run_times": run_times,
            "total_perf_time": total_perf_time,
            "avg_perf_time": total_perf_time / run_times,
            "total_proc_time": total_proc_time,
            "avg_proc_time": total_proc_time / run_times
        }

class ScheduledTask:
    """定时任务执行器"""
    def __init__(self, task_func: Callable, interval: float, max_runs: Optional[int] = None):
        """
        :param task_func: 无参数的任务函数
        :param interval: 任务间隔（秒）
        :param max_runs: 最大执行次数（None 表示无限循环）
        """
        self.task_func = task_func
        self.interval = interval
        self.max_runs = max_runs
        self.run_count = 0
        self.start_time = None

    def _log_execution(self):
        """记录单次执行的时间"""
        timestamp = time.time()
        local_time = time.strftime("%Y-%m-%d %H:%M:%S", time.localtime(timestamp))
        print(f"[执行记录] 第{self.run_count}次 | 时间戳: {timestamp:.6f} | 本地时间: {local_time}")

    def run(self):
        """启动定时任务"""
        self.start_time = time.perf_counter()
        print(f"定时任务启动 | 间隔: {self.interval}s | 最大执行次数: {self.max_runs or '无限'}")
        
        try:
            while True:
                # 检查是否达到最大执行次数
                if self.max_runs is not None and self.run_count >= self.max_runs:
                    break
                
                self.run_count += 1
                # 执行任务
                self.task_func()
                # 记录执行时间
                self._log_execution()
                
                # 检查是否继续（避免最后一次执行后还 sleep）
                if self.max_runs is None or self.run_count < self.max_runs:
                    time.sleep(self.interval)
        
        except KeyboardInterrupt:
            print("n定时任务被手动中断")
        
        finally:
            total_duration = time.perf_counter() - self.start_time
            print(f"n任务结束 | 总执行次数: {self.run_count} | 总耗时: {total_duration:.2f}s")

# 实战案例使用
if __name__ == "__main__":
    # ------------------------------
    # 1. 性能测试示例
    # ------------------------------
    print("="*60)
    print("代码性能测试")
    print("="*60)

    # 定义要测试的代码：模拟一个计算密集型任务
    def test_task():
        result = 0
        for i in range(1000000):
            result += i
        return result

    # 测试 3 次
    tester = PerformanceTester()
    perf_result = tester.test_code_block(test_task, run_times=3)

    print("n性能统计:")
    print(f"执行次数: {perf_result['run_times']}")
    print(f"总实际耗时: {perf_result['total_perf_time']:.6f}s")
    print(f"平均实际耗时: {perf_result['avg_perf_time']:.6f}s")
    print(f"总 CPU 耗时: {perf_result['total_proc_time']:.6f}s")
    print(f"平均 CPU 耗时: {perf_result['avg_proc_time']:.6f}s")

    # ------------------------------
    # 2. 定时任务示例
    # ------------------------------
    print("n" + "="*60)
    print("定时任务执行")
    print("="*60)

    # 定义定时任务：打印一条消息
    def scheduled_job():
        print("执行定时任务：Hello, time!")

    # 创建定时任务：间隔 2 秒，最大执行 5 次
    task = ScheduledTask(scheduled_job, interval=2, max_runs=5)
    task.run()
```

## 五、总结

- `time` 模块是 Python 处理时间的**底层工具**，核心围绕**时间戳**和**结构化时间**，适合系统级时间操作、性能计时、任务休眠；

- 基础用法需掌握 `time()`（时间戳）、`sleep()`（休眠）、`localtime()`/`gmtime()`（结构化时间）、`strftime()`/`strptime()`（格式化）；

- 进阶用法需关注 `perf_counter()`/`process_time()`（高精度计时）、`mktime()`（结构化时间转时间戳）；

- 实战中，`time` 常与性能测试、任务调度、日志记录结合，能精准控制时间相关逻辑。
