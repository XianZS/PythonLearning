# Python标准库smtplib完整教学文档（QQ邮箱专属版）

## 一、概念部分

### 1.1 smtplib库详细概念
smtplib是Python标准库中用于实现**SMTP（Simple Mail Transfer Protocol，简单邮件传输协议）**客户端的核心模块。它提供了一套完整的、面向对象的API，允许Python程序连接到SMTP服务器，执行邮件发送、认证、加密传输等操作。

从技术本质上讲，smtplib是对SMTP协议RFC 5321标准的Python语言封装。它处理了底层的TCP套接字连接、协议命令编码与解析、响应码处理、错误状态管理等复杂细节，使开发者无需深入了解SMTP协议的底层实现，就能快速实现邮件发送功能。

### 1.2 应用场景
smtplib库在Python项目中有着极其广泛的应用，主要包括：
- **自动化通知系统**：程序运行完成、出错或达到特定条件时自动发送邮件通知
- **定时报表系统**：定期生成业务报表、数据分析报告并发送给相关人员
- **用户管理系统**：向新注册用户发送验证邮件、密码重置邮件、账户安全提醒
- **监控告警系统**：服务器监控、应用监控、数据库监控发现异常时发送告警邮件
- **自动化运维**：服务器备份完成通知、系统更新通知、任务执行结果报告
- **营销与客户关系管理**：向客户发送产品更新、活动通知、节日问候等邮件

### 1.3 理论基础
#### SMTP协议工作原理
SMTP是一个基于文本的请求-响应协议，工作在TCP/IP协议栈的应用层。其基本工作流程如下：
1. 客户端与服务器建立TCP连接
2. 服务器返回220响应码，表示准备就绪
3. 客户端发送HELO/EHLO命令标识自己
4. 服务器返回250响应码，表示接受客户端标识
5. 客户端发送AUTH命令进行身份认证
6. 认证成功后，客户端发送MAIL FROM命令指定发件人
7. 客户端发送RCPT TO命令指定收件人
8. 客户端发送DATA命令，表示准备发送邮件内容
9. 客户端发送邮件头和邮件体，以单独一行的"."结束
10. 服务器返回250响应码，表示邮件已接受
11. 客户端发送QUIT命令关闭连接

#### QQ邮箱SMTP服务器关键信息
| 连接方式 | 服务器地址 | 端口号 | 推荐程度 |
|---------|-----------|-------|---------|
| SSL加密 | smtp.qq.com | 465 | 强烈推荐 |
| TLS加密 | smtp.qq.com | 587 | 推荐 |
| 未加密 | smtp.qq.com | 25 | 不推荐（多数网络环境已屏蔽） |

#### QQ邮箱授权码机制
QQ邮箱为了提高账户安全性，**不允许直接使用邮箱密码登录SMTP服务器**，必须使用**授权码**。授权码是QQ邮箱为第三方客户端提供的专用登录凭证，相当于一个应用密码。每个授权码只能用于特定的服务，且可以随时撤销。

### 2.2 发送最简单的纯文本邮件
这是smtplib最基础的用法，演示了完整的邮件发送流程。

**理论说明**：
- `smtplib.SMTP_SSL()`创建一个基于SSL加密的SMTP连接，这是QQ邮箱推荐的最安全连接方式
- `login()`方法使用邮箱地址和授权码进行身份认证
- `MIMEText`类用于创建纯文本邮件内容
- `sendmail()`方法实际发送邮件
- `quit()`方法优雅地关闭SMTP连接

**示例代码**：
```python
import smtplib
from email.mime.text import MIMEText

# 配置信息（请替换为你自己的信息）
SENDER_EMAIL = "your_email@qq.com"
# 注意：这里是授权码，不是邮箱密码
SENDER_PASSWORD = "your_16bit_auth_code"  
# 目标邮箱
RECEIVER_EMAIL = "recipient@example.com"
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 465

# 创建邮件内容
subject = "Python smtplib基础测试邮件"
body = "这是一封使用Python smtplib库发送的纯文本测试邮件。\n\n如果您收到这封邮件，说明基础发送功能正常！\n\n发件人：Python程序"

# 构建MIMEText对象
# 参数说明：邮件内容、内容类型、编码方式
msg = MIMEText(body, "plain", "utf-8")
msg["From"] = SENDER_EMAIL  # 发件人
msg["To"] = RECEIVER_EMAIL  # 收件人
msg["Subject"] = subject    # 邮件主题

try:
    # 建立SSL加密连接
    server = smtplib.SMTP_SSL(SMTP_SERVER, SMTP_PORT, timeout=10)
    
    # 登录邮箱
    server.login(SENDER_EMAIL, SENDER_PASSWORD)
    
    # 发送邮件
    # 参数说明：发件人、收件人、邮件字符串
    server.sendmail(SENDER_EMAIL, RECEIVER_EMAIL, msg.as_string())
    
    print("✅ 邮件发送成功！")

except smtplib.SMTPAuthenticationError:
    print("❌ 认证失败：请检查邮箱地址和授权码是否正确")
except smtplib.SMTPConnectError:
    print("❌ 连接失败：请检查网络连接和SMTP服务器地址端口")
except Exception as e:
    print(f"❌ 邮件发送失败：{str(e)}")
finally:
    # 确保连接被关闭
    if 'server' in locals():
        server.quit()
```

### 2.3 发送给多个收件人
演示如何将邮件发送给多个收件人，包括普通收件人(To)、抄送(Cc)和密送(Bcc)。

**理论说明**：
- `sendmail()`方法的第二个参数可以是字符串列表，表示多个收件人
- 邮件头中的"To"和"Cc"字段需要用逗号分隔多个地址
- "Bcc"（密送）收件人不会在邮件头中显示，其他收件人看不到他们的地址
- 所有收件人（包括To、Cc、Bcc）都必须包含在`sendmail()`的第二个参数中

**示例代码**：
```python
import smtplib
from email.mime.text import MIMEText

# 配置信息
SENDER_EMAIL = "your_email@qq.com"
SENDER_PASSWORD = "your_16bit_auth_code"
TO_EMAILS = ["recipient1@example.com", "recipient2@example.com"]  # 普通收件人
CC_EMAILS = ["cc1@example.com", "cc2@example.com"]              # 抄送收件人
BCC_EMAILS = ["bcc@example.com"]                                # 密送收件人
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 465

# 创建邮件内容
subject = "Python smtplib多收件人测试邮件"
body = "这是一封发送给多个收件人的测试邮件。\n\n包含普通收件人、抄送和密送三种类型。"

# 构建MIMEText对象
msg = MIMEText(body, "plain", "utf-8")
msg["From"] = SENDER_EMAIL
msg["To"] = ", ".join(TO_EMAILS)  # 多个收件人用逗号分隔
msg["Cc"] = ", ".join(CC_EMAILS)  # 多个抄送人用逗号分隔
msg["Subject"] = subject

# 所有收件人列表（普通+抄送+密送）
all_recipients = TO_EMAILS + CC_EMAILS + BCC_EMAILS

try:
    server = smtplib.SMTP_SSL(SMTP_SERVER, SMTP_PORT, timeout=10)
    server.login(SENDER_EMAIL, SENDER_PASSWORD)
    server.sendmail(SENDER_EMAIL, all_recipients, msg.as_string())
    print("✅ 多收件人邮件发送成功！")
except Exception as e:
    print(f"❌ 邮件发送失败：{str(e)}")
finally:
    if 'server' in locals():
        server.quit()
```

### 2.4 使用TLS加密连接
除了SSL加密，smtplib还支持TLS加密连接，这是一种更现代、更灵活的加密方式。

**理论说明**：
- TLS（Transport Layer Security）是SSL的继任者，提供了更好的安全性和性能
- 使用`smtplib.SMTP()`创建普通TCP连接，然后调用`starttls()`方法启用TLS加密
- QQ邮箱支持TLS加密，使用端口587
- TLS加密允许在同一个端口上同时支持加密和未加密连接

**示例代码**：
```python
import smtplib
from email.mime.text import MIMEText

# 配置信息
SENDER_EMAIL = "your_email@qq.com"
SENDER_PASSWORD = "your_16bit_auth_code"
RECEIVER_EMAIL = "recipient@example.com"
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 587  # TLS端口

# 创建邮件内容
subject = "Python smtplib TLS加密测试邮件"
body = "这是一封使用TLS加密连接发送的测试邮件。\n\nTLS是比SSL更现代的加密协议。"

# 构建MIMEText对象
msg = MIMEText(body, "plain", "utf-8")
msg["From"] = SENDER_EMAIL
msg["To"] = RECEIVER_EMAIL
msg["Subject"] = subject

try:
    # 建立普通TCP连接
    server = smtplib.SMTP(SMTP_SERVER, SMTP_PORT, timeout=10)
    
    # 启用TLS加密
    server.starttls()
    
    # 登录邮箱
    server.login(SENDER_EMAIL, SENDER_PASSWORD)
    
    # 发送邮件
    server.sendmail(SENDER_EMAIL, RECEIVER_EMAIL, msg.as_string())
    
    print("✅ TLS加密邮件发送成功！")

except Exception as e:
    print(f"❌ 邮件发送失败：{str(e)}")
finally:
    if 'server' in locals():
        server.quit()
```

### 3.2 发送带附件的邮件
这是项目中非常常见的需求，需要发送包含文件附件的邮件。

**理论说明**：
- 发送带附件的邮件需要使用`MIMEMultipart`对象作为根容器
- `MIMEMultipart`可以包含多个部分：邮件正文、附件等
- 使用`MIMEText`添加邮件正文
- 使用`MIMEApplication`添加任意类型的文件附件
- 需要设置附件的`Content-Disposition`头为"attachment"，并指定文件名

**示例代码**：
```python
import smtplib
import os
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication

# 配置信息
SENDER_EMAIL = "your_email@qq.com"
SENDER_PASSWORD = "your_16bit_auth_code"
RECEIVER_EMAIL = "recipient@example.com"
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 465
ATTACHMENT_PATH = "test_document.pdf"  # 替换为你的附件文件路径

# 创建MIMEMultipart对象（多部分邮件）
msg = MIMEMultipart()
msg["From"] = SENDER_EMAIL
msg["To"] = RECEIVER_EMAIL
msg["Subject"] = "Python smtplib带附件测试邮件"

# 添加邮件正文
body = "这是一封带附件的测试邮件。\n\n附件是一份PDF文档，请查收。\n\n如果附件无法打开，请检查文件是否完整。"
msg.attach(MIMEText(body, "plain", "utf-8"))

# 添加附件
try:
    with open(ATTACHMENT_PATH, "rb") as f:
        # 读取文件内容并创建MIMEApplication对象
        attachment = MIMEApplication(f.read())
    
    # 获取文件名（不包含路径）
    filename = os.path.basename(ATTACHMENT_PATH)
    
    # 设置附件头信息
    attachment.add_header(
        "Content-Disposition", 
        "attachment", 
        filename=filename
    )
    
    # 将附件添加到邮件中
    msg.attach(attachment)
    
    print(f"✅ 成功添加附件：{filename}")

except FileNotFoundError:
    print(f"❌ 错误：附件文件 {ATTACHMENT_PATH} 不存在")
    exit(1)
except Exception as e:
    print(f"❌ 添加附件失败：{str(e)}")
    exit(1)

try:
    server = smtplib.SMTP_SSL(SMTP_SERVER, SMTP_PORT, timeout=10)
    server.login(SENDER_EMAIL, SENDER_PASSWORD)
    server.sendmail(SENDER_EMAIL, RECEIVER_EMAIL, msg.as_string())
    print("✅ 带附件邮件发送成功！")
except Exception as e:
    print(f"❌ 邮件发送失败：{str(e)}")
finally:
    if 'server' in locals():
        server.quit()
```

### 3.3 发送内嵌图片的HTML邮件
有时候我们需要在HTML邮件中嵌入图片，而不是作为附件发送，这样图片会直接显示在邮件正文中。

**理论说明**：
- 使用`MIMEMultipart("related")`创建相关多部分邮件，用于包含内嵌资源
- 使用`MIMEImage`添加图片资源
- 为每个图片设置一个唯一的`Content-ID`
- 在HTML中使用`<img src="cid:content_id">`的方式引用图片

**示例代码**：
```python
import smtplib
import os
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.image import MIMEImage

# 配置信息
SENDER_EMAIL = "your_email@qq.com"

msg = MIMEMultipart("related")
msg["From"] = SENDER_EMAIL
msg["To"] = RECEIVER_EMAIL
msg["Subject"] = "Python smtplib内嵌图片测试邮件"

except FileNotFoundError:
    print(f"❌ 错误：图片文件 {IMAGE_PATH} 不存在")
    exit(1)
except Exception as e:
    print(f"❌ 添加内嵌图片失败：{str(e)}")
    exit(1)

try:
    server = smtplib.SMTP_SSL(SMTP_SERVER, SMTP_PORT, timeout=10)
    server.login(SENDER_EMAIL, SENDER_PASSWORD)
    server.sendmail(SENDER_EMAIL, RECEIVER_EMAIL, msg.as_string())
    print("✅ 内嵌图片邮件发送成功！")
except Exception as e:
    print(f"❌ 邮件发送失败：{str(e)}")
finally:
    if 'server' in locals():
        server.quit()
```

### 3.4 完善的异常处理与重试机制
在实际项目中，网络问题、服务器问题、临时限制等都可能导致邮件发送失败。因此，完善的异常处理和重试机制是必不可少的。

**理论说明**：
- smtplib库定义了多种具体的异常类，可以针对不同类型的错误进行不同的处理
- 对于临时错误（如网络波动、服务器忙），可以使用重试机制提高发送成功率
- 对于永久错误（如认证失败、收件人地址不存在），不需要重试
- 可以设置最大重试次数和重试间隔，避免无限重试和频繁重试

**示例代码**：
```python
import smtplib
import time
from email.mime.text import MIMEText
from smtplib import (
    SMTPException,
    SMTPAuthenticationError,
    SMTPConnectError,
    SMTPRecipientsRefused,
    SMTPSenderRefused,
    SMTPDataError
)

# 配置信息
SENDER_EMAIL = "your_email@qq.com"
SENDER_PASSWORD = "your_16bit_auth_code"
RECEIVER_EMAIL = "recipient@example.com"
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 465
MAX_RETRIES = 3  # 最大重试次数
RETRY_DELAY = 5  # 重试间隔（秒）

def send_email_with_retry():
    """发送邮件，带重试机制"""
    
    # 创建邮件内容
    subject = "Python smtplib异常处理与重试测试邮件"
    body = "这是一封测试异常处理和重试机制的邮件。\n\n如果发送失败，程序会自动重试。"
    
    # 构建MIMEText对象
    msg = MIMEText(body, "plain", "utf-8")
    msg["From"] = SENDER_EMAIL
    msg["To"] = RECEIVER_EMAIL
    msg["Subject"] = subject
    
    for attempt in range(1, MAX_RETRIES + 1):
        server = None
        try:
            # 建立连接
            server = smtplib.SMTP_SSL(SMTP_SERVER, SMTP_PORT, timeout=10)
            
            # 登录
            server.login(SENDER_EMAIL, SENDER_PASSWORD)
            
            # 发送邮件
            server.sendmail(SENDER_EMAIL, RECEIVER_EMAIL, msg.as_string())
            
            print(f"✅ 邮件发送成功！（第{attempt}次尝试）")
            return True
            
        except SMTPAuthenticationError:
            print(f"❌ 第{attempt}次尝试失败：邮箱认证错误")
            print("💡 提示：请检查邮箱地址和授权码是否正确")
            return False  # 认证错误是永久错误，不需要重试
            
        except SMTPConnectError:
            print(f"❌ 第{attempt}次尝试失败：无法连接到SMTP服务器")
            
        except SMTPRecipientsRefused:
            print(f"❌ 第{attempt}次尝试失败：收件人地址被拒绝")
            print("💡 提示：请检查收件人邮箱地址是否正确")
            return False  # 收件人错误是永久错误，不需要重试
            
        except SMTPSenderRefused:
            print(f"❌ 第{attempt}次尝试失败：发件人地址被拒绝")
            return False  # 发件人错误是永久错误，不需要重试
            
        except SMTPDataError as e:
            print(f"❌ 第{attempt}次尝试失败：邮件数据错误 - {e}")
            
        except SMTPException as e:
            print(f"❌ 第{attempt}次尝试失败：SMTP协议错误 - {e}")
            
        except Exception as e:
            print(f"❌ 第{attempt}次尝试失败：未知错误 - {e}")
            
        finally:
            # 确保连接被关闭
            if server:
                try:
                    server.quit()
                except:
                    pass
        
        # 如果不是最后一次尝试，等待后重试
        if attempt < MAX_RETRIES:
            print(f"⏳ 等待{RETRY_DELAY}秒后进行第{attempt+1}次尝试...")
            time.sleep(RETRY_DELAY)
    
    print(f"❌ 所有{MAX_RETRIES}次尝试都失败了")
    return False

# 调用发送函数
if __name__ == "__main__":
    success = send_email_with_retry()
    if success:
        print("\n🎉 邮件发送任务完成")
    else:
        print("\n⚠️ 邮件发送任务失败")
```

### 3.5 批量邮件发送优化
当需要发送大量邮件时，每次发送都建立和关闭连接会非常低效。可以使用长连接来优化批量邮件发送。

**理论说明**：
- 建立一次SMTP连接，发送多封邮件，可以显著提高发送效率
- QQ邮箱对SMTP发送频率有限制，一般是每天不超过500封，每小时不超过100封
- 可以在每发送一定数量的邮件后，暂停一段时间，避免被判定为垃圾邮件
- 批量发送时，建议为每个收件人创建单独的邮件，而不是使用多收件人方式

**示例代码**：
```python
import smtplib
import time
from email.mime.text import MIMEText

# 配置信息
SENDER_EMAIL = "your_email@qq.com"
SENDER_PASSWORD = "your_16bit_auth_code"
SMTP_SERVER = "smtp.qq.com"
SMTP_PORT = 465
BATCH_SIZE = 10  # 每批发送的邮件数量
BATCH_DELAY = 60  # 每批之间的间隔（秒）

# 收件人列表（实际项目中可以从数据库或文件读取）
recipients = [
    {"email": "user1@example.com", "name": "用户1"},
    {"email": "user2@example.com", "name": "用户2"},
    {"email": "user3@example.com", "name": "用户3"},
    {"email": "user4@example.com", "name": "用户4"},
    {"email": "user5@example.com", "name": "用户5"},
    # 添加更多收件人...
]

def send_batch_emails():
    """批量发送邮件"""
    
    total_recipients = len(recipients)
    total_sent = 0
    total_failed = 0
    
    try:
        # 建立一次连接
        server = smtplib.SMTP_SSL(SMTP_SERVER, SMTP_PORT, timeout=10)
        server.login(SENDER_EMAIL, SENDER_PASSWORD)
        
        print(f"✅ 成功连接到SMTP服务器")
        print(f"📧 开始批量发送邮件，共{total_recipients}个收件人")
        print("-" * 50)
        
        for i, recipient in enumerate(recipients, 1):
            email = recipient["email"]
            name = recipient["name"]
            
            # 创建个性化邮件内容
            subject = f"尊敬的{name}，这是一封批量发送的测试邮件"
            body = f"""尊敬的{name}：

您好！

这是使用Python smtplib库批量发送的测试邮件。

您是第{i}位收件人。

祝您生活愉快！

Python邮件发送程序
"""
            
            # 构建MIMEText对象
            msg = MIMEText(body, "plain", "utf-8")
            msg["From"] = SENDER_EMAIL
            msg["To"] = email
            msg["Subject"] = subject
            
            try:
                # 发送邮件
                server.sendmail(SENDER_EMAIL, email, msg.as_string())
                print(f"✅ [{i}/{total_recipients}] 成功发送给 {name} <{email}>")
                total_sent += 1
            except Exception as e:
                print(f"❌ [{i}/{total_recipients}] 发送给 {name} <{email}> 失败：{str(e)}")
                total_failed += 1
            
            # 每发送BATCH_SIZE封邮件，暂停BATCH_DELAY秒
            if i % BATCH_SIZE == 0 and i < total_recipients:
                print(f"\n⏳ 已发送{BATCH_SIZE}封邮件，等待{BATCH_DELAY}秒后继续...")
                time.sleep(BATCH_DELAY)
                print()
        
        print("-" * 50)
        print(f"📊 批量邮件发送完成！")
        print(f"   总收件人数：{total_recipients}")
        print(f"   成功发送：{total_sent}")
        print(f"   发送失败：{total_failed}")
        
        return total_sent, total_failed
        
    except Exception as e:
        print(f"❌ 批量邮件发送失败：{str(e)}")
        return total_sent, total_failed
    finally:
        if 'server' in locals():
            server.quit()
            print("✅ 已断开与SMTP服务器的连接")

# 调用批量发送函数
if __name__ == "__main__":
    send_batch_emails()
```

### 4.1 完整的QQ邮箱发送工具类
结合前面所学的所有内容，我们来实现一个功能完整、可复用、生产级别的QQ邮箱发送工具类。这个工具类将封装所有邮件发送的细节，提供简洁易用的接口。

**工具类功能**：
- 支持纯文本和HTML格式邮件
- 支持添加多个附件
- 支持添加多个内嵌图片
- 支持普通收件人、抄送和密送
- 完善的异常处理
- 可配置的重试机制
- 详细的日志记录
- 中文文件名支持

**完整代码**：
```python
import smtplib
import time
import os
import logging
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication
from email.mime.image import MIMEImage
from smtplib import (
    SMTPException,
    SMTPAuthenticationError,
    SMTPConnectError,
    SMTPRecipientsRefused,
    SMTPSenderRefused
)

# 配置日志
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('email_sender.log', encoding='utf-8'),
        logging.StreamHandler()
    ]
)

class QQEmailSender:
    """
    QQ邮箱发送工具类
    封装了smtplib的所有复杂操作，提供简洁易用的接口
    """
    
    def __init__(self, 
                 sender_email: str, 
                 sender_password: str, 
                 smtp_server: str = "smtp.qq.com", 
                 smtp_port: int = 465, 
                 use_ssl: bool = True,
                 max_retries: int = 3,
                 retry_delay: int = 5):
        """
        初始化邮件发送器
        
        Args:
            sender_email: 发件人QQ邮箱地址
            sender_password: 发件人QQ邮箱授权码
            smtp_server: SMTP服务器地址，默认smtp.qq.com
            smtp_port: SMTP服务器端口，默认465(SSL)
            use_ssl: 是否使用SSL加密，默认True
            max_retries: 最大重试次数，默认3次
            retry_delay: 重试间隔（秒），默认5秒
        """
        self.sender_email = sender_email
        self.sender_password = sender_password
        self.smtp_server = smtp_server
        self.smtp_port = smtp_port
        self.use_ssl = use_ssl
        self.max_retries = max_retries
        self.retry_delay = retry_delay
        self.logger = logging.getLogger(self.__class__.__name__)
        self.server = None
    
    def _connect(self) -> bool:
        """
        连接到SMTP服务器并登录
        
        Returns:
            bool: 连接成功返回True，失败返回False
        """
        try:
            if self.use_ssl:
                self.server = smtplib.SMTP_SSL(
                    self.smtp_server, 
                    self.smtp_port, 
                    timeout=10
                )
            else:
                self.server = smtplib.SMTP(
                    self.smtp_server, 
                    self.smtp_port, 
                    timeout=10
                )
                self.server.starttls()  # 启用TLS加密
            
            self.server.login(self.sender_email, self.sender_password)
            self.logger.info("成功连接到SMTP服务器")
            return True
            
        except SMTPAuthenticationError:
            self.logger.error("邮箱认证失败，请检查邮箱地址和授权码")
            return False
        except SMTPConnectError:
            self.logger.error("无法连接到SMTP服务器，请检查网络和服务器地址端口")
            return False
        except Exception as e:
            self.logger.error(f"连接SMTP服务器时发生未知错误：{str(e)}")
            return False
    
    def _disconnect(self):
        """断开与SMTP服务器的连接"""
        if self.server:
            try:
                self.server.quit()
                self.logger.info("已断开与SMTP服务器的连接")
            except Exception as e:
                self.logger.error(f"断开连接时发生错误：{str(e)}")
            finally:
                self.server = None
    
    def _build_message(self, 
                      to_emails: list, 
                      subject: str, 
                      body: str, 
                      body_type: str = "plain",
                      cc_emails: list = None,
                      bcc_emails: list = None,
                      attachments: list = None,
                      inline_images: dict = None) -> MIMEMultipart:
        """
        构建邮件消息对象
        
        Args:
            to_emails: 普通收件人列表
            subject: 邮件主题
            body: 邮件正文
            body_type: 正文类型，"plain"或"html"
            cc_emails: 抄送收件人列表
            bcc_emails: 密送收件人列表
            attachments: 附件路径列表
            inline_images: 内嵌图片字典，格式为{content_id: image_path}
        
        Returns:
            MIMEMultipart: 构建好的邮件消息对象
        """
        # 处理参数默认值
        cc_emails = cc_emails or []
        bcc_emails = bcc_emails or []
        attachments = attachments or []
        inline_images = inline_images or {}
        
        # 创建根容器
        if inline_images:
            msg = MIMEMultipart("related")
        else:
            msg = MIMEMultipart()
        
        # 设置邮件头
        msg["From"] = self.sender_email
        msg["To"] = ", ".join(to_emails)
        if cc_emails:
            msg["Cc"] = ", ".join(cc_emails)
        msg["Subject"] = subject
        
        # 添加邮件正文
        msg.attach(MIMEText(body, body_type, "utf-8"))
        
        # 添加附件
        for attachment_path in attachments:
            if not os.path.exists(attachment_path):
                self.logger.error(f"附件文件不存在：{attachment_path}")
                raise FileNotFoundError(f"附件文件不存在：{attachment_path}")
            
            with open(attachment_path, "rb") as f:
                attachment = MIMEApplication(f.read())
            
            filename = os.path.basename(attachment_path)
            attachment.add_header(
                "Content-Disposition", 
                "attachment", 
                filename=filename
                )
            msg.attach(attachment)
            self.logger.debug(f"成功添加附件：{filename}")
        
        # 添加内嵌图片
        for content_id, image_path in inline_images.items():
            if not os.path.exists(image_path):
                self.logger.error(f"内嵌图片文件不存在：{image_path}")
                raise FileNotFoundError(f"内嵌图片文件不存在：{image_path}")
            
            with open(image_path, "rb") as f:
                image = MIMEImage(f.read())
            
            image.add_header("Content-ID", f"<{content_id}>")
            msg.attach(image)
            self.logger.debug(f"成功添加内嵌图片：{image_path} (Content-ID: {content_id})")
        
        return msg
    
    def send_email(self, 
                  to_emails: str | list, 
                  subject: str, 
                  body: str, 
                  body_type: str = "plain",
                  cc_emails: str | list = None,
                  bcc_emails: str | list = None,
                  attachments: str | list = None,
                  inline_images: dict = None) -> bool:
        """
        发送邮件（带重试机制）
        
        Args:
            to_emails: 普通收件人，可以是字符串或列表
            subject: 邮件主题
            body: 邮件正文
            body_type: 正文类型，"plain"或"html"
            cc_emails: 抄送收件人，可以是字符串或列表
            bcc_emails: 密送收件人，可以是字符串或列表
            attachments: 附件路径，可以是字符串或列表
            inline_images: 内嵌图片字典，格式为{content_id: image_path}
        
        Returns:
            bool: 发送成功返回True，失败返回False
        """
        # 统一参数格式
        if isinstance(to_emails, str):
            to_emails = [to_emails]
        if isinstance(cc_emails, str):
            cc_emails = [cc_emails]
        if isinstance(bcc_emails, str):
            bcc_emails = [bcc_emails]
        if isinstance(attachments, str):
            attachments = [attachments]
        
        # 所有收件人列表
        all_recipients = to_emails + (cc_emails or []) + (bcc_emails or [])
        
        if not all_recipients:
            self.logger.error("没有指定任何收件人")
            return False
        
        try:
            # 构建邮件
            msg = self._build_message(
                to_emails=to_emails,
                subject=subject,
                body=body,
                body_type=body_type,
                cc_emails=cc_emails,
                bcc_emails=bcc_emails,
                attachments=attachments,
                inline_images=inline_images
            )
        except Exception as e:
            self.logger.error(f"构建邮件失败：{str(e)}")
            return False
        
        # 发送邮件（带重试）
        for attempt in range(1, self.max_retries + 1):
            try:
                # 如果连接已断开，重新连接
                if not self.server:
                    if not self._connect():
                        continue
                
                # 发送邮件
                self.server.sendmail(
                    self.sender_email, 
                    all_recipients, 
                    msg.as_string()
                )
                
                self.logger.info(f"邮件发送成功！（第{attempt}次尝试）收件人：{', '.join(all_recipients)}")
                return True
                
            except SMTPRecipientsRefused:
                self.logger.error("收件人地址被拒绝，请检查收件人邮箱是否正确")
                return False
            except SMTPSenderRefused:
                self.logger.error("发件人地址被拒绝")
                return False
            except SMTPException as e:
                self.logger.error(f"第{attempt}次尝试失败：SMTP协议错误 - {str(e)}")
                self._disconnect()  # 连接可能已损坏，重新连接
            except Exception as e:
                self.logger.error(f"第{attempt}次尝试失败：未知错误 - {str(e)}")
                self._disconnect()
            
            # 如果不是最后一次尝试，等待后重试
            if attempt < self.max_retries:
                self.logger.info(f"等待{self.retry_delay}秒后进行第{attempt+1}次尝试...")
                time.sleep(self.retry_delay)
        
        self.logger.error(f"所有{self.max_retries}次尝试都失败了")
        return False
    
    def __enter__(self):
        """上下文管理器入口"""
        self._connect()
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        """上下文管理器出口"""
        self._disconnect()
```

```python
        dict: 包含CPU、内存、磁盘使用率和时间戳的字典
    """
    # 获取CPU使用率（采样1秒）
    cpu_percent = psutil.cpu_percent(interval=1)
    
    # 获取内存使用情况
    memory = psutil.virtual_memory()
    memory_percent = memory.percent
    memory_used_gb = round(memory.used / (1024 ** 3), 2)
    memory_total_gb = round(memory.total / (1024 ** 3), 2)
    
    # 获取磁盘使用情况（根分区）
    disk = psutil.disk_usage("/")
    disk_percent = disk.percent
    disk_used_gb = round(disk.used / (1024 ** 3), 2)
    disk_total_gb = round(disk.total / (1024 ** 3), 2)
    
    return {
        "cpu_percent": cpu_percent,
        "memory_percent": memory_percent,
        "memory_used_gb": memory_used_gb,
        "memory_total_gb": memory_total_gb,
        "disk_percent": disk_percent,
        "disk_used_gb": disk_used_gb,
        "disk_total_gb": disk_total_gb,
        "timestamp": datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    }
```

## 五、注意事项与最佳实践

### 5.1 QQ邮箱使用注意事项
1. **必须使用授权码**：QQ邮箱不允许直接使用邮箱密码登录SMTP服务器，必须使用授权码
2. **发送频率限制**：QQ邮箱对SMTP发送频率有严格限制，一般是每天不超过500封，每小时不超过100封
3. **垃圾邮件过滤**：避免发送包含敏感关键词、大量链接、大量附件或相同内容的邮件，否则可能被判定为垃圾邮件
4. **发件人一致性**：发件人地址必须与登录邮箱地址一致，否则会被拒绝
5. **附件大小限制**：QQ邮箱SMTP服务对附件大小有限制，单个附件一般不超过50MB，总附件大小不超过100MB

### 5.2 代码最佳实践
1. **使用加密连接**：始终使用SSL或TLS加密连接，保护邮件内容和登录凭证的安全
2. **配置分离**：将邮箱配置信息（地址、授权码）与代码分离，使用配置文件或环境变量
3. **完善异常处理**：邮件发送可能因为各种原因失败，必须有完善的异常处理机制
4. **实现重试机制**：对于临时的网络问题或服务器问题，重试机制可以显著提高发送成功率
5. **批量发送优化**：批量发送邮件时，使用长连接并控制发送频率
6. **日志记录**：记录邮件发送的详细日志，包括发送时间、收件人、主题、状态等，便于问题排查
7. **使用上下文管理器**：使用`with`语句管理SMTP连接，确保连接总是被正确关闭
8. **测试环境**：在测试环境中充分测试邮件发送功能，避免影响生产环境

### 5.3 常见问题与解决方案
1. **认证失败**：检查邮箱地址和授权码是否正确，确保SMTP服务已开启
2. **连接失败**：检查网络连接，确认SMTP服务器地址和端口是否正确，尝试使用465端口
3. **邮件被拒收**：检查邮件内容是否包含敏感信息，避免被判定为垃圾邮件
4. **中文乱码**：使用`utf-8`编码，设置正确的`Content-Type`头
5. **附件无法打开**：确保附件文件路径正确，文件没有损坏，使用`MIMEApplication`处理附件
6. **内嵌图片不显示**：检查`Content-ID`是否正确，确保图片文件存在，使用`MIMEMultipart("related")`
