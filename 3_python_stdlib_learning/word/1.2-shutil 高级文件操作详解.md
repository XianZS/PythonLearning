# B站Python授课：`shutil` 标准库——高级文件操作神器

## 课程导入

上节课我们学习了 `os` 库的基础文件操作，但 `os` 库在**复制非空目录、保留文件元数据、批量压缩解压**等场景下比较繁琐。`shutil`（shell utilities）库正是 `os` 的“黄金搭档”，专门处理**高级文件/目录操作**，是自动化脚本、文件整理工具的必备利器。

---

## 第一部分：文件与目录复制（核心功能）

### 核心知识点

`shutil` 提供了多种复制函数，区别在于是否保留文件元数据（创建时间、权限等）、是否支持目录递归复制。

### 常用函数与示例代码

```Python

import shutil
import os

# 准备测试文件
with open("test.txt", "w") as f:
    f.write("Hello shutil!")
os.makedirs("src_dir", exist_ok=True)
with open("src_dir/nested.txt", "w") as f:
    f.write("Nested file")

# 1. 复制文件（不保留元数据）
shutil.copy("test.txt", "test_copy.txt")  # 复制到当前目录
shutil.copy("test.txt", "src_dir/test_copy.txt")  # 复制到指定目录

# 2. 复制文件（保留元数据：创建时间、权限等）
shutil.copy2("test.txt", "test_copy2.txt")  # 推荐用这个，更“完整”地复制

# 3. 递归复制整个目录（类似shell的cp -r）
shutil.copytree("src_dir", "dst_dir")  # dst_dir必须不存在，否则报错
shutil.copytree("src_dir", "dst_dir_backup", dirs_exist_ok=True)  # Python 3.8+：允许目标目录存在

print("复制完成！")
```

### 内容讲解

- `shutil.copy()`：仅复制文件内容和权限，不保留创建/修改时间（元数据），适合简单文件备份。

- `shutil.copy2()`：**最常用复制函数**，保留文件所有元数据（如修改时间、权限），复制后文件“几乎和原文件一模一样”。

- `shutil.copytree()`：递归复制目录，`dirs_exist_ok=True`（Python 3.8+）是避坑关键，避免目标目录存在时报错。

### 应用场景

1. 项目备份：用 `copytree()` 定期备份整个项目目录，保留文件修改时间方便追溯。

2. 素材整理：从相机SD卡复制照片到电脑，用 `copy2()` 保留照片拍摄时间。

## 第二部分：文件/目录移动与重命名

### 核心知识点

`shutil.move()` 既能移动文件/目录，也能实现重命名，跨磁盘分区也能正常工作（自动处理复制+删除逻辑）。

### 常用函数与示例代码

```Python

import shutil
import os

# 准备测试环境
os.makedirs("old_dir", exist_ok=True)
with open("old_dir/move_test.txt", "w") as f:
    f.write("Move me!")

# 1. 移动文件到新目录
shutil.move("old_dir/move_test.txt", "dst_dir/move_test.txt")  # dst_dir需存在

# 2. 重命名文件（移动到同一目录，不同文件名）
shutil.move("test_copy.txt", "test_renamed.txt")

# 3. 移动整个目录
shutil.move("old_dir", "dst_dir/old_dir_moved")  # 移动old_dir到dst_dir下并重命名

print("移动/重命名完成！")
```

### 内容讲解

- `shutil.move(src, dst)`：

    - 若 `dst` 是**已存在的目录**：将 `src` 移动到 `dst` 目录下。

    - 若 `dst` 是**不存在的路径**：将 `src` 重命名为 `dst`。

    - 跨分区移动时，`shutil` 会自动先复制再删除原文件，无需手动处理。

### 应用场景

1. 下载文件夹自动整理：遍历 `Downloads`，将 `.pdf` 移动到 `Documents/PDF`，`.jpg` 移动到 `Pictures`。

2. 批量重命名：结合 `os.listdir()`，将 `img_001.jpg` 批量重命名为 `vacation_001.jpg`。

## 第三部分：删除非空目录（危险操作，谨慎使用）

### 核心知识点

`os.rmdir()` 只能删除空目录，`shutil.rmtree()` 可以**递归删除非空目录**（包括所有子文件和子目录），是“危险但实用”的功能。

### 常用函数与示例代码

```Python

import shutil
import os

# 准备测试目录
os.makedirs("to_delete/sub_dir", exist_ok=True)
with open("to_delete/file.txt", "w") as f:
    f.write("Delete me!")

# 删除非空目录（危险操作！建议先打印确认）
target_dir = "to_delete"
if os.path.exists(target_dir):
    confirm = input(f"确认删除目录 {target_dir} 吗？(y/n): ")
    if confirm.lower() == "y":
        shutil.rmtree(target_dir)
        print(f"已删除目录：{target_dir}")
    else:
        print("取消删除")
else:
    print(f"目录 {target_dir} 不存在")
```

### 内容讲解

- `shutil.rmtree(path)`：直接删除整个目录树，**无法通过回收站恢复**，务必谨慎！

- 避坑指南：删除前先 `os.path.exists()` 判断路径是否存在，或加用户确认逻辑，防止误删重要文件。

### 应用场景

1. 清理临时文件：删除程序运行生成的临时缓存目录（如 `__pycache__`）。

2. 卸载脚本：删除软件安装目录下的所有文件（需配合权限判断）。

## 第四部分：压缩与解压（实用功能）

### 核心知识点

`shutil` 支持直接创建和解压 `zip`、`tar`、`gztar` 等格式的压缩包，无需额外安装第三方库。

### 常用函数与示例代码

```Python

import shutil
import os

# 准备测试文件
os.makedirs("compress_dir", exist_ok=True)
with open("compress_dir/file1.txt", "w") as f:
    f.write("File 1")
with open("compress_dir/file2.txt", "w") as f:
    f.write("File 2")

# 1. 创建压缩包
# 参数：压缩包路径（不含后缀）、压缩格式、要压缩的目录
shutil.make_archive("my_archive", "zip", "compress_dir")  # 生成 my_archive.zip
shutil.make_archive("my_archive_tar", "gztar", "compress_dir")  # 生成 .tar.gz

# 2. 解压压缩包
# 参数：压缩包路径、解压目标目录（可选，默认当前目录）
shutil.unpack_archive("my_archive.zip", "extract_dir")  # 解压到 extract_dir
shutil.unpack_archive("my_archive_tar.tar.gz", "extract_dir_tar")

print("压缩/解压完成！")
```

### 内容讲解

- `shutil.make_archive(base_name, format, root_dir)`：

    - `base_name`：压缩包路径（不含后缀，自动根据格式添加）。

    - `format`：压缩格式，支持 `zip`、`tar`、`gztar`、`bztar`、`xztar`。

    - `root_dir`：要压缩的目录路径。

- `shutil.unpack_archive(filename, extract_dir)`：自动识别压缩格式，无需手动指定。

### 应用场景

1. 自动备份脚本：每周用 `make_archive` 压缩项目目录，按日期命名（如 `project_backup_20260412.zip`）。

2. 批量解压：遍历下载文件夹，用 `unpack_archive` 自动解压所有 `.zip` 文件。

## 课程总结与实战练习

### 核心回顾

1. **复制**：`copy2()` 保留元数据，`copytree()` 递归复制目录。

2. **移动/重命名**：`move()` 一专多能，跨分区也能用。

3. **删除**：`rmtree()` 危险但高效，务必加确认逻辑。

4. **压缩解压**：`make_archive()` 和 `unpack_archive()` 搞定常见格式。

### 实战练习

结合 `os` 和 `shutil` 库，写一个“自动文件整理脚本”，实现以下功能：

1. 在当前目录创建 `sorted` 文件夹，并在其下创建 `images`、`documents`、`others` 三个子文件夹。

2. 遍历当前目录（不包括 `sorted` 文件夹）：

    - 将 `.jpg`、`.png`、`.gif` 文件移动到 `sorted/images`。

    - 将 `.txt`、`.pdf`、`.docx` 文件移动到 `sorted/documents`。

    - 其他文件移动到 `sorted/others`。

3. 最后将 `sorted` 文件夹压缩为 `sorted_backup.zip`。
