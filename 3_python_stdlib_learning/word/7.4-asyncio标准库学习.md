# Python 3.14 asyncio 标准库学习文档

## 一、概念与核心原理

### 1.1 异步编程与协程
异步编程是一种并发编程范式，核心思想是**在等待I/O操作时主动让出CPU执行权**，避免线程阻塞，从而提升程序整体吞吐量。

协程（Coroutine）是asyncio的核心执行单元，它是一种**用户态轻量级线程**：
- 由Python解释器调度（而非操作系统内核）
- 内存开销远小于线程（仅KB级别）
- 切换成本极低（无需内核态上下文切换）

### 1.2 事件循环（Event Loop）
事件循环是asyncio的"大脑"，负责：
- 管理协程任务队列
- 监听I/O事件（网络、文件等）
- 调度协程的执行与挂起
- 处理回调函数

Python 3.14中，事件循环的默认实现已优化为基于`epoll`（Linux）/`kqueue`（BSD/macOS）/`IOCP`（Windows）的高性能版本。

### 1.3 asyncio的核心优势
- **高并发**：单线程可处理数千并发连接
- **低开销**：协程切换成本远低于线程
- **语法简洁**：`async/await`语法使异步代码逻辑清晰
- **标准库支持**：无需第三方依赖即可实现异步I/O


## 二、基础部分：核心API与使用

### 2.1 协程的定义与运行
使用`async def`定义协程函数，调用协程函数会返回协程对象，需通过事件循环执行。

```python
import asyncio

# 定义协程函数
async def hello_world():
    print("Hello")
    # 模拟I/O等待，挂起当前协程
    await asyncio.sleep(1)
    print("World")

# Python 3.7+推荐使用asyncio.run()运行主协程
asyncio.run(hello_world())
```

**输出**：
```
Hello
（等待1秒）
World
```

### 2.2 await关键字
`await`用于挂起当前协程，等待另一个协程或`Future`对象完成。只有在`async def`函数中才能使用`await`。

```python
async def compute(x, y):
    print(f"Computing {x} + {y}...")
    await asyncio.sleep(1)  # 模拟耗时计算
    return x + y

async def main():
    # 等待compute协程完成并获取结果
    result = await compute(3, 5)
    print(f"Result: {result}")

asyncio.run(main())
```

### 2.3 Task对象：并发执行协程
`asyncio.create_task()`将协程包装为`Task`对象，加入事件循环队列并发执行。

```python
async def say_after(delay, what):
    await asyncio.sleep(delay)
    print(what)

async def main():
    # 创建两个并发任务
    task1 = asyncio.create_task(say_after(1, "Hello"))
    task2 = asyncio.create_task(say_after(2, "World"))

    print("Tasks started")
    # 等待两个任务完成
    await task1
    await task2
    print("All tasks done")

asyncio.run(main())
```

**输出**：
```
Tasks started
（1秒后）Hello
（再1秒后）World
All tasks done
```

### 2.4 gather与wait：批量管理协程
- `asyncio.gather()`：并发运行多个协程，按输入顺序返回结果
- `asyncio.wait()`：等待协程完成，支持返回条件控制（如`FIRST_COMPLETED`）

```python
async def fetch_data(delay, data_id):
    await asyncio.sleep(delay)
    return f"Data {data_id}"

async def main():
    # 使用gather并发执行并收集结果
    results = await asyncio.gather(
        fetch_data(1, 1),
        fetch_data(2, 2),
        fetch_data(3, 3)
    )
    print("Gather results:", results)  # 按输入顺序返回

    # 使用wait等待第一个完成的任务
    tasks = [
        asyncio.create_task(fetch_data(1, "A")),
        asyncio.create_task(fetch_data(2, "B"))
    ]
    done, pending = await asyncio.wait(
        tasks,
        return_when=asyncio.FIRST_COMPLETED
    )
    for task in done:
        print("First completed:", task.result())

asyncio.run(main())
```


## 三、进阶部分：高级特性与模式

### 3.1 同步原语：协程间的协作
asyncio提供了类似线程的同步原语，但专为协程设计：

#### 3.1.1 Lock（互斥锁）
保护共享资源，防止并发访问冲突。

```python
import asyncio

shared_counter = 0
lock = asyncio.Lock()

async def increment():
    global shared_counter
    # 获取锁，确保临界区代码互斥执行
    async with lock:
        temp = shared_counter
        await asyncio.sleep(0.1)  # 模拟I/O操作
        shared_counter = temp + 1

async def main():
    # 启动10个协程并发修改共享变量
    await asyncio.gather(*[increment() for _ in range(10)])
    print("Final counter:", shared_counter)  # 正确输出10

asyncio.run(main())
```

#### 3.1.2 Semaphore（信号量）
控制并发访问数量，常用于限制并发连接数。

```python
async def limited_access(sem, resource_id):
    async with sem:  # 最多允许3个协程同时进入
        print(f"Accessing resource {resource_id}")
        await asyncio.sleep(1)
        print(f"Releasing resource {resource_id}")

async def main():
    sem = asyncio.Semaphore(3)  # 限制并发数为3
    await asyncio.gather(*[limited_access(sem, i) for i in range(10)])

asyncio.run(main())
```

### 3.2 异步上下文管理器
使用`async with`定义支持异步进入/退出的上下文管理器，需实现`__aenter__`和`__aexit__`方法。

```python
class AsyncDatabaseConnection:
    async def connect(self):
        print("Connecting to database...")
        await asyncio.sleep(1)
        print("Connected")

    async def disconnect(self):
        print("Disconnecting...")
        await asyncio.sleep(0.5)
        print("Disconnected")

    async def __aenter__(self):
        await self.connect()
        return self  # 返回给as后的变量

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        await self.disconnect()
        # 返回False表示不抑制异常，True表示抑制
        return False

async def main():
    async with AsyncDatabaseConnection() as conn:
        print("Using database connection...")
        await asyncio.sleep(1)

asyncio.run(main())
```

### 3.3 异步迭代器与生成器
- 异步迭代器：实现`__aiter__`和`__anext__`方法，使用`async for`遍历
- 异步生成器：使用`async def`+`yield`，简化异步迭代器实现

```python
# 异步生成器示例
async def async_counter(n):
    for i in range(n):
        await asyncio.sleep(0.5)
        yield i  # 异步生成数据

async def main():
    # 使用async for遍历异步生成器
    async for num in async_counter(5):
        print(f"Count: {num}")

asyncio.run(main())
```

### 3.4 任务取消与异常处理
协程可以通过`Task.cancel()`取消，需在协程中处理`CancelledError`。

```python
async def long_running_task():
    try:
        for i in range(5):
            print(f"Working... {i}")
            await asyncio.sleep(1)
    except asyncio.CancelledError:
        print("Task was cancelled!")
        # 可选：重新抛出异常让调用者感知
        raise
    finally:
        print("Cleaning up resources...")

async def main():
    task = asyncio.create_task(long_running_task())
    await asyncio.sleep(2.5)  # 等待2.5秒后取消任务
    print("Cancelling task...")
    task.cancel()
    try:
        await task
    except asyncio.CancelledError:
        print("Main caught task cancellation")

asyncio.run(main())
```


## 四、实战案例：异步网页爬虫
我们将使用asyncio + `aiohttp`（异步HTTP客户端库）实现一个高并发网页爬虫，批量获取网页标题。

### 4.1 安装依赖
```bash
pip install aiohttp beautifulsoup4
```

### 4.2 完整代码
```python
import asyncio
import aiohttp
from bs4 import BeautifulSoup
from typing import List, Tuple

# 目标URL列表
TARGET_URLS = [
    "https://www.python.org",
    "https://www.example.com",
    "https://httpbin.org/html",
    "https://stackoverflow.com",
    "https://github.com"
]

async def fetch_page_title(session: aiohttp.ClientSession, url: str) -> Tuple[str, str]:
    """异步获取单个网页的标题"""
    try:
        async with session.get(url, timeout=10) as response:
            # 检查HTTP状态码
            response.raise_for_status()
            # 异步读取HTML内容
            html = await response.text()
            # 解析标题
            soup = BeautifulSoup(html, "html.parser")
            title = soup.title.string.strip() if soup.title else "No title found"
            return (url, title)
    except Exception as e:
        return (url, f"Error: {str(e)}")

async def main(urls: List[str]):
    """主协程：并发爬取所有URL"""
    print(f"Starting crawl of {len(urls)} URLs...\n")
    
    # 创建异步HTTP会话（复用连接池）
    async with aiohttp.ClientSession() as session:
        # 创建所有爬取任务
        tasks = [fetch_page_title(session, url) for url in urls]
        # 并发执行所有任务
        results = await asyncio.gather(*tasks)
        
        # 输出结果
        print("Crawl results:")
        print("=" * 80)
        for url, title in results:
            print(f"URL: {url}")
            print(f"Title: {title}")
            print("-" * 80)

if __name__ == "__main__":
    # 运行爬虫
    asyncio.run(main(TARGET_URLS))
```

### 4.3 代码解析
1. **异步HTTP会话**：`aiohttp.ClientSession`作为异步上下文管理器，自动管理连接池，提升性能
2. **并发控制**：通过`asyncio.gather()`同时发起所有HTTP请求，总耗时取决于最慢的请求
3. **异常处理**：单个请求失败不影响其他请求，错误信息会被记录
4. **资源管理**：`async with`确保会话和连接正确关闭

### 4.4 运行效果
程序会在几秒内完成所有URL的爬取（取决于网络速度），输出每个网页的标题或错误信息。
