# B 站 Python 授课：`sys` 标准库 ——Python 解释器的 “交互控制台”

## 课程导入

在写 Python 代码时，你一定遇到过这些场景：

- 想给脚本传命令行参数（比如 `python script.py input.txt`）；

- 程序出错时想主动退出并返回错误码；

这些需求都能通过 **`sys`** 标准库解决！`sys` 是 Python 与**解释器 / 操作系统**交互的核心接口，提供了大量控制解释器行为、获取系统信息的功能，是编写脚本、工具、调试代码的必备库！

本节课我们重点学习 `sys` 中最常用的功能，包含命令行参数、程序退出、模块路径、系统信息等，最后还有一个综合实战案例！

## 第一部分：核心概念

### 1. `sys` 库的作用

`sys` 是 Python 内置库，无需安装，它主要负责：

- 与 Python 解释器交互（如退出程序、修改递归限制）；

- 与操作系统交互（如获取命令行参数、系统平台）；

- 管理 Python 运行时环境（如模块搜索路径、标准输入输出）。

### 2. 学习建议

`sys` 库的功能比较杂，我们按 “实用频率” 排序，先学最常用的，再学进阶的。

## 第二部分：常用功能详解

### 1. `sys.argv` —— 命令行参数（脚本工具的 “入口”）

#### 核心知识点

`sys.argv` 是一个**列表**，存储了从命令行传递给脚本的所有参数：

- `sys.argv[0]`：**脚本本身的名字**（比如 `script.py`）；

- `sys.argv[1:]`：传递给脚本的**其他参数**。

#### 示例代码

```python
import sys

# 打印所有命令行参数
print("所有命令行参数：", sys.argv)
print("脚本名称：", sys.argv[0])

# 处理参数（如果有参数的话）
if len(sys.argv) > 1:
    print("传递的参数：", sys.argv[1:])
    # 示例：计算参数的和（假设参数是数字）
    try:
        nums = [int(arg) for arg in sys.argv[1:]]
        print("参数的和：", sum(nums))
    except ValueError:
        print("错误：请输入整数参数！")
else:
    print("提示：请在命令行传递参数，例如：python sys_argv.py 1 2 3")
```

#### 运行方式（命令行）

```bash
python sys_argv.py 10 20 30
```

#### 内容讲解

- `sys.argv` 的元素都是**字符串**，如果需要数字，要手动转换（如 `int()`/`float()`）。

- 一定要检查 `len(sys.argv)`，避免访问不存在的索引报错。

#### 应用场景

1. **脚本工具**：比如 `python converter.py input.jpg output.png`，传递输入输出文件路径。

2. **批量处理**：传递多个文件路径，脚本批量处理。

3. **配置开关**：传递 `--debug`/`--verbose` 等开关，控制脚本行为。

### 2. `sys.exit([status])` —— 程序退出（主动 “结束” 程序）

#### 核心知识点

`sys.exit()` 用于**主动退出 Python 程序**：

- `status=0`：表示程序**正常退出**（默认）；

- `status` 为非 0 整数（如 1）：表示程序**异常退出**，可被操作系统或其他脚本检测到。

- 也可以传字符串（如 `sys.exit(&#34;错误：参数不足&#34;)`），会先打印字符串，再以状态码 1 退出。

#### 示例代码

```python
import sys

def check_args():
    """检查命令行参数数量"""
    if len(sys.argv) < 2:
        # 方式1：传字符串，打印后退出
        sys.exit("错误：请至少传递一个参数！用法：python sys_exit.py <filename>")
    
    filename = sys.argv[1]
    if not filename.endswith(".txt"):
        # 方式2：传状态码，结合 print 使用
        print("错误：只支持 .txt 文件！")
        sys.exit(1)
    
    print("参数检查通过，文件名：", filename)

# 测试
check_args()
print("程序正常结束（这行不会在出错时执行）")
```

#### 内容讲解

- `sys.exit()` 会抛出 `SystemExit` 异常，如果在 `try-except` 中捕获了这个异常，程序不会退出（通常不建议捕获）。

- 对比 `quit()`/`exit()`：`sys.exit()` 更适合在**脚本 / 生产代码**中使用，`quit()`/`exit()` 主要用于交互式解释器。

#### 应用场景

1. **参数验证**：参数不对时主动退出，避免后续代码报错。

2. **错误处理**：遇到致命错误（如文件不存在、数据库连接失败）时退出程序。

3. **脚本返回值**：让其他程序（如 Shell 脚本）通过返回值判断是否成功。

### 3. `sys.path` —— 模块搜索路径（解决 `ModuleNotFoundError` 的 “钥匙”）

#### 核心知识点

当你 `import` 一个模块时，Python 会按 `sys.path` 中的**路径顺序**依次查找模块，找不到就报 `ModuleNotFoundError`。

- `sys.path` 是一个**列表**，可以动态修改（添加 / 删除路径）。

- 默认包含：当前脚本所在目录、Python 标准库路径、第三方库路径。

#### 示例代码

```python
import sys
from pathlib import Path

# 1. 打印当前模块搜索路径
print("===== 当前模块搜索路径 =====")
for i, path in enumerate(sys.path, 1):
    print(f"{i}. {path}")

# 2. 动态添加路径（解决模块导入问题）
# 假设我们有一个模块在 ../my_modules 目录下
module_dir = Path(__file__).parent.parent / "my_modules"
# 转为绝对路径，避免相对路径的问题
module_dir_abs = str(module_dir.resolve())

# 添加到 sys.path 的开头（优先查找）
if module_dir_abs not in sys.path:
    sys.path.insert(0, module_dir_abs)
    print(f"n已添加路径：{module_dir_abs}")

# 现在就可以 import my_modules 下的模块了（假设存在）
# import my_module
```

#### 内容讲解

- `sys.path.insert(0, path)`：把路径添加到**开头**，优先查找（避免同名模块冲突）。

- `sys.path` 的修改**只在当前 Python 进程有效**，退出程序后失效（永久修改需设置环境变量 `PYTHONPATH`）。

- 推荐用 `pathlib` 处理路径，避免 Windows/Linux 路径分隔符的问题。

#### 应用场景

1. **解决导入错误**：当模块不在默认路径中时，动态添加路径。

2. **项目结构管理**：比如项目有 `src/` 目录，把 `src/` 添加到 `sys.path`，方便导入。

3. **测试代码**：测试时添加源码目录，导入被测试的模块。

### 4. `sys.stdin` / `sys.stdout` / `sys.stderr` —— 标准输入 / 输出 / 错误流

#### 核心知识点

- `sys.stdin`：标准输入流（默认是键盘输入）；

- `sys.stdout`：标准输出流（默认是屏幕打印）；

- `sys.stderr`：标准错误流（默认是屏幕打印错误信息）。

- 这三个都是**文件对象**，可以重定向到文件（比如把日志写到文件里）。

#### 示例代码

```python
import sys

# ====================== 1. 标准输入：替代 input() ======================
print("请输入一行文字（sys.stdin）：")
# 读取一行（去掉末尾的换行符）
line = sys.stdin.readline().strip()
print("你输入的是：", line)

# ====================== 2. 标准输出：替代 print() ======================
sys.stdout.write("这是通过 sys.stdout 打印的文字n")  # 要手动加换行符

# ====================== 3. 重定向输出到文件 ======================
# 保存原来的 stdout（避免重定向后无法恢复）
original_stdout = sys.stdout

# 重定向到文件
with open("output.log", "w", encoding="utf-8") as f:
    sys.stdout = f
    print("这行文字会写到 output.log 里")
    print("这行也会")

# 恢复 stdout
sys.stdout = original_stdout
print("输出已恢复到屏幕")

# ====================== 4. 标准错误：打印错误信息 ======================
sys.stderr.write("这是一条错误信息（会显示在屏幕上，即使 stdout 被重定向）n")
```

#### 内容讲解

- `print()` 本质上就是调用 `sys.stdout.write()`，并自动加换行符。

- 重定向 `sys.stdout` 后，所有 `print()` 都会写到文件里，记得用完恢复！

- `sys.stderr` 通常用于打印错误信息，即使 `stdout` 被重定向到文件，错误信息也会显示在屏幕上。

#### 应用场景

1. **日志记录**：把程序的输出重定向到日志文件。

2. **管道处理**：配合 Shell 管道（如 `python script.py | grep error`）处理输出。

3. **交互式工具**：用 `sys.stdin` 读取用户输入，实现更灵活的交互。

### 5. 系统与解释器信息

#### 核心知识点

|属性 / 函数|说明|
|---|---|
|`sys.version`|Python 版本信息（字符串）|
|`sys.version_info`|Python 版本信息（命名元组，方便比较）|
|`sys.platform`|系统平台（如 `win32`/`linux`/`darwin`（macOS））|
|`sys.executable`|Python 解释器的可执行文件路径|
|`sys.getdefaultencoding()`|Python 默认编码（通常是 `utf-8`）|

#### 示例代码

```python
import sys

print("===== Python 解释器信息 =====")
print("版本字符串：", sys.version)
print("版本元组：", sys.version_info)
print(f"主版本：{sys.version_info.major}，次版本：{sys.version_info.minor}")

print("n===== 系统信息 =====")
print("平台：", sys.platform)
print("解释器路径：", sys.executable)
print("默认编码：", sys.getdefaultencoding())

# 示例：版本兼容性检查
if sys.version_info < (3, 8):
    sys.exit("错误：需要 Python 3.8 或更高版本！")
else:
    print("nPython 版本符合要求！")
```

#### 内容讲解

- `sys.version_info` 是命名元组，比较版本时用它更方便（如 `sys.version_info &gt;= (3, 8)`）。

- `sys.platform` 的值：Windows 是 `win32`，macOS 是 `darwin`，Linux 是 `linux`。

#### 应用场景

1. **兼容性检查**：确保程序在指定 Python 版本上运行。

2. **跨平台适配**：根据不同系统平台执行不同代码（如 Windows 用 ``，Linux 用 `/`）。

3. **调试信息**：打印解释器路径、版本，方便排查问题。

### 6. `sys.getsizeof(object)` —— 查看对象占用的内存大小

#### 核心知识点

`sys.getsizeof()` 返回对象占用的**字节数**（注意：只计算对象本身的大小，不计算对象引用的其他对象的大小）。

#### 示例代码

```python
import sys

# 查看基本类型的大小
print("int(1)：", sys.getsizeof(1), "字节")
print("str('hello')：", sys.getsizeof("hello"), "字节")
print("list([1,2,3])：", sys.getsizeof([1,2,3]), "字节")
print("dict({'a':1})：", sys.getsizeof({'a':1}), "字节")

# 查看大列表的大小
big_list = [i for i in range(10000)]
print("10000个元素的列表：", sys.getsizeof(big_list), "字节")
```

#### 内容讲解

- `sys.getsizeof()` 只计算 “容器” 本身的大小，比如列表的大小不包含列表里元素的大小（要计算总大小，需用 `pympler` 等第三方库）。

- 不同 Python 版本、不同系统平台，对象大小可能不同。

#### 应用场景

1. **性能优化**：查看对象大小，优化内存占用（比如用 `tuple` 替代 `list` 节省内存）。

2. **调试内存泄漏**：初步查看对象大小，定位内存占用大的对象。

### 7. `sys.getrecursionlimit()` / `sys.setrecursionlimit(limit)` —— 递归深度限制

#### 核心知识点

Python 为了防止栈溢出，默认限制递归深度（通常是 1000）。

- `sys.getrecursionlimit()`：获取当前递归深度限制；

- `sys.setrecursionlimit(limit)`：修改递归深度限制（⚠️ 谨慎使用！设太大会导致栈溢出崩溃）。

#### 示例代码

```python
import sys

print("当前递归深度限制：", sys.getrecursionlimit())

# 定义一个递归函数
def recursive_func(n):
    if n <= 0:
        return
    print(n)
    recursive_func(n-1)

# 测试递归（默认限制下，n=1000 会报错 RecursionError）
try:
    recursive_func(1000)
except RecursionError:
    print("n报错：RecursionError（递归深度超过限制）")

# 修改限制（谨慎！设为 2000）
sys.setrecursionlimit(2000)
print("n修改后的递归深度限制：", sys.getrecursionlimit())
# 现在可以递归到 1500 了
recursive_func(1500)
```

#### 内容讲解

- 默认递归深度通常是 1000，足够大多数场景使用。

- 如果遇到 `RecursionError`，优先考虑**用循环替代递归**，而不是修改限制（修改限制有风险）。

#### 应用场景

1. **递归算法**：比如深度优先搜索（DFS）、斐波那契数列递归实现（但更推荐循环）。

2. **特殊场景**：某些必须用递归且深度较大的场景（谨慎使用）。

## 第四部分：实战案例 —— 简易命令行系统信息工具

### 功能需求

结合 `sys.argv`、`sys.exit`、`sys.version`、`sys.platform`、`sys.path`，实现一个命令行工具：

1. 支持参数：

    - `--version`：打印 Python 版本信息；

    - `--platform`：打印系统平台；

    - `--path`：打印模块搜索路径；

    - `--all`：打印所有信息；

2. 没有参数或参数错误时，提示用法并退出。

### 完整实战代码

```python
import sys

class SystemInfoTool:
    def __init__(self):
        # 检查参数数量
        if len(sys.argv) < 2:
            self.show_usage()
            sys.exit(1)
        
        # 获取参数（sys.argv[1] 是第一个参数）
        self.arg = sys.argv[1]
        self.run()

    def show_usage(self):
        """显示用法"""
        print("===== 简易系统信息工具 =====")
        print("用法：python sys_tool.py <参数>")
        print("参数列表：")
        print("  --version   打印 Python 版本信息")
        print("  --platform  打印系统平台")
        print("  --path      打印模块搜索路径")
        print("  --all       打印所有信息")

    def print_version(self):
        """打印 Python 版本"""
        print("===== Python 版本 =====")
        print(sys.version)
        print(f"主版本：{sys.version_info.major}，次版本：{sys.version_info.minor}，微版本：{sys.version_info.micro}")

    def print_platform(self):
        """打印系统平台"""
        print("===== 系统平台 =====")
        print(sys.platform)
        if sys.platform == "win32":
            print("当前系统：Windows")
        elif sys.platform == "darwin":
            print("当前系统：macOS")
        elif sys.platform.startswith("linux"):
            print("当前系统：Linux")
        else:
            print("当前系统：其他")

    def print_path(self):
        """打印模块搜索路径"""
        print("===== 模块搜索路径 =====")
        for i, path in enumerate(sys.path, 1):
            print(f"{i}. {path}")

    def print_all(self):
        """打印所有信息"""
        self.print_version()
        print()
        self.print_platform()
        print()
        self.print_path()

    def run(self):
        """根据参数执行对应功能"""
        if self.arg == "--version":
            self.print_version()
        elif self.arg == "--platform":
            self.print_platform()
        elif self.arg == "--path":
            self.print_path()
        elif self.arg == "--all":
            self.print_all()
        else:
            print(f"错误：未知参数 '{self.arg}'")
            self.show_usage()
            sys.exit(1)

# ========== 运行工具 ==========
if __name__ == '__main__':
    SystemInfoTool()
```

### 运行方式（命令行）

```bash
# 打印版本
python sys_tool.py --version

# 打印平台
python sys_tool.py --platform

# 打印路径
python sys_tool.py --path

# 打印所有信息
python sys_tool.py --all

# 错误参数（会提示用法）
python sys_tool.py --wrong
```

### 代码讲解

1. **面向对象封装**：把工具功能封装在 `SystemInfoTool` 类里，结构清晰。

2. **参数处理**：在 `__init__` 中检查参数数量，根据 `sys.argv[1]` 执行对应功能。

3. **用法提示**：参数错误或无参数时，调用 `show_usage()` 提示用户。

4. **综合应用**：用到了 `sys.argv`、`sys.exit`、`sys.version`、`sys.platform`、`sys.path`，覆盖了本节课的核心知识点。

## 课程总结与避坑指南

### 核心知识点回顾

|功能|属性 / 函数|说明|
|---|---|---|
|命令行参数|`sys.argv`|列表，存储命令行参数（第一个是脚本名）|
|程序退出|`sys.exit([status])`|主动退出程序，0 = 成功，非 0 = 错误|
|模块路径|`sys.path`|列表，模块搜索路径，可动态修改|
|标准流|`sys.stdin/stdout/stderr`|标准输入 / 输出 / 错误流，可重定向|
|系统信息|`sys.version/platform`|Python 版本、系统平台|
|对象大小|`sys.getsizeof()`|查看对象占用的字节数|
|递归限制|`get/setrecursionlimit()`|获取 / 修改递归深度限制（谨慎使用）|

### 避坑指南

1. `sys.argv[0]` 是脚本名，不是第一个参数！

2. `sys.path` 的修改只在当前进程有效，永久修改需设 `PYTHONPATH`。

3. 重定向 `sys.stdout` 后记得恢复，否则后续 `print()` 不会显示在屏幕上。

4. 不要随意修改 `sys.setrecursionlimit()`，优先用循环替代递归。

5. `sys.getsizeof()` 只计算对象本身大小，不计算引用的对象。
