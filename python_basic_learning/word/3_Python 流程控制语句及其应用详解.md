# 3_Python 流程控制语句及其应用详解

你想系统了解Python中用于控制程序执行顺序的流程控制语句，以及每种语句的具体应用场景，这是编写有逻辑、能分支、可重复执行的代码的核心。

Python的流程控制语句主要分为**分支结构（条件判断）**、**循环结构**和**循环控制语句**三大类，下面结合语法、示例和实际应用场景详细说明：

## 一、分支结构（条件判断）

核心作用：根据不同的条件，执行不同的代码块，让程序“做选择”。

### 1. 基础if语句

**语法**：

```Python

if 条件表达式:
    满足条件时执行的代码块（注意缩进）
```

**应用场景**：仅在满足某个条件时执行特定逻辑，不满足则跳过。

**示例**：判断是否成年，仅成年时打印提示：

```Python

age = 18
if age >= 18:
    print("你已成年，可以独立操作！")  # 满足条件，执行该语句
```

### 2. if-else语句

**语法**：

```Python

if 条件表达式:
    满足条件时执行的代码块
else:
    不满足条件时执行的代码块
```

**应用场景**：二选一的逻辑（满足/不满足条件各执行不同操作）。

**示例**：判断成绩是否及格：

```Python

score = 59
if score >= 60:
    print("成绩及格")
else:
    print("成绩不及格，需要补考")  # 不满足条件，执行该语句
```

### 3. if-elif-else语句

**语法**：

```Python

if 条件1:
    满足条件1执行的代码块
elif 条件2:
    不满足条件1但满足条件2执行的代码块
...（可多个elif）
else:
    所有条件都不满足时执行的代码块
```

**应用场景**：多条件分支判断（如等级划分、场景匹配）。

**示例**：成绩等级评定：

```Python

score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")  # 满足该条件，执行
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 4. 三元表达式（简化版if-else）

**语法**：`结果1 if 条件 else 结果2`

**应用场景**：简单的二选一逻辑，简化代码（替代短小的if-else）。

**示例**：快速判断并赋值：

```Python

age = 17
status = "成年" if age >= 18 else "未成年"
print(status)  # 输出：未成年
```

## 二、循环结构

核心作用：让程序“重复做同一件事”，避免重复编写相同代码。

### 1. for循环

**语法**：

```Python

for 变量 in 可迭代对象（列表/字符串/range等）:
    每次循环执行的代码块
```

**核心特点**：遍历可迭代对象的每个元素，执行固定次数的循环。

**常见应用场景**：

- 遍历列表/字符串/字典等容器的元素；

- 执行固定次数的重复操作（结合`range()`）。

**示例1：遍历列表**（批量处理数据）：

```Python

fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(f"我喜欢吃{fruit}")  # 依次输出每个水果的语句
```

**示例2：固定次数循环**（打印1-5）：

```Python

for i in range(1, 6):  # range(1,6)生成1、2、3、4、5
    print(i)
```

### 2. while循环

**语法**：

```Python

while 条件表达式:
    条件满足时执行的代码块
    （需设置终止条件，避免死循环）
```

**核心特点**：只要条件为True就持续循环，适用于“不确定循环次数”的场景。

**常见应用场景**：

- 用户输入验证（直到输入合法为止）；

- 游戏循环（直到游戏结束）；

- 不确定次数的重复操作。

**示例1：用户输入验证**（直到输入数字为止）：

```Python

while True:
    num = input("请输入一个数字：")
    if num.isdigit():  # 判断是否为数字
        print(f"你输入的数字是：{num}")
        break  # 满足条件，终止循环
    else:
        print("输入错误，请重新输入！")
```

**示例2：简单计数器**（从1数到5）：

```Python

count = 1
while count <= 5:
    print(count)
    count += 1  # 关键：更新计数器，否则死循环
```

### 3. 嵌套循环

**语法**：循环内部嵌套另一个循环（for/while可互相嵌套）。

**应用场景**：处理二维数据（如矩阵、表格）、多层遍历（如打印九九乘法表）。

**示例：打印九九乘法表**：

```Python

for i in range(1, 10):
    for j in range(1, i+1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()  # 换行
```

## 三、循环控制语句

核心作用：调整循环的执行节奏（终止、跳过），或占位补全语法。

### 1. break语句

**作用**：立即终止**当前所在的循环**（嵌套循环中仅终止内层）。

**应用场景**：满足某个条件时，提前结束循环（如找到目标值后停止遍历）。

**示例**：遍历列表，找到“香蕉”后停止：

```Python

fruits = ["苹果", "香蕉", "橙子", "葡萄"]
for fruit in fruits:
    if fruit == "香蕉":
        print("找到目标水果：香蕉")
        break  # 终止循环，后续元素不再遍历
    print(f"当前遍历：{fruit}")
```

### 2. continue语句

**作用**：跳过**当前轮次**的剩余代码，直接进入下一轮循环。

**应用场景**：过滤掉不需要处理的元素（如跳过偶数、跳过空值）。

**示例**：打印1-10的奇数：

```Python

for i in range(1, 11):
    if i % 2 == 0:
        continue  # 跳过偶数，直接进入下一轮
    print(i)  # 仅打印奇数
```

### 3. pass语句

**作用**：空语句，仅作为语法占位符（无任何实际操作）。

**应用场景**：临时占位（如先定义分支/循环结构，后续补充代码）。

**示例**：临时定义if分支，暂不实现逻辑：

```Python

age = 20
if age >= 18:
    pass  # 暂不编写逻辑，避免语法错误
else:
    print("未成年")
```

## 四、综合实战示例（猜数字游戏）

结合分支+循环+循环控制，实现经典的猜数字小游戏：

```Python

import random

# 生成1-100的随机数
target_num = random.randint(1, 100)
print("欢迎来到猜数字游戏！")
print("我已经生成了1-100之间的随机数，请开始猜测～")

while True:
    # 获取用户输入并处理
    try:
        guess = int(input("请输入你猜测的数字："))
    except ValueError:
        print("请输入有效的整数！")
        continue
    
    # 条件判断
    if guess > target_num:
        print("猜大了，再试试！")
    elif guess < target_num:
        print("猜小了，再试试！")
    else:
        print(f"恭喜你，猜对了！数字就是{target_num}")
        break  # 猜对后终止游戏
```

### 总结

1. 流程控制语句核心分三类：**分支结构**（if/elif/else，做选择）、**循环结构**（for/while，做重复）、**循环控制**（break/continue/pass，调节奏）；

2. for循环适合“固定次数”遍历，while循环适合“不确定次数”的条件循环；

3. break终止当前循环，continue跳过当前轮次，pass仅作为语法占位符无实际功能。
