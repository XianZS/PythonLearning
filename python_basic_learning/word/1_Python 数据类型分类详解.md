# 1_Python 数据类型分类详解

你想清晰地了解Python中数据类型的具体分类，以及每种类型的核心特点和使用场景，这是掌握Python基础的关键一步。

Python的数据类型可以按照“是否能存储多个值”分为**基本数据类型（标量类型）** 和**组合数据类型（容器类型）** 两大类，下面为你详细拆解：

### 一、基本数据类型（标量类型）

这类类型只能存储单个值，是Python中最基础的“原子级”数据类型。

#### 1. 数值类型

- **整数（int）**

  - 定义：无小数部分的数字，正数、负数、0都属于整数

  - 示例：`age = 20`、`num = -5`、`zero = 0`

  - 特点：Python的int没有大小限制，可存储超大整数（如`10**100`）

- **浮点数（float）**

  - 定义：带小数的数字，也可通过科学计数法表示

  - 示例：`height = 1.75`、`weight = 60.5`、`sci_num = 3.14e2`（即314.0）

  - 特点：存在精度问题（如`0.1 + 0.2 ≠ 0.3`），需注意数值计算场景

- **复数（complex）**

  - 定义：由实部和虚部组成的数，格式为`a + bj`

  - 示例：`c = 3 + 4j`

  - 场景：主要用于科学计算、工程领域，新手日常使用较少

- **布尔值（bool）**

  - 定义：只有两个值：`True`（真）和`False`（假），本质是int的子类（`True=1`，`False=0`）

  - 示例：`is_adult = True`、`has_money = False`

  - 场景：主要用于条件判断（if/while语句）

#### 2. 字符串（str）

- 定义：由字符组成的不可变序列，用单引号`' '`、双引号`" "`或三引号`''' '''`/`""" """`包裹

- 示例：`name = "小明"`、`desc = '''多行字符串'''`、`empty_str = ""`

- 特点：不可变（定义后不能修改单个字符），支持拼接、切片、格式化等操作

- 场景：存储文本信息（名称、描述、内容等）

#### 3. 空类型（NoneType）

- 定义：只有一个值`None`，表示“空”“无”，不是0/空字符串/空列表

- 示例：`result = None`

- 场景：用于初始化变量、函数无返回值时的默认返回值等

### 二、组合数据类型（容器类型）

这类类型可以存储多个值（元素），是Python处理批量数据的核心。

#### 1. 列表（list）

- 定义：有序、可变、可重复的序列，用`[]`表示

- 示例：`nums = [1, 2, 3]`、`mix = [1, "a", True]`、`empty_list = []`

- 特点：可修改元素（增/删/改），支持索引、切片、嵌套

- 场景：存储有序的、需要频繁修改的批量数据（如用户列表、成绩列表）

#### 2. 元组（tuple）

- 定义：有序、不可变、可重复的序列，用`()`表示（单个元素需加逗号：`(1,)`）

- 示例：`point = (10, 20)`、`single = (5,)`、`empty_tuple = ()`

- 特点：不可修改元素，比列表更节省内存，支持索引、切片

- 场景：存储不可变的、有序的批量数据（如坐标、配置参数）

#### 3. 字典（dict）

- 定义：无序（Python 3.7+默认有序）、可变的键值对集合，用`{key: value}`表示

- 示例：`user = {"name": "小明", "age": 20}`、`empty_dict = {}`

- 特点：键（key）唯一且不可变 hash（字符串/数字/元组），值（value）可任意类型，支持快速查找

- 场景：存储有映射关系的数据（如用户信息、配置项）

#### 4. 集合（set）

- 定义：无序、可变、无重复元素的集合，用`{}`或`set()`表示（空集合必须用`set()`）

- 示例：`nums = {1, 2, 3}`、`empty_set = set()`

- 特点：自动去重，支持交集、并集、差集等集合运算

- 场景：去重、数据交集/并集判断（如两个列表的共同元素）

### 快速验证数据类型的方法

你可以用`type()`函数查看任意变量的类型，示例：

```Python

a = 10
print(type(a))  # <class 'int'>

b = [1, 2, 3]
print(type(b))  # <class 'list'>

c = None
print(type(c))  # <class 'NoneType'>
```

### 总结

1. Python数据类型核心分为**基本标量类型**（数值、字符串、None）和**组合容器类型**（列表、元组、字典、集合）；

2. 区分容器类型的关键维度：是否**有序**、是否**可变**、是否**允许重复元素**；

3. 布尔值是整数的子类，`None`是特殊的空值类型，与0/空字符串等有本质区别。
